# Q-RMEA 互补测量：固定验证 trace 诊断

本次仅验证固定数值干预路径。两例中，原始注意力与 logits 复现通过；互补项改变权重和 logits，但原本正确的两个预测均未改变，纠错和误伤均为零。两个样本属于同一目标类别，没有覆盖原模型错例。这不是任务效果或 L3 证据。

互补项的跨关系平均混合质量分别为36.52%和31.75%，最大 logit 改变量分别为0.7343和0.6813。变化并非恒等，但其有益性尚待验证。去相干 pair 对照也没有改变这两个预测；它是固定模型干预，不是独立训练的对照模型。

本次复用历史 seed29 所选模型生成的验证数值 trace，未重新加载模型推理或训练，未读取训练/测试特征。输入按原始固定样本选择与版本锁定归档哈希验证；原始 v1 数值 trace 和同例 v2 provenance 已交叉核对。CPU 诊断经共享调度器完成，退出0，执行源码与报告中的 source_revision 绑定。私有输入与逐例输出保留在项目私有工作区。

候选仍为低置信度探索项。已有代数审计表明该权重可分解为原始支持、rank-two 2-DPP degree 和 epsilon 底值的混合；构造样例也显示误伤及无关词稀释风险。文献新颖性、跨类别作用、独立训练收益和总体风险均未解决。经典可计算性不作为普通任务效用的否决条件。

下一步先冻结多类别验证诊断与最小恢复成本契约，再决定训练版实现。没有重跑历史 baseline，没有正式实验交付或自动多 seed。
