# Q-ECPA 私有案例阅读器

此入口从审计报告和私有原值目录按需读取数值，不把案例复制到公共静态站点。需要已有环境的 Python >=3.10、NumPy；不依赖 PyTorch，不训练、不上传、不提交 Git。

```bash
python scripts/serve_ecpa_case_reader.py \
  --report-dir /私有目录/审计报告 \
  --case-dir /私有目录/已校验解包的案例 \
  --port 4191
```

只监听 `127.0.0.1:4191`，浏览器打开该地址。远程使用时通过已授权 SSH 的本地端口转发访问；不要把监听改成公网地址。返回链接指向本项目门户 `127.0.0.1:4189`。

报告中的 `REPORT_COMPLETE.json` 必须列出并绑定 `case_study.json`、`run_manifest.json`、`run_config.json`。私有归档来自 `exchange_manifest.json` 中按序记录的分片，先验证每片大小/SHA256，拼接后验证归档大小/SHA256，再安全解包。`--case-dir` 指向包含 `jobs/` 的目录，不能把它放在 `research-web/` 内。

页面显示句子、token、指定实体及位置、正确关系和实际判断。各阶段输入输出按原 trace 引用衔接；模型权重是外部状态。矩阵使用末两维，向量使用末一维，其余维度可输入任意合法坐标；支持复数实部、虚部和模。每次读取校验原文件哈希，最多显示 32×32 矩阵或 128 个向量元素，显示精度为 7 位有效数字；原文件保持完整无损。

真实训练记录中的单案例 loss 与整逻辑批次梯度分别标注，不把它们解释为单样本完整因果链。重放梯度只用于诊断，不更新模型。没有可训练参数时，空梯度明确标为不适用。

`synthetic_canary` 明确显示合成验收边界，不作为正式指标或 L1 成果。此阅读器的验收不能补齐旧实验没有保存的状态，也不自动提高其他历史案例的完整性等级。

视觉系统：`research-editorial-v1`，复用门户原始 token 样式表。`theme.css` 仅做布局及可读性适配；弹窗使用本地系统无衬线字体，无外网字体依赖。
