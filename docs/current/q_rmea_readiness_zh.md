# Q-RMEA 前置检查：数据、共同特征基线与 GPU 执行

2026-10-26。本页记录开发检查结果，不是交给合作者执行的正式实验协议。

已完成数据和分词审计、7 项 GPU 单测、三种经典基线的小规模运行，以及故障后的仅导出恢复。Q-RMEA 量子方法尚未实现；数据适配于新研究的整体资格状态仍为 `insufficient`，未建立 L2/L3。

## 实际流程

输入是原句 token 和有顺序的主语、宾语跨度。关系标签只用于训练反馈和评估，文档编号、样本编号、实体类型均不进入模型。主语用 `@`、宾语用 `#` 标记，由锁定版本的 RoBERTa-large 提取冻结特征；同一原词的子词表示取均值，标记不参与词级池化。

三种经典头共享同一份词级特征、值投影、40 类解码器初始化、样本顺序和优化预算。B0 对有效词均匀加权；B1 为每种候选关系学习 softmax 词权重；B2 用归一化实向量内积的平方得到词权重。每个样本始终计算全部 40 类分数，不用真实关系选择池化分支，也没有额外分类残差绕过权重。

训练采用 40 类交叉熵，验证集 Macro-F1 选择 checkpoint。Macro-F1 固定对训练标签表的 40 类平均，缺失类的 F1 为零；排除 `no_relation` 的 benchmark micro-F1 与全标签 micro/accuracy 分开报告。

## 数据与输入边界

私有 JSONL 与历史 reference manifest 的 **source_sha256** 一致，未将 adapter 输出哈希当作原始输入哈希。原官方切分保持不变：train 58,465、valid 19,584、test 13,418，训练标签共 40 类；test 没有 `per:country_of_birth`。

全量检查未发现非法实体跨度、实体跨度重叠、同 split 重复输入或跨 split 重复样本 ID。发现 train/test 和 valid/test 各有一个相同“句子＋有序实体跨度”的输入，标签一致；还存在文档、句子及实体表面形式重叠。因此只能支持该官方固定切分上的表现评估，不能声称独立文档、独立实体或 OOD 泛化。完整计数见 [输入审计](../evidence/rmea/20261026-readiness/input-audit.json)。

全量仅分词检查的最大长度（含标记和特殊 token）为 train 336、valid 217、test 248；采用 512 上限且不截断时，原词和两个实体均保留。原先的 256 草案会截断部分训练输入，已放弃。见 [分词审计](../evidence/rmea/20261026-readiness/tokenization-audit.json)。

只复制已有获准访问的私有数据，不向 GitHub 发布原句、数据、预测或 checkpoint。数据原始访问及许可凭据仍需由数据持有人保留；本检查不授予再分发权。

## 固定小规模预算和结果

按 split 与稳定样本 ID 的哈希预先选择 train 2,048、valid 1,024，不按标签或结果筛选。seed 13，两轮、batch 128、AdamW 学习率 0.001、weight decay 0.01，每个条件 32 次更新。三个头使用同一份冻结特征；未读取 test 样本进行模型计算。

代码版本：`b04f728230d2f5cefa4ce05ea2d1747cb3b8eecc`。环境：Python 3.10.10、Torch 2.5.1+cu121、NumPy 1.26.4、Tesla P4。特征提取和三个头训练合计约 88.64 秒；不含下载、传输、排队和导出。

| 条件 | 初始验证交叉熵 | 第二轮验证交叉熵 | 按验证选定的 Macro-F1 | 选定的非空关系 micro-F1 |
| --- | ---: | ---: | ---: | ---: |
| B0 均匀池化 | 4.348214 | 1.922970 | 0.01795995 | 0 |
| B1 关系 softmax | 4.347909 | 1.895476 | 0.02090650 | 0.03418803 |
| B2 实向量平方重叠 | 4.355017 | 1.876120 | 0.02894379 | 0.16061185 |

多数类预测的验证 Macro-F1 为 0.01795995。B0 选定结果等于多数类预测，两个可学习权重头略高于该参考；这些短测分数不足以比较成熟模型优劣，也不能据此选 B2 为新 idea。三种条件均有有限梯度、验证损失下降；B1/B2 的 query、key 参数获得非零交叉熵梯度。共同初始化哈希一致，独立重算 13 份初始/逐轮/选定/多数类混淆矩阵的全部指标通过。

公开证据：[完整聚合结果](../evidence/rmea/20261026-readiness/pilot-result.json)、[独立审计](../evidence/rmea/20261026-readiness/pilot-audit.json)、[开发审查](../evidence/rmea/20261026-readiness/development-review.json)。参数量 B0 68,200，B1/B2 各 76,752；参数数目不代表有效容量相等。这些是新写的任务匹配对照，不是对已发表方法的忠实复现。

## 实际调度与故障恢复

使用已有共享控制器、已有 GPU 节点的项目授权和锁定源码运行；没有新增付费服务器。7 项单测验证掩码、归一化、均匀池化恒等式、共同初始化、梯度和评估约定。

小规模训练在 `features.npz`、`heads.pt`、`summary-private.json` 封存后，按预设故意在生成 `result.json` 前抛错。调度器确认失败进程组已经退出，随后独立 CPU 任务从同一封存目录执行 `--export-only`。导出结果与封存摘要字节一致，原三个文件的大小、SHA-256 和修改时间均未改变，原失败目录没有最终报告。未重训、未改白名单；恢复结果及任务身份见独立审计。

这证明本次私有同源产物的导出恢复路径可用，不证明通用不可信 manifest 导入、训练断点恢复、服务器丢失后的 COS 恢复或全部项目 GPU 就绪。大文件仍为私有本地产物，未获 COS 独立恢复认证。
