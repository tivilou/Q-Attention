# RTX 3060：15 个参考配置短测及 seed 13 全量时长粗估

实测设备：NVIDIA GeForce RTX 3060，12 GiB；单 GPU、逐个独占测试。代码提交：`a90ea2e6e95b82d0731d2b2a6fe031aec357462f`。
每个配置使用完整预训练权重、实际任务代码和真实抽样数据，完成 1 次预热及 2 次完整逻辑 batch 的计时更新。计时同步 CUDA，训练之外另测验证、测试和本地 checkpoint 保存。未运行完整实验。
短测发现并修正 LUKE CoRE/CFIE 验证调参的指标接口缺参：补传 `loss=None`，以验证集 F1 选系数。两项针对性行为测试通过；这两个配置使用修正后的代码重新测量。训练机制、loss、数据及预算未因该修正改变。
训练池 632 句（固定随机抽样加类型/关系覆盖），验证、测试各 128 句。数据全量为 train 58,465 / valid 19,584 / test 13,418。原始样本和权重仅存私有服务器，不随报告公开。

MetaEntail 的更新单位是展开后的 NLI 候选对，其余是句子。因此不同配置的 batch/s 不能直接比较。
Curriculum 包含 3 个 reviewer 和主模型。主模型课程比例取决于未来 reviewer 的预测，尚不可实测确定；表中按三等份课程给出中心估算，完整训练更新预算约 7,316–14,624，中心 10,970。
范围以中心估算的 0.75–1.5 倍做敏感性分析（Curriculum 同时考虑课程预算范围），不是统计置信区间，也不是完成时间保证。长句或进一步 OOM 降档可能超出此范围。

## 外推边界

- 两次计时更新不足以覆盖全部句长和输入类型；表中 micro 档位仅说明本次抽样通过，不保证全量运行不会再降档。
- 原生完整 case study 张量采集/序列化、HTTP 上传下载和 Git 导出推送未计时，因此整条一键流程还需额外时间。正式实验的完整证据记录未关闭。
- 权重已从授权 3080Ti 中转服务下载并核对固定 SHA256/大小；这次补齐权重的网络等待不计入每个模型的常规训练估算。
- Curriculum 的 reviewer 额外推理以及 LUKE CoRE/CFIE 的验证调参均纳入估算。MetaEntail 也计入当前 runner 的最终 train 分组推理。
- 本表测的是当前项目中的 15 个参考配置，不代表完成了 15 个原论文 SOTA 结果的严格复现；原有 fidelity 标记保持不变。
