## 最小可检查的形式

固定row-major向量化vec，d=8：

```
f0 = vec(rho0), e_r = vec(E_r)
L_t = (U_t tensor conjugate(U_t))/2
M_t = (I_(d*d) + U_t tensor conjugate(U_t))/2
P_(t-1) = M_(t-1) ... M_1       (empty product I)
S_(t+1) = M_n ... M_(t+1)       (empty product I)
g_rt = real[e_r^H S_(t+1) L_t P_(t-1) f0]
alpha_rt = g_rt/sum_words(g)
```

这只是原CPTP prefix/suffix公式的线性代数重写；早段A、晚段B的组合必须是B@A，不能因“结合”就交换顺序。40个类共享通道序列，终端仍是40个独立binary效果，不伪造一次40结果POVM。独立D和强C使用自己的原8×8转移、值/decoder与初始化，Gcov不变；不以Q精确回放代替C。

[成本未知] 简单倍增scan的Q稠密算术为O(B*N*logN*d^6)，每个超级算子栈O(B*N*d^4)，autograd还会保留多级激活。B4/N96/d8/complex64的一栈为12582912bytes=12MiB，**不是峰值显存证书**。它比逐词向量路径做更多算术，收益可能被完全抵消。当前没有实现、实际速度、GPU成本或小筛准入结果。
