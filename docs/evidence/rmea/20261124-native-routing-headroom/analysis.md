Q有99.114%的原错误、real12有99.935%的原错误保留逐输入、逐关系独立query的修复空间。全体样本分别为[1,31,58433,0]和[0,2,58463,0]，逐类全部计数见summary.json。32个Q障碍并非全部分类错误的主解释；不能将读出或固定key“表达不了”当成已证明的主要原因。

这不是共享模型的可达上限：放宽族为每条输入及每个关系单独选择query，知道gold后比较端点，也超出了实际有限电路查询族。它不区分共享参数冲突、参数化、电路覆盖、优化、数据支持或泛化。99.1%不是可部署收益或预期准确率，数值负间隔也不是严格实数不可行证书。不给新L3/T，不挽救三个已关闭完整配置。

## 数值与执行范围

- 任意simplex及保留EPS=1e-6的广义Rayleigh端点，均为标准数学工具。未做严格舍入外包络。
- 小型实/复/重复key/padding/EPS例子通过；固定首3条真实行独立NumPy/Cholesky与Torch谱结果最大差分别1.759e-13、7.185e-13。
- 原生FP32前向与FP64读出重构差分别6.454e-6、1.550e-5；直接检查原生logit在谱区间内，两个模型最大越界均0；自由query端点在simplex范围内的最大越界也为0。
- 最大广义特征对相对残差4.896e-14、5.324e-14；最大B条件数7.667e5、8.961e5只是总体最大值，可能受短序列秩亏/EPS支配，未保存其分布，不能据此宣称普遍病态或选定条件数为根因。
