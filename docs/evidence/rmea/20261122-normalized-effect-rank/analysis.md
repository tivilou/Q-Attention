# 归一化实体保护：纯态／混合态能力边界

本轮解决的是一个有限可达性问题，还没有建立新的任务效果或 L5 结论。原先固定两次校正的测试仍保留：32个样本中仅1个双向通过；没有修改它的步长、阈值或结果。历史限定 L4 与已完成全量结果也保持原样。

## 本轮认知

保护实际的实体注意力权重，只需要固定归一化后的权重。此前同时固定原始实体概率和总分母，增加了额外约束。新问题使用不同的可行集，单独提出并验证，不是把旧实验改成通过。

将纯态测量推广到密度矩阵后，归一化分式通过 Y=rho/Tr(B rho) 精确转为一个紧的半正定仿射切片。在复数 Hermitian 空间，极端最优解的秩满足 r²≤m+1；m为实体权重等式数（独立等式更少时可收紧）。因此 m≤2 时混合态最优值总可由某个不受电路限制的纯态达到。m=3时可以出现严格差距。它是存在性阈值，不是每个输入都出现优势的断言，也不是新的通用半正定秩定理。

对此前32个m=8..13的输入，定理只给出不受电路限制的最优解可取秩≤3；不保证秩2足够，更不保证同一组共享电路参数能同时实现各输入的最优解。

## 推进决定

这是值得保留的正向数学结果：在同样实体注意力约束下，纯态和混合态可以有有限的严格能力差距。它没有证明任何量子独占优势：混合态注意力也等价于分母加权的经典纯态头混合。

当前仅effect侧的三个态已在原始浅电路中实现。构造的token态及正交补仍是state-port实例，没有证明它们能由训练后的token prepare层或自然文本产生。逐样本逐关系的logit上界是oracle；它不是共享训练头，也不保证正确分类或更低CE。不能把历史Q-RMEA的L4效果移交给新混合态模块。
