1. **负eta接口。** 现有`measured_attention`拒绝eta<0，故v001建议的对称差分

   三点公式为二阶导数近似；有限步长误差和舍入误差仍需单独检查。
2. **效用错配。** 命题1–3只用于构造效用与最终readout效用相同的full/pinched。
   对`construction_utilities`错配分支，一般导数是
   `tr[A_readout L(A_construction)]/(N_construction D)`，没有平方型非负保证。
   这类错配不用于本轮平方恒等式检查，也不伪称被正性定理覆盖。
3. **原生对应。** 本地读取既有、R94冻结的
   `experiments/rmea_context_geometry/legacy/rmea.py`，SHA256
   `9f4bfc57a1a966c3383c1a2e82fe406ac3d115b653b062290fcf42d3c4683ee0`。
   第9行EPS=1e-6；第62–65行以`(|phi*psi|²+EPS)`在有效token上归一化并用同一u聚合。
   对单位态，`tr(E0 rho_t)=(|phi*psi_t|²+EPS)/(1+8 EPS)`，公共分母在token归一化中抵消。
   这是原生eta0的代数对应；后续数值检查仍必须使用真实原生forward。
   既有R94/R95对应验收保留，不将本次源码阅读写成新执行证据。
4. **单位态误差。** 理论使用精确单位态，接口容许2e-10绝对范数误差，不静默修复。
   后续诊断记录最大态范数偏差、`P²-P`与解析log/E0对应残差，使用前瞻容差。
   理想恒等式不自动等于所有容许浮点输入上的精确相等。
