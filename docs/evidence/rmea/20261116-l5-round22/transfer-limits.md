# 一般答案识别框架与原生线路约束

有限测量分类识别的基本表述已有直接原文覆盖。本轮没有形成新算法、理论创新或 L5；补充的是一个原生头可实现的解析反例，防止用错误的模型放宽方向制造采样下界。

## 1. 原文已有的框架

[Degenne 与 Koolen，1902.03475v1](https://arxiv.org/abs/1902.03475v1)，已核对精确版本，阅读 PDF pp1–8、16–17、19及28–29的选定内容。PDF p1 的 PMLR `vol XX` 是占位符，本轮没有认证正式出版版本。没有复现源代码或实验；未完整审查连续性、全部鞅集中和算法上界证明。

PDF pp2–4 允许均值模型集合 `M ⊆ O^K`、有限答案集 I 和任意指定的正确答案规则 `i*(mu)`。它并不只限于“找最大原始均值”。策略逐次选臂、接收该臂的新观测，停止后返回答案，并要求对 M 中每个模型满足声明的正确率。单参数指数族和独立新观测是模型边界；Bernoulli 是相应的内部参数特例。

对答案 i，其错误替代集合在 **M 内** 定义。Theorem1 的渐近信息复杂度包含答案选择、采样分配与错误替代之间的优化；sub-Gaussian 条件及 `delta→0` 渐近范围不能删掉。pp16–17 的极小极大讨论允许最优替代分布不取到时使用逼近序列，不能把存在精确有限支持最优解当成无条件数值算法。

pp5–8区分答案专属最优分配集合的凸性与多答案并集的非凸性。算法依赖求解分配/答案区域的子问题；统计渐近最优不是任意非线性模型的高效计算保证。Appendix F.1 的半空间闭式分配是**无约束高斯平方散度**的结果；不等于 Bernoulli 线路流形上的公式。关键下界与半空间公式已渲染核对。

## 2. 当前问题已能嵌入，嵌入不是创新

沿用 Round21 的固定输入、有效词集、已知 u 与 b：

\[
z_r(q)=b_r+\frac{\sum_t u_{rt}(q_{rt}+\epsilon)}{\sum_t(q_{rt}+\epsilon)},\qquad\epsilon=10^{-6}.
\]

如果**另外声明**测量专用接口，把每个(r,t)作为可取新 Bernoulli 样本的臂、把关系类别作为答案，并以 `argmax_r z_r(q)` 定义正确答案，已经属于原文的一般答案区域框架。可先限制唯一最大值实例，不能靠忽略边界把 tie 的终止性问题消掉。

因此，写出 `max_w inf_alternative sum w*KL`、调用 Track-and-Stop、加入分式阈值改写，均不足以构成本项目的新贡献。真实线路 q 共享输入状态/效应，M 必须反映拟研究执行模型允许变化的未知量；当前源代码的参数和8维状态已知，普通模拟不满足“未知均值只能采样”的信息前提。

## 3. 模型放宽的方向

固定当前 q、答案 i 和采样分配 w。若 `M_native ⊆ M_free`，错误替代集合也相应包含，故

\[
\inf_{\lambda\in\neg i_{free}}\sum_k w_k d(q_k,\lambda_k)
\le
\inf_{\lambda\in\neg i_{native}}\sum_k w_k d(q_k,\lambda_k).
\]

在非退化、同一答案规则下取最大分配并倒数后，自由模型的困难时间可以**更大**。所以自由立方体上的下界不能直接作为原生模型的下界。反过来，限制到原生集合中的真正困难子族，才可能给原生问题一个有效下界；本轮没有构造或宣称这样的正下界。

这只是已知的信息集合单调性。允许新测量基、共享测量、相关噪声或批量状态操作时，观测接口也变了，不能把逐臂 Bernoulli 统计下界当成任意量子策略下界。

## 4. 原生可实现的解析检查

这是一个**能力类中的退化反例**，不是实际训练 checkpoint 的事实，也没有执行模型或实验。

取两个有效词，`h_1=e_0,h_2=-e_0`，角色任意。令 `prepare.weight=0,prepare.bias=0`，两词的三比特状态均为 `|000>`。令值层第一输出读取 h 的第0坐标、其余权重和偏置为0；关系1解码器只读取该输出，于是 `u_1=(1,-1)`。关系2及其余38组解码器置0，偏置分别为 `b_1=0,b_2=1/4,b_3...b_40=-2`。这些维度和带偏置线性层都与不可变源对应。

关系1效应线路只在第一层第0线使用 `RY(theta)`，其他角为0，`0<theta<pi`。两层 CNOT 环只置换非零基矢并固定全零基矢，因此两词都有

\[
q_{11}=q_{12}=\cos^2(\theta/2)\in(0,1).
\]

其余关系可固定内部概率为1/2。`pi*tanh(effect)` 可实现上述角度，所需有限参数为 `atanh(theta/pi)`；没有把端点角无限参数偷偷包含进来。对这个对角概率族，含同一 epsilon 的两个权重严格为1/2，所以 `z_1=0,z_2=1/4`，其余分数-2。关系2对所有 theta 都是唯一答案；即便假想 theta 在测量接口中未知，也可以仅由已知结构返回关系2，零次测量。

若错误地允许(q11,q12)独立变化，则在当前(1/2,1/2)外引入(0.9,0.1)这一替代，得到 `z_1=0.8/(1+2e-6)>1/4`，答案改变。它不是上述共享状态/效应族的成员。要求算法同时对这个虚构扩大模型正确，当然会制造额外辨别工作；不能转嫁给原生族。这里用直接零测量论证，不在空替代集合上强行套用源文的非退化复杂度公式。

准备层碰撞与值层不同并不矛盾：两词 h 不同，而准备矩阵特意为0，值层依然区分它们。这避免了“相同 h 却凭空指定相反 u”的错误。原生线路/线性层映射已只读核对，但没有以此宣称真实模型普遍零测量、注意力无用或旧 L4 失效。

## 5. 当前结论与后续

关闭“只把非线性分类器嵌入一般采样框架就足够新”的路线。保留源文作为可用工具；没有否定真正利用线路结构的未来理论，也不以经典可模拟否定量子机制价值。

要继续有限测量线索，必须有自然执行需求，并给出超出该一般框架的原生约束求解、适当观测模型或可区分结果。目前没有这些证据，故它不作为下一实现。没有重跑 Round15 的已知均值估计/比值/间隔界，没有新模型、训练、正式实验、私有数组或 COS 访问。

下一步回到已测权重—值对齐这一核心：用只含已验证公式、L4范围和近邻/反例的包做一次候选盲的问题重构咨询，要求提出自然跨输入结构及竞争预测。按既有模型路由先检查可用传输，不把任何模型建议当证据；无合格问题则如实保留未解决状态。不能靠再换术语接受 L5。
