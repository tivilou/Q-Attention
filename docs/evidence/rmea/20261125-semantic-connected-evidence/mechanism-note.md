# 均值乘积对照意味着什么

这是对已实现公式的解释，不是新理论证书或重新指定的成功条件。

对关系r，令注意力均值为μ_r=Σ_t α_rt v_t。均值乘积对照的额外项为

    Σ_j β_rj μ_r,2j μ_r,2j+1 = μ_r^T B_r μ_r,

其中对称矩阵B_r仅在相邻通道(2j,2j+1)及其转置位置取β_rj/2，其余为0。
因此，它是对注意力池化后的特征做稀疏经典二次读出。展开为token双和后确有
跨token乘积，但这些乘积可完全由一个均值向量重建，并没有额外保留两个token的
独立身份、次序或量子相位。Q/G/D的区别仍在产生α的router；这个二次分类器本身
没有量子排他性。它表现好不能直接证明相干贡献，也不能证明经典router一定同样好。

中心化对照则为Σ_j β_rj(E_α[v_2j v_2j+1]−μ_2j μ_2j+1)。在α固定时，它对
所有token的共同value平移不变，而均值乘积不具有这一性质。这是已知协方差恒等式，
不是本项目的新T；更不能仅从此次成绩断言平移不变性造成性能变化。
