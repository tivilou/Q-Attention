# 固定原路由后的读出子问题

状态：诊断推导；尚未实现或审核新拟合。以下为已知线性代数、凸性和变量消去工具，不作新定理或L5主张。

## 精确函数分解

原RMEA的取值为 `v_t=P h_t+q`，其中P为64×1024；decoder为C，40×64；关系r的注意力alpha_rt非负且逐行和为1。当前科学源中alpha的计算不使用P、q或C。

因此

`z_r = Σ_t alpha_rt C_r(P h_t+q)+b_r = W_r bar_h_r + c_r`，

其中 `bar_h_r=Σ_t alpha_rt h_t`，`W=C P`，`c=C q+b`。即使每个关系具有不同池化特征，合并恒等式仍成立。浮点实现需实测误差，不以符号等式代替数值验收。

由于64≥40，任意40×1024的W都可由 `C=[I_40,0]`、P前40行为W表示；取q=0、b=c即可实现任意有效偏置。故固定路由时，原参数化没有限制W的矩阵秩。此结论不意味着原AdamW已找到最优W、泛化良好，或非线性取值没有潜在收益。

## 条件凸性

固定原注意力及输入后，每个样例的所有logit关于(W,c)均为线性函数。交叉熵为

`L=mean_i [logsumexp_r(z_ir)−z_iy_i]`。

其对任意扰动logit方向d_i的二阶型为 `mean_i Var_{r~softmax(z_i)}(d_ir)≥0`，因此固定路由读出子问题为凸问题。加正的二次正则可使该变量空间严格凸。原训练采用的因子化参数、AdamW以及对路由的同时更新，不等价于直接求解这个凸子问题；更不等价于某个未经核对的显式核范数优化。

梯度为 `dL/dW_r=mean_i[(p_ir−1[y_i=r])bar_h_ir]`，`dL/dc_r=mean_i[p_ir−1[y_i=r]]`。对未正则化的条件目标，若C满行秩，则 `dL/dP=C^T(dL/dW)`，从而 `||dL/dP||_F≥sigma_min(C)||dL/dW||_F`。有偏置及正则时应分别列项；不把总参数梯度直接当作这一未正则恒等式。

## 已运行的完整TRAIN诊断

在当前重建缓存TRAIN58,465条上，原完整Q与softmax头实际前向共116,930条，38.258秒、0更新。合并与原logit的最大误差分别8.094e-6与6.757e-6，对前一轮同缓存输出误差均0。实际C均满行秩40，条件数分别9.014与7.802。直接W梯度范数分别1.258988与0.985679，因子P梯度范数1.966156与1.453715。独立NumPy核对SVD、链式梯度、类别支持和旧CE，最大恒等式误差7.994e-14。不是第二次全梯度扫描。

梯度范数还存在一个重要坐标问题。记有效梯度为G、偏置梯度为g。若把所有池化特征平移为 `bar_h−mu`，并令新偏置为 `c+W mu`，函数不变；在固定新偏置的坐标下梯度变为 `G−g mu^T`。其最小F范数的平移为 `mu*=G^T g/(g^T g)`，因此原始梯度大部分可能只反映公共特征原点与偏置的耦合。

对已保存梯度进行这项解析描述：Q可移除99.985147%的平方范数，剩余范数0.015344；经典头可移除99.964922%，剩余0.018461。mu*利用了标签梯度，不是已测特征均值或新拟合规则。此结果限制了“大梯度意味着巨大特征学习余量”的解释；剩余非零也不构成可泛化收益或训练损失差距证书。详见同批geometry记录的gradient-decomposition.json。
