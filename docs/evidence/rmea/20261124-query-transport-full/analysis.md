## 实际做了什么

任务仍是Re-TACRED四十类关系分类。冻结编码器产生逐词特征；本轮先准备词态和每个关系的查询态，再让同一个实体摘要控制的酉电路作用于全部四十个查询；词态保持原路径，Born分数在有效词上归一化，然后汇聚另一路带正负号的分类值。原来是在查询角的tanh前加实体摘要，本轮在态准备后作共同酉输运。

三个新条件为Q、末端计算基去相干D、实电路输运。共用完整TRAIN58465、VALID19584、TEST13418，seed13、20epochs、batch128、FP32及原生AdamW；每路9140次更新，合计27420。按VALID全部40类Macro-F1严格选最好轮次、并列取最早，选中状态只评估一次TEST。原生五路与上轮条件查询五路完整结果直接复用，未重跑基线。十二对照资格规则在该插件执行前冻结。

三个新模型均注册81028个参数；相同注册参数数目不代表相同有效容量。实查询采用四层RY/CNOT，每次实电路12个CNOT，相对复电路6个更多；query执行base与context两次电路。完整公式和限制见protocol.md、theory-boundary.md。

## 本轮有意义的认知

[已测事实] 新Q相对原生Q的TEST增加1.0990个百分点，VALID下降1.1383个百分点，TEST CE增加.0213853。相对上轮条件Q，TEST下降1.5598个百分点、VALID增加.5133个百分点、TEST CE增加.0624356。因此两个split和CE都要保留，不能把单个正差称为稳定提升。

[已测事实] 新Q比自身D高11.1554个百分点，但新D本身降到.394760，低于原生D的.504768和上轮D的.467680。新Q也低于上轮Q。较大的同轮Q-D差距没有伴随新Q任务性能进一步提高，故它不是“idea更成功”或更强独立贡献的替代指标；三个条件仍是分别训练的模型，并非同权重相干干预。

[已测事实] 相对最强native/real12，新Q仅8类F1上升、28类下降、4类并列；相对原生Q为18升、19降、3并列。TEST正类误判为无关系为1276（最强经典1185），无关系误报正类为1048（经典850）。这些是同一总体上的计数，不是逐例修复/损害配对，也不说明唯一原因。

[已测事实] 训练日志末轮在线平均CE：新Q .204835、D .277454、实电路 .225356，原生Q .189442、原生real12 .165235。它们是训练期间的批次损失，不是selected checkpoint全TRAIN重评估，不能与VALID/TEST直接相减认定过拟合，更不授权追加epochs。

[机制解释] 共同酉精确保留查询Gram的设计已经通过插件技术检查，但固定完整效用没有改善。这关闭了“单靠此次共同酉输运即可修复上轮查询压缩并晋级”的具体方案；不是所有实体条件方法不可能，也不是从成绩反推没有保持Gram。此前较强softmax压缩词路由更多的实际诊断同样保留，几何分离并非已确立的任务收益代理。

[尚未证明] QKSAN已有query/key Born重叠，QGAT已有输入相关酉attention，CNM已有复词态/混合密度/可训练Born测量；量子metric learning也已有距离与特定线性损失的联系。当前归一化signed-value多类CE不自动满足该最优测量论证。来源、实际阅读范围、版本/身份及未读内容见nearby-reading.md、embedding-reading.md。这些近邻限制和已知守恒不是T验收；目前没有同核心独立L3或实质新理论。
