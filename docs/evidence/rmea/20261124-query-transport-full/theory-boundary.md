# 当前候选的理论边界：不是用Gram守恒申请T

固定一个输入。令Q_r=q_r q_r*、K_t=k_t k_t*，实体摘要产生所有关系共享的酉U(c)。实际量子分数是 tr[U Q_r U* K_t]，等价于 tr[Q_r U* K_t U]。因此“旋转关系查询”也可写成“反向旋转全部词态”；这是精确的共同坐标变换，不是额外算法优势。

共同酉保持query复Gram：q_r*U*Uq_s=q_r*q_s。它不保持与固定词态的重叠，更不保持按词归一化后的注意力行距离、交叉比或分类margin。实酉控制同样有这一守恒，不能以该恒等式区分量子与实控制。固定TRAIN128旧模型的query压缩与成绩并无单调关系，因此本方法的任务收益仍是尚待完整实验证伪的假设。

本实验的D是读出前的计算基去相干：score_D=tr[Delta(U Q_r U*) Delta(K_t)]，等价于tr[U Q_r U* Delta(K_t)]。它不等于去掉整个电路内的相位或相干：去相干之前的酉仍能把相位变成基概率。Q与D不同只限定在这个已声明的末端读出，不自动证明量子硬件必要性或排除经典复数计算。实电路、原生/条件化real12和softmax12仍是独立必要控制。

有限维经典表达也直接存在：把上述密度矩阵展开到Hermitian矩阵的64维实坐标，Born分数是这些坐标的欧氏内积。d=8的模拟不是硬件加速证明，不能把输入投影宽12误当作分数核的秩上限12，也不能在已有real12平方核至多78维展开面前主张简单秩优势。

已读近邻CNM（NAACL2019）已有复词态、混合密度、秩一可训练测量与实数消融；2509.11390v1已有输入相关酉的attention。当前“实体摘要共享输运40个关系query、相对固定词态按词Born归一化并读signed值”的组合与已核具体公式有区别，但近邻区别、正确恒等式、实现可运行和独立任务收益是不同问题。现阶段没有非平凡新定理、理论新颖性或L4-T结论。
