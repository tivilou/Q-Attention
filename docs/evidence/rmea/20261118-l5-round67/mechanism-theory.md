# R67：从既有结果构造角色保护的背景收缩假说

## 研究状态

本文件是原生 Q-RMEA 的一个未实现、未实验的路由修改假说，不是 L5 验收。既有限定 L4 不变，新方法不继承它。灵感来自项目自己的成功与失败记录，再以信号处理和自适应注意力原作检查碰撞；不是先找到论文再为它寻找应用。

## 1. 先排除一个坐标歧义

实际代码令 v_t=Vh_t+c，u_rt=d_r^T v_t，s_r=Σ_t α_rt u_rt+b_r；每个有效 α 行归一化，且路由不依赖 c 或 b。
对任意 δ∈R64，执行 c↦c+δ，b↦b−Dδ。所有输入的分类函数在精确算术下不变，而 u_rt↦u_rt+d_r^Tδ。
因此，未指定基准的正／负效用质量，以及 Σα|u|−|Σαu|，不是分类函数可识别的量。
例如 α=(1/2,1/2)，u=(-1,1)，b=0，原分数0、相消量1；整体加2并把b减2后，u=(1,3)，分数仍0、相消量0。
这只是普通代数，不是新理论，也不否定固定已声明坐标中的路径分析。中心化效用、两词效用差、两组归一化注意力的读出差是平移不变的；R66 的固定方差探针仍按其负结果关闭，不因中心化而重开。

## 2. 操作定义

状态维度 d=8，原始单位 token 态 ψ_t 与关系纯效应 φ_r 不变。对两个实体角色组分别求平均密度矩阵 R_j，其最高特征值的完整特征子空间为 E_j；P 为两个子空间张成空间的正交投影，Q=I−P。
只对有效、非实体上下文词构造 C=mean_t ψ_tψ_t†，令 K=QCQ，F=(I+dK)^−1。
缺任一角色组或没有有效上下文时采用 F=I，并记录回退。P=I 时也退化为恒等。最高特征值接近重数时会不稳定；数值聚类阈值尚未冻结，本文没有承诺已经实现。
关系效应改为 w_r=Fφ_r/||Fφ_r||，注意力继续使用 (|w_r†ψ_t|²+ε) 的词间归一化，ε=10^-6；有符号值聚合和分类偏置保持原样。
这会改变原先输入无关的效应，是新模型定义，不是对原模型等价重写。

## 3. 可证明的保护与限制

以下都是已知谱／扰动工具的组合，只用来核对机制，不作为已经具有新颖性的定理。

### 3.1 定义存在且收缩有界

C⪰0、Tr(C)=1，所以0⪯K⪯I。F 的特征值在[1/(1+d),1]，FP=P，且对单位φ有 ν=||Fφ||²∈[(1+d)^−2,1]。
因此效应归一化总存在。对 s∈range(P)，s†Fφ=s†φ；归一化后的受保护 Born 分数不会降低，但其最终注意力仍依赖其他所有词。

### 3.2 相对路由界必须包含 ε

令 N 为 K 在 Q 内特征值至少μ>0的某个谱子空间，Π_N 为其投影。对单位 n∈N 与单位 s∈P，记 a=|s†φ|²>0，B=||Π_N Qφ||²。
谱收缩与 Cauchy–Schwarz 给出 |n†Fφ|²≤B/(1+dμ)²，而 |s†Fφ|²=a。
对同一关系两个有效词，注意力分母相消，正确的实现级比值为

    α'_n/α'_s = (|n†Fφ|²+εν)/(a+εν)
              ≤ [B/(1+dμ)²+εν]/[a+εν]。

只在 ε=0 时才能直接去掉 εν。此界不保证任意混合态 token 的单独响应都会下降，也不保证分类收益。F 改变效应方向；如果 Fφ 只是 φ 的标量倍数，归一化后整个路由完全不变。

### 3.3 条件稳定性不能省略估计器变化

比较两个由算法产生的 (P,C) 与 (P~,C~)，二者均满足上述投影、PSD与范数约束。设 η_P=||P−P~||、η_C=||C−C~||。
逐项展开 QCQ−Q~C~Q~ 得 ||K−K~||≤2η_P+η_C；逆矩阵恒等式给 ||F−F~||≤d(2η_P+η_C)。
对固定同一单位φ，归一化向量差满足 ||w−w~||≤min(2,2d(1+d)(2η_P+η_C))。
这比较的是同一待评估 token 态与效应在两个估计器下的响应；若 token 态本身也变了，另有其变化项，不能省略。
若 Δ=min(1,2||w−w~||) 界住每个固定 token 的 Born 分数变化、有效词数为T、两个原始注意力分母为Z,Z~，则

    ||α'−α'~||_1 ≤ min(2,2TΔ/min(Z,Z~))。

固定效用的范围 U_r=max_t u_rt−min_t u_rt，因两行注意力和相同，

    |s'_r−s'~_r| ≤ (U_r/2)||α'_r−α'~_r||_1。

若当前赢家k对每个j的分数间隔大于相应两个读出变化界之和，则分类动作保持。它是条件稳定性证书，不是性能提升保证；全局只用ε作分母下界可能极松。实体密度矩阵的最高特征值接近重数时，η_P可能很大；尚未证明文本扰动下该估计器稳定。

## 4. 必须保留的反例

取正交基e1,e2，P=e1e1†，所有上下文态为e2，φ=(e1+e2)/sqrt2。则Fφ=(e1+e2/9)/sqrt2。
若实体 token 效用为0，而真正决定关系的上下文e2具有足够大的正效用，过滤会减少必要上下文的注意力，使本来正确的正类变为空类。
这个构造满足全部操作定义：频繁且不在角色代表子空间内，不等于背景噪声。
反之，如该方向真的只产生有害竞争，它可能值得抑制；其语义性质是待验证前提，不能由协方差频率自行证明。

## 5. 原作碰撞和缺失贡献

ABIC-MVDR原文为语音增强独立估计目标和噪声SCM；其Eq5不是本文的角色投影公式。DAMCHA原文以输入生成跨头度量，Eq4–8对行和度量产生的分数做softmax；原作明确不要求该度量正定。
它们分别说明，协方差背景抑制、输入相关注意力几何已经存在。PGM／frame whitening和受约束子空间滤波的已知数学也不能重新命名为量子创新。
尚缺的是：角色几何何时能保护真正关系证据，同时把可移除背景留在外部；以及这一规则相对一般白化、匹配实数头和完整分数变换究竟带来什么可重复的差别。
这需要同一机制上的有界诊断、必要的新训练与独立验证，而不是用上面的初等界直接宣布L5。
