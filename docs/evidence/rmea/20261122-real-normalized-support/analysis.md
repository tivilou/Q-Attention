显式协议唯一正例：保持各mention归一化注意力及context总质量，原始无bias logit为6.1029257300，构造两端为6.1694276960与6.1708529831。因此这三个可行点给出的可达区间宽度下界是0.0679272531；两构造端点的差只有0.0014252871，须区分这两个数字。mention误差不超过1.12e-16，context质量误差不超过2.23e-16；配对效用差的理论预测误差1.55e-15。该例证明真实词态输入上存在有限密度效应移动，不证明任务正确率提高、纯态参数线路可达或共享训练头可实现。

显式中心构造CPU中位时间0.006145秒/单样本单关系，最大0.010250秒；没有测量完整batch×40关系的训练速度，不能当作GPU加速。已知答案的简单SDP得到0.12500000000018757（真值1/8），误差1.88e-13；这只排除了该简单问题上的库故障，未解释复杂约束的数值失败。
