# 序列长度无关界与低维核回归率均有原始近邻，不能直接解释当前增益

本轮选读两篇精确官方原文：Trauger/Tewari《Sequence Length Independent Norm-Based Generalization Bounds for Transformers》arxiv:2310.13088v1，以及Conn/Li《An Oracle Property of The Nadaraya-Watson Kernel Estimator for High Dimensional Nonparametric Regression》arxiv:1711.09200v1。PDF/版本/解析身份已核对，实际页码、图像和未读部分见reading-receipts.json；没有独立证明审稿或实验复现。

## 序列长度不出现，并不是新的注意力理论目标

第一篇第4、6–7页定义带CLS标量输出的softmax Transformer；定理4.1及推论4.1.1在明确输入、score、value和readout范数预算下得到不显含序列长度T的复杂度界。第14–15页证明使用softmax的Lipschitz性质、线性变换覆盖数及Dudley积分。这里的训练样本是完整序列，并不要求一条序列内的词独立。

当前Q-RMEA对有效词有alpha_rt=(q_rt+EPS)/sum_t(q_rt+EPS)，EPS=1e-6，精确数学中q为Born重叠且0<=q<=1。于是固定有效集合上

alpha_r=softmax_t(log(q_rt+EPS))，
max_t log(q_rt+EPS)-min_t log(q_rt+EPS)<=log((1+EPS)/EPS)。

这是归一化的标准恒等式，没有运行新的数值模型。它不把完整Q-RMEA变成原文的双线性score类：当前log Born重叠还依赖公共非线性准备、电路和关系效应。要迁移界，仍需证明完整score类的覆盖、输入和值/decoder/bias的范数预算及多类损失桥接。也没有因为有限核特征或类别固定，就自动得到比匹配控制更紧的界。仅证明一个不含T的宽泛上界，既有先例，也没有解释现有Macro和局部对齐增益。

## 低维率依赖真实任务结构，不是状态维数

第二篇第1–9页使用n个独立观测(X_i,Y_i)、平方损失、Gaussian核和半正定逆带宽矩阵，通过K折交叉验证选择模型。定理2.2的低维率进一步假定真实回归函数psi(X)=phi(TX)，T是m行正交投影、phi为Lipschitz；它不是说只要内部表示较小，就能假定任务真值低维。

当前求和对象是一条文本中的上下文化词，value是学习到的带符号utility，关系查询也经训练得到；它们不是原文中的独立观测响应Y_i。当前训练用联合多类交叉熵、评估Macro，也没有按该K折平方风险方案挑Gaussian带宽。三量子比特既没有证明真实任务是3维multi-index，也没有封住独立value路径。因此不能把原文样本率直接换成当前词数或训练文本数。

原文定理2.1允许有明确gamma误差的近似CV最优点，并非只能谈完全精确优化；但定理2.2使用全局CV最小点。第9页Remark5实用算法只称取得可接受的局部最小点，不能自动把它认证为gamma=0。我们没有把原文理论承诺或局部优化实验等同。
