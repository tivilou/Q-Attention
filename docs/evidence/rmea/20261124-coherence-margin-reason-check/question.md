# 下一项可反驳问题：相干贡献的竞争 margin 可靠性

## 已有问题证据

完整模型TRAIN回放Q有867条三个非均匀对照都能答对的错误，其中754条涉及正关系/无关系边界，但两种方向都有，统一偏置不成立。Q也独有答对295条。同Q权重关闭内部相干，修复974条（其中838条无关系误触发），损害5467条（5149条gold正关系）。不允许只报974条而隐藏损害，或把oracle当可部署规则。

## 尚未选择的候选训练假设

令Q和D为同一参数状态的完整/内部去相干前向，margin `m_yr=z_y-z_r`。研究对相干增量`Delta_yr=m_yr^Q-m_yr^D`的训练约束能否减少无关系误触发，同时保持正确正关系识别。

这不是统一降低null分数，也不是改变native推断读出。仍然输出完整独立Q头，去相干参考仅用于训练诊断/损失。实现前必须解决：

1. 防止联合训练把D分支故意弄坏以满足`Delta>=0`，避免只是让两个分支共同抄近路。比较stop-gradient参考、固定参考与约束含义；不能一开始就随意选lambda。
2. 使用相同输入/预算/监督的real12 cross-term去除参考和同规则loss作公平经典对照；原Q、原dephased、softmax12等稳定对照保留。不能把“Q能使用cross-term”误认作量子独占。
3. 该margin形式是已知监督约束工具，不能直接宣称非平凡理论或T通过。阅读counterfactual regularization、right-for-right-reasons和量子coherence/diagonal-regularization近邻后，先判断是否存在有用区别。
4. 冻结一次可反驳的matched试验，再执行；不得依据结果追lambda、种子、训练预算或筛选正向类别。小规模TRAIN筛选只是规划，不替代L3完整实验。

若上述问题没有合理解，不为形式漂亮硬上GPU，另想与已观察错误对应的方法。当前没有新插件、更新或正式实验；L3与L4-T均未通过。
