# 后继同词出现位置测试：先修正输入认识，尚未运行

直接相位读出的负结果、数值检查和停止结论保持不变。后继专家建议是“同一个词、同样角色的两个出现位置之间，关系相关的权重分配是否帮助正确判断”，尚无实验结果。

源码核对发现，原模型按**原始词**而非 wordpiece 分配注意力；四个角色坐标中，前两个是裁剪到 [-1,1] 的实体相对距离，后两个才是主语／宾语成员标记。因此保留已声明的完整四坐标 key 时，可匹配位置只在相对距离饱和区出现，不能把它悄悄替换成仅两个角色标记。

只读检查中，8,192 条 TRAIN 有 938 条、19,584 条 VALID 有 1,598 条存在任意相同四坐标的位置；这只是加入“词相同”和 TRAIN 支持数条件前的上界，不是实际测试覆盖率，更不是门槛已通过或已失败。原定至少 1,000 条有效 VALID、250 条正类的门槛保持。

恢复后的缓存仅给每个 split 的前两例保留完整原词，其余只有样本 ID 哈希和词数。下一步先从已授权的现有 owner／COS 数据找回精确 TRAIN／VALID 原词元数据，校验源哈希和缓存顺序对应，再计算预定 key 的支持范围。无需重建词表示或重训，也不因缺词信息而把该科学假设判负。
