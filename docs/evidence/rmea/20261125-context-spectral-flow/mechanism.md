# 保持总测量质量的上下文谱流：机制假设及边界

## 为什么试这个，而不是重开上一轮

五路完整印证门控没有胜过最强经典对照；同一已学checkpoint的TRAIN开关诊断又说明该门并非无作用。这两点一起保留。当前没有证据定位其泛化失败的唯一原因。新问题改为：能否让上下文改变每个关系选择哪些词，同时不改变该关系的总Born质量，避免把两者的变化混在同一次干预里。不是说守恒本身改善分类。

## 精确构造与推导

令X的列为n个有效词的8维纯态，S=XX†/n，U(t)=exp(-itS)，q为一个原关系态。
测量p_i(t)=|psi_i†U(t)q|²，实际权重为(p_i+eps)/(sum_j p_j+n eps)。
因为U†SU=S，总质量D=n q†S q+n eps与t无关。
反过来，一个酉变换对所有向量q都保留q†S q，当且仅当U†SU=S（等价于U与S对易）。这里是所有q的陈述，不能由仅40个native query的检验推出必要性。

固定第r类的signed utility u_ri，令V_r=sum_i u_ri rho_i，则
z_r(t)-bias_r=[q_r† U†V_rU q_r+eps sum_i u_ri]/D_r。
其导数为 i q_r†U†[S,V_r]U q_r/D_r；若[S,V_r]=0则整个轨迹恒定。
因此保持总质量并不保证gold-v-max-rival margin提高；对手也会移动。要解释实际分类，必须看全部40类，而不是仅gold分数。
绝对变化可由 |t|*||[S,V_r]||op/D_r 上界，但该上界不是性能收益下界。

G=X†X/n满足X† exp(-itS)=exp(-itG)X†。所以同一方法也可精确解释为词位置Gram上的相干传播，并可在8维空间计算；不声称8维模拟具有量子加速。

## 可区分但不独占的预测

- 相同参数、相同输入下，原Born分母和流后分母相同，包含真实每词EPS。
- 全部词态相同，或全部互相正交时，所有rho_i与S对易，因此固定读出不变。部分重叠本身仍不保证收益。
- 若keys和query都为实数，t=0的一阶响应为零；有限t仍可能改变概率。因此real12_flow不是“完全去相干”。
- 改变S通常改变各关系的词选择，不像共享标量gate的无EPS交比不变量；但这个结构差异不是任务效用或新颖性证明。

## 已有研究与适用性

Lloyd/Mohseni/Rebentrost的[Quantum principal component analysis](https://arxiv.org/abs/1307.0401v2)，实际阅读PDF第2–3页式1和Gram/访问假设，已明确使用密度矩阵产生exp(-i rho t)。本项目显式模拟小矩阵，不继承其量子输入oracle、qRAM、复杂度或分类保证。
谱函数、矩阵指数交织、Ehrenfest对易子和守恒量是已知工具。以上推导用于设计可证伪的小实验，不提交为L4-T理论。

原PGM是实谱幅度滤波/词POVM重构；此前实体酉输运用prepare(entity-summary)生成线路。本候选按所有词的经验密度生成谱相位，并有额外的分母守恒条件。这个差别足以区分实验配置，不等于近邻新颖性清场，更不开放旧配置的参数救援。

96组NumPy合成态检查通过（见algebra-verification.json），utility变化有正有负。没有任务数据或训练收益。新插件只进入固定8192/4096单seed筛选；完整研究与独立L3/T仍未启动和未接受。
