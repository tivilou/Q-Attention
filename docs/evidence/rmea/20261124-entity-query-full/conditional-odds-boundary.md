# 条件化能改变什么：一个明确的对照边界

这是当前实现的代数分析和合成参数见证，不是新颖性证明、自然语言可达性证据或L4-T理论验收。它不改变运行中的模型或完整效用门。

设两个关系r、s与两个非实体词t、u，定义注意力交叉对数比

`I = log(alpha[r,t]) + log(alpha[s,u]) - log(alpha[r,u]) - log(alpha[s,t])`。

每个关系的词归一化常数在此相消。对本轮参数共享softmax条件，分数是 `(q_r + k(c)) dot k_t / sqrt(12)`；额外锚项仅依赖词和c。因此当这两个词的key保持不变时，I严格不随c改变。该式就是乘法行/列因子消去的已知性质，不是新的数学发现。

这不限制其分类器不能利用实体信息，也不说明它一定较弱：其他词、归一化和value均参与最终logit。这里只说明这个特定路由统计量的性质。

本轮原Q电路存在不同的合成实例：投影仅使用第二层wire0的RY参数（展开坐标6），其余投影和effect坐标为0。第一层保持零态，最后共同CNOT只置换输出；两个态的Born重叠为 `cos²[(pi*tanh(e_r+c)-pi*tanh(x_t))/2]`。令两个实体的h[0]都等于c，便能改变anchor，同时保持两个非实体词的h[0]不变。其他角色维投影为0。

用 `e=(.2,-.3)`、非实体词坐标 `x=(.1,.8)`、c从0变.4，并保留实现的1e-6，I从−4.34239378变−1.39191022。数值见conditional-odds-witness.json，未加载模型/语料、未拟合。

但这项能力不是相干独有：本轮D在同一RY实例中I也变化；real12只需两个非零坐标就能变化。real12具体共享线性映射可取 `key(x)=(1,x,0,...)`、固定query `(0,e_r,0,...)`，加同一key(anchor)后就是 `(1,e_r+c,0,...)`，符合当前参数共享约定。四层实RY电路也能在对应单坐标实例中复现相同的cos²重叠，后续共同置换不改变内积。

因此，未来即使看到Q改变了这种交叉比，或优于当前softmax条件，也不能直接归因为量子/复相位创新。真正的区分预测必须继续面对D、real12和实电路，以及全部效用结果。该边界没有给当前完整实验增加选优指标、子群或救援条件。
