# 本轮问题、对照与理论边界

本轮检验实体对显式条件化是否有任务效用，不预先认定固定查询是错误根因。当前冻结表示 h 已包含主客体标记；新的 anchor 是额外共享路径，没有新增信息源或参数。

令 k_t=W x_t+b、c 为主客体均值的平均。softmax12 新分数为 (q_r+k(c))·k_t/√12。故条件化严格等价于在原关系分布上乘以输入相关、所有关系共享的词先验 exp(k(c)·k_t/√12)，再归一化。这是已知代数，不是理论创新，也不是“不公平地让经典控制失效”：它是同一参数共享方式在原 softmax 族中的精确实现。

real12 用 normalize(q_r+k(c)) 与 normalize(k_t) 的平方内积。它可以产生关系与 anchor 的交互，不能把任何交互现象归因于复数。实电路也使用同一 anchor/12个投影坐标，四层RY及12个CNOT，对照相对原复电路多6个CNOT的事实必须披露。

Q/D 使用同一 Wc+b 加入 effect 的 tanh 前。Q是40个独立二元Born测量；不是40结果联合POVM。由于 tanh 以及非交换门，新增的共享平移一般不等价于对 key/query 共同施加同一个幺正变换，因此本方法没有自动的共同幺正不变性或相对相位协变性保证。不得借用上一轮对潜在相位的恒等式作为当前文本层定理。

新增路径的梯度包含实体锚项，因而即使Q超过自身D，也可能仅反映一般条件查询的任务收益。先与同输入经典、实电路及未条件化原Q比较；第一seed通过仍只是资格实验。若Q未赢任一预声明对照，关闭此固定方法，不用可视化、稀有类优势、其他指标或新种子替代。

近邻表述校正：已有原文记录中，NAV/MNAV是学习单个或多个NOTA向量，不能概括成“已实现当前条件查询”。ATLOP的Localized Context Pooling利用主客体注意力的乘积建立实体对局部上下文，另有输入相关TH与专用损失。它们说明若干相关问题/组件已有研究，并不等同当前参数共享公式，也不为当前组合自动提供新颖性。来源和实际阅读范围见 `null-class-heterogeneity-20261124/reading.md` 与 `qattn-l5-round62-20261118/atlop-reading-receipt.json`；ATLOP原文 https://arxiv.org/abs/2010.11304v3 ，NAV/MNAV原文 https://arxiv.org/abs/2104.08481v1 。本记录不声称完成新的邻域检索或理论审核。

真正L4-T仍需：先从完整、独立确认的同核心效用获得L3，再提出且审核实质近邻区别、非平凡正确理论、可区分预测及其实现和独立实证。本轮没有预先接受该理论路线。
## 有条件的后续诊断，不是理论创新

令`z=prepare(anchor)`为12维投影锚点，本轮查询角是 `pi*tanh(e_r+z)`。令每个坐标 `B_j=max_r |e_rj|`，
`m_j=max(|z_j|-B_j,0)`。均值定理直接给出
`|theta_rj-theta_sj| <= pi*sech(m_j)^2*|e_rj-e_sj|`。
逐门差的望远镜和RY/RZ的导数范数1/2进一步给出纯查询投影的迹距离
`D=||P_r-P_s||_1/2 <= eta=min(1, sum_j |theta_rj-theta_sj|/2)`，并控制同一词上的Born概率差；eta不是态向量欧氏距离的截断上界。
去相干读出也是一个0到I之间的对角效应，故有同一上界；实RY电路也受逐门上界控制。

这些都是已知微积分/算子范数性质，不是L4-T结果。大锚点可能压缩关系查询的差异是一个条件性预测，尚未在本轮实际checkpoint中测量。归一化可放大微小概率差：若n个有效词、Z为加EPS后的行和，注意力L1差至多`min(2,2*n*eta/max(Z_r,Z_s))`，因此原始态接近也不自动等于注意力相同。即使注意力相同，关系decoder仍不同；不能由此推出分类失败。

若完整效用门失败，可在原门关闭后，以全部40类、固定TRAIN前缀和原selected checkpoint只测量一次锚点大小/态距离/路由距离，区分“存在压缩”与“仅猜测压缩”；不换种子、不重新训练、不根据诊断挽救本配置。也不能仅凭共同幺正变换保持query Gram这一恒等式，宣称另一个方法保持归一化注意力或有理论创新。
