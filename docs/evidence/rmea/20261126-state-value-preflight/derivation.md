# 同一词态的注意力和值：四种读出的边界

只讨论固定词态和固定可观测量的代数。令有效词数 T>0，ρ_t 为密度矩阵，E=|φ⟩⟨φ| 为迹一秩一类效应，V=V† 且 ||V||op≤R。定义 p_t=Tr(Eρ_t)，ε=10^-6，Z=Σ_t(p_t+ε)，α_t=(p_t+ε)/Z。省略各式共同的类 bias。它们可逐类使用，不要求40个 E 构成联合 POVM。

## A：先秩一投影，再读 value

当 p_t>0，Eρ_tE=p_tE，所以条件态为 E，u_t=Tr(VE)，与词态无关。于是 Σ_t α_tu_t=Tr(VE)。若 p_t=0，该物理条件事件未发生；用 EPS 补概率不构造新的投影条件态。将同一常数延拓过去仍然是常数。该配置因失去输入依赖而未通过关系注意力主路径资格。这不推及所有 sequential/back-action 方法。

## B：未正则化弱值与原生 EPS 的不相消项

在 p_t>0 定义 n_t=Re Tr(EVρ_t)，w_t=n_t/p_t。原生池化给出

`z_B=[Σ_t n_t + εΣ_t n_t/p_t] / Z`。

第二项没有相消。取 E=|0⟩⟨0|、V=X，另加一个 ρ_anchor=|0⟩⟨0| 的词，anchor 的 p=1,n=0。取

`|ψ_t⟩=(2t|0⟩+(1−t²)|1⟩)/(1+t²)`，t>0。

则 p=4t²/(1+t²)²，n=2t(1−t²)/(1+t²)²，w=(1−t²)/(2t)。因此 z_B=(p+ε)w/(1+p+2ε) 随 t→0 以 ε/[2t(1+2ε)] 发散。相同 anchor 下，ε=0 时该贡献趋于0。p=0 处 w 未定义；这里没有把0/0设成0。V的谱半径为1，所以发散不是 value observable 变大。这一指定配置因极点停止，不改 EPS、rank 或 normalizer 救援。

## C：另一种已写明函数的恒等式，不是 B 的补救实验

若一开始就定义 u_t^ε=n_t/(p_t+ε)，则它属于另一个函数。设 F=(EV+VE)/2，S=Σ_tρ_t，有

`Σ_t α_t u_t^ε = Tr(FS) / [Tr(ES)+Tε]`。

它只依赖词态的一阶和，而非词态二阶异质性。一般并非常数。由 |n_t|≤R√p_t，得到 |u_t^ε|≤R/(2√ε)，不是≤R。取 V=X、单词 p=ε/(1+2ε)，便有约499.99975R的取值（R=1）。有界不等于保留了 observable 的原始范围；也不赋予这个正则化函数实际后选择条件期望的解释。此式不恢复 B，不提供任务收益或新 T。

## D：在投影前的同一词态上读有界 value

定义 v_t=Tr(Vρ_t)，有 |v_t|≤R，且

`z_D=[Σ_t p_tv_t + εΣ_t v_t]/Z`

`=[Tr((E⊗V)M)+εTr(VS)]/[Tr(ES)+Tε]`，其中 M=Σ_tρ_t⊗ρ_t。

取任意实正交 Hermitian 坐标 x_t∈R^(d²)，e、v 为 E、V 的坐标，s=Σx_t、K=Σx_tx_t^T，则完全相同的分数为

`(e^T K v + ε v^T s)/(e^T s+Tε)`。

这给出必须纳入的精确经典矩控制。d=8 时二阶对称坐标最多2080项；这是上界，不是最小有效秩或任务所需维数。该读出更改了原生从 h 独立线性生成 value 的约束，因此一般不是 gen93 的等价折叠；它也不等于 gen97 对自由经典 value 的32对通道做注意力加权中心化协方差。二者都用二阶统计，不应仅凭“二阶”判定相同或不同贡献。

D 不退化为 S 的函数。反例：两个词态集合分别为 { |+⟩, |−⟩ } 和 { |0⟩, |1⟩ }，两者 S=I。取 E=|+⟩⟨+|、V=X，前者 z_D=1/(1+2ε)，后者为0。C在两者上相同。该反例属于一般二维算符族，可嵌入八维；本轮未运行原生 circuit，未证明它位于已固定 ansatz 的可达子集，更不是自然语言任务证据。

若 route 和 value 都来自量子态，“只看 Q 对完全去相干 D”会同时改变两处。至少要区分 p_Q=Tr(Eρ)、p_D=Tr(ΔE Δρ)，以及 v_Q=Tr(Vρ)、v_D=Tr(ΔV Δρ) 四种组合；路由归因时固定 v_Q。上述 |±⟩ 例子中，仅 Qroute/Qvalue 非零，其余组合为0。这是构造预测，不是量子优势或任务改善。

## 资格结论

A因常数退化停止，B因原EPS极点停止；C是已知矩代数上的不同正则化函数，不作为失败B的救援。D是非退化的候选组件，但当前没有证据说明原生词态保留了所需 signed value 信息，更没有 L3、实质新机制、新 T 或独立审核。因此没有选择任务方法。有限算符检查只核计算，未作外部理论新颖性评审。

下一步若研究 D，应先用固定已有模型和既有 TRAIN cohort 做信息可表示性诊断：新输入访问须另冻结来源、资源和停止门，不以本轮构造例子自动启动训练。保持原限定L4、gen98 STOP和所有负结果；精确经典表示本身不否决量子方向。
