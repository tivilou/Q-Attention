## Exact observable and known tools

For a fixed relation and score threshold s, let a_t=b_r+u_rt-s, T be the number
of valid words, and p_rt the original Born probability. The native logit exceeds
s exactly when C_r=mean_t a_t(p_rt+EPS)>0, since its denominator is positive.
If a selected token t has independent overlap bit B~Bernoulli(p_rt), sampling
t~q yields X=a_t B/(T q_t); E X + EPS mean_t a_t=C_r. Conditional on a frozen
pilot/threshold, this is an unbiased threshold numerator estimate. Tokens with
a_t=0 need no stochastic query. For nonzero coefficients q_t proportional to
|a_t| minimizes max_t |a_t|/(T q_t), but NOT generally the actual variance or
the required decision cost. Extreme values with nearly zero overlaps are an
explicit counterexample to automatic variance/cost benefit.

This is standard ratio-sign algebra, importance sampling and sequential testing,
not new L5 theory. A future controller must not see exact probabilities or gold
labels; exact probabilities may serve the simulator and independent grader.
Union-bounded fixed-look intervals can permit optional stopping, but the exact
bound/range, zero-coefficient handling and pilot-conditioning proof need source-
specific review. Normal-approximation intervals do not certify decisions.
