# 自然轨迹的秩与读出审计

本轮直接复用 Round3 已闭合的35份私有轨迹（7个匹配案例×5个固定seed29头，约7.96MB）。这些案例按先前正确/错误组合选择，结果是事后描述，不是新独立证据。冻结头来自原全量实验，但特征在CPU重建；不声称复现原GPU缓存。

对每个头构造 L[(i,t>0),r]=log(alpha[i,r,t])-log(alpha[i,r,0])，共253×40；固定首词锚点，对全矩阵做一次秩8截断SVD，插回零锚点并沿词轴softmax。每个接收头始终使用自己的utilities与bias，比较归一化原权重与投影权重的分数和argmax。没有读取目标标签，没有训练，也没有实际模型前向。原始分数的float64重组与存储logits最大差为3.3800400736083702e-6，低于预先固定1e-4。

这里的“30.8%”是量子头对数比矩阵的相对Frobenius残差，不是方差比例、任务信息损失或性能变化。量子头的注意力平均L1变化约0.245、最大logit变化约2.086，但7个argmax全部保持。简单2delta间隔上界对其中3例不给保证；实际投影后的argmax仍逐例计算且不变。实数重叠头尾部更大，并改变3例argmax；未读标签，不能称之为3次退化或改善。去相位头也有明显非秩8部分。这些比较不能支持量子独有的高秩解释。

共同特征差矩阵D为253×1028，在固定rcond=1e-6下数值行秩253；最大/最小奇异值72.72298010705882/0.8007683015228084。因而所有五个秩8代理在这些同案例特征上均可作实际仿射key/共享query参数化的有限插值，最大代数残差小于4e-14。该拟合使用被评价案例的教师注意力；没有执行替代头，不是学到的新基线，不证明有界范数、优化可达性或未见输入保真。所报告参数范数依赖SVD因子尺度，不能拿来声称复杂度最优。

## 结论与停止边界

“量子log-odds秩超过8，因此实际分类必须依赖这部分能力”这条自动推论不成立。本轮没有观察到7例量子预测因这种截断改变；这既不是总体等价检验，也不排除其他数据上高秩部分有用。投影破坏其他头的预测也不能证明没有更好的保决策低秩替代。结合已读MoS/Sigsoftmax的非线性秩提升先例、精确经典cosine解释、原五种头的全量匹配对比尚未建立关键优越性，当前rank-lifting分支停止作为L5核心自动推进；保留表达性引理和描述性数据。

不再增加rank39合成演示、不更换锚点/秩/容差/种子求挽救，也不对这7例再做输出优化拟合。原限定L4卡与历史实验不变。下一条研究线须从任务读出约束或其他实质不同机制提出可证伪假设，并区分已知注意力非可辨识/非线性特征映射与新的贡献；先读原始近邻和检验自然前提，再决定最小诊断。任何新正式全量实验仍交师弟。
