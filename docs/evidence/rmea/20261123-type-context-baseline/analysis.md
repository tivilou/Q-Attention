# 2026-11-23｜先确认可修复的任务问题，再选择机制

[已测事实] 当前最明确的性能问题是**显式实体类型没有进入原版表示，关系预测会违反实体类型的经验兼容性**。固定的经典类型规则已经在开发数据中产生净收益。下一层是同一类型组合内的关系证据判断；它有真实错误实例，但还没有被确认为适合量子方法、且优于同输入经典方法的研究问题。

## 实际流程与本次改变

项目输入是句子、主客体及其位置；原版 `marked_words()` 使用不带类型的 `@ ... @`、`# ... #` 标记，明确排除类型元数据。冻结语言模型生成词特征，Q-RMEA 对每个候选关系聚合词级证据，输出40类分数，取最大值。评估主指标是39个正关系类别的 Macro-F1，`no_relation` 为第0类；准确数与三类错误计数用于诊断。

此前只用固定4,192条 TRAIN 构造实体类型对的经验支持表，保留 `no_relation`、未知类型对及拟合区缺失类别；在4,000条 TRAIN 评估区和完整19,584条开发 VALID 上应用同一个规则。该规则增加了显式类型输入，既不是逻辑定律，也不是量子创新。本次复用原有所有预测，加入两组标准凸校准对照，并检查修复之后剩余的任务错误。没有重新运行编码器或正式深度模型训练。

[已测事实] 冻结规则相对原版修复352条、误伤34条，净多判对318条，Macro提高0.026473。经验支持表同时排除了130条 VALID 金标签，因而硬约束的失误必须保留。两个软偏置校准器均没有通过“优于原版、全局校准、冻结规则”三项比较门槛；关闭这组固定校准配置，不调整惩罚或重新选样本。

校准仅使用既定4,192条 TRAIN，原模型已见过完整 TRAIN，因此另4,000条也不是独立测试。目标为平均交叉熵加固定0.01二范数惩罚；原分数系数固定为1。全局模型40参数、类型模型1,040参数，参数量不匹配，不作效率结论。两者分别10/12次迭代收敛，梯度最大绝对值8.53e-8/4.56e-8；科学计算耗时1.263秒，0次模型前向、0次GPU计算、0次COS写入。7组报告混淆计数和 Macro 已从保存预测重新核对。

[机制解释] 当前这种交叉熵偏置校准降低了部分假阳性，但增加真实关系漏判，无法解决已观察到的整体问题。它没有直接优化 Macro-F1，且只在暴露过的 TRAIN 区拟合；所以该失败不能证明一般经典校准、类型输入训练或经典模型都无效。

## 剩余问题与案例边界

[已测事实] 类型规则之后还有3,787条错误，其中2,451条是真关系被判为无关系。仅依赖实体类型对、用拟合区多数标签分类，开发 Macro只有0.043425；当前 VALID 中所有25种类型对都有多个标签。即使利用当前 VALID 标签选每对的最频繁类别，类型对确定分类器的最高正确数也只有12,445/19,584（准确率0.635468）。这只是本有限总体上类型对分类器的准确率上界，不是 Macro上界、可部署模型或未来性能界。

在同一冻结类型规则下，之前缓存的上下文相干去除干预使 Macro从0.542947降到0.490697。它是固定检查点上的干预关联，没有重新训练经典对手，不建立量子必需性。

六例按每种剩余错误族中 `SHA256(type-context-case-v1:id_hash)` 最小的两例选择；属于按结果分层的解释性案例，不估计群体比例。私有原句只在服务器，公开文件保留索引和语义判断：

- 17396：明确的 director-of 结构把人和组织连接起来，仍预测无关系。
- 14623：明确的亲子表达被预测成反方向；双方类型相同，类型本身无法判别方向。
- 1426：在学校任教被预测成就读于学校；两种关系共享 PERSON–ORGANIZATION 类型。
- 12431、16331、7533：涉及代词、继任者及身份指向，主审判断不确定。保留原标签，不宣称是标注错误。

这是原始输入—给定类型—原版分数—冻结约束预测—金标签的诊断记录，私有来源见已固定的两份元数据哈希。没有训练逐步语义 trace，也没有新增机制的中间轨迹；不从最终预测反推内部因果路径。完整反向输入对中，430对符合声明的逆/对称关系，但423对是对称关系、只有7对是方向关系。389对预测相同不能解释成389次方向错误。方向错误目前只是子问题，不升格为主要瓶颈。

## 原始文献与新颖性

阅读 Zhou与Chen 的 [An Improved Baseline for Sentence-level Relation Extraction](https://arxiv.org/abs/2102.01373)，实际版本为 arXiv:2102.01373v4（2022-09-22），原PDF第1–3页，含任务输入和 typed punctuation marker 定义。作者已明确将实体类型作为关系抽取输入，并研究类型标记。故“加实体类型”是已知方法。后续实验页未深读，其F1和微调编码器设置也不与本项目冻结编码器下的正39 Macro直接比较。[阅读范围](reading-receipt.json)记录这一边界。

## 当前决策与下一步

[尚未证明] 类型增强不是现成L5 idea；同类型内的证据绑定也还没有量子优势、独立验证或理论创新证据。原版限定L4保留，L5仍未接受。

唯一推荐方向：**先建立同等类型输入的可训练经典关系头对照，量化其仍然漏掉的上下文关系证据，再选择是否需要新的量子机制。** 假设是：类型解决粗粒度候选兼容，剩余部分需要句子中的谓词、指代和主客体关系条件；这是假设，不能由六例或去相干结果直接确证。最小下一步复用稳定训练入口和已有特征，固定同一输入/预算，仅比较类型增强经典头与类型增强Q-RMEA；先做有界实现检查，按适用授权再决定正式运行。科学成功门槛是新方法在同输入强经典对照之上仍有明确剩余增益；如果强经典模型已经消除目标错误，就关闭该问题的量子独占叙事。不要再调本轮失败的固定偏置配置。预计有界检查只需现有节点，不购买或扩容；正式预算和独立证据在选定机制时固定。
