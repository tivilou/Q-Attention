# 先找值得解决的任务问题：真实关系被拒识，而不只是类型不兼容

[已测事实] 已找到值得继续研究的问题：**句子含有支持给定实体对的关系证据，模型仍输出“无关系”；修复时又必须避免把其他实体的证据错归给该实体对。** 前一部分已有重复漏检和固定语义样本支持；后一部分由已有误报反例约束。尚未把它归因为某一个注意力、线路或训练缺陷。

## 实际问题与可修复证据

[已测事实] 在同一重建缓存和同一TRAIN类型规则下，完整训练的经典关系softmax头开发VALID的39个正关系宏平均F1为0.60818446，Q-RMEA为0.60003351。类型给所有对照带来通用收益；不能借此主张量子增益。原历史缓存不同，原正式结果不改写。

四个非均匀关系头共同漏掉1,155条真实关系，其中1,070条的真实关系仍被类型规则允许。在选中的8条TRAIN漏检中，两次隔离Sol/medium语义判断共同有把握支持原标签的有5条，反对2条，不确定1条。它们不是独立人类标注，也不能证明所有共同漏检均可修复。固定案例包括任职、亲属、身份指代和组织成员关系，原文与逐词数值留在私有计算节点。

[已测事实] 固定案例的证据均匀聚焦在放松读出中使2/5条有支持的漏检越过原竞争分数；另1条即使任意重排目标关系这一行也不足。这说明不能一概把问题写成“注意力不够集中”，也不能只降低无关系偏置：之前固定偏置校准已经失败。

[已测事实] Macro-F1对低频类别很敏感：以事后100条支持数为界，22类共1,168条正样本，在上述1,155条共同漏检的理想修复增量中占0.11872523。完整39类计数和贡献均保存。这不能用来事后挑类别或调损失函数；下一轮应同时报告全部类别、正关系漏检和无关系误报，避免正确数改善却Macro下降。

## 唯一推荐方向

**围绕给定实体对，建立共享、无标签的“支持某个关系／拒识为无关系”证据判别机制。** 它需要同时考虑证据属于谁及竞争类，而不是只把目标行变尖或统一降低无关系分数。研究假设是：这类机制能修复有明确证据的漏检，同时保住无关系和有竞争实体的反例。当前没有选定量子操作。

最小下一步是在现有固定TRAIN32及已保存真实词级数值上，提出一个可实现的共享预测规则，说明与原独立归一化及已关闭族的结构差异，并给出同输入经典对照。成功条件是获得能区分漏检修复与误报增加的可反驳预测；仅得到标签选词、已知恒等式或已失败配置调参时停止该提案。理论设计无需新GPU训练；实现后沿用既有稳定训练器和按改动范围检查，不重做生命周期矩阵。现有持续研究授权有效，未新增付费资源或新实验启动。
