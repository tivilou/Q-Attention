# 找到问题后再选择方法：正关系证据为何仍输给无关系

当前可检验的问题是：**句子确实支持目标实体对的某种关系，模型也能在正关系中选对，但最终仍被无关系类别拒识。** 修复这类真实漏检，同时不增加无关系样本的误报，才可能改善模型表现。仅让注意力更集中、提高正关系分数或减少输出无关系的次数，都不足以证明修复。

## 已有范围与本次读出

此前完整模型在重建缓存的19,584条VALID上，四个非均匀头按相同类型规则共同漏检1,155条正例，其中1,070条正确标签被允许，672条四个头都把正确关系排在所有正关系第一。这是带标签的定位结果，不能把672直接当成可恢复数量或预期收益。历史正式结果不变，当前缓存并非原始特征字节。

沿用上轮固定32例：8条Q-RMEA正确正关系排第一的共同漏检，另各8条正确正例、无关系误报、正确无关系，且句子互异。两次隔离的Sol6.1/medium语义判断在8条漏检中共同支持4条；其他分歧保留，同模型调用不等于独立人工审核。这是按结果选出的诊断集，不能估计总体比例。

本次只用原完整模型选定的4个checkpoint进行CPU实际读出，32例×4头，共128次；2.895秒，0参数更新。复算得到的logit与已有GPU结果最大差1.622e-5，预测一致。独立NumPy核对读出分解和条件界，最大差5.106e-6。见[汇总](summary.json)、[验证](verification.json)、[运行源](readout.py)。

## 新发现：集中到证据词并不足够

在4条共同语义支持的Q-RMEA漏检中：

| 固定读出诊断 | 条数 |
| --- | ---: |
| 正关系对无关系的共同注意力取值差为负 | 4/4 |
| 假设将目标行均匀放在语义证据词，分数可以越过固定对手 | 1/4 |
| 在证据词中任意选择目标行非负权重，其上界可以越过固定对手 | 2/4 |
| 即使允许在全部词中任意选择目标行非负权重，仍过不了固定对手 | 1/4 |

后一条样例的原正关系差为−3.851；保持取值、偏置及所有对手行不变，即使把该正关系的全部权重放到对它最有利的词，其最大差仍为−0.621。另一样例在证据词上已有约均匀注意力的7.12倍质量，证据词内的最佳读出差仍为−1.510。它们说明局部权重变化有时受取值与竞争关系限制。

这些是**冻结取值和对手后，仅放宽一条目标行**的条件界，属于已知加权平均性质。它既不是共享量子线路的可达性判断，也不能证明重新训练原模型仍做不到。正确正例也会出现负的共同取值项，因此该项本身不是可部署的错误检测器。金标签和语义证据位置始终只用于诊断。

## 对后续方法的要求

新方法应学习：哪些词在当前实体对下提供正关系证据，哪些是背景或其他实体的证据，以及何时仍应拒识。必须同时检查正确标签修复、正例变为错误正类、原正确正例损伤和无关系误报；仅减少正例到无关系的次数可能只是换一种错法。

本次诊断支持探索取值与拒识竞争，而未确定一个量子原因。作为下一步小规模可证伪候选，可以考察保留词间相位的条件读出，与原Born读出、内部退相干、允许有符号权重的经典读出对照。它可能超出固定非负加权平均的区间，但弱值和有符号权重界是已有工具，不能据此声称新定理、量子必要性或L5。若任务效果不成立，保留这一问题定位并停止该固定实验方案。
