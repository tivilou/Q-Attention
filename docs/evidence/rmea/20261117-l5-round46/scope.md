# 证据归属抽取：执行范围与下一道门

从固定train的58,465行、10,153个多查询原tokens组中，按R45已冻结的哈希顺序提取32组，每组取两个按整数span坐标排序的query。选择不读取label值，不按混合标签、预测、易标注程度或期待结果筛选。源JSON字节包含训练标签，不能称为“未访问标签数据”。

私有包18,959字节，只在owner的精确attempt输出内；目录0700、文件0600。公开报告只含受校验的固定字段、数量、哈希；既不含原文，也不含样本ID。还没有读者、标注、模型forward或训练。原文包是可重建缓存，没有COS上传。

这不是Case Study，也没有恢复任何已关闭的实验家族。它仅为下一个有限语义前提提供盲审材料，不证明“证据归属切换”已经存在，更不证明量子独特性或L5。原有范围受限的L4保持不变。

审查先发现内容白名单、原任务恢复身份、输出清单和schema检查问题；下一轮又发现原始JSON重复字段可绕过解析后的白名单。原始BLOCK保留，修正后重新冻结同一审查路径，没有改样本预算或寻找不同审查者获取肯定。

实际canary经共享调度器运行，调用真实extractor子进程，在pack与紧凑报告写好后注入完成标记失败，精确清理后以不变source/input/protocol重试，私有包字节一致。随后实际抽取也由同一共享调度器接纳；两次配置均恢复原字节并核实controller存活。CPU资源申请96MB/GPU0，抽取峰值RSS为20028KiB。节点容量未增加。

全局排名及语料成员资格依赖已审查确定性源代码、固定输入哈希、实际执行身份和合成独立oracle；collector只独立校验结构、schema、span/ID/order和receipt哈希，未重读全语料做独立重排序。历史训练语料已有诊断暴露，所选组未按其结果排除，不宣称独立数据证据。

下一步需先明确两个独立读者的身份、提示、访问权限及隔离方式。原始文本不得发往外部模型咨询；没有新的人类联系或读者启动授权。模型间一致也只是暂定，成为gold前需人类裁定。保留全部32组、歧义与分歧；没有支持的witness就关闭该32组probe，不扩样本抢救。即使得到有限witness，还需推导针对完整40类signed margin、能区分实体感知经典对照的非平凡预测，才讨论模型实验。
