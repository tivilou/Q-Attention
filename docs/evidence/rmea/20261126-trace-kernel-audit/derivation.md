# Pauli核、注意力质量与Mercer物理实现的边界

记n=3、r_P=tr(ρP)、s_P=tr(σP)，P∈{I,X,Y,Z}^⊗3。原生Q概率为(1/8)Σ_P r_Ps_P；D仅保留{I,Z}^⊗3。源Eq42的H-body核为 k_H=Σ_(wtP=H)r_Ps_P/√d_H，d_H=C(3,H)3^H。因此 Q=(1/8)Σ_H√d_H k_H。它是已知Pauli展开，不是新贡献。

每个H的Gram矩阵半正定，因为它是显式特征的内积；其非对角元素仍可负。两状态ρ_+=|+++>_X<+++|、ρ_-=|--->_X<---|给出k_1(ρ_+,ρ_+)=1、k_1(ρ_-,ρ_+)=-1。它们都可由原生电路的末层RY=±π/2配合现有CNOT环达到，角度严格在tanh允许区间内；这不是实际任务数据对。

对一个query、两个token及u=(1,-1)，把k_1直接替代native概率，再用EPS=10^-6归一化，则α=((1+EPS)/(2EPS),(-1+EPS)/(2EPS))，有一项为负，z-b=10^6。原生Q在同一理想端口为(1,0)，所得signed加权值约0.999998，保持在utility范围内。这个例子否定“合法PSD核即可直接充当非负Born注意力质量”，不否定源的SVM使用或所有改造后的投影注意力。

令ℓ_S为全部S子系统HS重叠的算术均值，则
ℓ_S = [1/(2^S C(3,S))] Σ_(wtP≤S) C(3-wtP,S-wtP) r_Ps_P。
它逐项为[0,1]内的混合态重叠，且保留identity常数。源的S-LPQK采用1/√C(3,S)求和，等于√C(3,S)ℓ_S；这不是相同尺度。n3时源S1/S2的重叠Pauli权重l2范数平方为3/2，而非一般自动为1。可以另行归一化，但必须明示：有固定EPS的attention不是任意全局缩放都严格不变。增加常数或删掉常数同样改变原生分母及与均匀路由的关系。本轮没有选择任何补偿方案。

Mercer算符为L(A)=Σ_x μ_x ρ_x tr(ρ_x A)。对上述两个正交纯态，取μ_+=1/3、μ_-=2/3，则ρ_±是唯一对应正特征值1/3、2/3的单位HS范数本征算符，矩阵rank均1。所有规范化三qubit Pauli的rank均8；可逆共轭保持rank。因此一般不存在一个U0把这组Mercer算符按A_i=U0†P_iU0/√8变成Pauli基。一般的64维算符空间旋转与一个8维物理基变换不同。这个论证只限制源p7的通用物理实现解释；抽象Mercer重加权和固定Pauli的PSD构造仍可使用。

在两点分布上Q的核矩阵是I_2，D为(1/8)11^T。对应的对称加权积分矩阵T_Q=diag(1/3,2/3)、T_D=(1/8)√μ√μ^T，其交换子Frobenius范数平方为1/1296，非零。因此任意Pauli重加权并不只是保持本征函数而重缩放本征值；该结论需要在真正的Mercer基中加权。它也不构成Re-TACRED上的收益或根因证明。

源的p^(1/4)复杂度项来自固定base kernels、范数受限二元margin类；原生prepare/effect/value均训练、40类和token归一化需要另行论证。有限p与既有核恒等式没有提供本项目的L3或非平凡T。
