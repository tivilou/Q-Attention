# 整集 soft Macro-F1 锚点与量子纠错计算边界

## 一次全局锚点并不保证后续训练方向正确

设一类的原分母和软真阳性为 D₀、T₀，变化后分母为 D₁>0，令该类的一阶预测变化为 ℓ=2(ΔT/D₀−T₀ΔD/D₀²)。精确有限变化等于 ℓD₀/D₁。因此所有类的 ℓ 均非负时，整集软分数不会降低；各类符号混合时，分母各自变化会重新加权正负贡献。若每类相对分母变化绝对值不超过 ρ<1，整集误差最多为 ρ/(1−ρ) 乘各类 |ℓ| 的均值。这是可检查的充分界，通常仍需要一个同权重的复算点。

用 40 类、40 条合成记录复算。固定 38 个类，另两条预测的第二类概率从 (.10,.10) 沿 (.25,.10) 的方向变化。固定锚点的一阶预测在完整一步为 **+1/2016**，真实软分数变化为 **−19/36456**。在 11 点固定网格中，走到 s=.3 时，真实局部导数已经低于零，最大分母相对漂移为 **8.75%**，全部硬预测一路不变。复算验证了精确有限关系以及每个网格点的误差界。s 是合成路径坐标，无法折算为任务里的更新次数。[精确代码](anchor_math.py) · [有理数结果](anchor-result.json)

## 四臂成本与公平归因

固定系数使这条路等价于一个逐样本的共同目标：加权奖励金标预测概率，同时线性扣除各类预测概率。系数由全局软真阳性与分母决定，和逐标签 CE 及 gen94 先验重加权的公式不同。这个目标可以原样给 Q、独立去相干及最强同输入经典，采用相同的系数规则。若只看到 Q 在新目标下改善，通用训练目标改善和量子机制贡献尚未分辨；若主张量子与新目标有交互，还需匹配的原目标比较。现时缺乏由量子状态或测量决定的独立任务预测。

## 新计算角色的先决条件

转向量子电路能否保留任务信号并移除一个数据支持的干扰。核读 Zhou 等原作 v2 第 1–6 页及定理1所要求的连续马尔可夫噪声、快速控制和适当辅助系统。其区分信号与噪声代数的原理提供探路依据，计量精度结论不迁移至关系抽取。[原作](https://arxiv.org/pdf/1706.02445v2)

用三比特偶奇子空间做离散边界测试。第一个比特的随机 X 翻转能由奇偶测量与校正消除，第 2 根线存储的逻辑相位保持，最大误差 **2.22×10⁻¹⁶**。若把信号本身编码成第 1 根线的 X 旋转，同一回收会抹掉信号，误差 **1.11×10⁻¹⁶** 相对于原未编码状态。保持奇偶性的 Z 扰动也未被还原，示例恢复后测量概率为 .75。64 个合成密度矩阵、40 个独立二元效应的复算显示，对于单次确定性回收与固定读出 E，结束测量可精确等价为初始态上的 E+XEX，最大差 **1.11×10⁻¹⁶**。因此此静态写法没有给出可与等输入等读出区分的独立计算。40 个效应是各自的二元测量。[模拟代码](syndrome_boundary.py) · [数学核验](syndrome-result.json)

同时探查当前任务中是否有自然支持的简单干扰。只对冻结 FIT4096 删除实体跨度之外的独立标点 token（句点、逗号、分号、冒号、问号和叹号），保留全部其他词并重映射有序实体边界。4,041 条记录存在这样的标点；但在整个 FIT 中，没找到原 token 不同、去标点后词序和实体对完全一致的自然变体对。这条规则缺少可供核验的自然变体，未建立语义不变性或可标定噪声通道。结论仅覆盖当前谓词和样本。[FIT 盘点](punctuation-result.json)
