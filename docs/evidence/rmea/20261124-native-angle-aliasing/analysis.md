## 已知条件信息几何的原电路反例

令所有门角为0，仅最后一层wire2的RY为非零；原有两轮CNOT不变。两词key角为正负(pi-2delta)，query角为pi*tanh(e)，e=0。角度均在原生可达开区间内；这是角度端口例子，不证明共享prepare能在自然输入上同时实现它。

query纯态QFI为pi^2，原生epsilon词归一化注意力Fisher为

`F_attention = pi^2 * sin(delta)^2 * cos(delta)^2 / (sin(delta)^2 + epsilon)^2`。

epsilon=1e-6，delta=.3/.1/.03/.01/.003/.001时，注意力Fisher/QFI依次约10.45、99.31、1107.98、9802.30、89999.41、249999.75。NumPy独立电路/有限差分与解析式最大相对差3.426e-9。初始差分步长1e-7在最小delta下截断误差过大；用1e-8并检查1e-9收敛，未放宽解析误差门限，也没有真实数据选择。

零epsilon时缩放二词effect各1/2，可补成合法subPOVM；成功概率sin(delta)^2乘条件Fisher/QFI=cos(delta)^2<=1。没有超越量子信息界。原生RMEA的词概率并非现成jointPOVM，这个缩放/完成只用于解释反例，不能把原始词归一化直接称为物理联合测量。

因此普通纯态QNG/QFI不自动等于本任务的注意力几何；直接把QFI当目标曲率缺少依据。这是已知条件信息/后选择现象及标准Fisher协方差恒等式，**不是新T、任务根因或方法收益**。
