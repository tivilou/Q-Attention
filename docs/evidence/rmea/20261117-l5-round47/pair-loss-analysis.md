# 同句双查询条件目标：正确性质与反例

状态：exploratory_only。本文是解析推导，不是模型实验或新颖性声明；不改训练代码、不启动数据读取或模型任务。原范围受限的L4不变。人工语义盲审已从主线搁置，不是L5的必要条件。

## 定义与成立的恒等式

固定同一句话的两个自然实体查询q1、q2，其训练标签为不同类a、b。令z(q,c)是完整40类输出，p_q(c)=exp(z(q,c))/sum_j exp(z(q,j))。以下仅定义乘积伪联合分布p_1(c1)p_2(c2)，不假设两个真实查询或标签统计独立。

在此伪联合分布内，条件事件为标签多重集等于{a,b}。两个互异排列的归一化概率为

P((a,b)|{a,b}) = exp(z1a+z2b)/(exp(z1a+z2b)+exp(z1b+z2a)) = sigmoid(D),

D = z1a+z2b-z1b-z2a。

因此对应条件负对数似然为log(1+exp(-D))。这属于标准条件似然/配对逻辑损失代数，本身不是非平凡新理论。a=b时事件只有一个排列，条件NLL为0；不能将两个相同排列重复计数并套用log2。

对任意行偏置A_q和列偏置B_c，变换z(q,c)->z(q,c)+A_q+B_c不改变D。这是目标的偏置不变性，不能直接称为原推断器的偏置鲁棒性。

## 完整决策反例

1. 即使只有a、b两类，D>0也只保证两个正确标签边际之和为正，不能保证各自为正。例如q1的(a,b)=(2,0)，q2的(a,b)=(1,0)：D=1，但q2预测a而真实为b。将所有分数乘T>0，D=T趋于无穷、条件损失趋于0，q2仍错。配对排列更可能不等于两个独立查询均分类正确。

2. 在40类中取第三类d，其余37类分数为-1。令q1的(a,b,d)=(T,0,2T)，q2=(0,T,2T)，T>0。D=2T趋于无穷，条件损失趋于0，两个查询却都预测d。此为抽象logit反例，未声称这组分数已经由原生量子电路实现或执行。

3. 更直接的原生实现对应：Q-RMEA实际输出为z(q,c)=sum_t alpha(q,c,t)*u(q,c,t)+bias[c]；bias是自由的40维可训练参数。固定任意有限输入/参数和两个标签a、b之外的类d，仅把bias[d]增大到超过两个查询的所有竞争分数，即可令两次推断均输出d，同时D及条件损失严格不变。这个修改是原模型参数族内的解析变换；无需假定前述任意logit表都可由受限电路实现。没有执行该修改。

4. 若用已知{a,b}来约束测试时配对分配，会用到测试时未知标签并改变原40类逐查询任务；不能作为修补。标签盲的组内推断也需要重新定义可用输入/协议，不能继承旧L4。

## 准确的推论和停止范围

这排除了“条件目标消除共享偏置，所以原生40类预测必然正确/鲁棒”的推论。加入原CE可惩罚错误类，本文不证明CE+条件目标无效、不可训练或必然低于原模型；也不证明任何量子或经典方法整体不可行。
