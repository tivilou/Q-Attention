# 输入距离与词态相似度的配对：一个诊断及其限度

仅使用既有 contextual word vector h、role 和模型词态；不选词、不读 gold 来定义统计。
对全部有效 i<j，令 d_ij=1−cos(h_i,h_j)，KQ_ij=|ψ_i*ψ_j|²。
定义 A(K,d)=ΣK_ij d_ij/ΣK_ij−mean(d)，以及唯一主统计 S=A(KQ,d)−A(KG,d)。
KG 用既定最强 Gaussian-covariance 控制的原 key 投影与尺度。
同 Q 词态的 KD_ij=Σ_a |ψ_ia|²|ψ_ja|² 是诊断去相位控制；精确 real16 两内积表示必须等于 KQ。
零输入范数、少于两词、零 pair kernel mass 都报告 undefined；不加 EPS 或换定义。
这里的 contextual cosine 只是输入代理，未认证其语义或任务充分性。

原 native 源代码9f4bfc57 的第一层 wire0 RY 为 ±π/2，其他所有角为0时，
RY 产生(e0±e4)/√2；两轮 CNOT ring 将索引4依次映到3和2，因此词态为(e0±e2)/√2。
本轮复用此前实际执行且核验过的 native-stage.json ec3965de 中的这两态，未调用任何电路。
四个词态固定为 +,+,−,−。其 Gram 与密度矩阵固定，平均密度纯度1/2，
off-diagonal KQ 的两个1恰在01、23，其余0；同态去相位 KD 在每一对都是1/2。

构造两个4词输入的单位范数 Gram。A 的非对角1/2在01、23；B 在02、13；其余0。
它们的谱都是{1/2,1/2,3/2,3/2}，全部输入距离的多重集合也相同：两个1/2、四个1。
令每个输入第一坐标 k=(1,1,−1,−1)/10，剩余坐标由 Gram−kkᵀ 的 Cholesky 给出。
最小特征值至少1/2−||k||²=23/50>0，故这样的1024维输入确实存在，只用前5维。
同一 prepare 仅 weight[0,0]=atanh(1/2)/(1/10) 非零；它在两组输入都产生上述 ±π/2 角。
这证明输入与 native 线性 prepare 的数学相容性，没有证明自然语言 encoder 或真实 checkpoint 会产生它们。

六个无序 pair 的普通平均距离为5/6。A 中 Q 加权平均距离1/2，故 AQ=−1/3；
B 中为1，故 AQ=1/6，差正好1/2。AD 两组都是0。
在固定原 Gaussian 尺度下，选一个其 scaled key 保留前5输入维度的人工线性投影，
得到 KG=exp(−2d)。输入距离多重集合相同使 AG 两组相等，实算均为−0.12139177571624793；
于是唯一统计 S 的差也为1/2。这个 Gaussian 是人工可实现实例，并非已训练强基线的复现。

所有40查询都取e0，所有value、decoder和bias都为0，词概率均1/2、alpha均1/4、
attention collision mass均3/4、utility variance均0，Q/D的40输出都为0。
因此该统计不由长度、纯度、谱、浓度、效用方差或输入距离直方图单独决定；
同时它能在整个模型输出不变时变化，不能单凭统计大小推出任务错误、量子因果或有效更新。
这是明确的充分性反例，限制后续解释；不是新T或新方法。
