# 交叉分折与 Noise2Self 的理论边界

Noise2Self 已把“排除自身坐标参与预测，并利用条件独立、条件无偏噪声”用于自监督平方风险。原文的定义与命题1见PDF第2页，推导见第6页；已逐页阅读1—6页并视觉核对第2、6页公式，后续页、补充材料和代码未读。[原论文](https://proceedings.mlr.press/v97/batson19a.html)。仅这条原则不足以构成新的L5理论贡献。

以下是针对本项目源码的分析，尚无新增任务实验。冻结状态与原生质量时，cross_fold的接收组A路由alpha_A只使用B组效用；这与既有数值检查相容。但源码cross_fold.py第67、73行仍用接收组状态归一化并读取本组效用，最终分数包含alpha_A(u_B)^T u_A。对u_A的路由偏导为零，不等于最终预测不访问u_A。实际上下文状态也由同一文本产生。因此，本模型的完整预测没有因路由分折而自动满足Noise2Self的坐标不自访问条件；该平方风险恒等式也没有自动变为多分类CE或Macro-F1保证。这是适用边界，不是实现缺陷或已观测任务失败。

一般平方风险展开中的交叉项只有在对应条件下才消失；识别了哪一层变量的独立性，需要明示。先前固定状态、指定噪声律下的局部响应及小信号CE排序继续保留其原限定范围。不能把训练后共享表征当作已满足噪声独立的证据。已完成数值canary不改变此限制。

新颖性判断分两层：坐标隔离/噪声交叉项消除属于已知原则；特定量子效用构造、可微原生分组质量和多分类风险预测是否形成实质新贡献，仍待近邻比较、非平凡理论及独立实证。本轮近邻核查只有一篇有针对性的原文，不是全领域查新。

同预算cross_fold/self_fold任务比较仍有判别价值：它能观察改变供体映射是否有开发集收益，但正结果不证明上下文噪声独立，也不自动获得L4/L5。维持已经冻结的联合门槛，未修改候选实现、数据或预算。新正式全量实验仍交由合作者。
