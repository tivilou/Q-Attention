# 原版的稳定收益与损害具有类别差异

这是对原版已完成五种子报告的补充分析，未训练或推理新模型。项目流程仍为
固定词元特征／实体角色→关系条件量子注意力→分类值汇聚→40 类预测。
本次只复用各条件原先已选定的 selected_valid 混淆矩阵，覆盖全部 39 个正类、
五个既定种子 29/53/71/97/113，以及 uniform、relation_softmax、real_overlap、
quantum、dephased 五条件；不使用 TEST 数值作本次比较或选题。

与刚完成的单 checkpoint 固定一步相比，这次检查的是既有完整训练在五种子
之间是否反复出现同方向的类别收益。统计规则在运算前写入 protocol：五次
F1 差均严格大于 1e-12 才称“稳定正向”，均小于 -1e-12 才称“稳定负向”。
这是描述性稳定性，**不是多重比较后的显著性或独立发现／确认划分**。

**[已测事实]** 原始 summary SHA256 与既有 run_summary 封印一致；25 个
selected_valid 混淆矩阵重新计算逐类 F1，最大误差 1.11e-16，支持数逐条件一致。

| 原版量子对比 | 39 类中五种子均正向 | 五种子均负向 |
| --- | ---: | ---: |
| 均匀注意力 | 36 | 0 |
| 关系 softmax | 2 | 7 |
| 实数 overlap | 4 | 2 |
| 去相位模型 | 3 | 2 |

**[已测事实]** 年龄关系 per:age（VALID 支持 256）对三个较强对照均五次正向；
平均 F1 差分别为 +0.016748、+0.017478、+0.027476。就读学校关系
per:schools_attended（支持 46）对这三个对照均五次负向，平均差分别为
-0.049818、-0.052873、-0.035748。它仍五次优于均匀注意力，平均 +0.232269。
这里按全 39 类规则计算后展示两个共同稳定的结果，不把事后类别选择当成
预声明确认；完整逐类、逐种子差值全部保留。

**[机制解释]** 原版相对不做有效路由的基线具有广泛收益，但与较强模型的
差别并不均匀。这比“原版整体好／新模型整体差”更具体，也说明只把正类
合并成一个平均损失组会遗漏类内差异。

**[尚未证明]** 没有证据说明年龄的收益来自数字词、相位或某种句法，也没有
证明学校类的损害来自长距离／多实体竞争。分别训练的去相位模型比较不是
冻结同一个量子模型再去相位的因果干预。支持 46 的类别尤其敏感；没有用
事后正向类重新计算一个“更好”的总体指标。原版限定 L4 和所有历史结论不变，
本次不接受新的优势等级、量子必要性、新颖性或 L5。

个案轨迹不适用于这次既有混淆表算术；未重建文本、模型或隐藏中间状态。

下一步唯一推荐：从 TRAIN 文本和原有结构元数据建立**对结果盲的上下文
证据结构假设**，覆盖全部类别，不先按本次正负类挑选有利样本。首先检查
该结构在 TRAIN 是否有可测、充足的支持，再决定是否值得一次原版内部的
有界机制干预；不直接新增架构或全量训练。若结构定义依赖 VALID 收益、
缺乏 TRAIN 支持，或只是把既有工具改名，就停止该理论路线。
