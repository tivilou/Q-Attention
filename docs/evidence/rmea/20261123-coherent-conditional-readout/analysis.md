# 问题已定位，第一种条件读出未解决它

**优先问题：句子支持目标实体对的关系，模型也把正确正关系排在前面，却最终输出无关系。** 修复这种真实漏检且不增加无关系误报，才可能提高表现。完整模型四头在同一类型规则下共同漏检的672条中，都已把正确关系排第一；这是带标签的机会定位，并非可实现收益或可部署选择器。

## 完整模型提供的限制

固定32例的实际读出进一步表明：两次隔离Sol6.1/medium判断共同支持的4条漏检中，把Q-RMEA目标行均匀放在证据词上，仅1条可越过固定对手；其中1条即使放宽到全部词的任意非负目标行，仍过不了固定对手。另有样例对证据词的注意力已达均匀值的7.12倍，证据词内的最佳目标读出仍落后。

这些条件界固定取值、偏置与所有对手，只放宽目标行，属于已知加权平均性质。它们不能证明共享量子线路不可达，也不能证明重训原模型无效。固定样例按输出选取、语义判断存在分歧；没有总体比例或量子原因的结论。完整诊断见[读出报告](https://github.com/tivilou/Q-Attention/blob/codex/research-loop-runtime-20261122/docs/evidence/rmea/20261123-complete-model-readout/analysis.md)。

## 得到了什么，接下来查什么

相干读出允许有符号权重、保留常量取值，并能超出固定非负加权平均的区间；但这种表达自由在本次实验中没有转成任务收益。弱值、退相干和有符号权重界都是已知工具，没有据此建立新定理、新颖性、量子必要性或L5。小范围文献查询未检出相近题目，不构成新颖性证明。

下一步继续围绕同一任务问题，先区分：实体对所需的语义信息是否进入现有表示，以及取值/拒识分支是否能利用它。优先检查同句不同实体对、同关系正确与漏检对照；只在有共享、无需金标签的区分规则后选择下一插件。避免把“减少无关系输出”当成正确修复，也不预设量子操作必然适合。
