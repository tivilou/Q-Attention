# R69：跨关系资源竞争的适用性检查

状态：一个新探索方向的理论资格检查，未选作训练候选，L5 未接受。R68 固定滤波保持关闭，旧限定 L4 不变。

## 来源与区别

R68 只证明本次几何保护干预退化，没有定位退化的语义原因。另一个结构不同的想法是：不修改单个关系的效果态，而让关系行共同分配 token 证据。原模型每行独立归一化，所有关系可以同时重用同一词；联合配额会改变跨行依赖。这不是改滤波系数或重启 complement/outcome 家族。

Sinkformers 2110.11773v2 的第3节已把逐行归一化改成 Sinkhorn 行列平衡；第4页 Proposition1 给出代价中加行项、列项的不变性。它研究方形自注意力及残差层，梯度流部分另需对称性和深度极限。OTKE 2006.12065v4 第3.1–3.4节已经使用矩形的输入—可训练参考集合熵正则运输及 pooling，第4节讨论与注意力的关系。参考槽不是语义类别。已阅读的这些内容足以确认“跨行共同归一化、运输 pooling”已有直接近邻；并未穷尽文献、复现其代码或迁移其性能和所有定理。

## 精确映射：正标量质量，不是矩阵值运输

固定一条输入，R=40，T 为有效词数，定义 K_rt=|φ_r†ψ_t|²+ε>0，ε=10^-6。
考察正标量运输计划 P，行边缘 1/R、列边缘 1/T，目标为 Σ_rt P_rt log(P_rt/K_rt)（总质量固定，省略常数）。严格凸性给唯一正解，标准矩阵缩放形式为 P_rt=a_r K_rt b_t。
令 β_rt=R P_rt。它满足每行和为1、每列和为R/T，并且

    β_rt = K_rt b_t / Σ_j K_rj b_j。

因此平衡后的每个关系行等价于共享输入相关 token 先验 b_t 后再归一化。b 由全部行与配额联合确定，不是原模型的等价重写。与 R20 的矩阵值量子最优运输不同，这里运输的是严格正的标量质量；纯态支撑交为零不会使该问题退化。不能复用 R20 的否定理由。

对任意两行两列，β_rt β_su/(β_ru β_st)=K_rt K_su/(K_ru K_st)。标准对角缩放保留交叉比。这是已知缩放性质，不是新的量子相干项或 L5 定理。选择 log(K) 作为相似度得到上述目标；OTKE 原文使用其自身的核代价 −κ，不能声称公式完全相同。

## 原生电路可达的正反例

两个有效词的第一个特征为 h1=+1、−1，其余特征0。prepare 只在第一层 wire0 的 RY 预激活保留 atanh(1/2)·h1，其余旋转0；因此两词旋转为 ±π/2。40 个效果都用 +π/2，其余角0。两次 CNOT 环构成相同固定酉作用 U，故词态为 U|+> 与 U|−>，效果为 U|+>。全部由原两层三比特电路、有限参数产生，重叠平方为 (1,0)。这里是精确算术构造，没有运行原始浮点电路。

这是分类头特征边界的合成构造；尚未证明真实文本经冻结编码器会产生这两个 h。所有 K 行相同，原注意力为 ((1+ε)/(1+2ε), ε/(1+2ε))。平衡解为 P_rt=1/(RT)，β=(1/2,1/2)。对角缩放证书和唯一性证明见下方。

可令原 value 的第一坐标为 (h1+1)/2，其余0，正类1的 decoder 取该坐标，bias1=0；null decoder=0、bias0=3/4，其他类 decoder=0、bias=-1。原头判正类1，平衡后判null。因此合法的 Born 几何、平衡约束和自由 signed readout 不能保证预测不变或收益。实体角色可在两词标记中保留，不影响已选定 prepare。

同一几何下，改为 value 第一坐标 (1−h1)/2、null bias=1/4，原头判null，平衡后判正类1。这也否定“平衡总会有害”。两例证明收益方向依赖读出和任务，而不是证明当前真实数据的错误原因或训练后方法无效。

对相同行 K=(1+ε,ε)，取 b=(1,(1+ε)/ε)，a_r=1/[RT(1+ε)]，则 diag(a)Kdiag(b) 的每项为1/(RT)，满足所有边缘，故它是上述严格凸目标的唯一缩放解。公共脚本用 Fraction 核验该证书、两例的完整40类 argmax，以及一般2×2交叉比和行条件化代数；它没有数值执行 Sinkhorn 或模型。

## 决策

单标签关系抽取中的40行是互斥候选假设，不是同时需要被服务的40个物理对象；一个词可合法支持多种候选。均匀列边缘也要求每个词消费同样的总质量，尚无任务证据支持。现有结果并未显示“跨关系争用不足”是瓶颈。已知机制组合仍可做有界性能探索，文献碰撞本身不封禁实验；但目前没有足够的任务前提和非平凡理论将该线索选作 L5 机制。

本轮不提交模型任务。若以后发展这一方向，先给出由输入/训练数据确定的配额或非平衡目标、它和错误的可测联系、区别于既有运输注意力的预测，再冻结独立验证。不要直接为均匀配额追加超参数搜索，也不要把检查脚本通过当成新方法通过。
