## 一次真实接口错误及最小收尾

原gen52在uniform第一次前向报错：旧稳定头把mask无条件转Float，与本轮Double值相乘失败。此前七路各1024已完成，uniform没有一次成功更新、没有任何评估。保留原失败记录，gen52释放。

修正只让uniform按输入dtype计算同一masked mean；七路final/latest/result按原哈希复用到新attempt，不再训练。gen53仅训练uniform1024，之后统一评估八路，实际exit0/无stderr，gen53已释放。七路原result/final/latest文件未改，七路模型没有重训；总科学更新仍是8*1024。

既有runner的summary.seconds=107.76仅计算恢复attempt，不能写成全部八路总耗时。原attempt约1199.73秒，加恢复attempt约111.01秒为实际原生执行时间；中间修复间隔另计。

共享源码的一行修正也已针对性验证：旧Float64错误复现，FP32前向最大差0，Float64对直接masked mean参考差2.22e-16，梯度有限且一次更新成功。没有重做单卡/多卡/COS矩阵，没有改变原不可变训练源或重训模型。

一次独立NumPy复算全部八路CE、40/39类F1、正确数、最终状态哈希和全部事前对照，最大指标差8.33e-17；确认全部训练先于任何评估。没有新VALID/TEST、Windows数据/模型/checkpoint文件或COS写入。低成本负向筛选不新增checkpoint长期档案。
