# 关系证据的三个不同问题

两篇原始预印本的选定范围已读：DREEAM2302.08675v1（13页）与Eider2106.08657v2（12页），均读PDFpp1-7，实际查看pp3-4图像。其余附录、完整代码/优化链和原实验复现未审计。本轮没有模型前向、训练、新样本轨迹、私有数组或COS读取；以下不构成L5。

## 原文带来的约束

DREEAM在可训练编码器上，用人工证据及教师生成目标引导实体对注意力；其关系边际化按标注出现次数计权，不能随意改称均匀关系混合或简单二值并集。方法还使用远程监督关系数据，故不是完全无监督证据发现。Eider对原始全文和提取出的证据文本分别运行模型，再融合预测；这包含重新编码，不等同于在已有词表示上改掩码。

两者均为文档级、多标签/阈值式关系抽取。它们的实体对共享上下文、监督条件、数据和完整读出均不同于当前Re-TACRED冻结表示上的关系分支Born赋权。原文结果不能搬作本项目的新效果，也不能把已存在的证据监督/普通融合称为新理论。

## 为什么现有L4不能代替证据验证

1. 人工语义证据：标注者认为哪些原始句子足以推断关系。
2. 模型输入充分性：以该子文本重新编码时，完整模型是否保留所需预测信息。
3. 固定表示局部对齐：保留值层，只改变已有权重和值之间的对应，输出损失是否改变。

当前限定L4支持第三项与原来的任务效用；没有自动验证前两项。冻结编码器参数并不令文本删除后的表示不变；普通证据分数也不是最小充分性或“保留全文分支就必不变差”的定理。Eider的全文分支仍可用是架构事实，并非普适性能保证。
