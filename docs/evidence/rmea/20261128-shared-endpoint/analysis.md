# SEARCH-48 自然共享端点的覆盖与历史表现

同句自然对必须共享同一角色的一端，另一端使用不同的有序实体，并各自存在真实语料记录。两条记录的实体位置碰撞或重复时排除歧义记录。该检查不交换实体角色、不推断逆关系、不把未标注的关系当作无关系。对每条正例和无关系记录只计一次模型表现。

在新小筛冻结的 FIT4096 中，按文本与实体位置有 **442 对／304 句组**可能配对。既有 FIT 标签确认其中 **123 个正例—无关系对／98 句组**，涉及 107 条不同正例、116 条不同无关系记录、23 个正类。只有 5 个正类覆盖至少 5 个句组。123 对中 **122 对共享主体、1 对共享客体**。新选模、资格队列分别有 128、353 个仅按位置推得的几何候选对。几何候选不能当作同样比例的有效正负对。三个新小筛角色之间整句组重叠为 0。

旧 TRAIN 开发的 4,096 条和其原拟合句组无重叠。它与未来选模／资格有 **201 条**同一记录，按整句排除涉及这些角色的句组后留下 3,598 条。该旧开发诊断始终属于既有训练开发证据，未来小筛的独立性另行核验。旧开发中的历史资格暴露必须记入迁移限制。

第一次脚本为重新核旧混淆矩阵，先读过旧开发全体历史标签，包含上述 201 条重叠记录。研究统计已经按隔离组计算。我保留这次审计记录，并修正代码在索引历史标签前就排除整句。修正前后本表完全一致。修正执行未索引新选模或资格标签，不把历史重叠说成清零。

严格隔离的旧开发子集中，正例—无关系天然配对 **145 对／102 句组**，涉及 118 条独立行的正例、129 条独立行的无关系样本、21 个关系类。其中 141 对共享主体，4 对共享客体。原先已封存四臂分数得到：

| 方案 | 正例判对／118 | 无关系误报／129 | 忽略无关系时正类首位命中／118 |
| --- | ---: | ---: | ---: |
| Qdistinct | 62 | 16 | 89 |
| Ddistinct | 56 | 20 | 94 |
| Gdistinct | 66 | 22 | 96 |
| Gcov | 64 | 21 | 97 |

在这个窄子集中，Q 的无关系误报比 Gcov 少 5，正类首位少 8；旧开发全体无关系误报比 Gcov 多 55。两个不同范围均有证据。共享端点这类例子没有复现全体的无关系劣势，故不以它作为原相位存在性分支或其改阈值的任务证据。可作为下一轮的狭义正类竞争诊断，其主体偏置和长尾覆盖不足必须保留。下一步围绕正类首位的差距寻找与已有角色反转、共享查询、图反馈和旧跨词协方差机制不重复的单个假设，并以同输入强经典和去相干作对照。缺乏新的可区分预测时记为不立项。当前没有新方法准入。
