# Two returns through the relative encoding unitary

2026-11-22. Exploratory analytical draft and source prototype. NOT_REVIEWED / NOT_RUN / L5_NOT_ACCEPTED. No automatic training admission.

The completed full protected-context method has ordinary utility but loses to its matched controls. The just-completed frozen local-channel screen also fails. Rather than retuning those transformations, change the quantum object: use the action of the actual encoding unitary, not only its prepared vacuum state.

For native two-layer 3qubit circuit U(a_t), V(theta_r), define W_rt=V_r^dagger U_t. Original p1=|W_00|². New p2=|<0|W²|0>|². Its matched intermediate-dephasing control is pD=sum_j |W_0j W_j0|². Both are binary success probabilities in[0,1]. They retain exactly native parameters, features, utilities, EPS normalization and decoder. They do not form a 40outcome POVM. No classical residual is added. Same complete unitary actions, two passes and active parameters in both arms; only the intermediate dephasing changes. Equal parameter count does not itself prove equal function capacity.

Compute only a_j=W_j0 and b_j=W_0j: a_j=sum_k conj(V_kj)psi_k, b_j=sum_k conj(phi_k)U_kj. Then p2=|sum_j a_jb_j|², pD=sum_j|a_jb_j|². Construct U and V from the unchanged native circuit by evaluating eight basis inputs. Its RY(a+pi*b)|0>=RY(a)|b>, b0/1, so add pi*b to each first-layer Y angle in eight column evaluations, then transpose. No basis-dependent phase appears. The physical learned angles remain pi*tanh(raw); the pi shift evaluates a basis column, rather than changing the learned ansatz. Avoid a[B,R,T,8,8]tensor; cost is about eight native preparation passes plus8component paths for each relation/token.

A. Source-specific failure of factoring only through prepared states.
Let F be the source's directed CNOT ring. Set the relation angles all0, hence V=F². Token first-layer Y angles are0; set first-layer Z0=z, second-layer Y0=pi/2, all other angles0. Then U_z=F RY0(pi/2)F RZ0(z). U_z|0>=exp(-iz/2)U_0|0>, so its density and every original native score are unchanged asz varies. However W_z=S RZ0(z), S=F^-1 RY0(pi/2)F. The source ring has F^-1|100>=|110>, so S rotates the logical span{|000>,|110>} and RZ0 gives opposite phases there. Consequently p1=1/2, pD=1/2, and p2=sin²(z/2): z0 gives0, zpi/2 gives1/2. All nonzero physical angles pi/2 lie strictly inside the native range; raw=atanh(1/2). A numerical fixture must verify actual circuit columns, state-density equality and these probabilities before this claim is accepted.

This is a unitary-versus-state access distinction, not novel quantum physics or a no-classical-simulation result. It does not prove that no differently learned state-based NLP classifier can fit the task. The new head depends on the chosen unitary completion: right multiplication by a vacuum stabilizer may leave the old state unchanged and change the new score. This dependence must be explicit, not described as a property of the old prepared state alone.

B. Same-source non-PSD return similarity.
The symmetric diagonal-one function K2(U,V)=|<0|(V^dagger U)²|0>|² need not be a positive-semidefinite kernel. On the above source, choose three circuits with first-layer Z0=-phi, second-layer Y0=y, second-layer Z0=phi, all else0: A(phi0,y=pi/2), B(phi0,y=-pi/2), C(phi=pi/3,y=pi/2). Relative to the common F², their actions on the same logical span are equatorial SU2 rotations. The proposed exact Gram matrix is

    [[1,1,7/16],[1,1,13/16],[7/16,13/16,1]], determinant -9/64.

Derivation: for two quarter-turns with equatorial axis differenceDelta, relative quaternion scalar is(1+cosDelta)/2 and relative z component is±sinDelta/2. Squaring that relative unitary yields the listed return probabilities. A and B haveK2=1 but different similarities toC; a diagonal-one PSD kernel would identify their feature vectors and force equality. This rules out a common-feature fidelity/PSD-kernel representation of this exact unitary similarity, even with a larger common feature space. It does NOT rule out asymmetric encoders, indefinite classical kernels, different learning parameterizations, or classical circuit simulation. Do not automatically transfer raw-score obstruction to arbitrary normalized attention parameterizations; their scale/gauge conditions need a separate proof.
