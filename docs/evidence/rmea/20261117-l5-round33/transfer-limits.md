# Q-RMEA：准齐次/近齐次优化理论的两项实现条件审查（Round33）

本轮把“有界可学习attention＋可放大分类器”对应到两个原始理论框架，并得到两个具体的适用性反例条件。它们是源码导出的分析工具，没有建立Q-RMEA的优化优势、新方法或L5。原限定L4保持。

## 原始结果及实际阅读范围

[Kunin等，2210.03820v2](https://arxiv.org/abs/2210.03820v2)的Definition3.1允许不同参数缩放率，Theorem4.1要求A1–A7：准齐次、正则性、损失、gradient flow、强可分性、Λ归一化参数收敛及条件可分性。p39 AppendixH明确扩展至多类CE，以平均训练CE<log(2)/n作为强可分条件A10；没有理由仅因当前有40类就排除它。结论是约束问题的一阶KKT点，不是全局最优或任务性能。p7 Cascading Minimization仍是Conjecture5.1。pp17–18讨论非唯一Λ及proper条件，不能任意挑一个方便的分级后省略A7。

[Cai等，2502.16075v2](https://arxiv.org/abs/2502.16075v2)的Definition1同时控制输出、梯度和Euler残差；输出有二次增长界不等于整个模型near-2。pp4–5还要求低风险阈值和其他梯度条件；pp8–9的离散GD结论使用明确的vanilla GD及额外Hessian/阈值条件。p7原文明确把normalization/softmax-attention排除在给出的模块演算之外。该句本身不是对原生Born归一化的反例，需要另外检查。

指定阅读页、7张核对页图及PDF/解析哈希在[reading-receipts.json](reading-receipts.json)。未完成两篇全文证明审计、实验复现或独立理论评审。

## 原生仿射head与准齐次身份

保持attention参数θ_Q不变，原生value(h)=Ah+c，A为64×1024、c为64维；decoder D为40×64，最终bias b为40维。逐关系有效词权重和为1，

    z_r = Σ_t α_rt D_r(Ah_t+c) + b_r。

对任何a∈[0,1]，令θ_Q缩放率0，A,c的缩放率a，D的缩放率1−a，b的缩放率1，便有z(e^{sΛ}θ)=e^s z(θ)。因此原生类确有这种已知准齐次身份。这里不要求attention固定训练，只在这条缩放变换中保持它不变。身份本身没有证明收敛、选择器可达、实际样本可分或AdamW隐式偏置。

## 条件一：内点分级的最高率bias并非必要

下面是完整函数的精确重参数化，而非近似数据拟合。记W=DA，v=Dc+b，构造

    D'=[I_40,0]，A'=[W;0_24×1024]，c'=[v;0_24]，b'=0。

维度全部符合现有64维value接口。对每个关系、每个输入及同一attention，D'A'=DA，D'c'+b'=Dc+b，所以全部40个logit逐一相同。关键是Σ_t α_rt=1：value常数项与最终bias在输出上冗余。这不是删除bias后的重新训练性能结论。

当0<a<1时，上述自然分级中最高率参数只有b。若存在任何可分训练解，构造后仍可分且b'=0；沿准齐次曲线归一化也保持b'=0，于是其Λmax半范数为0。这直接违背p5 A7要求所有分离器的归一化最高率半范数至少为某个κ>0。若样本本就不可分，强可分条件也未满足。故这一内点分级不能直接调用Theorem4.1。

范围：这没有证明每个Λ都失败，也没有排除a=0或1的端点分级；端点涉及未缩放参数的实际归一化收敛，尚未得到证明。没有把p7的cascading猜想升级成定理。该冗余也适用于共享相同仿射head的对照，并非量子独有机制或已测增益的解释。

## 条件二：输出二次有界不保证全局near-2梯度界

给出一个允许输入上的解析证据，不声称它就是实际训练样本。两个有效词的第一个h坐标取0、1，其他输入坐标对本例无影响。effect角度全0，只启用prepare映射到第一层第0个wire的RY权重w，其他准备角为0。在w=atanh(1/2)处，两词RY角分别0和π/2。原生两个CNOT环把|100>依次映为

    100→110→111→011→011→010→010，

而|000>保持不变；所以与全零effect态的Born概率为q1=1、q2=1/2。q2'(w)=−3π/8。令value和该关系decoder的对应系数同时为R，其他value/decoder/bias取0，得到

    z_0 = R² α2(w)，
    (∂z_0/∂w)/π = −R² (3/8)(1+ε)/(3/2+2ε)² ≠0。

当R→∞，完整参数范数为sqrt(w²+2R²)=O(R)，该梯度分量却为固定非零常数乘R²。Definition1对M=2要求||∇f||≤q'(||θ||)，其中q次数至多2，右侧至多线性增长；本例违背这一全局界。若用0号logit减一个恒0对照logit作为标量margin，同一结论成立。

固定解析fixture的CNOT整数路径与有理数系数已执行核验：ε=1/1000000，α2=500001/1500002，导数除π为−93750093750/562501500001，R=1,2,4的比值为1,4,16。它只核验本段代数，不执行原生模型、encoder、数据或训练，不是经验效果、独立理论审查或新贡献。

范围：这排除的是该允许输入上整个函数类的全局near-2梯度前提，并非实测数据的局部条件，也没有排除其他阶数、数据条件化/轨迹条件化理论。更高阶还要重新核对强可分性与homogenization，不能仅把M加大便宣布适用。优化算法仍与实际clipped AdamW不同。

## 对研究方向的影响

当前两项结果收紧了原文适用条件，也避免了“有界分数所以没有任何间隔理论”和“找到准齐次身份所以已证明优化优势”这两种跳跃。它们没有给出量子必要性、对照优势或独立判别证据，L5仍未接受。

下一步停止仅以齐次身份或任意KKT问题作为候选贡献，转向实际有限AdamW下Born准备/effect更新能否产生区别于共享head对照的、预先可证伪的预测。先核对相关原文与可公开核查的现有协议；若只剩相同head的通用优化性质，关闭该直接升级路线。尚未选方法、改变optimizer或启动训练，新全量正式实验仍由师弟完成。
