## 完整匹配错误

- Q 错、三个非均匀对照都正确：867 条，其中正类→无关系 349、无关系→正类 405、正类间误判 113；前两项合计 754/867（86.97%）。
- 四个非均匀模型都错：918 条，其中 Q 正类→无关系 552、无关系→正类 283、正类间误判 83。
- Q 对、三个对照都错：295 条。相干路由既有独有长处也有独有错误，不能只看一边。
- Q 的 1,872 条正类→无关系中，1,658 条的 gold 已是最高正关系 logit。该诊断使用 gold；不是可部署的阈值或预期收益。

结论：主问题优先放在关系／无关系边界的样本依赖可靠性，不能退回统一降低无关系分数，因为两种方向的独有错误都存在。也不能从 no_relation 类型多直接推导多个 null effect 或混态必然有利。全部 40 类混淆矩阵、配对错误和不利结果一并保留。

## 下一项问题与证据边界

下一项可检验问题：本次完整 Q 模型中，实际内部相干对每条 TRAIN 决策的贡献，是否同时包含正确修复和无根据的双向边界翻转？先固定同一 Q 权重与全部 TRAIN，做内部全去相干的配对因果干预，区分“训练出不同模型”与“同权重关闭相干”。它是机制定位，不是选择去相干强度/新读出/新训练方案；不新增 VALID/TEST，不对旧失败配置换名挽救。

仅当该定位给出可由输入识别、内容支持且相对经典对照有价值的错误结构，才选择新插件。已关闭的偏置、null differential、滤波与 word-coherent conditional 等精确配置仍关闭。已知去相干/稳健学习工具本身不是新理论；L3 和新 L4-T 继续未通过。
