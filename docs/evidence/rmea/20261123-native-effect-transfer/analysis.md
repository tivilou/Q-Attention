# 原版存在共享下降方向，但整体CE与正关系表现出现取舍

本轮没有提出替代架构，也没有进行续训。保持原版 checkpoint、输入状态、
分类值和bias不变，仅对40个原生测量电路的480个参数求导，包括无关系类别。
在4192条校准样本上计算平均40类CE梯度，将其负方向单位化并先封印，再检查
4000条评估样本。样本仍来自此前暴露的TRAIN，checkpoint可能训练过它们；
这不是独立泛化或新L1/L4结果。

计算耗时 **125.366秒**，优化器更新数为 **0**，没有步长搜索、VALID、TEST
或COS写入。评估组平均CE沿该方向的导数为 **−0.116523**；两组梯度的余弦
相似度为 **0.787425**。因此，在这个原生参数坐标和指定损失下，存在可跨
两组样本迁移的局部下降方向，不只是逐样本选择标签后才有路由空间。

方向导数是无穷小性质。266个错误间隔增大不表示修复了266个预测，
1143个正确样本间隔下降也不表示它们变成错误。没有报告有限步的准确率或
Macro-F1增益；这更不是量子相位必要性、方法新颖性或L5证明。

## 同一方向的类别取舍

对不可变结果做一次事后算术分解，不产生另一条方向或重新前向。按真实标签
分组而非只看错误，评估侧无关系2623条的平均CE导数为 **−0.258383**，
正关系1377条为 **+0.153702**。校准侧也分别为−0.321025与+0.175052。
因此，当前方向的整体CE下降伴随正关系组损失上升；这与Macro优化可能
不一致，但尚未测量有限步Macro变化，也未证明这是历史所有失败的原因。

评估正关系组的+0.153702中，无关系测量输出变化贡献+0.121363，其他测量
贡献+0.032338。漏报216条的负间隔导数−0.924895中，无关系测量贡献
−0.679449，正关系测量贡献−0.245446。两端均参与取舍，简单固定无关系
测量也未被证明足够。完整分解见derivative-decomposition.json。
该分解使用原版各测量参数只影响对应logit的结构；两块CE贡献与各自
autograd梯度内积一致，最大误差1.11e-16。它是当前固定方向的局部代数
归因，不是一般训练因果结论。

## 核对与边界

原生phi的JVP、固定首8条的logit导数通过唯一固定h=1e-5的中心差分。
全部8192条的原生logit与旧预测一致，argmax逐行一致。评估CE的逐行JVP均值
与独立autograd梯度内积差8.33e-17；校准导数与−梯度范数之差1.11e-16。
独立代码再次核对封印、方向归一化、分组、全部表格和上述两种计算。
两组标签及分区完全相同；没有筛选有利样本、更换损失或参数子集。

静态审查首次指出零评估梯度与空描述单元的边界处理；原BLOCK保留，执行前
修复为null余弦／null均值，精确复审PASS。原生训练、恢复和调度核心未改，
没有重做单卡／多卡／COS能力矩阵。第20代资源已释放，宿主及进程组退出；
原有权重和checkpoint未改。私有方向与预测留在GPU节点，本机只收聚合报告。

下一步保留原版结构，检验两种标签组是否存在可迁移的共同下降方向，并与
简单的两组等权平均损失作匹配比较。多目标梯度工具本身不构成新颖性；
该假设、对照与停止边界另列primary-next-decision.md。原版限定L4保持，
L5理论区别与独立实证仍开放。
