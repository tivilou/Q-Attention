# Q-RMEA：预算受限、面向全量目标的小筛方案 v1

本方案是已冻结的项目设计，尚未证明全量晋级命中率，也尚未接入训练执行器。
原40类任务、独立量子贡献/L4-T目标、历史限定L4及所有STOP保持。

## 样本与计算预算

固定4096条拟合、1024条选模、2048条资格评估，共7168条；旧方案8192+4096=12288条。
全部来自已暴露TRAIN，按原始句子分组，三组无交叉。样本总量减少41.7%，拟合集减半。
每臂最多640科学更新、logical batch128，对应20个小集epoch；最多四臂2560科学更新。
如确需新增技术克隆，最多四臂各一次128样本更新；科学与技术合计上限2564更新、328192样本暴露，不重复补测扩帽。
总GPU时间上限3600秒、campaign2400秒、最多既有两卡、每卡Torch4GiB；全部臂、评估和新增技术测量均计入。
额外选模计算也要计成本，尚未实测端到端提速。成本不足返回暂缓，不追加预算救援。

## 与全量目标对齐

在160/320/480/640保存态上，用1024条开发选模集选择最佳全40类加权Macro-F1，平手最早；所有臂同规则。
选模完成后，2048条资格集只评所选状态一次。资格集、选模集均包含全部40类。
分层抽样补充稀有类，先按TRAIN类别先验形成加权混淆矩阵，再计算Macro；人工补样的原始分数另列为诊断。
估计对象是开发角色池的TRAIN先验重加权效用，不冒充自然TEST效用。
最多四臂分别为Q、独立量子禁用控制、强任务经典参考、同信息/输出路径的强经典替代；可严格证明同一角色时才合并。
新协议不复用不匹配的旧8192/1024/final-only控制分数作为过门依据。

## 晋级与不确定性

预设Q相对每个必要控制的资格Macro差至少+0.01；500次句子组配对bootstrap的最小控制差名义90%区间下限>0；
最后两次选模点对强控制无反向趋势。混合或微弱信号返回defer，不扩样本/种子/预算。
机制测量按具体假设冻结；相干依赖头可沿用fixedQ双去相干CE差>=0.005，但它单独通过不晋级。
这些只是全量投资条件，不是统计确认、量子归因、新颖性或L4-T验收。
历史研究参数、门槛和STOP均不追改。

## 已核验的收益与限制

整个TRAIN最稀有类仅6条/5句子组。新资格集不足10条的类别4个、不足5条的1个；旧4096评估分别为18和6。
覆盖改善来自预定分层结构，同时改变了抽样分布，所以必须加权并单列估计对象；它尚未证明预测力提高。
旧跨侧印证领先Gaussian0.0036457，保存预测的句子组bootstrap90%区间[-0.0217029,0.0408133]。
新门槛在这例上会暂缓，但这是见过结果后的回顾分析，不是前瞻验证。真正可配对晋级全量结局当前有界审计仅0/1。
技术准入直接全量失败、筛掉未跑全量、多seed失败分别记账。前三个完成的新协议配对后复盘；不为凑分母重训旧STOP。

## 实施状态与下一步

新cohort已在数据所在主机物化、哈希绑定并核验原始分组来源；Windows只保留聚合证据。
首版误用旧预测包中未全量填充的group字段，资格覆盖异常时被识别，原件保留；改从原始TRAIN重建33477个句子组，v2通过。
旧runner仍锁定8192/4096、1024步、final-only，未被此设计静默改写。
下一步恢复SEARCH-23的量子信息/学习反馈父层比较；新候选合格后只适配必要的数据/选模设置，完成变更范围审查，才进入新协议训练。
骨干/输入或量子计算角色实质变化时重新声明适用方案，预算上限继续约束；不把当前缓存头方案强套所有方向。
