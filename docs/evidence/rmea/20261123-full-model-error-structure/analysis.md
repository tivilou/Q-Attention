# 完整模型的问题定位：候选关系已排对，却仍判为无关系

[已测事实] 本轮找到更明确的优先问题：**对给定实体对，模型常已把正确关系排在其余正关系之前，却仍让“无关系”胜出。需要修复的是有语义支持的漏检，并保住真正的无关系样本。** 当前没有证明它由哪种量子结构造成，也没有得到可部署的修复收益。

项目输入句子与给定主、客体跨度，冻结 RoBERTa-large 输出逐词表示。五种关系头分别采用均匀、经典 softmax、实数重叠、Q-RMEA Born 权重与去相干权重；对词级关系分数加权，输出包含无关系的40类。历史模型均已完成58,465条 TRAIN、20轮训练，按既定 VALID 指标选检查点，选择轮次各不相同。本轮只回放已有检查点，不更新模型。用当前重建 TRAIN 缓存做固定模型推断，复用之前已完成的19,584条 VALID 推断；另外做固定32例的隔离语义判断。

| 上一检查点 | 本次改变 | 对结论的影响 |
| --- | --- | --- |
| 4轮模型的 TRAIN32 与完整模型的共同开发漏检混合用于问题构思 | 回到完整模型，并对旧32逐项对齐 | 区分训练预算问题与完整模型的剩余错误 |
| 已知四个较强头共同漏检 | 检查正确关系在正关系中的排名 | 区分关系类别错认与关系被拒识 |
| 旧 TRAIN32 语义判断 | 另取完整模型的固定 VALID32 | 新样本只定位问题，不是独立验证或旧失败方法的样本挽救 |

## 固定模型的训练与开发差距

[已测事实] 同一当前缓存、原检查点、float32、无类型规则的39个正关系 Macro-F1（各关系F1的算术平均）：

| 关系头 | TRAIN58,465 | VALID19,584 |
| --- | ---: | ---: |
| 经典 softmax | 0.86669034 | 0.58540633 |
| 实数重叠 | 0.86632009 | 0.55722051 |
| Q-RMEA | 0.80278699 | 0.57917101 |
| 去相干 | 0.79820370 | 0.56435546 |

四个非均匀头共同把正例判成无关系：TRAIN为560/19,704，VALID为1,006/8,338。这个差距说明应检查泛化与证据判别，不能仅凭短预算训练的错误就断言原模型缺少表达能力。它也不单独证明过拟合、训练支持不足或某一因果缺陷。

当前 h 缓存与历史原缓存字节不同；角色、偏移、标签、样本元数据身份一致。仅有的原 TRAIN前2例特征夹具最大绝对差0.017578125、RMS0.000904873；这不是全缓存误差上界。本表是当前缓存上的 split gap，不能改写历史正式成绩或称为原始精确训练损失。不同模型选中轮次不同，训练/开发类别分布也不同。

## 可以具体描述的决策问题

[已测事实] 沿用既定 TRAIN经验类型规则，四个较强完整模型在 VALID共同漏检1,155条正例；其中1,070条真实关系被规则允许。对这1,070条，只比较被允许的正关系类别：

| 关系头 | 正确关系已排在正关系首位、最终仍为无关系 |
| --- | ---: |
| 经典 softmax | 804 |
| 实数重叠 | 827 |
| Q-RMEA | 815 |
| 去相干 | 820 |

其中672条在四个头中都满足这一现象。这是使用标签事后定位错误，**不是无标签选择器、可达上限或预期提升**。排在正关系首位不代表句中证据一定充分。类型规则后的1,155与未用规则的1,006是不同错误集合，不能相减作为修复数。

[机制解释] 优先区分“是哪种关系”与“这对实体是否确有关系”两项任务。前者的相对排序在很多错误中已正确，后者仍拒识；仅继续改变正关系之间的相对注意力，不一定解决问题。此前固定偏置校准及差分读出失败均保留；本轮未尝试另一个阈值或偏置。

## 完整模型真实错误的语义检查

从上述815条 Q-RMEA正确关系首位却拒识的样本中，按输入哈希固定取8例；另取 Q-RMEA正例正确、无关系误报、无关系正确各8例，全局32个不同句子。选择在调用前固定，未替换样本。两次独立上下文的 A6API gpt-6.1-sol / medium 判断仅看句子、主客体和给定类型，隐藏标签、模型预测、分组和另一次答案；64行均合法且齐全。同模型的两次判断不等于独立人类专家。

| 固定分组 | 两次判断共同支持原标签 | 其他情况 |
| --- | ---: | --- |
| 正确关系首位但共同漏检 | 4/8 | 2条共同反对原标签、1条不确定、1条两次分歧 |
| 正例正确 | 7/8 | 1条不确定 |
| 无关系误报 | 7/8 | 1条共同支持模型预测的正关系 |
| 无关系正确 | 8/8 | 无 |

四条得到共同支持的漏检均有句中证据引用；其中2条两次都判断需要共指，1条为同位语，1条为直接谓词。但正例正确组也有2条需要共指；有竞争实体的情况同时出现在误报和正确无关系组。**不能从这个小样本把共指、竞争实体、长句或某个结构定为已证实根因。** 不修改任何存储标签，不把4/8外推成总体可修复比例。

这是实际推断案例检查：私有计算节点的 semantic/selection.private.json 固定案例和原预测，semantic/semantic-results.private.json 保存两次判断与真实引用索引；本地和公开记录仅含哈希、汇总和协议。没有新训练、反向传播或注意力干预。本轮没有生成新的词级 sample-trace.v2，因而只能解释输入—标签判断—最终决策，不能宣称观察到证据如何经过内部注意力成为分数。

## 对旧问题依据的补充

[已测事实] 旧4轮 TRAIN32中的5条“双方支持原标签的漏检”，完整经典 softmax、实数头与 Q-RMEA各已答对4条，去相干答对3条。仅一条亲属关系仍被四者共同判为无关系。完整模型训练见过这些 TRAIN样本，这不是泛化改善证据；它说明旧5例多数不再是完整模型的共同瓶颈。旧报告和失败配置不改写，本记录补充其适用范围。

低频类别的共同漏检比例较高，但高支持类别也有明显错误，例如任职关系有2,136条 TRAIN支持，VALID576条中仍有150条共同漏检。因此“增加少样本类权重”也不是目前已证明的解决方案。全39类支持和错误计数保留在 structure.json。

没有估计完整训练集的实体/模板覆盖：缓存元数据只有每个 split前2行保留词与跨度，其余只有身份哈希和词数；已有8,192行词元子集不能冒充58,465行训练支持。没有为补这个统计搬运原始数据到本机。

## 唯一推荐的下一步

**先为“给定实体对的关系证据足以胜过无关系”建立可证伪的共享判别假设，再选择量子或经典实现。** 需要区分有标签支持的漏检与真正无关系的反例，不能统一压低无关系分数，也不能只增加正关系输出数量。

最小下一步：在本次已固定32例和现有完整模型上，对齐证据引用、正关系及无关系的真实读出项，判断可区分信息究竟在词级价值、实体对归属还是竞争决策中；原标签只用于诊断，预测规则不读取标签或读者答案。只做必要的固定模型诊断，不重跑 baseline。若提出可实现的共享规则，再用稳定插件入口和同输入经典对照做一次冻结预算筛选。

成功门：发现既能预测有证据漏检的修复、又能保住无关系反例的结构性区别，随后以全39类正确标签修复/新损伤及 Macro-F1验证。停止门：只得到已失败的阈值/偏置、事后选词、某一例专用规则、已知恒等式或无差异对照，则不进入全量。资源预估为现有节点的一次有界回放；没有新购买，持续研究授权有效。尚未选择新训练机制，量子收益、理论新颖性和L5仍未证明。
