# Attainable attention and a shared-effect observability audit

Status: exploratory mathematical scope audit; no L5 or task-mechanism acceptance.
The independent builder was blind to this primary route until its pass ended.
Its first route independently converged on attainable measurement changes.
Convergence is useful problem selection, not independent validation of this note.

## Fixed object

Use the executed quantum head, d=8, epsilon=1e-6. For example i and valid token t,
let B_it=|psi_it><psi_it|+epsilon I, S_i=sum_t B_it, and
H_ir=sum_t u_irt B_it. All prepared states, utilities, masks, biases and the other
39 relation effects are fixed. Change only E_r=|phi_r><phi_r|. Then

    alpha_irt(E) = Tr(E B_it) / Tr(E S_i)
    s_ir(E) = z_ir(E)-b_r = Tr(E H_ir) / Tr(E S_i).

Actual depth-two circuit effects are a subset of pure trace-one effects, which
are a subset of mixed trace-one positive effects. These are optimistic outer
relaxations, not equivalent parameterizations of the actual head. Epsilon makes
every denominator positive. The forty effects are separate binary measurements.

## 1. Feasibility is not replay usefulness

For one example, a candidate probability vector beta can be generated by some
mixed effect iff there is Q>=0 with Tr(Q B_it)=beta_t for every t. Necessity uses
Q=E/Tr(E S_i); sufficiency uses E=Q/Tr(Q), since summing gives Tr(Q S_i)=1.
Q cannot be zero. No rank-one or circuit-reachability conclusion follows.

If sum_t c_t B_it=0, every such beta obeys c.beta=0. If ||c||_infinity=1,
then distance_L1(beta_target, feasible_set)>=|c.beta_target|. PSD inequalities
give related one-sided witnesses. For a whole cohort, separate Q_i are
insufficient: one global E must satisfy

    Tr(E(B_it-beta_it S_i))=0 for all i,t, E>=0, Tr(E)=1.

This is known lifted linear/PSD feasibility. Rank/circuit constraints remain.

The independent six-token construction is transcribed in check_attainability.py
using dense NumPy gates and the source's exact hash rule. It has all finite
preparation inputs, fixed entity anchors, and exactly the source circuit.
The shuffled attention is at least 0.1767764301 in L1 from this mixed-effect
relaxation, yet shuffled CE exceeds actual CE by 0.0883882151. Negating the one
true-class utility row reverses the CE direction without changing feasibility.
Thus replay CE damage does not imply a changed, attainable measurement, and
geometry-only infeasibility does not imply positive task damage. This does not
invalidate intervention on intermediate weights for functional dependence.

## 2. Global output preservation can constrain attention

Given actual s_ir, put M_ir=H_ir-s_ir S_i. For any trace-one E', exact
preservation of this relation's cohort logits is equivalent to

    Tr(E' M_ir)=0 for every i.

Proof: multiply each equality of ratios by its positive denominator. For
Delta=E'-E, the equations are Tr(Delta M_ir)=0. If the corresponding real linear
map is injective on trace-zero Hermitian matrices, Delta=0; hence the effect and
all resulting attention rows are unique on this cohort. Full rank d^2-1=63 is
sufficient, NOT necessary for the pure or actual circuit family. If it fails,
nonzero null directions need not be positive/circuit-reachable. With all other
class logits fixed, equal full softmax probabilities is equivalent to equal
selected-relation logits. Equal argmax labels alone is much weaker.

For an orthonormal trace-zero Hermitian basis, define L_ik=Tr(M_ir F_k).
If sigma_min(L)>0,

    ||E'-E||_F <= ||(Tr((E'-E)M_ir))_i||_2 / sigma_min(L).

This is an ordinary singular-value bound. For finite logit shifts delta_i,
Tr((E'-E)M_ir)=delta_i Tr(E' S_i). Bounding the second factor by
lambda_max(S_i) gives a conservative observable logit-error bound. It can be
loose; numerical near-rank is not exact rank or a semantic explanation.

The reproducible source-compatible construction uses 64 prepared states from
four finite single-qubit settings per wire, with second-layer rotations zero.
Their projectors span all Hermitian 8x8 operators after the common CNOT network.
Across 63 synthetic examples the states are the same, while independent value
coordinates select token j as the sole nonzero utility. Fixed affine prepare
and value maps realize this: inverse-tanh angle coordinates and an additional
utility coordinate are available within h's 1024 dimensions. The selected-effect
constraint matrix has rank63, sigma_min=0.04083940725. Each single scalar example
still admits free-simplex, output-preserving attention changes; one exhibited
alternative has L1 distance0.03170799456. Therefore a per-input free-attention
nullspace does not alone prove ambiguity under one shared parametric effect.
The construction is not Re-TACRED and says nothing about its actual conditioning.

## 3. Nearest work prevents a novelty claim

Brunner et al., On Identifiability in Transformers (1908.04211v4), section3,
pages2-4, equation7: free per-input attention alternatives obey output-nullspace
and simplex constraints; effective attention removes output-null components.
Their result does not assert that one fixed shared Born effect realizes every
alternative. The distinction is a scope difference, not a refutation.

Heinosaari, Mazzarella and Wolf, Quantum Tomography under Prior Information
(1109.5478v3), section2, pages2-5, proposition2: informational completeness on a
constrained state set is exactly the absence of nonzero state differences in
the observational orthogonal complement. The shared-effect equality above is
an application after ratio normalization, not a new informational-completeness
principle. Pure-state restrictions may require far fewer than63 scalar probes;
the actual circuit requires its own reachability analysis. We make no optimal
sample-number or quantum-exclusivity claim.

Jain/Wallace and Wiegreffe/Pinter also already address counterfactual attention
and globally trained adversarial alternatives (round-one scoped receipts).
Thus neither feasibility nor cohort identifiability is currently a substantive
novelty claim. Classical normalized overlap models also admit operator lifts.

## Research decision

Keep these as falsification/audit tools. Do not allocate a real-data diagnostic
merely to count infeasible shuffles or compute a generic rank, and do not
reinterpret original fixed-head L4 as an attainable-measurement experiment.
The independent duplication-budget route is also generic normalized pooling
algebra and has no justified natural-text perturbation process; keep it unselected.

The next productive route is empirical mechanism discovery on an existing
training/validation trace cohort, with stronger and weaker classical controls,
before a new theorem or operator. Ask what allocation/utility failure is actually
observed, not what geometry sounds quantum. Any such trace audit is descriptive;
new predictions need independent validation, and changed methods do not inherit
the old L4. No formal test-cohort selection or new full experiment is proposed.
