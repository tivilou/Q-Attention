# 下一步研究入口：全量条件下的公平参照资格

当前两次短比较分别回答了固定1024更新下的参照排序、以及线性去相干训练路径是否改善。前者 Q 不及三个对照，后者相对原 Q 有局部收益但仍不及关键对照。两个固定实验的判定都不变，训练路径候选关闭。

不能从这些结果跳到“原 Q 在完整训练条件下不可能贡献独立效用”。4192条拟合样本只覆盖38/39个正类，16类不足10条；4000条评估只覆盖37/39类。完整TRAIN支持度核对又确认：58465行来自33477个不同句子；最稀有的 per:country_of_death 总共只有6行、5个句子组。任意二分的数据行数约束，都使这个类在两侧较小的支持度至多为3。因此简单重切分并不能保证所有类别都有充分支持，更不能通过删稀有类改变原来的39类分母。

完整原始研究采用20epoch、batch128、VALID选点；当前训练路径筛选为4192行、1024步、batch32、固定末状态。另一个已完成的 native 4epoch/batch32/fixed-final 研究也不是原始协议。即便参数名字一样，也不能把三种训练与选择条件的数值混为一张公平比较表。当前特征缓存的 h 字节与原始研究不同，原完整模型在重建缓存上的回放结果只能单独解释。

下一步不继续尝试课程曲线，也不以新的小切分挽救旧候选。优先准备“原始完整训练协议下，Q 是否仍优于新增的宽12公平经典替代”这一共同参照研究及合作者交付。其动机是已有完整五种子结果中的正向平均差和仍未补齐的容量公平比较，不能称作本次短筛选通过或新方法推广。

准备阶段先锁定原始数据/编码器/源代码、训练与选点规则、全部方法及种子、主要指标和所有关键对比。已完成基线只在输入字节、协议、状态与选择规则相容时复用；不相容时明确列出重算的必要范围，禁止偷换旧指标。新正式运行只通过GitHub交付师弟，当前不启动。固定确认批次不得因显著性不足追加可选种子，不能擅自增加付费资源。

新L3仍要求完整计划内的正向效用、消融和相关公平经典对照。满足后才选择L4-E或L4-T；既有已暴露的TRAIN与VALID都不会因改名而成为独立确认。现阶段没有接受新L3/L4/L5，也不重复审查已稳定的调度、恢复和多GPU核心。

支持度事实来自 full-train-support.json（TRAIN标签/句子计数，无模型前向、更新、VALID/TEST或COS操作），本轮数值与关闭边界来自 summary.json。下一次源码操作应围绕既有全量runner的参数化公平经典插件和准确交付，避免另建训练系统。
