# 原生可学习角度槽位重排的适用边界

固定原生 prepare 的 W∈R^(12×1028)、b∈R^12，角度 a(x)=πtanh(Wx+b)。令 P 为任意12维置换矩阵，候选仅在角度进入原电路前采用槽位分配 P，即电路输入 P a'(x)。取 W'=P^T W、b'=P^T b，则逐元素tanh满足 P tanh(P^T y)=tanh(y)，所以 P a'(x)=a(x)。effect、value、decoder、bias保持原值，原Q与D的所有概率、EPS归一化、signed logits均逐点相同。

该参数对应为双射，故对任意样本/参数成立，梯度按同一行置换对应。正交行置换也保持L2范数。若另行讨论训练轨迹，还需对应初始化、优化器状态和更新规则；本轮没有执行优化器或声称独立训练收益。随机不补偿槽位更改在固定checkpoint可以改变输出，这不等于增加函数类或建立任务先验。

论文的输入是原始有序时间窗，各角度直接绑定具体时间步，且幅度编码也固定依赖整窗；上面的自由仿射层重参数化论证不覆盖它。它也不覆盖对W加任务约束、改变可达电路拓扑、跨token序列编码等更广模型。这里只排除把原生12个自由latent角度重排改名为时间结构迁移。该结果属于已知参数对称性，不计新的非平凡理论贡献。

固定一次横跨层/线/RY-RZ槽位的置换，原生源码SHA锁定；Q/D各一个随机初始化、3×7合成输入、有效长度7/5/1、40effects、81028参数。原生baseline与局部路由器使用同一原生circuit，核对angles/probability/alpha/logits和全部7参数tensor及输入梯度。独立验证只核对置换代数、源表算术、字面执行与hash，不冒充第二个完整电路实现、独立任务确认或外部科学评审。
