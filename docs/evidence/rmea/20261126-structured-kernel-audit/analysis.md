## 对原生Q-RMEA的具体核验

原生输入不是原始16/32时间序列，而是每token上下文h与roles经自由1028→12线性层和tanh生成角度。仅重排12个角度槽位，可由投影层W、b的逆行重排逐点抵消，原电路及40独立binary effects不变。该双射保留Q/D概率、token分母、signed utility输出和对应梯度，故“分组latent角度”本身没有新的结构先验。它不否定真实原始坐标分组或受约束编码，也不证明所有分组方法失败。

在先冻结的合成协议下，Q/D各一次原生随机headforward与一次局部路由forward：前向最大误差0，全部7参数tensor及输入梯度最大5.42e−20，参数hash不变；主审计约0.063秒。未经参数补偿的同一槽位置换确实改变state，说明这不是恒等置换。它仍只是已知重参数化的实现一致性证据，不是新的T、任务收益或独立样本确认。独立验证核对置换代数、源表算术和执行hash，不声称完整电路再实现或外部评审。

本轮任务数据/训练checkpoint读取、训练headforward、优化器更新、GPU/申请、serverwrites、COS及模型API均0；另有2次合成原生headforward、2次合成局部路由forward与2次未补偿circuit端口，全部明确记录。源副本未改。source-only范围扩展只为解决该具体迁移歧义，事前记录于synthetic-protocol，而非候选训练。
