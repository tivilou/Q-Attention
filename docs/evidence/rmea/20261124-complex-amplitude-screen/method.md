# 线性复振幅 Born 读出的待检验假设

输入和任务不变：已有1024维实体标记词特征与4维角色；每个词由共享实线性层生成12坐标，组成6个复振幅并归一化。补两个零振幅后可置于原三qubit状态空间。本次模拟没有执行硬件制备，也不声称制备/查询/采样速度优势。每个关系仍是独立二元秩一测量，Born分数加固定EPS后在词维归一化，汇聚原64维有符号value并沿原decoder读出；没有经典残差旁路。

对实归一化向量 k=(x,y)、q=(a,b)，令 Jq=(-b,a)。已知恒等式为 |<a+ib,x+iy>|²=(q·k)²+(Jq·k)²。q和Jq正交且等长，所以同一个复测量等于实12维中的一个特定二维平面投影。任意每词共同复相位只旋转这一平面坐标，不变更概率。这是常见复实表示，不是新定理或量子排他性。

关键经典对照释放每个关系的第二个query向量，经Gram-Schmidt得到任意二维平面；它从完全相同的(q,Jq)初始化，因此初始概率、logits和共享value相同，但后续可以离开共同J约束。候选/去相干各81028参数，自由平面对照81508参数，后者多480，不宣称等有效容量。它用于检验共同复结构是否是有用约束，不能用候选只胜原实12秩一来归因。另保留原PQC、原去相干、real12、softmax12和uniform五路已完成同协议基线。

经验动机是现有完整Q训练拟合较强而新完整预算泛化低于三个控制，词frame替换也未恢复；这不证明tanh电路是问题。新试验只检验一个不同的状态编码假设，不调frame强度、不挽救旧配置。三路新模型均1024更新，4192fit/4000assessment、seed13、原CE/AdamW/最终状态；先全部训练再评估。若候选不能严格胜全部七个控制，关闭精确配置，不换维度/初始化/epsilon/预算/seed/指标救结果。

CNM: An Interpretable Complex-valued Network for Matching（NAACL2019，DOI10.18653/v1/N19-1420）原文方法及实数消融已读，复状态、Born测量和复实对照是已知先例。其局部密度窗口特征/问答匹配流程不同于这里逐关系词权重/有符号value读出；此差异并不自动成立实质新颖性。即使筛选成功，也只进入独立完整实验设计；当前不接受L3或L4-T，更不以复实恒等式包装T。
