# 输入依赖的无关系参考滤波：误报增多，关闭本轮方案

本轮从原模型的实际错误出发：探索性 TRAIN 评估侧 478 个错误中，418 个跨越
有关系／无关系边界；共享全局阈值的最佳准确率 oracle 也只净修复 12 条。
据此检验一个输入依赖机制，而不是继续替换分类值路径。

保持原生词元量子态、全部分类值和归一化加权汇聚。用原生无关系注意力构成
输入自身的状态二阶矩 N，再把正关系测量向量变换为 unit((N+I/8)^-1 phi)。
无关系输出在同一组固定参数下保持原样；训练时正关系损失可经 N 反馈到
无关系测量参数。对照只将 N 换成其计算基对角线。

三个分支使用同一个固定 checkpoint、相同的新 AdamW 状态和批次顺序，
全部 81,028 个参数均可训练。各做 128 次更新；完整与对角参考在两张
2080 Ti 并行，随后完成原版同预算续训。全部训练结束后才评估最终状态。
总计 384 次更新，脚本耗时 143.434 秒，退出 0，stderr 为空。

| 方法 | CE，越低越好 | 正类 39 类 Macro-F1，越高越好 |
| --- | ---: | ---: |
| 完整参考滤波 | 0.496154 | 0.590671 |
| 对角参考滤波 | 0.455220 | 0.572872 |
| 同预算原版续训 | **0.418078** | **0.612598** |

对角减完整的平均 CE 差为 -0.040935，下 2.5% 组 bootstrap 百分位为
-0.060634；原版减完整为 -0.078076，下百分位为 -0.098854。
完整分支只通过“Macro 不低于对角参考”一项，另外五项门槛失败。
这些重采样是条件于当前模型与暴露 TRAIN 划分的探索性样本敏感度检查，
不能当成独立确认。**关闭这一个 128 次更新、固定正则和初始化的筛选方案，
不换正则、学习率、预算、样本、种子、控制或归一化挽救。**不是方法族不可能证明。

| 错误类型 | 完整参考 | 对角参考 | 原版续训 |
| --- | ---: | ---: | ---: |
| 有关系被判为无关系 | 246 | 241 | 284 |
| 无关系被判为有关系 | 373 | 342 | 224 |
| 正关系之间混淆 | 78 | 79 | 56 |
| 总错误 | 697 | 662 | 564 |

完整参考相对原版少 38 个漏报，却多 149 个误报和 22 个正关系混淆，
总错误增加 133。没有逐词元因果轨迹，不能据此断言具体哪些背景词被压制，
或认定原生无关系注意力就是噪声估计器。

还有一个重要限制：未做本轮续训的固定 checkpoint 在这同一探索评估侧
CE 为 0.331887、Macro 为 0.678963，优于本轮三个分支。由已有全训练权重
在较小子集上用全新优化器续训，连原版对照也退化了。因此本轮比较说明该
固定续训方案没有赢得其匹配对照；不能把结果泛化为所有训练方式下滤波无效，
也不能把续训对照的较低分数当作原版 L4 被推翻。该限制不改变已经冻结的停止判定。

独立机制审查先 BLOCK 两项：配置残留“第 512 次”字样，以及密度参考 oracle
共享了待测构造。执行前已修成第 128 次，并改为从独立原生前向显式构造
加权 ket-bra；重新审查 PASS。原记录保留，失败版本从未执行。
真实数据下参考、前向、梯度、padding 和固定参数无关系输出一致性均通过；
还观察到正关系输出到无关系测量参数的非零梯度。状态端反例验证了滤波
可以损害真正信号，即使对应 Rayleigh 目标改善也不保证分类更好。

最终封印、私有数组、三路 checkpoint、CE、混淆矩阵、Macro、2,000 次
整句子组重采样及全部六项门槛已由独立代码核对；进程组为空，第 18 代
资源分配已通过既有接口释放。稳定训练核心、宿主包装器、保存和调度器未改。
没有重做单卡／多卡／COS 恢复矩阵，没有新编码器、正式全量训练或 COS 写入。
私有预测、训练历史和 checkpoint 留在 GPU 节点；代码与聚合报告归 GitHub。

已知的正则化自适应滤波、Rayleigh 商和输入依赖度量只是工具。本轮未建立
新颖性、独立任务收益、量子必要性或 L5。原版限定 L4 保留。下一步先量化
固定分类值下“任意注意力”和“放松量子测量”各自能修复多少原生错误，
再判断瓶颈在路由还是分类值，不再直接从错误总数跳到另一个模型替换。
