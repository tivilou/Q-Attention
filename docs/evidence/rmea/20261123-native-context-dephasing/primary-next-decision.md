# 下一步：保留原版，检验选择性通道是否移动可判对边界

原版保留，outer 去相位提分配方关闭；六项门槛不能事后更换。CNM 原文方法范围阅读已经核实已有复数／密度／测量先例，但后续近邻全文尚有缺口。

唯一推荐假设：固定原版状态、分类值和 bias 后，选择性去相位是否在真实 TRAIN 上同时造成“任意关系测量也不能判对”的新障碍，以及解除原有障碍。不是再问当前固定测量是否掉分，也不是救回去相位提分。

最小实验在 native-selective-attainability-20261123：既有首8192TRAIN，7950条输入定义可干预样本、全部类别。原版／全部上下文去相位两路零训练推理；对所有正确性翻转，计算8维广义特征值端点。原关系测量被放宽为每个输入可任意选40个独立纯效应，因此负的最优 gold margin 才能排除这个超集中的正确判别，正值不保证浅线路或共享训练可达。

成功仅指两个方向均出现数值可判定的存在性证据；报告全部翻转分母、占比和40类计数。不使用严格区间算术，因此称数值障碍而非精确计算机证书。任一方向计数为零，关闭这次双向假设；不换区域、样本、阈值或 checkpoint。两卡、最多20分钟、预期分钟级；没有优化／模型／COS／VALID／TEST。持续科研授权覆盖，科学代码经既定独立审查后才执行。

这是 Astra/high 有界建议，由主模型检查并决定执行；标准 Rayleigh 工具本身不作为新理论。即使通过，也只支持暴露 TRAIN 上的点态存在性，L5 新颖性、共享可学习机制和独立证据仍开放。此诊断不改已结束的上下文实验及其结论。
