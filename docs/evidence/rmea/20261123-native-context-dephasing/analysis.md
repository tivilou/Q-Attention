# 原版上下文的两个区域都不能简单当作相干噪声

本项目在 Re-TACRED 中预测句子的40种关系，包括无关系类。原模型把冻结编码器的词特征和实体角色映射成三量子比特词状态，以40个分别训练的关系测量计算 Born 分数；分数加 EPS 后在有效词上归一化，再汇聚独立分类值，得到40类 logits。本轮固定已经训练好的原模型，只有推理，没有训练、优化器、新 checkpoint 或 TEST 访问。主指标为39个正关系类别 F1 的等权平均（正类 Macro-F1）；另报交叉熵 CE、混淆矩阵和预测修复／损害数。

与上一轮改变原生测量参数的固定一步不同，本次测量参数、词状态的基态概率、实体状态、分类值和 bias 均保持不变；仅在指定非实体词上执行计算基去相位通道。区间内 bridge 是不相交实体跨度之间的非实体词；outer 是其余非实体上下文；context 为二者并集。区域定义仅依赖输入半开跨度，不依赖标签、词表或预测结果。跨度重叠或任一区域为空时，四条件均保持原样，没有丢弃评估行。

[已测事实] 首8192条已有 TRAIN 映射的资格检查通过：7950条可用、2620条正类，24个正类各至少16条。初次资格脚本误用闭区间，尚未调用模型即发现并修正为源数据的半开区间；失败记录保留。随后在全部19584条开发 VALID 上一次性运行四条件，两卡各9792条。19007条可干预，577条全部条件为恒等。科学推理22.405秒，优化更新0次。

[已测事实] 预声明候选 outer 在 CE 和 Macro 两指标上均未超过原版，六项联合门槛失败两项；它在这两指标上超过 bridge 和 context，只通过其余四项。结论为 `FAIL_CLOSE_CONTEXT_PROFILE`。关闭这一次固定通道／区域／强度测试，不调掩码、强度、种子、checkpoint、评估类别或门槛挽救；也不将它解释成所有局部性学习方法都无效。

[机制解释] 对这个固定读出接口，两种区域的去相位都造成总体损害，不能把实体外侧上下文直接视为应删除的相干噪声。区域大小、内容和位置并未匹配；因此较小损害也不能单独归因于位置。局部密度通道并非真实文本编辑，亦非重新训练的去相位模型。原版从相干项获益的这一固定模型现象，不等于量子必要性、所有样本都获益或新方法的跨种子优势。

[已测事实] 所有原版输出与原实现一致，最大误差7.11e-15；逐行归一化有限响应恒等式误差1.09e-14。每卡首批显式密度通道与高效实现一致，所有577条不适用行的恒等规则通过，源权重不变。独立 NumPy 从 GPU 本地私有预测复算全部指标、混淆、修复／损害和六项门槛，最大指标误差1.67e-16。初版复算器请求了本报告未声明的分组 CE 字段，失败后只修复复算器，保留旧版与错误；科学输出未改、未重跑。执行退出0、stderr为空，第23代调度分配已释放。

本轮未声明逐词案例因果归因，没有物化 sample-trace.v2；不从总体混淆推断个案隐藏过程。私有预测及有限响应数组留在计算服务器；Windows 仅接收紧凑报告，没有模型／数据下载或 COS 写入。稳定核心、运行器和调度均未改。

近邻原文补充：CNM（NAACL2019，10.18653/v1/n19-1420）已包含复数词态、局部密度混合和可训练投影测量；这些组件不能单独作为本项目的新颖性。本项目先测量词态，再形成关系条件的词权重并汇聚独立带符号分类值，与该文先做局部密度混合再测量、池化、匹配的具体流程不同。这只是已经核实的结构差异，尚未形成非平凡理论贡献或完整近邻排除。TIST2022近邻仍只有摘要，普通 HTTP 与浏览器均403，全文缺口保留。

[尚未证明] 全部上下文与两个区域干预的损害并非相加，这本身不能证明跨区域量子协同：共享归一化分母和交叉熵也会产生非加性。基本归一化恒等式仅为工具。原版限定 L4 保留；L5 新颖性、实质理论与独立支持仍未达标。唯一后继研究决策见 primary-next-decision.md，不由这次失败直接推出新架构或全量训练。
