## 已核实的源事实

1. §3、公式3–4：词是复数单位向量，词组合用词投影的混合密度矩阵表示；测量用秩一投影的 Born 期望。
2. §4.1–4.2、公式5–6：词向量范数参与局部窗口混合权重，窗口中的权重经 softmax 归一化；先混合词密度，再进入测量层。
3. §4.3、§5.2.2：共享的可训练单位测量向量产生窗口特征，随后对句子维 max-pool，并匹配问答表示。任务是问答匹配，而非本项目的40类关系条件分类值汇聚。
4. §5.4：原文已有实数替代、局部／全局混合、测量／trace匹配消融。因此“加入复数／密度／可训练测量”不是新贡献声明。

## 我们的解释与边界

源 Q-RMEA 对每个关系逐词计算 Born 分数，再在词维归一化并汇聚另一个有正负号的分类值；它没有直接使用 CNM 的窗口密度特征池化与问答匹配流程。这个顺序和读出差异值得继续比较，但不能由此自动推出新颖性、量子必要性或学习收益。CNM的作者解释与其任务消融不移植为本项目证据。
