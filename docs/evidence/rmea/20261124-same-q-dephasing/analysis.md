# 同一完整 Q 权重的内部去相干干预

所有58,465条TRAIN、固定epoch17的Q-selected权重、原EPS/mask/value/decoder/bias。只把既有`Head`的mode设为`dephased`，使用完整相同参数状态；没有拟合、选强度、新VALID/TEST或改变任务。45.600秒，exit0，独立混淆矩阵重算通过；CPU gen2已按进程组退出证据归还。

- 原Q TRAIN all40 Macro：0.87559004399，CE0.17239059930。
- 同权重全内部去相干：Macro0.73992766192，CE0.36597784788。
- Q正确、干预后错误：5,467条；其中gold无关系318、gold正关系5,149。
- Q错误、干预后正确：974条；其中Q无关系→正类838、正类→无关系65、正类间误判71。
- 两边都错2,637条；总预测改变6,608条。全部40类和不利结果保留。

这是真实实现下对同一权重关闭内部相干的TRAIN定位，证明该已训练模型的许多TRAIN决策依赖相干；不证明泛化增益、量子必要性、实质理论新颖性或新L3。独立训练的dephased模型Macro0.793650，与此干预后0.739928是不同问题，不能混用。

相干贡献在TRAIN上修复多于损害，统一抑制相干缺少依据。损害中838/974落在无关系误触发，支持把“相干对竞争margin是否提供可靠增量”作为下一项训练假设。没有从TEST选择样本/类别/阈值，没有用gold-oracle充当收益。

候选方向仅为问题定义：在既有Q-RMEA中约束相干相对内部去相干参考的gold-v-rival margin增量，并给实数重叠头施加相同cross-term参考和同规则训练。该监督margin工具不是已认定的新理论；需先核对近邻、避免参考分支任意变差来满足约束，再固定一次公平测试。当前尚未实现、未review、未训练；不预设positive、不重新开放偏置/滤波/differential/旧word-coherent配置。
