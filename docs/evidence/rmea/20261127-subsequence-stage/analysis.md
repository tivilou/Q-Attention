## 原任务与本轮变化

原关系分类任务以含有序主客体的句子为输入，复用固定词特征及4维角色；四臂都保留全词值和40类原读出。Q为固定三阶递增子序列相干路由；独立路径去相干D、独立非线性signed-real16与强经典Gcov是必要比较，原任务与冻结研究目标不换。

| 环节 | 旧实际runner | 本轮新阶段 |
| --- | --- | --- |
| 数据 | 8192 FIT / 4096评估 | 4096 FIT / 1024选模 / 2048资格，三角色按句组隔离 |
| 更新与选模 | 每臂1024，终点一次 | 每臂640，160/320/480/640独立选模，同分取最早 |
| 资格评价 | 旧all-arm终点评估 | 选模全部冻结后，各选定状态一次资格集；原TRAIN先验加权全40类Macro、CE及配对组bootstrap |
| 机制 | 旧单去相干 | 同一选定Q参数分别做路径D、末态双D，各自CE差≥.005，互不替代 |

这不是换一套训练核心。原optimizer、backward、worker、checkpoint不改；新适配读取实际已提交更新的回调，写独立选模证据，仍不触发调度。未取得一套新作用于科学任务的Macro或因果结论。
