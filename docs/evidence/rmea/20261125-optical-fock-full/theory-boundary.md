# 本候选的理论边界与可区分内容

当前没有新的T结论。已有光学特征核和Fock输入表达能力研究覆盖了“非Gaussian”“光子数增加表达力”的宽泛动机。单光子Laguerre零点、奇偶twirl、Gaussian局部斜率以及下面的小量展开都是已知工具的直接推论，不能据此接受L4-T。

对于每个d_j<1，有

log K_F = -3 sum_j d_j - sum_j d_j² - (2/3)sum_j d_j³ - ...。

因此六模Fock核相对同斜率Gaussian3的区别包括二阶及更高抑制；若真实学到的所有距离都很小，即便出现收益，也可能只体现局部高阶曲率，而非有限距离零点的利用。全量实验保留Gaussian3与强RBF12，不能只比真空核。当前不据训练中期分数调节缩放、模式或对照。

有限距离零点能产生Gaussian单中心径向核没有的非单调分数结构，但这只是固定编码下的分数族区别。自由学习经典key/query可能重新编码；value/decoder也可能抹掉attention差异。不能把分数零点、注意力秩或固定编码的序关系直接称为完整预测模型的表达/风险优势。项目过去已遇到输出因子化与经典可重编码问题，不能在新光学术语下重复。

奇偶消融只识别本通道移除的奇偶扇区相干整体作用。它也改变混态纯度及对原点的响应；不声称唯一孤立“所有量子相干”。本候选核可精确高效经典求值，六模式/六初始光子不同于原三qubit，注册参数相同不意味着物理或有效容量相同。

研究顺序：完整固定九门先判断任务贡献；失败则关闭确切配置，保留所有结果。全通过后先固定独立确认，再针对同一核心建立任务相关而非纯分数层面的新理论、实质近邻区别、可区分预测、实现一致性及独立实证与内容审核。不得用漂亮的已知光学代数替代这些条件。
