# 角色交换输入资格审计：快捷方案停在训练前

## 结论

这轮没有产生可训练的新 Q-RMEA 候选。只交换四维 roles、保留原缓存 h，再给全部40类套一个反向标签置换，缺少成立前提。停止的是这个快捷方案，不是所有部分关系增强、角色建模或量子方案。原限定L4、gen98–100及全部正负结果保留；完整新L3和L4-T仍未接受。

## 1. 实际输入作用

冻结源码先在主语边界加入 `@`、宾语边界加入 `#`，随后才送入冻结RoBERTa；原词隐向量由子词均值构造。标记虽不直接进入证据池，仍属于编码器上下文。

源码函数端口上，穷举长度2–12的非空、不重叠有序实体span，共6,006组：交换后标记词序列全部变化，原词索引映射不变，二次交换复原；四维roles的 `[1,0,3,2]` 置换误差严格为0。label/metadata不进入此构造。这不是6,006次模型评估，也不证明隐向量一定数值不同；结论是**现有证据不允许假设 h 不变**。若以后设计真正的文本角色反事实，需要重新编码或证明适用的缓存变换，并给Q/D/G相同信息和成本边界。

## 2. 标签和输入域

官方Re-TACRED仓库README确认版本1.1为91,467例、40标签。官方补充材料Table4只列PERSON/ORGANIZATION两种主语类型，而宾语类型还包括TITLE、DATE、NUMBER等。因此，例如PERSON/TITLE交换为TITLE/PERSON后已离开其主语类型域；交换不是整个基准输入域上的封闭群作用。模型数学上仍能接收此类输入，但不等于存在合法任务标签。Table6及AppendixF给出identity语义；这不是全部40标签反向映射的证明，也不认证历史八标签映射的每项语义。

## 3. 复用旧证据，避免重复尝试

旧自然角色反转统计已存在，本轮只核对其JSON算术及来源哈希，没有重新枚举数据：1,242对、837句；历史映射一致1,056、未映射141、不一致45。一致者中identity占878；两个有向关系组仅27+6=33对，占全部配对2.657%，占一致配对3.125%。该统计按观察到的标签筛出一致子集，是描述性证据，不是新冻结训练资格或量子特有失败原因；不据此降低阈值、扩映射或筛样本救援。

另一个31对、低于预设100对而停止的natural-pair-training，是同句/同主语、不同宾语的正负对，不是上述角色反转，保持其训练前停止结论。旧实体均值anchor、实体转移路由、幅相重参数化和controlled-order结果也保持关闭。
