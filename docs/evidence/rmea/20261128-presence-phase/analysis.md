# SEARCH-43：保留一个“相位影响关系存在性、保护正类排序”的候选

**决策：允许一个候选进入隔离实现与技术资格审查，尚未准入科学小筛。** 上一轮同 4,096 条开发样本中，Q 比 Gcov 多 55 个无关系误报、少判对 4 个正例。Q 的 485 个正例错误中，244 个金标本来排在正类首位。这次不重新选择样本或阈值，而问：能否给“是否有关系”的干预一个量子自由度，同时从结构上保护“哪种关系”的条件排序？

## 候选的固定接口与结构预测

保留原单样本输入与掩码、同一原生两层 3 比特词态 `ψ_t`、全部带符号 64 维词值 `v_t` 和全部 40 类。令 `Π₀,Π₁` 是**末层逻辑 wire0 经最后 CNOT 环共同置换后**的两个 4 维扇区投影。一个可训原生状态 `χ` 负责关系存在性，39 个原生状态 `φ_r` 负责正类。它们不是 40 个联合 POVM 结果，不把任何物理失败当成无关系标签。

```
  存在性质量 m_t = 1/4 + |χ†ψ_t|²/2     (1/4 ≤ m_t ≤ 3/4)
  正类身份质量 a_rt = Σ_b |φ_r† Π_b ψ_t|²
  V(w) = Σ_valid (w_t+ε) v_t / Σ_valid(w_t+ε), ε = 原生 1e−6
  g = dᵀ[V(m)−V(1−m)] + b₀;    u_r = w_rᵀ V(a_r) + b_r
  z_null = 0;                   z_r = g + u_r − logsumexp(u)
```

`m` 的测量是合法二元效果；`a_r` 是各类别单独的块平均测量。训练目标仍是原 40 类交叉熵；把它写成存在性二元 CE 加正例的身份 CE 是等价恒等式，不是创新。原贡献假设只在**量子证据形成**：可独立地改变任意有效词的两个扇区之间的相位，正类 `a_r` 及 `u_r` 对所有词精确不变，但 `m_t` 的跨扇区交叉项可变。对固定 Q 在输入去掉跨扇区相干，删除的是这项，不删除块内相干，也不相当于把全部训练对照硬设常数。全40决策仍比较 `g+log max softmax(u)` 与 0，因此不是无条件把 `g>0` 当正类阈值。共享编码器训练能改变两个分支；结构保证是指定相位干预下的不变性，不是该模型相对旧 Q 的任务排序一定不下降。

**经典对照要匹配什么。** 设有效词均值为 `m̄`，则 `V(m)−V(1−m) = (1+2ε)Cov(m,v)/[(m̄+ε)(1−m̄+ε)]`。这条恒等式已独立重算；由此明确存在性分支也是一个输入依赖的归一化协方差池。单靠“互补”或“协方差”不支持新机制声明。独立经典 C 原型使用同样的 `h,roles,mask`，由不同的可训实值词映射和查询产生实16双象限表示，允许存在性跨块项和正类独立块，使用相同的全词值池、同样监督和40类读出。对照 D 用同接口独立训练，但 `m_t` 改成 `1/4 + (Σ_b |χ†Π_bψ_t|²)/2`；正类公式不变。另需在同协议纳入 Gcov；旧8192条 FIT 的历史分数只作参照。C 可以学习这一计算结构，公平问题正是受约束变分线路是否给出不同的学习结果；固定张量的精确复算仅用于查实现。

**与停止项的差别。** 旧互补固定插入用旧每类原分数并观测 3 修复／16 误伤；旧二元 outcome contrast 用旧解码器，26 修复／29 误伤；两者都不复活。本候选不是给旧每类附加补项，而是对所有正类的身份测量固定一个可精确验证的相位不变结构。gen94 只改变先验损失；gen79 分池只拆值坐标，这里两支都保留全部64；SEARCH‑41 的物理拒答不参与本模型；旧同源 [类帧记录](../20261122-class-frame/source-unit-result.md) 也没有这项干预保护。该排重仅覆盖核过的本地近邻，未作完整新颖性裁定。

## 实际人工结果和成本边界

以哈希固定原生 `circuit()` 逐字 AST 运行，将最终单线 RZ 差设置为 π，用可达的两词态（±π/2），两词值在第一维 ±1。两种状态的计算基种群相同；互换相位后，存在性分数从 **+0.999998** 到 **−0.999998**，39 个正类分数的最大差 **0**，同处去相干后存在性分数为 **0**。这验证原线路角度可达，而不是自然文本或旧已训练编码器可达。

[数值脚本](check_presence_phase.py)独立检查稠密效应、完整64维词值及40类输出：全40 logit 最大差 3.56e−15；存在性相位导数 0.00650，中心差分误差 3.90e−11；身份对同干预的导数约 1.24e−14；padding 和协方差恒等式通过。[执行结果](math-result.json)

进一步运行了隔离的[批处理原型](presence_phase.py)。Q、块 D、独立实16 C 在人工 CPU 输入通过 FP32/FP64、三组长度（含单词和 padding）、所有参数张量的非零有限梯度及严格保存／恢复复算。冻结 Q 的块去相干与同权重 D 输出一致，正类分数逐位相同；独立 C 完整读出与稠密复算误差为 4.77e−7（FP32）和 8.88e−16（FP64）。实际注册参数 Q 与 D 均 81,028，C 84,235。试验使用人造初态及 Torch 2.8，未验证目前原生环境 2.4.1、生产初态和实际 Gcov 接线。[原型验证](plugin-result.json)

**成本只够进入资格流程。** 原生词态只制备一次；39 个正类用两个半块内积再平方求和，存在性只加一个8维内积和两个全值池。词数上的计算仍为线性，无递归、矩阵函数、额外量子比特或组合路径。计划同尺寸可复用原40个查询槽和40个64维解码槽（含存在性，含各偏置）的原参数表面计数 **81,028**，有效容量及初态仍待核。旧 gen98 Q 的 129.80 计算秒／1024 更新仅作为同规模操作的保守可行性参考，非新运行的 GPU 秒或速度承诺。累计剩余上限 3256.105 GPU 秒，若用满 2560 科学更新，连开销都不扣的平均也只有约 1.272 秒/更新。须测实际 runner 与全臂开销，绝不凭人工 CPU 放行。

## 下一步

仅此一候选推进原生资格：将已验证的隔离 Q、块 D、同信息独立 C 与原 Gcov 接入现有注册入口及冻结小筛 runner，独立复核实际执行源码、同数据／初始化及有界成本。科学预测是比公平 C、D、Gcov 降低真实无关系误报，同时不牺牲正例正确和正类前3、并通过原加权 all40 Macro 与冻结选择门；固定 Q 块去相干应削弱存在性证据，不动条件正类排序。只定一个同源协议，不扫描块/增益/阈值/seed，先于任何真实更新独立复核，成本不过即暂缓。没有新任务行、训练、GPU 或持出读入，gen98 10/13 继续停止，原限定 L4 保留，新的 L3/L4‑T 仍未达到。
