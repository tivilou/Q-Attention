# A native log-attention-rank witness and its loss limitation

This derivation concerns the class-by-token attention matrix inside one head input, not the final probability matrix over examples and relations. It is an analytical capacity question on admitted H/R features, not a statement about the frozen encoder image, trained checkpoints, task advantage or L5 novelty. One isolated adversarial review checked the derivation and inline pinned source, found no fatal defect, and required explicit target y=0 and arithmetic scope for the loss fixture. These corrections were adopted in a separate reviewed verifier/record, preserving the original review inputs. No native floating-point forward was executed.

Restrict attention to ten valid words and retain all forty relation rows. For the native relation_softmax control, S=QK^T/sqrt(8) has rank at most8. Let C=I-11^T/10 center token columns. Since log(alpha)=S-c1^T, the row normalizers cancel and

    log(alpha) C = S C,    rank(log(alpha) C) <= 8.

This is the familiar log-probability factorization obstruction. It remains a necessary constraint when keys are restricted to the actual affine1028->8 map. No universal-approximation or native sufficiency claim is imported from language modeling.

For a native overlap witness, set theta_i/pi=-1+(2i+1)/10 for i=0,...,9. Every angle is strictly inside(-pi,pi). Use features

    H_i[0]=atanh(theta_i/pi),
    H_i[1]=cos(theta_i/2), H_i[2]=sin(theta_i/2),
    H_i[3]=1 if i=0 else0, other coordinates0.

Rows8/9 can carry subject/object membership, so the ten rows contain8context+2entity words. Role coefficients in the witness selectors are zero. The first ten effects use the ten grid angles; the remaining thirty repeat theta_0. Thus no relation row or token is silently removed.

Set prepare.W[0,0]=1 and other preparation coefficients/bias zero. Set each effect's only nonzero raw parameter to atanh(theta_r/pi), at first-layer first-wire RY; all other angles are zero. The same two CNOT rings act on every state/effect. Their common unitary cancels in the overlap, giving

    q_ri = cos^2((theta_i-theta_r)/2).

Every parameter is finite. No RZ phase is needed. The native real_overlap control EXACTLY reproduces this kernel: let its affine key select H channels1/2 into two of its eight coordinates, and set query_r=(cos(theta_r/2),sin(theta_r/2),0,...,0). Keys/queries have unit norm in exact mathematics. Hence this construction is not quantum-exclusive.

Write A=1/2+epsilon, B=1/2 and epsilon=1e-6. The first10x10 raw-weight block is the positive circulant matrix

    K_ri=A+B cos(2pi(i-r)/10).

Every row normalizer is10A. Let Delta=sqrt(A^2-B^2), t=B/(A+Delta) and C0=(A+Delta)/2. Then 0<t<1 and

    A+B cos x = C0(1+t exp(ix))(1+t exp(-ix)).

Its logarithm has an absolutely convergent Fourier expansion

    log K(x)=log C0 + sum_{m!=0} (-1)^(|m|+1) t^|m|/|m| exp(imx).

At nonconstant discrete mode j, the circulant eigenvalue is ten times the sum of these coefficients over m congruent to j modulo10. Since10 is even, all such aliases have the same parity and therefore the same nonzero sign; at least one coefficient exists. Every mode j=1,...,9 is nonzero. Centering kills only the constant mode, so

    rank(log(alpha_Q) C)=rank(log(alpha_real) C)=9.

The extra thirty duplicate effect rows preserve that rank. Exact nonrepresentability by the given rank8 dot-softmax attention follows. This is a single finite input witness; it is not strict inclusion of entire function families, a claim of superiority, a generalization theorem or evidence of task benefit.

In contrast, the ORDINARY unlogged overlap attention matrix has rank at most3, because K is generated by constant/cosine/sine features and row scaling preserves rank. Log-rank and ordinary attention rank must not be confused.

For this chosen dephased source, the common CNOT operation is a basis permutation. Removing off-diagonal terms yields

    q_dephased,ri=1/2+1/2 cos(theta_r)cos(theta_i).

The grid has only five distinct cosine values, each in a mirror pair. There are only five distinct token columns even after logarithm; centering makes their sum zero, leaving rank at most4. This bound belongs to THIS construction, not every dephased native head. Coherent real overlap can therefore differ here from this dephasing while remaining exactly reproducible by the real classical control. Neither necessity of RZ phases nor quantum-specific task attribution follows.

To show why capacity is not a loss theorem, keep this same attention and choose only value.W[0,3]=1, zero value bias, and only decoder[y,0]=s with s=+1 or-1. Other39 decoder rows and all class biases are zero. The target logit is s*alpha_y,0 and the other39 logits are zero. For y=0,

    alpha_Q,y0=(1+epsilon)/(10(1/2+epsilon)) > 1/10=alpha_uniform,y0.

The complete40-class target CE, log(exp(z)+39)-z, strictly decreases in z. Thus s=+1 improves CE versus uniform, while s=-1 worsens it, with the SAME high-log-rank attention. The matched real-overlap head has the same result. All maps fit the actual finite native value/decoder parameterization. The exact signed logit gains are +/-50000/500001. No subsetting of classes, binary-softmax approximation or numerical rank threshold is involved.

The original [Yang et al. v1](https://arxiv.org/pdf/1711.03953v1), pp1-4 read and pp1/3 visually checked, already frames low-dimensional dot-softmax through row shifts and matrix rank and uses a nonlinear mixture to obtain higher log-rank. The file is the November2017 under-review preprint, not a verified final proceedings version. Its appendices, experiments and code were not audited. These facts make generic softmax-bottleneck removal a known starting point, not a substantive novelty certificate for this witness.

The directly attention-specific [Bhojanapalli et al., ICML2020](https://proceedings.mlr.press/v119/bhojanapalli20a/bhojanapalli20a.pdf), pp1-3 read with pp1/3 visually checked, also analyzes head-size restrictions on attainable attention and separates that capacity question from value/readout identifiability. Its sufficient representation statement assumes full-column-rank token features and a positive column-stochastic target. Those conditions and its Transformer architecture are not transplanted to our engineered class-by-token output head; only the nearby rank-obstruction concept is used. Later proofs, experiments and code were not read. A specialized overlap witness is therefore not sufficient evidence of substantive nearest-work novelty.

This construction is useful for a prospective structural probe, but it leaves the central research question open: what NEW constraint or mechanism links the actual signed readout and learned steering to task risk, with a distinction from nearest original methods? Existing accepted fixed-model alignment does not by itself establish that higher attention rank caused the total utility gain. No stopped experimental family is revived and no new formal run is authorized by this derivation.
