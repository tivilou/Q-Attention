# SEARCH-46 · 保留双扇区等价实现，淘汰三比特乘积态替代

**原相位存在性构造保留一个等价执行原型，科学小筛仍暂缓。** 已有 gen98 的无关系误报差与正类排名差说明须同时看两端。本轮选择保留相同作用、全64维词值、40类、独立经典、块去相干和 Gcov。另一条路线虽然省掉逐词纠缠门，但有完全等价的公平经典参数化，且没有另立的任务机制。

## 保留路线：在最后一轮共同置换之前计算

设 \(P\) 是同一末端 CNOT 环，\(z=P\widetilde z\) 是原词态，\(q=P\widetilde q\) 是查询，旧扇区投影为 \(P B_s P^*\)，其中 \(B_s\) 在环作用前的基底上按 wire0 选择两个块。严格有

\[
q^* P B_s P^* z = \widetilde q^* B_s \widetilde z.
\]

原两个掩码把所有项置零后仍按 8 维做两次乘积。新算式在置换前直接取两个连续的 4 维块；保持每类质量、词归一化、全64维读出、40类 logits、Q 和块去相干的作用，C/Gcov 仍为独立对照。原生第一层由全零基态出发，直接构造三线乘积振幅；三次不同线 RZ 与其余线 RY 对易，合并为一次联合相位计算。第一轮 CNOT 环合成一个索引表，最后共同置换在内积中消去。实16对照保留自己的参数和输入，同时把每扇区的实部、虚部重排为一次实数矩阵乘法。没有把 Q 的中间结果喂给经典。

- 按稠密收缩的名义运算计数，Q/D 从每词 **640 降到 320 个复数乘加**，实16从 **2,560 降到 1,280 个实数乘加**，原线路显式 CNOT 索引访问从六次到一次。这里仅计算重排的算子，不把全模型成本算成减半。
- 原参数逐项加载。人工测试覆盖 FP64、FP32、单词、非连续掩码、完整的 2 个存在性池、39 个身份池、注意力、logit 和全部参数／输入梯度，以及固定 Q 块去相干。在本机 FP64 的最大输出误差 **8.89e−16**，FP32 **4.77e−7**，FP32 参数梯度最大差 **2.38e−7**。同一次新实现的固定 Q 与块去相干仍给逐项相同的原始正类分数。数学等价不代表有限精度下与原实现逐位相同，近并列类别要在原生入口核对。
- 同形状、单线程、暖机后交替比较，实16的收益明显小于 Q/D。以下比率来自不同机器上的人工 CPU 切片；算子融合、显存访问及 CUDA 同步可能有不同结果。[本机 CPU 核验](cpu-result.json) · [原生 Torch CPU 复算](native-result.json) · [独立评审初稿](review.json) · [独立复审](review-r2.json)

独立评审要求区分原物理分扇区与输出端的单线去相干。新回归测试固定其他角度为零，末轮 wire0 的 RY 为 \(\pi/2\)，并取词态等于查询。最后一环把 \(|100\rangle\) 送到 \(|011\rangle\)。保留的原控制给存在性质量 **0.50**，而对输出端 wire0 去相干给 **0.75**。改写继续使用冻结的环前扇区，两种操作的范围已经在源码和报告中标清。

实测新/旧时间中位比（Q、块 D、实16依次）为本机 **0.564 / 0.599 / 0.976**，原生 Torch 2.4.1 CPU **0.605 / 0.610 / 0.961**。独立复审 **PASS**，无必修项，范围为源码。

## 淘汰路线：去掉逐词纠缠与第二层的三比特乘积态

这一路保留同一存在性和正类读出，但把词态和查询都写成三条独立的 \(R_z(\phi)R_y(\theta)|0\rangle\)。对第 \(j\) 个比特，记

\[
d_j=(1+\cos\theta_j\cos\theta'_j)/2,\qquad
k_j=d_j+\tfrac12\sin\theta_j\sin\theta'_j\cos(\phi_j-\phi'_j).
\]

则存在性重叠为 \(\prod_j k_j\)，身份的块去相干重叠为 \(d_0 k_1 k_2\)。直接用同输入、同参数的经典三角函数求值，会得到相同的损失、值池和梯度。在人工输入上，40类输出复算差 **4.44e−15**，全部角度梯度差 **3.91e−14**。这个精确反事实只覆盖所提乘积态和读出。公平比较须让经典对照具备同一三角交互；所提路线在该对照下没有独立预测。

数据编码频谱受生成元和编码门制约的已有结果见 [Schuld、Sweke 与 Meyer 原文 v2](https://arxiv.org/pdf/2008.08605v2)。上面这条端到端恒等式在本轮单独推导、核对；并未援引原文的表达能力结论去推断 Re‑TACRED 效用。
