# 完整头引理的近邻、反解释与真实特征前提

## 1. 最近工作究竟覆盖什么

2610.25341v1 的单层模型使用固定查询、布尔词及位置嵌入；每个头经线性读出成为有系数约束的线性分式原子。其定理2清除正分母得到次数上界，定理5将对称布尔函数头数与 Hamming 层级的符号切换数相联。2608.04243v1 的定理2及引理7–8给出无位置嵌入设定下的多头/多项式读出阈值次数界。

我们上轮的连续两词仿射特征曲线上，清除两个 logistic 正分母后得到四个至多一次系数的实指数项；非零函数的七零点界仍不是上述布尔定理的直接实例。这个差别保留了技术命题，不自动产生顶会级贡献。清分母、低复杂度函数和符号切换的证明框架已有先例；傅里叶编码也已有原文记录。当前将它保留为经过机制审查及原代码夹具验证的技术引理，不作为已经成立的 L5 核心。

## 2. 余弦经典解释精确复现同一夹具

令 theta=pi*tanh(x)，q_±(x)=(1±cos(4theta))/8，固定锚词的 c=1/8，epsilon=1e-6。经典非线性打分

    s_±,1(x)=log(q_±(x)+epsilon), s_±,2=log(c+epsilon)

接原来的 softmax、词值(1,0)及两个类别读出，得到与上轮构造相同的 z_±=(q_±+epsilon)/(q_±+c+2epsilon)。其他38个类别仍可用零读出和-2偏置。因此全曲线函数相同，并非 softmax(cos) 的近似。

这里只用 scalar math 核对保存的九点结果，概率和 logit 的最大绝对误差均为1.1102230246251565e-16；没有模型调用。该评分器超出受限 affine-key 基线，所以它不推翻七零点分离，也不证明训练后的两个方法等效。它说明九点测试区分不了量子相位构造与一个显式余弦特征；经典可模拟性本身不取消量子方法的任务价值。

## 3. 自然高维特征还有一个插值障碍

这是条件线性代数命题，不是已测到的自然数据性质。取两词输入，锚词 h0 固定，另一个词取 h1,...,hm。假设 D 的第 i 行是 (hi-h0)^T，且 rank(D)=m（因而 m<=1024）。为任意二元标签设置 l_i=±log(3)。满行秩保证 Dw=l；另取 Dv=1。共享实际值层可用第一坐标 v^T(h-h0)，两个目标类读出都取该坐标，因此词值为(1,0)。

实际八维键只需第一行 w，其余为0；两个关系查询分别取 ±sqrt(8)*e1。softmax 第一词权重为 sigmoid(±l_i)，即两类的(3/4,1/4)或(1/4,3/4)。两个类别偏置取0，其余类读出0、偏置-2。这个完整经典头对全部 m 个点有严格间隔1/2，不需要增加键维度。

当前九点构造的 D 恰为秩1，因而不满足该条件。对真实特征，是否有足够多沿相同低维方向的点、垂直残差能否被有限范数的键利用，均未测量。在上述忽略角色坐标的构造内，Dw=l 的最小范数解为 D^+l；近共线时其范数可能很大。这不是对所有包含角色/其他特征的参数化所作的最小范数结论。因此“近似曲线”还必须明确范数/间隔/噪声预算，不能把九点标签直接搬到高维特征后宣称分离。此命题不是泛化或训练成功定理。

## 4. 一个应避免移用的精确集合论断

1805.10829v1 第6页定理4用常数位移趋于正无穷证明 softmax 包含在 sigsoftmax 像中。有限参数的像和其闭包需要区别。令 u=(-1,0,1)，S=span{u,1}，目标 p=softmax(u)。若有限 a,b 的 sigsoftmax(a*u+b*1)=p，则 g(a*u_i+b) 必须等于 u_i 加同一常数，其中 g(z)=2z-log(1+exp(z))。

g''(z)=-sigmoid(z)(1-sigmoid(z))<0。若 a!=0，严格凹性给出 g(b)>(g(b-a)+g(b+a))/2，与目标三个对数坐标的中点等式矛盾；a=0 只产生均匀分布，也不等于 p。因此这里有限参数的精确包含不成立；其极限可近似目标。该反例只针对精确像包含的移用，不否认该文非线性升秩定理3。我们也不把极限、闭包或数值近似当成原代码的精确等价。

## 5. 下一条有界线索：关系—词对数比瓶颈

以下是未独立复审的解析研究草案，不是已选新实验或新颖性主张。对同一句话、固定有效锚词0，定义 L[t,r]=log(alpha[t,r]/alpha[0,r])。实际经典八维键/关系查询给出 L=DeltaK*Q^T/sqrt(8)，故 rank(L)<=8；这里约束的是对数比矩阵，不能误说 softmax 后的权重矩阵秩也<=8。

原三量子比特两层构造的 token 态在000和101上的幅度为 exp(-3i*theta)/sqrt(8) 与 exp(i*theta)/sqrt(8)。末层对第三比特施加 RY(pi/2)、RZ(phi_r)，再接原 ring，能制备 effect=(|000>+exp(i*phi_r)|101>)/sqrt(2)。于是 q[t,r]=(1+cos(4theta_t-phi_r))/8。

取偶数 m=40，phi_j=(2j+1-m)*pi/m，theta_i=phi_i/4，所有角均在严格有限可达范围内。加同一 epsilon 后，G[i,j]=log(c+cos(2pi(i-j)/m))，c=1+8epsilon>1。令 rho=c-sqrt(c^2-1)∈(0,1)，则

    log(c+cos(t))=constant+2*sum[k>=1]((-1)^(k+1)*rho^k*cos(k*t)/k).

对于每个非零离散 Fourier 模式 k，m 为偶数使所有同余项的符号相同，系数严格非零。取一个相同相位的锚词并对每列减锚词值，常数模式被去掉，得到 rank(L)=m-1=39。这里可构造40个词加1个锚词、40个独立关系 effect；epsilon 保留，未把 effects 假定为 joint POVM。此处仅为解析推导，未执行新电路或自然数据验证。

但“非线性正分数的 log 可以升秩”早已有 MoS/Sigsoftmax。简单实数 nonlinear scorer 也能得到同一性质。秩39只涉及注意力分布，不自动约束重新学习后的值层/解码器，不推出分类或 Macro-F1 收益。旧五种子相比 relation_softmax、real_overlap、dephased 的均值差分别+.0024743、+.0049218、+.0034837，三个95%区间均跨0；既没有确认优势，也没有确认等效。

继续这条线索需要两个实质条件：自然训练头确有稳定、超出简单经典解释的结构；该结构穿过实际值/读出后仍对独立任务预测必要。必须先比较最近工作并形成有区分力的前提和审查契约；不能只再跑一个 rank39 夹具或把通用秩工具包装成 L5。没有新的正式运行授权或数据保留变更。
