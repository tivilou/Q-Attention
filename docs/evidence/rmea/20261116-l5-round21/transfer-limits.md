# 决策校准、任务量化与有限预算读出：迁移审计

本轮找到的是下一问题的边界，尚未形成 L5 贡献。三篇原文均核对精确版本并阅读选定范围；没有复现其代码或实验。旧限定 L4 只支持原模型的任务效用和局部权重—值对齐，不认证校准、量化或有限测量算法。

## 1. 实际对象与两个不同的概率

不可变源 `a4dfe1fd1966418a578492b4bd1038a27cfc7ead:experiments/rmea_semantic_probe/legacy/rmea.py` 的 L54–67 使用三比特纯态、40组独立二元效应。对固定输入的有效词集，有

\[
q_{rt}=|\langle\phi_r,\psi_t\rangle|^2,\quad
D_r=\sum_t(q_{rt}+\epsilon)>0,\quad
\alpha_{rt}=(q_{rt}+\epsilon)/D_r,\quad
z_r=b_r+\sum_tu_{rt}\alpha_{rt},\qquad\epsilon=10^{-6}.
\]

`u` 来自输入词表示的值层和带符号解码器。`alpha` 的坐标是词，不是关系标签。最终 `softmax(z)` 才是标签空间上的预测概率；40个二元测量也不自动组成一个40结果 POVM。本轮只读源文件，未导入 Torch、调用模型或读取私有数组。

## 2. 决策校准：可借用问题，不能借用保证

[Zhao 等，2107.05719v1](https://arxiv.org/abs/2107.05719v1)，PDF pp3–8、16–17：损失为 `ell(Y,a)`，不直接依赖 X；决策规则只通过预测概率选择动作。保证是总体平均损失，不是每个样本；无遗憾的比较对象是指定预测概率上的决策规则类。论文明确排除了额外读取 X 的规则。

一个检查适用范围的已知反例：X 在0、1上均匀，Y=X，而预测恒为(1/2,1/2)。该预测完全分布校准。若决策额外读取 X 并输出 X，真实0/1损失是0；从恒定预测模拟标签得到的损失是1/2。这没有反驳原文，而是说明删去其信息边界会使结论失效。

因此存在两条必须分开的映射：

- 把 `alpha` 当标签后验：坐标和随机变量不匹配，且读出还访问输入相关的 `u`，迁移没有成立。
- 把最终 `softmax(z)` 当标签后验：普通分类变量映射成立，但本项目没有测量或认证决策校准。交叉熵训练、较好 Macro-F1 和旧 L4 均不蕴含该性质；新增重校准器是方法变化。

PDF p6 的固定损失至多 K 支撑压缩按该损失的动作区域取条件均值；不是一份对任意未来损失通用的词压缩。pp7–8 的多项式样本保证也不等于无条件高效计算：内层最坏线性分区搜索在理论和实践近似之间存在明确区别。p7 的近似条件包含绝对值，已通过渲染核对。没有把这套性质升级为 Macro-F1、逐例或量子机制保证。

## 3. 任务量化：预算围绕任务，但硬件模型要对应

[Shlezinger 等，1807.08305v2](https://arxiv.org/abs/1807.08305v2)，PDF pp7–9、13–16、20、29–30：有限比特、线性模拟前端、相同标量 ADC、数字后端以及已知联合统计，目标是估计任务参数的均方误差。

其正面启示是：预算配置应围绕最终需要估计的任务量。它不证明当前 Born 权重是最优任务表示。p9 的条件均值/不可约误差分解使用已有 MMSE 工具；硬件受限最优设计另有条件。Lemma1 的线性 MMSE 映射和加性不相关抖动噪声需要无过载；不相关不等于独立，源文 p15 也说明无界输入下无过载只是小概率近似。没有借此宣称高斯输入上的无条件精确最优。

当前项目没有该 ADC 链。把模型的非线性归一化、分类损失换成线性均方估计，会改变所证明的对象。即使分数均方误差很小也不单独保持决策：两类分数(a,0)与(0,a)，a>0，平方差2a²可趋于0而预测相反。这是标准边界反例；需要额外间隔条件，不能作为新定理。

## 4. MCA 已覆盖的预算思想

[Kim 与 Ko，2201.12854v1](https://arxiv.org/abs/2201.12854v1)，PDF pp1–4，pp3–4均已渲染核对：已知注意力矩阵 A，近似 `Y=AXW` 的值投影。其基础是已有随机矩阵乘法；可预计算的采样分布由 W 的行范数决定，词的采样预算取决于 A 相应列的最大值。

原文式(9)给出 `sqrt(r_i)=n*max_j A[j,i]/alpha`；Theorem2 给出期望输出范数误差界及带 `1/delta` 的概率界。它不是指数尾集中、不直接保证分类不翻转。本文尚未检查源代码中的整数取整、最小预算或 CUDA 行为，不能把连续预算公式视为已验证的实现合同。原文的 GLUE/FLOPS 结果没有作为本项目效果。

所以“重要词多算、次要词少算”已经有直接近邻。它与未知 Born 概率上的采样决策并不完全相同，但这个区别本身没有建立新颖性；还要查最佳动作识别、结构化采样、比值估计和任务感知误差控制。

## 5. 保留的探索问题与最小可检查结构

**问题，非所选算法：** 若将来明确采用有限次数的量子测量，能否直接认证最终分类动作，并根据带符号值与竞争类别分配测量，而非逐项准确估计词权重？

一个可供近邻检索的初等改写：对固定分数阈值 h，令 `c=h-b_r`。由 `D_r>0`，

\[
z_r\le h\quad\Longleftrightarrow\quad
\sum_t(u_{rt}-c)(q_{rt}+\epsilon)\le0.
\]

这是分式阈值的标准半空间改写，**不是新定理**。比较两类时可以引入公共 h，但这不自动给出全局凸优化、最优采样、有限样本停止或计算效率。未知 q 和最优分配不能当成免费先验。普通 Neyman 分配、误差传递和最佳动作识别的 KL 下界也不能仅换变量名就作为 L5。

进入这条问题前，必须同时解决：

1. **访问模型：** 现有状态只有8维且线路参数已知，允许经典模拟时无需靠采样才能知道 q。测量专用接口可作为未来执行模型，但不能偷偷替换当前实现来证明样本必要性；经典可模拟本身也不否定研究价值。
2. **可行替代：** 实际 q 来自共享三比特线路与效应。对自由 `[0,1]` 立方体的统计下界不能直接认证线路约束下的下界；不实现的替代实例会给出错误难度。
3. **同一贡献：** 若近似读出保持原决策，桥接条件必须真实成立；若改变预测，则旧 L4 不认证新方法。资源节省还应计入编码、制备、值加载、控制及读出，不能借旧 Macro-F1 宣称硬件优势。

Round15 已完成已知量子均值估计/比值误差/间隔保证的适用性审计，本轮不重复、不重新命名该结果。下一步只读结构化最佳动作识别的原文，并尝试构造满足原生线路约束的解析替代；如果仅剩通用工具组合或没有自然执行需求，关闭这个具体有限测量线索，继续寻找任务相关结构。
