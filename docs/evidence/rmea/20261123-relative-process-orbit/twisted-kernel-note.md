# 双次返回的显式不定核表示

状态：数学推导与小矩阵恒等式核对。当前全量实验继续使用冻结源码、预算和判定门；本文不是任务效果、近邻新颖性或 L5 验收。

## 结论及其意义

双次相对返回并非“没有单对象特征表示”。它有一个明确的单对象过程特征和固定交换算符，其概率核可写成两个 PSD 核之差。更具体地，令

    W = V†U,
    K(U,V) = |(W²)00|²,
    H(U,V) = |Tr(W)|² |W00|²。

对任意 d 维酉矩阵，(H+K)/2 与 (H−K)/2 都是 PSD 核。因此在任意有限输入集上有 −H ⪯ K ⪯ H。H/d² 则是“归一化 Choi 态保真度 × 准备态保真度”的普通 PSD 核。

这把最近的表示层对照具体化了：当前读出有别于只看 U|0> 的固定保真度读出，但过程信息和同准备态分支敏感性也能出现在普通 PSD 核中。原始 Gram 非 PSD 以及分支敏感本身都不足以成为 L5 创新点。剩余价值取决于特定返回路径归纳偏置、任务效果及可区分预测，而不是给已有结构换名称。

## 命题与证明

用三个索引定义单对象向量

    f(U)_(a,b,c) = U_ab U_c0,
    (P f)_(a,b,c) = f_(c,b,a)。

P 是固定自伴酉交换，f(U) 的长度为 d³，||f(U)||²=d。直接缩并得到

    <f(V), P f(U)> = <0|V†U V†U|0>。

记 ρ_U=|f(U)><f(U)|，并按交换共轭分成

    D_U = (ρ_U + Pρ_UP)/2,
    O_U = (ρ_U − Pρ_UP)/2。

两者都是 Hermitian 算符，分别是共轭 P 的 +1/−1 特征空间分量，故在实 Hilbert–Schmidt 内积下相互正交。于是

    K(U,V) = Tr(ρ_V Pρ_UP)
           = <D_V,D_U>_HS − <O_V,O_U>_HS。

另一方面，

    H(U,V) = Tr(ρ_Vρ_U)
           = |<f(V),f(U)>|²
           = |Tr(V†U)|² |<0|V†U|0>|²
           = <D_V,D_U>_HS + <O_V,O_U>_HS。

定义 K_+=<D_V,D_U>_HS，K_−=<O_V,O_U>_HS，它们都是真实特征 Gram 核，故 PSD。相加相减得到 K_±=(H±K)/2。任意有限样本上的 H±K 均 PSD，从而得到 Loewner 界。证明不要求编码器角度一般位置，也不依赖其可学习参数个数。

由 K(U,U)=1、H(U,U)=d²，还得到

    ||D_U||_HS² = (d²+1)/2,
    ||O_U||_HS² = (d²−1)/2。

这是一个显式分解，不声称唯一、最小维、最小范数或等于有限 Gram 的谱正负部分。K_− 作为 PSD 核仍可有负的非对角元素，不能把它直接当作非负注意力概率。

## 同准备态分支并不排除 PSD 过程核

沿用原生线路的分支例子：相对酉矩阵在一根线上为 W=RZ(π/3)RY(π/2)，其余线为恒等。对右侧 Z 分支，native 概率均为1/2；K 从1/4变为3/4，而 H/d² 从3/16变为1/16。这个普通 PSD 过程核也观察到了分支差异。

因此，既有 TRAIN64 分支诊断即使为正，也只能说明该 checkpoint 的分支读出在该 TRAIN 切片上与监督损失有关；它不排除 H/d² 这类过程核，也不证明非 PSD 性的任务必要性。当前全量实验未加入这项新对照，本文不把它事后加入原判定门。

若当前原始效用及匹配对照门均通过，H/d² 可作为后续事前冻结、独立设计的近邻比较对象；目前没有实现、训练、选参数或许诺它的效果。若原全量门失败，按原规则结束当前配方，不借此追加拯救性实验。
