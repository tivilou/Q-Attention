## 研究对象与待解释的问题

固定特征输入经过原生角度映射，生成两层三比特线路 U；每层每根线先 RY 后 RZ，再依次 CNOT(0,1)、CNOT(1,2)、CNOT(2,0)。关系线路为 V。W=V†U；相干打分为 |(W²)00|²，中间计算基退相干打分为 Σj|W0jWj0|²，标量对照为 |W00|⁴。三组独立训练，保留相同参数、初始化、顺序、归一化和值读出，最终与已完成 native 比较。

每个关系对有效 token 的概率加 ε=10⁻⁶ 后归一化，再按各 token 的实数 utility 求加权和并加 bias。当前全量三路共 21936 次更新，固定最终第4轮；本文没有新训练或评估结果。

旧的同态反例只证明存在“相同准备态、不同相干分数”。它没有回答：这种自由度在真实12角线路中是否仅存在于奇异点，以及原始分数差异能否穿过归一化和值聚合。

## 命题1：一般位置局部可识别，但全局仍有离散分支

记 F 为一轮定向 CNOT。它把计算基位串 x=(a,b,c) 变为 Mx=(b⊕c,a⊕b,a⊕b⊕c)。考虑物理角度开盒 (-π,π)^12 到密度矩阵 ρ(θ)=U(θ)|0><0|U(θ)† 的映射。

其微分在开稠密、满 Lebesgue 测度的集合上实秩为12。因此每个一般位置点附近，准备态局部识别全部12个角；不存在非零的连续态不变切向自由度。这个结论不等于全局单射。

证明：取第一层三个 y 均为 π/2、三个 z 均为0，第二层角均为0。去掉末端固定 F 后，基础态为 |+++>，F 也固定它。把所有切向量共同左乘 F†。第一层六个导数分别为 -1/2 和 -i/2 乘以三个 X 基单激发，标签为100、010、001。第二层导数变为另外三个 X 基激发，标签为 Mᵀe0=011、Mᵀe1=110、Mᵀe2=111。六个基态彼此正交且与基础态正交，每个有实、虚两个实正交方向。投影掉全局相位后的态导数 Gram 为 I12/4；密度导数的 Hilbert–Schmidt Gram 为 I12/2，行列式为2⁻¹²。故在此处秩12。整个密度导数 Gram 行列式是非恒零实解析函数；其零集测度为0且无内点。局部嵌入由常秩定理得到。有限 raw 角到 π tanh(raw) 的微分可逆，不改变此结论。

另一方面，对第一层任一线，在 z≠0 的开图内实施

    T: (y,z) -> (-y, wrap_(−π,π)(z+π))。

单比特恒等式 RZ(z')RY(-y)=相位×RZ(z)RY(y)Z 给出 T_s U=相位×U Z^s，s∈F₂³；Z^s|000>=|000>。三个选择独立，故一般位置准备态至少有8个合法角代表。T_s 在这些开图中为微分同胚，同态的分支代表具有相同微分秩。这里没有声称这8个代表穷尽整个纤维，或存在已证明的全局8层覆盖。

原来的连续 z 反例与此不冲突：沿连续同态曲线具有非零速度的点必为秩亏点。离散分支可同时处于一般位置。

## 命题2：相干读出观察相对分支，native/退相干保持不变

对 token 线路施加分支 s、关系线路施加分支 t，有 W'≈Z^t W Z^s，其中≈只差全局相位。令 a_j=W0jWj0、χ_s(j)=(-1)^(s·j)，则

    pC(s,t)=|Σj χ_(s⊕t)(j) a_j|²。

native、native-square、pD 对全部这些选择均不变。共同分支 s=t 也使 pC 不变；可见的是相对分支，不是任意共同坐标选择。

这个区别并不只限于原来的奇异反例。取 V=F²，U 只有第一层 wire0 的 y=π/2、z=π/3 非零，则 W 为该线上的 RZ(z)RY(y)。其两个非零返回路径为 e^(−iz)/2 和 −1/2，原分支 pC=1/4，wire0 翻转后为3/4，pD=1/2，pS=1/4。对任意两个不同分支，都可选一个它们不同的位构造同类非零差。每个分支分数差是非恒零实解析函数；有限个零集的并仍为零测度。因此一般角对上的8个分支分数两两不同，并可同时使两编码器处于秩12、所有分支合法的开图。这里只证明固定编码/过程访问的结构区别，不排除任意重训练态编码器或经典模拟。

## 命题3：归一化之后可见的7个系数

固定一个关系的有效 token 集、utility u_t、bias b。仅对所有 token 使用共同分支 s，关系线路不动。记

    a_tj = W_t,0j W_t,j0
    g_tk = Σj a_tj conjugate(a_t,j⊕k)
    N_s = Σt (pC_t(s)+ε),   L_s = b+Σt u_t(pC_t(s)+ε)/N_s
    N_D = Σt (pD_t+ε),      L_D = b+Σt u_t(pD_t+ε)/N_D
    H_k = Σt (u_t+b−L_D)g_tk,   k≠0。

g_tk 为实数，g_t0=pD_t；Walsh 展开给出 pC_t(s)=Σk χ_s(k)g_tk。于是

    N_s(L_s−L_D) = Σ_(k≠0) χ_s(k)H_k,
    L_D = Σs N_s L_s/(8N_D),
    (1/8)Σs [N_s(L_s−L_D)]² = Σ_(k≠0) H_k²。

证明：展开路径模方并按 j⊕j' 分组，得到第一个概率展开。把归一化 logit 差乘 N_s，常数 Fourier 项等于 Σt(u_t+b−L_D)(pD_t+ε)=0。其余两式分别由字符均值和正交性得到。ε 和有效 token 掩码均保留，没有交换“先归一化”和“先平均”。

因此，退相干 logit 恰好是8个相干分支 logit 的分母加权中心，不是通常的算术平均。所有分支上的这一行 logit 都相同，当且仅当7个 H_k 全为0。原分支与退相干的差 Σk H_k/N_0 可为0，即使 Σk H_k²>0；不能只检查一个端点就断言整个轨道不敏感。

边界例：两个 token 的 W 相同、utility 不同。分支使两分数同时从1/4变3/4，但注意力一直各为1/2，所有 H_k=0。原始分数变化本身没有任务解释力。

## 一个定量推论及其访问边界

对只能看到固定准备态及固定 utility 的“分支盲”单行预测器 q，取明确的权重 w_s=N_s/(8N_D)。其轨道均方误差满足

    Σs w_s(q−L_s)² = (q−L_D)² + V,
    V = Σs [N_s(L_s−L_D)]²/N_s/(8N_D),
    Σk H_k²/(N_D N_max) ≤ V ≤ Σk H_k²/(N_D N_min)。

这是条件方差恒等式与 Parseval 的直接推论；若有 H_k 非零，任何这一访问类内的常数预测器都有严格轨道误差。它不是自然文本上对任意经典模型的学习下界：分支是编码后的反事实，原始特征可能携带相关信息，且转换后的角函数未证明可由同一个经典映射网络整体实现。

多类别预测还需检查 softmax 的共同平移自由度。单行 H 非零只保证行 logit 变化。相对退相干的 r/r' 对数优势变化恰为 F_rs/N_rs−F_r's/N_r's，其中 F_rs=Σ_(k≠0)χ_s(k)H_rk；逐行非零不能代替这个类别对比，更不能代替真实监督损失。

## 原文与新颖性边界

[Haug等，2102.01659v2](https://arxiv.org/html/2102.01659v2) 的III、IV节式(5)、(8)、(13)–(14)及附录B式(17)已经系统讨论状态导数/QFI秩、局部独立方向和特殊参数的奇异性。[Funcke等，2011.03532v4](https://arxiv.org/pdf/2011.03532v4) 的2.2节、3.1–3.2节以及第9–10页明确区分实 Jacobian 秩、局部嵌入和全局相位去除。其 HTML 转换缺少后续章节；本次使用37页原始 PDF 核对这些范围。二者都不能被当作本项目新定理。

旋转重参数化、字符展开、Parseval、条件方差也是标准工具。本项目新增的可核对对象是：实际定向 CNOT 原生线路的秩12证书、其准备态保持分支在相对返回中的作用、以及经过实际注意力归一化和值聚合后的7系数公式。是否足以构成实质近邻区别、是否已被已有过程核/重传方法包含、是否在文本上有用，仍需进一步证据。没有把它包装为 L5。
