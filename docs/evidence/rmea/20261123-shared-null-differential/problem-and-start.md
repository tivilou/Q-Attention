# 从关系漏检定位到可训练的共同参照实验

原版限定 L4 保留，L5 尚未达标。本记录是新实验启动及已有模型的算术诊断，尚无新方案的评估结果。

## 已定位的问题

主攻问题是句子中有明确实体对关系证据，却被模型判为无关系。同缓存历史完整训练的四个较强头共有 1,155 条此类错误，其中 1,070 条的金标没有被固定类型规则排除。这是任务机会，不是量子原因或可实现增益的证明。

另一个明确区分的证据来源是既有四轮原生模型的固定 TRAIN32：8 条漏检中，5 条获得两次隔离 Sol/medium 判断对金标的支持。它们不是随机总体样本，也不能当成上面 1,155 条共享错误的语义审计。前一轮冻结竞争变换在这 8 条漏检上没有修复，说明提高证据注意力不保证改善决策。

## 这次新增的定位

对原模型的关系 g 与无关系 0，记 a+=(alpha_g+alpha_0)/2，a-=alpha_g-alpha_0，u-=u_g-u_0，u+=(u_g+u_0)/2。原生分差精确等于：

    z_g-z_0 = (b_g-b_0) + sum a+ u- + sum a- u+.

固定 5 条语义支持漏检的算术回放中，`sum a+ u-` 全部为负；`sum a- u+` 有 3 条为正、2 条为负。恒等式最大误差 4.94e-15，未训练或重新前向。这支持继续检查证据到类别分数的联合映射，不能据此断言注意力已经正确或价值学习存在某种因果缺陷。

此分解不是新定理。放松的自由注意力上界也不是电路可达性或部署增益。

## 当前待检验假设

用所有关系共享的可学习无关系参照，读取 `sum(alpha_r-alpha_0)(u_r-u_0)`，再加偏置差。希望它能减轻共同背景的贡献，并学会关系特定证据；这仍是假设。若两张注意力相同，或相对价值在词间恒定，证据项会消失，因此它也可能损害正确关系。

同词正负价值直接相减可嵌入原模型的受限参数设置，未把它当成新增表达力。差分注意力本身已见于 [Differential Transformer](https://arxiv.org/pdf/2410.05258)，本次仅阅读原文 PDF 第 1、3、4 页。共享任务无关系参照、相对价值与 Born 路由的组合尚无实质新颖性、量子必要性或 L5 验收。

## 已启动的对照

固定旧 TRAIN 4,192 条拟合／4,000 条评估，句子组不交叉，均为已经暴露的探索数据。四路为量子差分、去相干差分、经典 softmax 差分、原生量子模型。各路从头学习、同 seed13／批次顺序／AdamW／batch32／最终 2,048 次更新。量子三路共享完整初始状态，经典路共享价值、解码器和偏置，但路由器更小，不宣称参数或有效容量完全匹配。

仅当全部四路最终状态完成后才评估；不读取 VALID、TEST，不按中途指标选方案。晋级准备门槛同时检查对原生及经典差分的 CE／Macro39、关系漏检减少和无关系误报不增加；去相干归因单独报告。失败不调种子、划分或预算救场，短筛选也不证明整个方法族无效。

代码通过一次 Astra6.2/high 的机制与有界执行定向审查。双 2080 Ti 共用一个调度分配，两条独立设备通道运行；原训练微批次、序列化、指标和宿主监督代码复用。新读出公式／梯度／padding 夹具最大误差 4.06e-16，实际训练已开始。没有重复单卡／多卡续训／COS 恢复矩阵。

这是可从既有持久输入重新运行的有界筛选，保留本地 latest 与训练批次损失 best；最终更新才用于评估。未写 COS，也未声称它具备跨主机断点保护。原始数据、数组与 checkpoint 留在计算节点，Windows 只有代码与紧凑记录。

完成后先分析这一个冻结方案，再决定是否进入完整数据研究。当前没有新的效果或 L1—L5 结论。
