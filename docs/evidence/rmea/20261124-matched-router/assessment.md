# 新标准研究路线：先达到明确的L4，再推进L5

本轮遵循2026-11-23用户对评级范围的纠正。长期L5目标保留，当前验收目标是`idea-maturity1`的L4：先L3，再满足统计强化E或实质理论强化T；L5要求同一贡献同时满足E与T。尚未接受新L3/L4/L5。

原2026-11-15的`advantage-evidence1`限定L4卡及原始研究完全保留。该卡证明官方固定数据上相对均匀池化的效用，以及模型内上下文权重对应关系的功能价值；不证明量子机制胜过公平经典替代。原五种子Q相对较强经典方法的40类Macro平均差为约0.25—0.49个百分点，相应区间跨零。不得把旧限定L4自动转换为当前量子方法的L4-E。

## 当前关键问题和最小动作

先检验完整的归因命题：相同输入、数据、训练与选择预算下，Q相对均匀基线、容量公平经典替代及去相干消融是否都保有正向贡献。一个正向平均值不等于显著性，更不等于理论新颖性。

旧经典头的路由宽度8，总参数76,752；Q的prepare为1028到12、40组12维效应，共12,828个路由参数，加共享值映射、解码与bias的68,200个参数，总81,028。经典key改为1028到12、query改为40到12，也恰为12,828个登记可训练路由参数，整个头81,028。该匹配只控制登记可训练参数数目，不认证相同有效自由度、可辨识维度、计算量或函数类。softmax的12个key bias在词softmax中被抵消；原去相干的末层RZ只改变相位，产生3×1029+3×40=3207个不影响其概率的参数。原消融保留不改，并在新fixture验证这些零梯度方向；精确模拟同一量子函数是正确性实现，不是必须输掉的竞争机制。

选择一次固定小规模四路比较：原Q、去相干、宽12 softmax、宽12实向量平方重叠。全部共享原输入、value/decoder/bias初始化、seed13、训练顺序与AdamW，局部末状态比较；经典两臂共享key/query初始化。复用已有句子不交叉的TRAIN4192拟合/4000评估，固定1024更新。官方VALID/TEST不读取。此TRAIN切分已被多次研究暴露，仅用于是否准备正式研究，不能视为独立验证或接受L3。所有条件训练结束后才评估。

若Q的39正类Macro不同时胜过三个控制，就不从本次结果推动新L3/全量验证，不改预算、种子、样本或控制救结果。保留全部指标并转向确有任务价值的新机制。若全部为正，下一步才冻结新的完整数据对照研究及独立确认协议；本次评估不授权正式长跑。新正式实验按当前用户目标经GitHub交给师弟执行；此前自行执行授权的历史批次保持原记录，不推断为本次已启动。

本次采用39正类Macro作为探索指标，原历史正式40类Macro数值不直接混用。新正式研究的主要指标、选点、种子、样本单位、所有关键对比及多重性处理需在运行前冻结；重建缓存身份与旧缓存不同，原结果不能挪作同缓存基线。
