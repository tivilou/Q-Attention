# 近邻边界

本轮只读取两篇官方arXiv摘要，未读取全文、证明或代码，不能据此声称完整查新。原HTML和hash receipt留在papers/；普通web搜索接口本轮返回404，使用官方HTTP读取。

- [Deep Residual Learning for Image Recognition](https://arxiv.org/abs/1512.03385)，He等，2015。摘要明确提出学习相对于输入的残差。本轮“保留主干、学习补充”是这类已知设计原理，不是新理论。
- [Differential Transformer](https://arxiv.org/abs/2410.05258)，Ye等，2024。摘要明确使用两个softmax注意力图的差。本轮am−uniform为中心化测量补充，不能把“注意力相减/噪声抵消”本身作为新T；本项目也未证噪声抵消是Q的实际优势。

本轮Q、D和经典分支使用既有原生路由，仅新增共同零gate中心化组合。与本项目旧冻结直接互补插入、关系v-null差分和弱值读出相比，这次主干与新补充分支从相同未拟合初始化共同训练，且包含同数经典补充分支和未经改动的最强原生经典控制。这个区别只定义新的可证伪实验，不建立文献新颖性、理论高级性或预期效用。

零gate包含原函数、系数和为1、value原点平移消去都是直接代数事实。它们不保证训练无害、实体绑定正确、量子特长或L4-T。若效用筛选通过，仍须完整独立验证和实质近邻/理论审查；失败保留结果并关闭本确切配置。
