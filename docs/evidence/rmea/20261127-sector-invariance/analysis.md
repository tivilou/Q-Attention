# SEARCH-36：角色标记振幅放大的词内路由不变性

## 为什么检查这个命题

上一轮是实质进展：gen129 原环境四臂通过技术预检并归还，但现实现成本不准入。双卡从单批速率外推约 120,641 GPU 秒，剩额 3,256 GPU 秒；不是全程实测或量子下界。gen128 历史后验也是技术通过、成本暂缓；两次都没做科学拟合。gen98、gen119、gen126 则是真实科学退门：gen98 10/13 门，Q .500925 低于 Gcov .512054；gen119 Q .022518 低于 GRU16 .059729；gen126 Q .194431 低于 RBF .470603。技术可运行、相干敏感与实际任务增益是三件事。

原任务约束不变：原输入、全部词的 64 维有符号 value、40 类输出、公平独立经典和关键消融。只比较三个不同作用点：

| 方向 | 改变 | 裁定 |
| --- | --- | --- |
| 固定角色/类接受标记的振幅放大 | 改量子读出，不递推历史 | 限定构造没有新组内词分辨，见下。不是否定非对易放大，也不等价于 gen98 的 value 统计或 gen129 的子集路径。 |
| 实体作用顺序的两路相干选择 | 改量子计算路径，不递推所有词 | 不投资：旧 controlled-order/OTOC 已暂缓，gen106 中置类查询和 gen77 共享相位词对有相关止损；路径少本身不是新的消歧证据。不是宣称两路与旧配置完全同构。 |
| 固定类条件酉搬运完整 value | 作用于 payload 而非词权重 | 固定线性版不扩大接口：若每类解码器无约束，固定 R_r 吸收为 w'_r=R_r^T w_r。非线性、正则、词依赖变换不受该等价约束；未找到足够区别于 gen79 / gen102 的新任务预测。 |

## 原作、推导和预测

直接核读 [Brassard、Høyer、Mosca、Tapp 原作 v1](https://arxiv.org/pdf/quant-ph/0005055v1) 的 PDF 页 1、5：身份、二扇区构造、式 (1) 和 Lemma 1。原纸的好/坏分量张成二维不变空间，讨论提高得到好结果的概率并使用可逆制备 A；没有证明本项目任务收益或提供标记 oracle。搜索接口失败不等于无近邻；官方 PDF 定点获取成功。[阅读凭据](source-reading.json)

**本项目限定推论，非新 L4-T 定理。**固定一个输入、一个类别的读出，把相互对易的标记联合分成互斥正交投影 Pi_s。令 psi_s=Pi_s psi，p_s=<psi_s|psi_s>。类接受即使由二元效果作合法膨胀，也须另核下述共同块条件；不假设 40 个类的效果互相对易。

初态 psi⊗a0 属于形如 Σ_s psi_s⊗a_s 的子空间。块控制的公共工作寄存器门只更新 a_s→U_s a_s。仅由工作寄存器投影 Q 控制的准备态反射 I−2|psi><psi|⊗Q 精确更新

    a_s → a_s − 2 Q (Σ_j p_j a_j) .

因为 <psi|psi_j>=p_j，这两类门、以及公共工作寄存器幺正，都保留每个块的词载体方向。若最终词/接受效果 M_t 与 Pi_s 对易，且工作寄存器终效 F 不随词变，则跨块项为零：

    q_t = Σ_s <psi_s|M_t|psi_s> <a_s|F|a_s>.

组总权重能变；但两个只落入同一有效块且原始质量非零的词，原始概率比不变。给定块质量和原边缘，组系数递推是精确经典计算，不是一条独立对照。若未来比较预测效用，独立强经典也必须看到相同输入和角色并可学习组权重，且保留 Gcov。若词已被标记分到不同细块，机器可区分它们，但不能把标记给出的判别归给放大。跨块或任意块内载体幺正、多准备态反射、随词终效、不对易标记等超出该结论。本文不以可模拟性本身淘汰量子研究。

**明确 ε 混淆。**若单有效接受块有 q'_t=c q_t，再作 q'_t+ε 归一化，则是原条件分布与均匀分布的混合，原条件分量权重为 cΣq/(cΣq+nε)。于是最终路由甚至 logits 可变，但只是固定 floor 相对放大概率的比例在变；零成功率时只有 ε 定义均匀读出，不存在原始比值。

## 实际检查及证据上限

[代码](check_sector.py)在人工四词、接受标记、一个工作比特上比较独立稠密乘法与组递推，包括空块、复相位、块控制、受控反射、末端工作寄存器效果与完整 64 维值池化。稠密态最大差 1.15e-16，全 64 维最大差 2.78e-16；组内概率比、重相位和归一化通过。固定非对易反射投影到 (e0+2e2)/√5：两个初态逐坐标概率和标记质量相同，原接受词比都是 1/4，反射后分别为 **81/100**、**9/4**，独立有理数和浮点稠密反射一致。这个边界例子不是 Q-RMEA 编码可达性、任务效用、量子独占或硬件高效证明。[人工输出](sector-check.json)

实际量子运行仍需可逆的完整输入制备与逆调用、角色和类标记实现、成功率及估计精度。本轮 **0 任务数据、0 任务前向、0 更新、0 GPU**，没有申请容量或重跑旧预检。已知算法和限定不变性不是理论验收。
