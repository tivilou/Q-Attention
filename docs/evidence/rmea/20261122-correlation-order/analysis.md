2026-11-22。固定模型诊断完成，预定门槛未通过，不进入全量训练；历史限定L4不变，L5未达标。

此前全量训练中三种上下文变换都优于原生头，但匹配/保护特有归因失败。本轮只检验一个解释机会：给原生量子效应施加按Pauli相关阶衰减，是否比同样纯度的整体平滑更有利。不是把此前训练收益预先归因于噪声。

一般数学解释边界：整体通道令q'=κq+(1-κ)/8；加入EPS后，注意力等于原生注意力与uniform的精确混合，原生分支权重为κS/[κS+n(1-κ)(1/8+EPS)]，S=Σ(q+EPS)。因此原生总得分小的类可能受到明显归一化放大。这是标准分式归一化恒等式，当前没有测量各样本混合权重分布，不把它当成本轮退化的已识别原因或L5理论创新。
