# 优先问题：关系证据没有可靠转化为关系／无关系决策

实际任务仍是Re-TACRED：输入一句话及指定主宾实体，带实体标记的RoBERTa产生现有词特征，Q-RMEA或经典头输出包含无关系在内的40类分数，最高分决定预测。本诊断使用39个正关系类别的平均F1（Macro-F1）；原fresh5正式主要指标含无关系共40类，不直接混用。本轮只分析完整模型已有TRAIN58,465条输出，不编码、不训练、不读取VALID/TEST，不改变历史模型或已验收限定L4；当前新政策L3/L4及L5仍未接受。重建特征缓存与原正式缓存字节不同，以下不替代原正式结果。

## 这次新增什么

此前同句正／负对象对中，Q的574对双拒识有459对仍保持正确金关系margin排序。这不代表459对都能通过一个拒识门槛修好：正例可能把错误的正关系排在第一，同句其他原本正确的无关系样本也可能被破坏。

这次直接算出一个严格限定、标签知情的可修复空间。对同一句的所有已标注实体对，给所有正关系分数加相同非负值t，无关系分数保持原样。相同句子只能使用同一个t；保护该句及全TRAIN所有原本正确的预测。句子身份依据原文本，不按模型结果划分。

设d是最高正关系分数减无关系分数。正例i只有在最高正关系类别本来就是金类别，且存在

`-d_i < t <= min(-d_j)`

时可被修复，右侧遍历同句所有原本正确的无关系样本；空集合上界为无穷。t非负，故不会损伤原正确正例。边界平分时原第0类无关系获胜。计算使用原浮点分数的float64差值、严格不等式及原类别平分规则。向量化上界与逐行独立重算一致，实际离线改判集合与不等式给出的可修复集合完全一致。金标签仅用于诊断，不是可部署输入。

## 也明确了统一句子门槛的局限

在原来的Q574个自然双拒识对中，383对满足局部可修复条件，只有257对能同时保护同句所有原正确样本，对应174个不同正例。此前459个正确排序对不能当作459个可修复错误。

四头共同双拒识的112个不同正例，只有15个能分别被四头各自的无损句子门槛修好。这里不是四头共用数值相同的门槛。故不能把共同漏判归结为一个已经证实的句子级偏移问题；剩余部分还涉及对象特定证据、正关系类别竞争或其他尚未确认的因素。
