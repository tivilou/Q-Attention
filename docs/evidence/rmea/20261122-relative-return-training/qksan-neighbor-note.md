# 相近方法核对：QKSAN / relative return

来源：https://arxiv.org/html/2308.13422v2，完整HTML已获取；本次实际阅读第III节定义III.1–III.6、式(9)、(16)、(17)、(21)、(22)。未将其报告的性能或效率结论作为本项目证据。

QKSAN的式(21)在输入编码与可训练query/key变换后，测量一次复合酉算符的零态返回概率，等价于两路终态的保真度；式(22)再将测量结果用于另一value寄存器的条件操作。它已有量子query/key/value、量子核注意力和条件value处理，因此这些词本身不足以构成本项目新颖性。

我们的候选对固定编码U、V使用同一个相对酉算符W=V†U两次，并比较相干返回、中途退相干和单步概率平方。已有同终态/不同酉完成的实际电路例子能区分这种访问方式与仅依赖原终态的固定保真度评分。这是已测源电路下的结构差异，尚不是相对于任意重新训练query/key编码器的表达能力分离，也不是整类QKSAN不可实现的结论。

尤其需保留两个限制：QKSAN允许query/key参数不同，其一般式不等于共同同映射PSD核，故我们的三电路非PSD Gram证据不能直接排除其整个函数类；允许pair-dependent表示时，W²|0>本身又是一个合法复合特征，原始共同特征核障碍不会排除这种表示。

下一步仍按冻结的全量三路对照测效用与中间相干性的必要性；即使两门均通过，也只形成单种子发现性结果。L5还必须补足相对重复编码/过程核等最近方法的实质差异与合适独立实证。暂不把两步酉演化或非PSD本身评为L5理论创新。
