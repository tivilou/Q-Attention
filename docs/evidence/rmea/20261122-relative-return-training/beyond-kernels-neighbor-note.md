原文给出了带额外比特的重传模型线性实现。我们的完整线路包含可学习的输入角映射，需区分“固定当前角度时按路径收缩可精确重写”与“整个共享参数函数族在某个固定低维特征空间内线性”两个问题。三线路非PSD原始相似度只排除共同同映射PSD核，不排除原文的扩大表示。

尤其B.3表明一种构造可表示原函数，并不保证把其特征直接拿来做核学习就保留同等泛化；这提供了一个可用的理论问题：在明确资源、共享参数与训练约束后，双次返回是否具有更合适的归纳偏置，而不是宣称一般函数类不可表示。目前没有本项目的资源分离、样本复杂度定理或泛化证明，不借用原文的条件性结论作为已有贡献。
