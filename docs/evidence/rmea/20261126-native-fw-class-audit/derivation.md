## Exact classical descriptions (known identities)

Set rho_t=x_t x_t*, E_r=q_r q_r*, Q_r=E_r+epsilon I8, M=sum_valid rho_t and V_r=sum_valid u_rt rho_t. Then z_r=Tr(Q_r V_r)/Tr(Q_r M). Both numerator and denominator include the original epsilon exactly because Tr(rho_t)=1. V_r can be indefinite when utilities have both signs; this is an algebraic readout memory, not an assertion that Ba writes signed memories. Orthonormal Hermitian coordinates (8 diagonal entries, sqrt2 real and imaginary off-diagonals) give a64-real-coordinate dot product for each trace. No probability, epsilon or denominator is changed.

For v=(Re x,Im x), w=(Re q,Im q), J=[[0,-I],[I,0]], |q*x|²=(w^T v)²+(w^T Jv)². Thus real16 with two squared overlaps is sufficient for arbitrary complex8 states; one real8 overlap suffices on the real-state fixture only. No minimal-dimension theorem is claimed. The native-angle pair with first-layer wire0 RY=pi/2 and RZ=±pi/2, all other angles zero, has opposite relative imaginary phases. Its exact complex probability is zero while discarding imaginary components gives a nonzero probability, even after real-part renormalization. This invalidates only that naive real-part reduction, not all possible R8 nonlinear encodings.

These are classical simulation controls, not rejection of quantum mechanisms and not new theory. At fixed3qubits no hardware speedup follows. The native circuit family, parameter constraints, learning dynamics and a properly trained classical comparator still matter for task attribution.

For stable dense contraction one may select any query-row constant c_r and compute z_r=c_r+Tr(Q_r sum_t(u_rt-c_r)rho_t)/Tr(Q_r M). This is the identical ratio, with original epsilon unchanged. The direct uncentered floating-point trace ratio incurred a scaled7.77085e-12 cancellation error on the frozen T=1 real case; its failure/code/exit record is retained. Using c_r=mean_t u_rt eliminates the needless constant-utility cancellation. This is an implementation repair, not a scientific parameter or tolerance change.

## The actual Ba conference recurrence

The latter retains b on every inner step. Its positive decayed hidden-state history is not just a normalized Born scalar lookup. Its state generation is recurrent, with layer normalization and learned gain/bias. A conditional map with identity nonlinearity and no LN is not the actual model. The arXivv1 has a different printed time index; this calculation uses conference timing only. Default eta=.5/lambda=.95 are source facts; S=1 is a permitted architecture setting, not a claim about every paper experiment. The stabilizer epsilon_LN=1e-5 is this explicit numerical instantiation, not a verified paper hyperparameter.

The original Q normalized pool and this recurrence have different interfaces and state histories. Observing different formulas or contrasting order sensitivity is insufficient for a general function-class separation or novel contribution. A lifted/signed rational operator readout establishes an exact classical implementation of Q; it does not assert that unmodified Eq5 with its ordinary output decoder is exactly that implementation.

Remaining checked differences are known identities, interfaces, normalization or ordering. No nontrivial new theorem or natural-task prediction favoring the original quantum core has emerged from this bounded audit.
