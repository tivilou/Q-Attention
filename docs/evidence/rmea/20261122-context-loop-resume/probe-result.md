## 实际实验

使用原生模型的不可变最终checkpoint `2da52b1ce826046a6f443269f47f49e4e9fa63e10f22f9ebdcde6f890e12ce51`，不训练新参数。训练集58465条中，按输出产生前确定的ID哈希顺序选18条no_relation及39类各2条，共96条。主分析为其中78条正类；这是训练集开发诊断，不是独立测试集效用。

原始流程是冻结编码器特征，经可训练的量子启发表示、注意力和值读出得到40类分数。新干预用上下文协方差调整查询，同时保留实体子空间；对照为固定DFT协方差换基及不保护实体子空间。所有条件共享同一checkpoint、输入、值和分类器。额外钳制每类的原生实体权重与上下文总权重，只改变上下文内部的相对权重。固定原生最高非目标类作为竞争类，margin为目标分数减该竞争类分数。
