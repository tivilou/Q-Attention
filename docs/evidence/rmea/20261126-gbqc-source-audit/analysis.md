[已测事实] 方法先在原特征空间以PCA切分形成粒球中心，再编码为逐维RY旋转的乘积态，按保真度构图。凝聚度是邻居相似度均值；最低10%暂时退出核心聚类，完成后重新分配，并非永久删除。原文p18明确把可训练量子映射列为未来工作，摘要中的“特征学习”不能作为联合训练机制的证据。

[机制解释] Eq5/6的理想核精确等于 `∏ cos²[π(c_l−c'_l)/2]`。保持中心、图、并列处理和随机状态相同，解析式会给凝聚度、合并与重新分配相同的输入。这是已知乘积恒等式，不是新T。实际有限shot实现及作者代码未审计。原文表格/消融没有报告这一完全相同解析核与完全相同流程的匹配对照，因此其结果未隔离量子执行的额外贡献；这不等于非线性核没有用途。
