the unchanged EPS only within S, giving beta_rs. Form

Q_r = sum_(s in S) beta_rs |psi_s><psi_s|,
W_r = (1/M) sum_(t not in S, valid) u_rt |psi_t><psi_t|,

## Mathematical question and limits

The advice proposes a synthetic retrieval witness with16 addresses arranged in
two mutually unbiased8-dimensional bases. Each bank has an independently drawn
balanced four-positive/four-negative payload vector; a query names one slot.
With ideal address encoding and value=2*payload, the intact read selects its own
payload while the other balanced bank cancels. For a diagonal read with query
encoding independent of payloads, all16 predictions lie in a fixed column space
of dimension at most8. The balanced payload covariance has14 contrast directions
of eigenvalue8/7; at least6 directions are missed, giving mean squared error at
least(6*8/7)/16=3/7. The constant bias adds no dimension because normalized query
diagonals already put the all-ones vector in that column space.

Primary assessment: this is a conditional covariance-projection argument using
known Born kernels/MUB/fast-weight tools. It is mathematically plausible but has
not been independently reviewed or numerically verified in this proposed plugin.
Finite native tanh-circuit realizability is unresolved; a limiting encoding is
not an attained finite-weight construction. Contextualized subject features may
already contain the answer, making the fixed-query-space assumption false. Bank
balance and locality are not established on Re-TACRED. Squared retrieval error
does not imply a classification CE or Macro gain. This conditional witness is
not yet a substantive new theorem or L5 contribution.

Source questions remain open: signed projector-key fast weights and quadratic
linear attention; quantum associative memories using density queries and
value-weighted token operators; task-level MUB retrieval versus relearned
diagonal bottlenecks. No new original paper was read for this lead in this turn.
Do not claim precedence or substitute a known rank identity for L5 novelty.
