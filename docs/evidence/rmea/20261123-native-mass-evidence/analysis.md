# 测量接受率读出：校准方向未能延续到评估集

原 Q-RMEA 对每个关系计算词元测量概率，再归一化为注意力；分类器只读取加权分类值。本轮检查归一化前的平均接受率是否还包含增量信息。保持原模型不变，候选特征为同一关系的完整接受率与去相位接受率之比的对数。

这个量可解释为两个平滑状态下、一次二元测量出现 ACCEPT 的对数似然比。它不是关系类别的似然、联合四十类测量、完整二元 KL 或相干性单调量；相关等式属于已有数学工具，没有据此建立新理论。它不依赖词元顺序或分类值，与上一轮有向面积方案不同。

[已测事实] 复用前 8,192 条 TRAIN 及封印的句子组划分：校准 4,192 条、评估 4,000 条。原 checkpoint 可能已见过这些训练样本，本研究也已使用这批数据，因此它们只是探索性开发数据，不是独立确认集。没有读取 VALID、TEST，没有参数更新。

控制对全部四十个关系的特征列执行一次固定错排，保留每条样本的数值集合，破坏与关系的对应。两路均用校准集拟合相同目标关系的置信度、去相位接受率、平均分类值、全局密度矩阵相干幅度及长度控制。然后对两路匹配每条样本的类别扰动均方根，各自在校准集锁定方向；全部样本保留。这不是训练过的经典匹配模型，也不是量子必要性检验。

| 评估量 | 平均交叉熵方向导数 | 句子组 bootstrap 百分位区间 |
| --- | ---: | --- |
| 完整关系对应／调整后 | +0.008824 | [-0.004096, +0.022925] |
| 关系列错排／调整后 | +0.013862 | 未单独设为主区间 |
| 完整减错排／配对比较 | -0.005038 | [-0.024777, +0.013047] |
| 原始接受率对数比／完整方向 | +0.030548 | 仅检查方向一致性 |

负导数才是降低原模型损失的局部方向。两路在校准集锁定的方向均为 -1，但到了评估集，完整特征的调整后和原始方向均增加损失；两项主区间也都跨过零。两千次固定种子的整句子组重采样只给出条件于校准拟合的近似探索区间，没有保证覆盖率。**原始方向及两项主区间门槛均失败，关闭这个具体方案；不换方向、控制、样本、尺度或随机种子挽救，不训练对应冻结读出插件。**该结论不等于所有可训练接受率模型均无效。

实际计算 28.064 秒。状态—测量形式与逐词元 Born 形式最大误差约 5.55e-16，原模型重放误差约 1.39e-16；对角状态零对比及全局相位不变夹具通过。执行前精确机制审查为 PASS。退出 0、stderr 为空，封印、私有数组哈希、方向导数、类别贡献、幅度匹配、错排和区间已独立核对，调度资源已释放。

稳定训练核心及宿主运行器均未修改，复用已验收的校准、幅度匹配和重采样函数。没有重跑单卡／多卡／COS 恢复矩阵，没有新增 checkpoint、COS 写入或向 Windows 下载模型和数据集。私有诊断数组仅留在 GPU 服务器。没有物化逐词元 sample-trace.v2，也没有宣称 Case Study 完成。

[机制解释] 当前结果不支持用这个冻结接受率特征修补分类输出。上一轮顺序交互和本轮接受率都不足以准入新插件训练，因此下一步转向可训练的量子注意力与值交互机制，而非继续增加冻结读出修正。[尚未证明] 新颖性、独立任务收益、量子必要性与 L5 均未成立；原有狭义 L4 保持不变。具体下一步及其边界见 primary-next-decision.md。
