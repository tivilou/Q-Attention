# v1矩阵多项式与QSVT电路的对应缺口

状态：PRIMARY_ANALYTICAL_SOURCE_CONSISTENCY_CONCERN；不是独立审核、执行实验或新理论。

来源定位：Quixer2406.04305v1，p5 Eq(14)写普通矩阵多项式P(M)，Eq(15)则交替使用块编码与其伴随；p7 Eq(22)和p15 Eq(35)-(37)按普通幂展开；p8 §4.1称经典模拟直接重复LCU作用。M在§3.2可为复系数一般酉矩阵之和，未限定Hermitian。p5、p7已视觉核对。[官方PDF](https://arxiv.org/pdf/2406.04305v1)。

以下是本轮自己的解析核对，无数值脚本运行，不归给原作。

若M本身是酉矩阵，精确块编码的选中子空间不与补空间泄漏。限制在该子空间后，Eq(15)的每对M与M†相消，投影相位只给标量：偶数次只剩I，奇数次只剩M（可能带相位/标量约定）。因此一般不能把它等同于普通M^d。用奇偶奇异值变换的常见写法，x²对应M†M或MM†、x³对应MM†M；对酉M分别为I、M。

例如M=diag(1,exp(iπ/3))、输入|+>、读出X。普通M²给期望cos(2π/3)=-1/2，而偶数奇异值变换x²给I、期望1；普通M³给-1，而奇数x³给M、期望1/2。差异不只是全局相位，两边成功范数都为1。这是解析例，不是原作者代码或本项目原生参数的执行反例。

结论只针对v1所印一般对应：缺少足以把交替伴随QSVT认作普通矩阵幂的附加假设，不能直接把其经典P(M)模拟继承为同一硬件电路。未检查作者代码、其他版本或所引QSVT完整定理，不能据此否定全部Quixer结果、LCU合法性或所有量子token mixing。

普通矩阵幂本身仍可通过逐次块编码/独立辅助空间及后选择，或直接对有序算子路径作LCU来实现；那需要自己的成功概率、归一化与资源合同，不能免费沿用式(15)的对应。本轮保留的探索线索仅使用明确定义的直接路径LCU，不借用这个一般QSVT等同。已知LCU、奇异值变换及反例代数都不是本项目的新T。
