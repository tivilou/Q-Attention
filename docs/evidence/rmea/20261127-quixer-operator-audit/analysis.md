## [机制解释] 一个不能直接继承的对应

p5式14将结果写为普通P(M)，式15交替块编码与伴随；p7及附录按普通幂展开，p8经典模拟重复LCU作用。对一般复酉组合M，这两者不自动相同。自己的解析核对：若M本身酉，交替M/M†在选中块上相消，偶次只剩I、奇次只剩M（相位/标量约定另计），不是一般M^d。例如diag(1,e^{iπ/3})作用|+>后读X，普通平方给-1/2，而x²奇异值变换给1。此为解析一致性疑点，非数值执行、新定理、作者代码反例或对全部Quixer的否定。[完整边界](source-consistency.md)。

因此不照搬“P(M)模拟=同一个QSVT硬件电路”的说法。直接对明确路径做LCU仍合法，但必须单独交代状态制备、路径相位、后选择及读出成本。

## [尚未证明] 唯一探索线索：有序子序列相干词责任

目标不是再改pair核，而是改变“先把不同证据路径混成概率”这一前提。保留原3比特/两层wordU_t和40个独立二元效应E_r=(|phi_r><phi_r|+I/8)/2，输入和完整value不变。n为有效词数，固定k=min(3,n)。令S={i1<...<ik}、U_S=U_ik...U_i1，C=choose(n-1,k-1)。对每个被标记词t：

    H_t = (1/C) sum_(S含t, |S|=k) U_S
    gQ_rt = Tr(E_r H_t rho0 H_t†)
    gD_rt = (1/C²) sum_(S含t) Tr(E_r U_S rho0 U_S†)
    alpha_rt = (g_rt + 1e-6) / sum_j(g_rj + 1e-6)
    logit_r = w_r^T sum_t alpha_rt Linear1024to64(h_t) + bias_r

Q是在幅度上相加后取Born质量；D在擦除路径标签前去掉路径间非对角项。D仍可有单条路径内的量子记忆相干，故它只检验**路径间相干**，不是所有量子性的总消融。C^-2不能改成C^-1后假装固定epsilon还相同。

物理实现是保留均匀marked词索引、条件制备含该词的均匀k-subsets、受控依次施门，再擦除subset标签和后选择，随后测E_r。联合词质量是g/n；加固定epsilon的非相干均匀成功支路可实现原归一化。即使加入floor，最坏也可能需要约百万次尝试；没有无成本qRAM、后选择或速度优势。具体合同、全部维度、控制与风险在[hypothesis](hypothesis.json)。
