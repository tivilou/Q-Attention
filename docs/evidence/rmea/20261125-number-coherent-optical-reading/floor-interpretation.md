# 两个 mixed 对照在实际分类读出中的精确区别

状态：固定参数代数分析，不是任务结果、独立实证或新理论贡献。不修改当前四路配置、训练源码、十三个主门或后续准入要求。来源为本候选实际 `rmea_number_optical.py` 的六模乘积与 `+1e-6` 后逐行归一化；数值检查见 `floor-interpretation.json`。

对某一类别的一行有效词，令未缩放 mixed 六模概率为 p_i≥0，P=Σp_i，有效词数 n≥1，ε=1e-6。当前代码给出

    α_i(ε) = (p_i+ε)/(P+nε)
           = (1−λ)β_i + λ/n,
    β_i=p_i/P, λ=nε/(P+nε).

P=0 时 α 恰为均匀分布；β 可任取，因为其系数为零。这是归一化恒等式，不称为新 T。

纯度归一对照把每模乘 2，六模总乘数为 64。因此，在**同一组 key/query/value/decoder 参数**下，它与原 mixed 对照使用相同的 p_i/P，只把有效 ε 换成 ε/64。它没有改变词之间未加 floor 的相对概率；效应谱不同、秩仍为二的物理说明与此分类层恒等式同时成立。

若该类别的词效用为 u_i=decoder_r·value(h_i)，则

    logit_scaled − logit_raw
      = (λ_scaled−λ_raw)(mean(u)−Σβ_i u_i).

所以本对照在固定参数下精确地改变“核加权词证据”与“均匀词证据”的混合，而非自动增加正确类别 margin。不同类别具有各自 P、β、词效用；某一行更尖锐不能推出分类改善。分别训练后的参数也不同，不能把两模型的最终性能差全归因于此固定参数公式。

令 t=P/(nε)。混合系数差为 1/(1+t)−1/(1+64t)，在 t=1/8 时最大，等于 7/9。这意味着在概率接近 floor 的区域，绝对 EPS 的作用可能很大；**尚未测量真实数据有多少行位于该区域**。两词解析例 p=(ε/4,0) 得 raw 权重 (5/9,4/9)、scaled 权重 (17/18,1/18)。取效用 (1,−1) 可提高一个固定 margin，反转效用则可降低；这只是反例，不是可部署收益。

当前解释边界：coherent 若只胜 raw mixed、未胜 purity-normalized mixed，就没有通过既定独立贡献门；不以“相干优势”包装 floor 对照。即使十三个主门全部通过，仍需适当独立确认和真正具有近邻区别的同核心理论；本恒等式不给予 L3/L4-T。无需为此加跑一套生命周期测试、重新训练或改动正在运行的实验。
