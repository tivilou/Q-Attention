# SEARCH-42：原留存分数显示，Q 对 Gcov 的净差主要来自无关系误报

**裁决：保留一个明确的任务瓶颈，尚无新方法准入。** gen98 的五臂十三门仍是 **10/13，未进全量**。本轮只用当时的原始分数，不接触新评估集、不重跑 gen98 或 gen105。它把先前猜测的错误来源拆成了可验证、可配对的三类。

## 来源与分解

原项目绑定主机的两份私有封包仍在；只读核对四个固定对象（金标、队列、Q/D/G 封包、Gcov 封包）的 SHA‑256 与 gen105 历史记录。gen105 自己的 4096 行结果只保留诊断分数和预测，完整 40 列来自上述两个原封包，避免把它的四案例或重放精度当全队列。检查两包队列索引、学习/评估分离、原金标数组、4 张旧混淆矩阵逐格相同。端口只回聚合；没有导出句子、单例标签／分数／索引、权重或特征。既存开发集 4,096 条（正关系 1,365；无关系 2,731），不是独立确认。常规 NumPy 正类排名和独立稳定排序完全一致；金标与其他正类或 null 均无精确并列。正式排名保留原 argmax 的小 ID 优先规则。

**Q 的任务缺口不是一回事。** 485 个错正例中，244 个（50.3%）金标本是正类第 1，只输给 null；161 个（33.2%）名列第 2–3，80 个（16.5%）第 4 及以后。这些是按存档预测与排名计数，固定排名下忽略 null 最多找回第一组；不是改阈值会实现的收益。旧 gen94 已做前一层的移除 null 诊断，本轮独特增量是严格同批的**排名深度及配对归因**。

**与强 Gcov 成对。** 既存整体 Q 独对 241、Gcov 独对 300，净差 59 并非全由正例排序驱动。正例 Q 独对 115、Gcov 独对 119（净差 4）；真实无关系样本中 Q 独误报 181、Gcov 独误报 126（净差 55）。分解只针对正确条数，不分解 Macro‑F1 或指认因果。Gcov 在金标正类排名上获胜 134 条、Q 103 条、其余 1,128 条同名次；进入前 3 的各自独占样本数为 **30 对 37**，总数 **1,285 对 1,292**。Q 也未胜使用相同 distinct 结构的 G（正例判对少 36、无关系误报多 13）。因此 Gcov 是必留强对照，而非用 Q 胜 D 替代。

**与去相干 D 成对。** Q 正例多判对 96 条、但无关系多误报 40 条；金标正类第1数量只增加 31，前3只增加 5。原配置的 Q/D 差异既涉及正例是否压过 null，也伴随真实 null 的代价。它提示应联合报告两端，但不把独立训练 Q/D 的差异说成冻结模型相位的精确因果量。

## 下一步及退出条件

优先检验一个**类别存在性与正类身份分开提供词级证据**的量子计算假设，而非重做统一阈值或先验重加权。只资格化一个合法的 standalone 量子证据路径：原 40 类标签、原输入、原全词 64 维值，无额外任务监督、推断分支输入或经典残差；要求同样标签的独立经典因子化头、去相干和强 Gcov。目标是无关系误报减少、同时正确正例和正类前 3 不被牺牲；这只是待核的方向，不是提前加进冻结小筛的门。首先排除常规两级 softmax 的重参数化、固定补效果、gen94 先验和 SEARCH‑41 物理拒答换名。无非等价量子作用、自然任务预测或成本依据则 NONE，继续上移；不调整旧阈值、不重启旧配置。本轮没有训练、前向、GPU 或新官方划分读取。原限定 L4 保留、未获新 L3/L4‑T。
