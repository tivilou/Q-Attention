# ECQP：实体条件化词态制备的探索草案

状态：EXPLORATORY_ONLY，尚无新模型、任务实验或L5接受。本草案保留原3-qubit两层电路、40个独立二元效果、ε=10^-6、原signed value/decoder/bias。旧L4只属于原方法。

## 从已有错误到待检验假说

原始多个头共有正类判空错误，且其中许多例子的正确正类已经排在39个正类之首。这个gold条件统计不提供可用的纠错规则，也未定位错误原因。R68失败的固定角色保护滤波不能证明实体条件化有效。这里换一条因果路径：让实体内容改变每个词的制备角度，再由量子效果得到路由。假说是这种条件化在已有上下文编码之外仍能帮助区分关系证据与无关相似性；该假说尚未得到数据支持。

冻结encoder的H已经含实体标记路径，不能称原模型没有实体信息。在特征边界固定非实体H而改变另一个实体摘要，是合成的支路干预，不是自然文本实体替换。

## 一个可以具体化的结构

按roles[...,2:4]和有效mask分别均值池化实体向量e1/e2，a=(e1+e2)/2。令P是固定16×1024投影，每项为±1/32，符号由SHA256('ecqp-projection-v1:i:j')首字节最低位决定，不按标签或输出选种子。设x_t=[h_t;roles_t]、z_t=(P h_t)⊙(P a)：

    raw_t = W x_t + c + B z_t，B ∈ R^(12×16)
    angles_t = π tanh(raw_t)，reshape(2,3,2)
    ψ_t = 原生两层电路(angles_t)
    q_rt = |φ_r†ψ_t|²
    α_rt = (q_rt+ε) mask_t / Σ_s[(q_rs+ε) mask_s]
    logit_r = Σ_t α_rt u_rt + b_r。

B建议零初始化以保持共同初始化时的原生函数；这是设计建议，尚未运行梯度或饱和测试。原头81028个可训练参数，此分支增加192个，共81220；P是固定buffer。投影、数值范围与内存/计算代价仍需在实际实现契约中验证，不声称硬件加速。

每个新增预激活分量恰为h_t^T M_j a，其中M_j=P^T diag(B_j)P，对称、秩至多16。这是标准低秩双线性形式，并非新理论，也不是任意双线性相容函数。共享P和对称实体摘要可能遗漏方向性；原roles仍保留，但不能由此宣称丢失的信息都被恢复。

若控制只增加B(P h_t)，它可以完全折入原W，是不同参数化而非新增函数类。控制至少还要包括B[(P h_t)⊙(P h_t)]，以匹配二次特征而不读取其他实体摘要。精确检查只核对这些恒等式和参数计数，不执行电路、模型或真实数据。

## 与旧尝试和原作的对应

原RMEA按词独立制备，固定关系效果跨样本共用；全句分母和上下文化H仍可带实体影响。旧ordered把实体作用放在查询/效果侧；旧joint将独立word/subject/object寄存器收缩成输入相关效果，并把word维数从8改成4。这里保持8维word寄存器，先改变每个word的编码，没有重跑旧ordered/joint或复用其效用结论。这是计算图位置的差别，不是已经证明的完整函数类分离。

1901.08163v1 pp3–5，尤其p4 Eq3.8–3.12，已有实体/位置/潜在类型条件化注意力；它是BiLSTM、SemEval-2010 Task8，不是冻结RoBERTa上的匹配实验。1610.04325v4 pp2–4 Eq3–8已经给出投影—Hadamard乘积—输出投影及其注意力用法。因此实体感知、低秩乘性交互、混合导数非零本身都不算本项目创新。量子编码位置是否带来实质差别仍未解决；经典可模拟性本身不是否定理由。

主模型另读2609.22005v2 p3–4：增加零值phantom位置/分母项和输出门已有先例。原式若把Σ(q+ε)增加κ，signed aggregate只被Z/(Z+κ)缩放；这是普通abstention构造，既不自动恢复正确正类，也不提供这里的L5新颖性。原文针对因果语言模型的论证/实证不迁移到本项目40类竞争。

## 下一项判别和理论缺口

先冻结一份训练数据范围内的、有实体分组的有界诊断契约，比较native分数/二次分数、相同P的实体交互、token-square交互、按ID同split错配的实体摘要。对象必须包括所有预定样本，不能仅在gold正类错误中调阈值。若使用拟合探针，需分离fit/eval并明确它只测开发关联；若负结果尚无事前灵敏度/功效，不能当整类条件化架构被否定。标签不得选择P、缩放、样本、阈值或验证集。

真正的机制测试还需要训练候选，与同特征的经典relation-softmax/real-overlap、参数/计算预算匹配的token-only量子扩展、错配摘要控制比较；共同初始化、预算和选择规则需要预先冻结。观测至少覆盖prepare_raw/angles、ψ/φ、q/normalizer/α、u/logits及全部40类混淆。必须同时报告正类恢复、新空类假阳性、正类错配与原正确预测损失。

一个能支持未来L5的理论必须把这种条件化与任务上的可区分预测连起来，并处理上下文化H已有实体信息、自由signed读出、空类竞争和适当独立验证。通用双线性展开、任意capacity分离、扰动界或训练集关联都不足以填补它。当前尚未给出这样的非平凡定理，也未证明实质近邻区别。保留ECQP仅供下一份前提/实现契约设计，不将它登记为已成立的L5方向。
