# 量子学习角色父比较：保留“量子历史后验注意力”一个探索线索

## 原任务和本轮边界

原任务是一句话与有序主客体位置→40类关系分类。既有缓存是插入当前主客体标记后得到的1024维上下文词特征，另有4维角色；任务主指标为40类Macro-F1。原Q-RMEA通过量子词分数分配词值，再作关系分类；量子路由是主模块，无额外经典分类残差旁路。历史限定L4保留，当前idea-maturity1 L3及L4-T尚未接受。

上一轮SEARCH-25属于进展：一次联合测量草案经精确分解，触发预先的“仅普通图正则则NONE”退出门；不是科学实验失败或P-INFER全族否定。本轮承接SEARCH-26，完成三种不同限制前提的比较及一次人工检查。零任务特征读取、编码器／任务模型forward、fit、GPU、heldout或外部模型调用；没有本轮Macro-F1或训练轨迹。新小筛4096FIT／1024选模／2048资格仍design-only，不以旧8192结果替代其资格。

## 唯一线索：非选择性量子历史后验注意力

[尚未证明／候选公式] 继续原3量子比特d=8、两层原生RY/RZ/CNOT，输入x_t=[h_t;role_t]∈R1028：

```
U_t = NativeUnitary(pi*tanh(W*x_t+b))
rho0 = |000><000|
K_t0 = I/sqrt(2),  K_t1 = U_t/sqrt(2)
T_t(A) = (A + U_t A U_t*)/2
F_t = T_t(F_t-1)
E_r = (|phi_r><phi_r| + I/d)/2
B_r,t = T_t+1* ... T_n*(E_r)
g_r,t = Tr[B_r,t K_t1 F_t-1 K_t1*]
alpha_r,t = g_r,t / sum_j g_r,j
v_t = V*h_t+c
z_r = sum_t alpha_r,t*v_t
logit_r = w_r' z_r + bias_r
```

星号在T上表示伴随映射，其余表示厄米共轭。每个r是独立的假设性二结果终端测量`{E_r,I-E_r}`；没有“观测到金标r”的额外输入，也没有宣称40个E组成一次POVM。分类输出由同一标准40类decoder／softmax得到，不能把这些独立binary概率直接当40类联合概率。

硬币在每个词独立公平选择skip/apply，可以完全经典地采样；量子性在memory轨迹的相干态，不在硬币分支间干涉。全部硬币历史和终端二结果构成一个合法全局经典记录分布：g是其中“第t次apply且终端yes”的边缘。即使部署没有真实终端观测，也可为每个候选r计算该统计；它不是借助未来gold的平滑。

原W12×1028+b12、effect40×12、value1024×64+b64、decoder40×64+b40的数组共81028标量，与native形状一致。当前只是方程计数，尚未执行原生实现、注册参数或验证有效容量／初始化；不以相同raw计数宣称公平归因。

## 实际人工检查：一个不可由固定逐词打分产生的依赖

[已测事实] 冻结四个词的qubit门、40个效应、一个末词替换及值矩阵，不搜种子／角度。prefix/suffix计算与全部16条skip/apply历史枚举最大误差2.220446049250313e-16，独立real4幅度枚举相同；40个终端边缘差3.3306690738754696e-16。计算耗时0.01680820000183303秒／exit0，预算10秒，具体输入和输出在`protocol.json`、`probe.json`。

[已测事实] 保持前两词局部门、class0效应与初态不变，只改变第4词门，前两词g比由0.9298689792915439变为1.0036271864882658，差0.07375820719672188。固定局部输入的pointwise分数模型，其相对权重比不会受第三方词门改变；这证明该人工规则的新依赖路径，不证明原3q角参数上同样可达、真实上下文信息改善、全模型表达分离或量子优于经典上下文模型。

[已测事实／限制] rho0=I/d时，全部随机酉通道保留I/d，伴随也保持trace；g_t=1/(2d)，alpha严格均匀。实际人工误差5.551115123125783e-17。这是实质退化，不得把前一pair方案的I/d探针照搬过来。纯初态也可能在长序列中混合至接近I/d，没有长期记忆或梯度保持保证。

## 正背景带来的采样界，也带来注意力上限

[机制解释／简单可核恒等式] E的本征值位于[1/(2d),(d+1)/(2d)]，每一步F为trace1正态，故所有

```
1/(4d) <= g_r,t <= (d+1)/(4d)
alpha_r,t <= (d+1)/(n+d)
```

在随机均匀选t、执行完整skip/apply轨迹、要求coin_t=1及终端yes的拒绝采样中，接受概率是sum_t g_r,t/n，至少1/(4d)。因此d=8时至少1/32；期望尝试次数≤32，不因n指数变差。被接受的t精确服从alpha。这里只约束理想概率／期望尝试次数，不是固定高概率walltime、精确有限shot输出或硬件优势。每次仍需词角装载、O(n)原生门、终端E实现；40类和值范数、期望估计精度都必须计费。

该固定1/2白背景在协议冻结前就已定义，不是数值失败后的EPS修补；代价是注意力不能任意尖锐：d=8时单词最大9/(n+8)。本轮不调背景系数来救援，后续若与任务要求冲突则停止当前模型。上述概率界／条件采样都是已知工具的直接结果，不足以支撑L4-T所需非平凡新理论。

密度计算只需d×d矩阵；保存前缀O(nd²)，对40个后向效应扫描约O(40nd³)，不显式枚举2^n历史。它解决的是公式层指数枚举需要，不是已测GPU性能。可用3量子比特memory加经典硬币记录／随机词索引采样；若选择相干硬币实现需额外辅助位，本文没有硬件编译或门数证明。

## 任务预测、强控制和下一步投资限额

[尚未证明／可证伪任务假设] 在保留原词值而不只压到末态的条件下，量子历史后验路由能改善完整40类Macro，且强于同路径独立D、同信息强经典平滑器及强任务参照；fixed-Q中间去相干应破坏相关任务贡献，而不只是改变任意人工分数。不能从gen119低分反推其失败原因，也不能从此人工比值推断真实改善。

独立D对每次非选择性及selected映射的memory施加固定计算基去相干，使用同值／decoder，单独训练；它等价于明确的正转移过程，但固定Q干预与独立D的目的不同。强经典平滑器需在同1028输入上独立训练更强非线性正转移与selected分量，并用同词值读出；Gcov保留为强任务比较。实幅度／Pauli精确回放仅作一致性，不能替代独立强控制，更不能因存在这种回放而否决量子候选。全量阶段还需无历史／无后向等关键消融。具体控制强度、参数冗余、评估与成本尚未核准，不先冻结效用训练。
