# SEARCH-39：整句重置稳态的词源读出可精确搬到类别测量端

**裁决：`NONE_SHARED_RESET_EQUILIBRIUM_READOUT`。** 固定一种全句机制：用同一整句输入形成有界 Hermitian 生成元 H_x，保存原各词 3 比特态 A_t 和 64 维有符号词值 v_t；过程以统一正速率 γ 重置到有效词态的均匀混合 σ_x，重置间按 H_x 演化。词源从实际重置结果定义，不借用金标、不新增推断输入、不压缩掉原词值。它确实不等于只用稳态分类；但其词源分数精确等于一个全句依赖的混合效应作用于原词态，未得到超出公平同输入对照的任务预测。暂缓此父方向，不把结果推广到所有开放系统。

## 原作与固定数学对象

核读 [Rose、Touchette、Lesanovsky、Garrahan，Spectral properties of simple classical and quantum reset processes，arXiv v2](https://arxiv.org/pdf/1806.01298v2) 的标题页、PDF 6–8 页 Sec. V（式 (52)–(74)，尤其是纯态重置跳跃、状态无关速率与能隙形式）。[APS 发表记录](https://journals.aps.org/pre/abstract/10.1103/PhysRevE.98.022129) 与原作作者和 DOI 一致。论文已有重置发生器及其谱；本轮的词源条件化、64 维值池和公平对照边界是项目分析，不是原作创新或新 L4‑T 定理。[取证范围](source-reading.json)

γ>0 时，合法发生器为 `L_x(ρ)=−i[H_x,ρ]+γ(σ_x Trρ−ρ)`。若 `σ_x=Σ_j s_j|j><j|`，跳算子 `√(γs_j)|j><k|` 给出重置项；不是把一般非酉矩阵冒充量子演化。以 T 表示随机重置年龄平均所得的通道：

```
T_H(A) = ∫₀∞ γ exp(−γt) exp(−itH) A exp(itH) dt
       = γ(γI+i ad_H)⁻¹ A,       ρ_ss = T_H(σ_x).
```

总质量守恒、态正性来自随机幺正平均；迹为 1 的稳态唯一，因为迹零差分经 `exp(−γt)` 乘以一个幺正共轭后收缩。对角化一次 H 后，每个矩阵元乘 `γ/(γ+i(λ_i−λ_j))`。简并等能量块不会自动退相干；这与任意逐向量“删非对角”不同。

## 正见证与精确边界

将实际重置词标记保留为经典记录。速率与词无关，词源先验为每个有效词 1/n；在该词条件下，末态为 `T_H(A_t)`。对每个类 r 单独做二元测量 `E_r`，40 类不是一个联合 POVM。于是：

```
p_rt = Tr[E_r T_H(A_t)] = Tr[T_H†(E_r) A_t]
α_rt = mask_t(p_rt+ε)/Σ_valid (p_rj+ε)
logit_r = w_rᵀ Σ_t α_rt v_t + b_r
```

统一的 1/n 在词条件化相消，ε 是沿用的读出 floor，不冒称是实际噪声概率。**全句只需一次 H 求谱，随后每个类别共享一个有效效应。** 这是一条对所有原词态及所有 64 维有符号值适用的恒等式，不是单条反例。若稳态只看 `ρ_ss`，词源分辨会丢失；若只搬运 `T_H` 而不注明它的效应变换，就会把普通上下文条件读出错报成额外递归汇聚。混合效应可能改变秩和类几何，因而不声称它与原固定秩一类查询、R99 固定谱旋转或 gen124 角色共轭完全等价。

人工两词：在 8 维中使用 2 维子空间，两个初始词态为 |0⟩、|1⟩，读出 Y+，把 `H` 从 `+γX/2` 变为 `−γX/2`。两个共同稳态相同、两 H 能谱相同，词接受概率却从 `[1/4, 3/4]` 变为 `[3/4, 1/4]`，有效效应秩从 1 变为 2。保留简并块的能量去相干令这对人工概率变为 `[1/2, 1/2]`。这个见证也由两个实数坐标的阻尼方程 `dy/dt=−ωz−γy`、`dz/dt=ωy+γ(z₀−z)` 逐分数重放；它击败能量种群对照，不击败较强经典平衡计算。这里的两实坐标是经典计算控制，不宣称它是 2 状态随机 Markov 链。

**成本与稳定性。** 固定 γ 时可解
`(γI+i ad_H)·δρ = γδσ−i[δH,ρ]`，并有 `||δρ||_F ≤ ||δσ||_F + (2/γ)||δH||_op||ρ||_F`。因为 `i ad_H` 为反自伴，逆的 Frobenius 诱导范数不超过 `1/γ`；重能级不会引入表象的求导奇点，这不为任何 GPU 自动求导库的特征向量反传背书。每句一次 `d×d` 谱分解再求类别效应，随后 `O(n·40·d²)` 比分和 `O(n·40·64)` 词值汇总；没有词数倍的 `d²×d²` 生产求解需要。GPU 时间、实现梯度、态制备、shot 与结果接受率未测；已花费的 343.895 GPU 秒保留，累计上限内余 3256.105 GPU 秒（未扣新开销）。未过机制门前不申请成本预检。
