# 同一词元共用测量：统一随机 Pauli 方案未通过资格检查

本项目的句子输入先形成带实体位置的词元特征，再由共享量子制备器得到各词元状态。40 个关系分别测量这些状态，按各自测量概率在词元间分配注意力，最后加权分类值并给出类别分数。本轮使用已有模型的固定参数，不训练，不读取标签、VALID 或 TEST；准确率和正类 Macro 不属于本轮评估指标。

[已测事实] 原始代码允许同一词元状态被不同关系复用。本轮对前 128 条存储顺序 TRAIN、全部有效词元及 40 类，精确枚举三量子比特的 27 个 Pauli 基和每基 8 个结果，计算共用测量的总体方差。计算约 **1.028 秒**，未抽取测量样本。

与上一轮每类独立的 Bernoulli 测量相比，本轮让一次随机基测量同时提供 40 个关系的估计。使用已有 classical-shadow 逆通道，估计值允许为负；没有修改原模型或宣称发现新公式。

为了按**相同总状态制备次数**比较，记录共用方案最大的标准化总体方差，以及直接测量在理想、连续、已知答案的类别预算分配下的标准化方差总和。两者比值是规划指标，不是有限样本所需次数、认证成功率或实际耗时。

| 对照 | 共用方案比值中位数 | 比值小于 1 的样本 |
| --- | ---: | ---: |
| 直接测量／均匀词元采样 | 7.020545 | 1/128 |
| 直接测量／按分类值采样 | 8.044705 | 1/128 |

事前门槛是第二行中位数不大于 0.8，且至少 103/128 条比值小于 1；两项均失败。128 条均保留且具备有效非零比较量。**关闭这个统一随机 Pauli 方案，不调基分布、样本、阈值或预算挽救。**这不是对所有共用测量方法的否定。

[机制解释] 对原模型实际效应矩阵的精确方差计算表明，这个逆通道的噪声抵消了共享类别测量的机会。共用估计量支持范围的中位数约为 165.943；该数值说明范围项也需要处理，但本轮没有据此计算有效置信区间或实际停止成本。此前直接测量的 1/128 规划结果与本轮的 1/128 改善计数含义不同，不能混为同一认证率。

三个固定复状态的逆通道重构误差不超过 5.56e-16，两个效应均值及非恒定词元加权方差夹具误差不超过 4.45e-16；实际原模型概率、上一轮比较量及直接方差重放最大误差约 2.00e-15。精确代码通过 A6API gpt-6.2-astra/high 的一次机制审核。退出 0，无 stderr，封印、私有数组哈希、规划比值与门槛独立复算通过。分配已释放，驻留进程已退出。核心训练代码、运行器和 GPU 源码工作树均未改动。

训练案例不适用。未保存 sample-trace.v2 或完整文本逐词元案例，不能从总体方差摘要反推轨迹。固定复状态夹具是实际数学检查，不是文本案例或独立任务实证。逐行小数组只留在 GPU 服务器磁盘/主存；未下载模型、数据集或 checkpoint 到 Windows，未写 COS。

[尚未证明] 本轮没有预测收益、实际测量加速、硬件优势、实质理论新颖性或 L5。原狭义 L4 保持原范围。Huang／Kueng／Preskill 的原文给出了共用估计工具；Ma／Liu 的近邻工作已经比较过 shadows 与直接测量的适用区间。这些工具和题材不能单独作为新的理论贡献。
