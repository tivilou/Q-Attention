Native source confirms shared token preparation and scalar normalized pooling; the encoder itself already contains order. Do not claim all order is absent from the native model.

Hypothesis: after the contextual encoder produces its fixed token records, native normalized summation discards a particular interaction between the order of overlap mass and the order of centered classification values. That interaction may predict residual errors beyond native confidence and single-token position information.

For one relation let q_i=p_i+EPS, m_i=q_i/mean(q), s=z-b,
v_i=(m_i,m_i*(u_i-s)), c_i=v_i-(1,0), and
A=n^-2 sum_{i<j}det(c_i,c_j), with sum_i c_i=0.
Candidate readout would add one globally shared signed coefficient times A inside
the quantum head; no parallel classical predictor. No such plugin exists yet.

Primary algebra to check: A=n^-3 sum_{i<j<k}det(v_j-v_i,v_k-v_i).
For B=n^-2 sum_{i<j}det(v_i,v_j),
B-A=n^-2 sum_i(2i-n-1)det((1,0),c_i), indexing from1.
Under a uniform permutation of fixed records, E[A|one named record at one position]=0;
this is orthogonality to additive single-record position scores under that null.
It is not independence from natural-language positions, evidence of semantic
order, quantum exclusivity, a new sequence-signature theorem or task improvement.
For n<3 or only two distinct contribution records the centered area is zero.

Smallest next work: establish the algebra's exact assumptions/counterexamples and
freeze an isolated first8192TRAIN diagnostic, with calibration/assessment partitions
fixed from source identifiers before reading outcomes. Use frozen native records,
no parameter update, VALID or TEST. Lock orientation on calibration only. On the
assessment partition test the native CE directional derivative for the intact A,

compare value-permuted A at matched class-centered logit-perturbation RMS. Use
source-group partitions/bootstrap when source groups are actually available;
otherwise record that only sample-level exploratory uncertainty is supported.
The original checkpoint may have trained on all of these rows, so this is not
independent validation even with a locked calibration split.
