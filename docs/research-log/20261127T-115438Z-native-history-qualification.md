## 实际定义的机制

每词只决定原生量子电路 U_t。初态固定为 |000><000|，不取最大混合态；每词抛一个公平的经典硬币，跳过或施加 U_t，因此非选择性信道为 T_t(A)=(A+U_t A U_t†)/2。前缀态保存之前所有硬币历史的平均；每个关系的终端二元效应 E_r=(|phi_r><phi_r|+I/8)/2 向后传播为 suffix effect。词 t 的正质量是“该词硬币为 apply 且终端 r 测试为 yes”的联合概率，再跨词归一化。没有把 40 个效应误当单个 40 结果 POVM，没有给推理传入真实关系或未来金标，没有硬币分支间干涉宣称。

权重始终作用于全部原词值向量，而不是仅用最后量子态做分类；这区别于 gen119。输入也不是 gen120 的连续特征选择性似然。它不是 gen126 的成对 Born 隐表示替换。padding 在进入线性层前清零，填充词执行恒等跳过、质量及输入梯度为零，包括序列内部的空位；不通过 NaN×0 来掩盖非法值。

**去相干 D：** 每次 T 和 selected map 之后（包括最后一个词）都施加固定基底对角投影。独立人口传播 (I+|U_t|²)/2、selected=|U_t|²/2、terminal=diag(E_r) 与密度矩阵实现一致。将来需要独立训练的 D；固定 Q 上干预不能替代它。

**经典 C：** 完整 1028 输入经可训练 tanh(12) 产生 8×8 正转移矩阵，按输出状态作 softmax；同样的公平 skip/apply、前后向算法和正终端效应。共享原词 value/decoder 接口，独立训练。注册参数 Q/D=81028，C=81700（多672）；这不是“相同有效容量”，也不把 exact realification 当强经典对照。另保留强 Gcov；新 cohort 下必须实际训练，旧输出不得冒充。

## 固定人工案例与结果

唯一 fixture 在执行前写入 `protocol.json`，SHA256 `2a5701b4167539430dabf71f46721f7ffe2d72cb1fdb0953850b0f5e02d5c907`。它有 2 条人工序列、分别 4/3 个有效词，包含内部 padding；全维余弦/正弦输入权重无任务语义，不是挑出来的真实成功案例。`sample-trace.v2` 的原词文本、tokenizer/编码器、训练反馈和金标阶段本轮不适用：它们没有运行，未重建任何真实轨迹。

[已测事实] NumPy 独立 Kronecker 8×8 门构造与原生源码扩展一致；Q 遍历全部 16/8 个硬币历史；D 用独立人口历史；C 还显式枚举全部隐状态历史。40 类质量、归一权重、完整 64 维 value 与 logits 都核对。最大数值误差 `8.8817841970012523e-16`，9 个指定坐标中心差分最大误差 `7.2521158796614617e-13`。Q/D/C 所有被检查参数和 h/roles 梯度有限、padding 梯度零。成功执行计算 `0.21149289999448229` 秒，CPU单线程；进程总时长见执行记录，含导入，不冒充 GPU 或真实长序列成本。

[已测事实] 固定第 0 类和前两词，只改第 4 词，质量比由 `0.97578818219642127` 变为 `1.0012718975456729`，差 `0.025483715349251645`。这证明该原生 fixture 的路由可依赖后续信道，排除“固定局部输入下的独立逐词分数”解释；不排除上下文经典注意力，更不是任务增益或量子优越性。

[已测事实] 最大混合初态仍退化到均匀路由；g≥1/32，长度 n 的 alpha≤9/(n+8)；人工样例全部通过。只做一个冻结样例，没有角度/深宽/seed/白背景搜索。

## 失败记录和核对边界

第一进程 exit3 是 NumPy/Torch 重复 OpenMP 运行库中断；使用顺序 MKL 后解除，没有使用允许重复库的绕过开关。第二进程 exit1 中，uniform 参照的 bool/int 除法生成 float32，误差9.934107536579972e-9；将**参照**显式转换 float64 后，保持相同方程、输入与1e-10门槛，最终 exit0。三个完整 stdout/stderr/exit 记录均保留。最终脚本仍有一个 scalar-conversion 性能提示；它不是数值失败。中断执行的计算耗时未单独保存，不宣称所有尝试累计科研计算时间精确可知。
