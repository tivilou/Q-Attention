# 同一实体对的跨句证据排序：本轮没有发现 Q 的优势

时间精度：仅有本轮执行日期证据，未单独记录统计命令的具体执行时刻。研究日期为2026-11-24（UTC+8）。这是已完成的只读诊断，不是待启动全量实验的结果。

Q-Attention 的任务是从原句及有序主客体中判断40类关系，其中一类表示无关系。冻结的 RoBERTa 产生带实体条件的词表示；各头把这些表示变成关系条件词权重，再汇聚带符号的词价值，得到40类分数。原 Q 用三比特电路的平方重叠评分，去相干与经典头提供不同的注意力机制。历史模型已经完成训练和验证集选模。本轮只读取它们在同一重建训练缓存上的既有分数，不重新编码、前向、拟合或选择模型。

本轮问题是：同一有序实体对出现在不同句子中，某句标为关系r、另一句标为无关系时，模型是否给前者更大的“r减无关系”分数？这不同于最终40类分类正确率，也不同于正式实验的Macro-F1。

| 对比 | 上一类自然配对诊断 | 本轮 |
| --- | --- | --- |
| 固定对象 | 同一句中的不同候选实体 | 同一有序实体表面词与类型，不同句子 |
| 观察 | 相对证据与绝对拒识 | 正句与无关系句的证据排序 |
| 新模型或新训练 | 无 | 无，直接复用既有分数 |

## 冻结单位与实际执行

[已测事实] 在读取模型分数前，先对全部58,465条TRAIN作精确匹配：有序主客体各自的词元序列及类型均相同，句子完整词元序列不同；不做大小写、别名或模糊匹配，也不按模型是否漏检挑选。得到1,563个实体对—类型组、1,672个实体对—关系组和18,621个正负跨句对照，覆盖37个正关系类。131个同句正负自配对边被排除。

重复的同标签句子先对其所有匹配标注的margin取均值。每个合法正负对，正句margin更大记1、相等记0.5，否则记0；先在关系组内平均，再对全部1,672组等权平均。预先保留的次要汇总为37个类别等权平均。没有拟合阈值或计算显著性，18,621对也不是独立样本数。

[已测事实] 统计输入逐文件核对既有哈希、行身份与类别；原始文本顺序通过样本ID哈希与缓存顺序对应。支持统计1.832秒，分数聚合3.836秒；新增模型前向、优化更新、GPU操作和TEST读取均为0。

本轮使用历史完整20轮seed13选定模型的同缓存回放。经典头是原width8，不是待启动的width12完整对照，也不是短训练筛选头。原训练h与当前回放h不同；该差异对全部模型使用同一重建缓存，但仍限制解释，不能覆盖历史报告。

[已测事实] 主汇总中Q比禁用头高13.145个百分点，但比softmax8、real-overlap8、去相干分别低3.183、3.682、0.762个百分点。类别等权汇总方向相同。所有37类结果和精确小数均保留在[汇总](../evidence/rmea/20261124-native-context-ordering/summary.json)中，不挑有利类别形成新晋升路线。

## 学到了什么，以及没有证明什么

[机制解释] 对同一实体对、类型和关系固定的任意加性margin偏置，在两句分数相减时抵消。因此这个统计量能观察到单纯共同偏置解释不了的排序反转。这个消去式与排序统计是已知工具，不是新理论。

[已测事实] 该历史模型切片不支持“Q比已测经典头更擅长同一实体对的跨句辨别”这一方向。无需为此再做已知秩或实数化演示，也没有理由把它转成一个已通过可行性检验的新插件。

[尚未证明] 高排序一致率不表示剩余漏检主要由阈值造成，更不保证一个偏置能同时修复所有正负句及其他38类竞争。同表面词不保证同一真实实体，任务无关系标签也不等于世界中无关系。TRAIN回放不是独立效用确认；类别重叠、重复句与分组相关性均保留。

独立训练的去相干头不等于对同一个Q checkpoint关闭干涉；后者没有既有分数，本轮未运行。没有新增sample-trace或训练病例，源状态、词权重和优化轨迹没有在本轮观测；这些缺失阻止内部因果解释，不影响本轮限定的分数排序汇总。没有Case Study完成或理论验收声明。

当前采用idea-maturity1。新L3/L4-E/L4-T/L5均未验收；原限定ordinary-alignment L4及全部历史结果原样保留。

## 唯一推荐下一步

优先完成已经冻结并交付的同缓存五路完整预算比较，而非追加排序拟合。待检验假设是原Q在该协议下对禁用、去相干、softmax12和real12均有正的TEST all40 Macro差值。师弟在现有双2080节点运行固定seed13、20轮、batch128、共45,700次更新；本方不代启动、不新增资源。

四项差值必须全部严格为正，才进入另行冻结的独立资格化讨论；任一不正则关闭本配置晋升，不补种子、改指标、挑checkpoint或加预算。即使单种子通过，也不自动获得新L3或L4。全量结果尚未知，本轮不会用历史TRAIN排序对其预判或修改合同。
