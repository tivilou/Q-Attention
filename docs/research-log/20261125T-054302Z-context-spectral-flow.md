# 上下文谱流：小数据单 seed 筛选结果

## 实际流程与想检验的问题

Re-TACRED输入句子及指定主宾语。固定词表示和角色距离先进入原生12角量子编码器，产生词态；40个关系态各自测量词态，形成词注意力，再聚合signed value并经分类decoder输出。

本候选只在测量前加一步：用当前句子全部有效词态的平均密度S，给每个关系态施加exp(-i*pi*S)。时间pi在运行前固定，没有扫描。相同参数下，它改变词间分配却保持每个关系未归一化Born分数总量；并不是把“注意力归一后总和为1”当新性质。没有改训练、选模、队列、checkpoint或COS核心。

这个假设来自前轮的正负证据，而非已证明的任务根因。原跨侧印证完整实验仍关闭，不以新筛选覆盖它。新方法的守恒量是结构预测，不保证准确率。

## 可接受与不可接受的认知

[已测事实] 相比原生Q，新谱流Macro提高约6.06个百分点。这个固定小数据配置中的“上下文改变投影”的方向有正结果，不应描述成所有尝试毫无正向。

[已测事实] 它仍比native dephased低约2.26个百分点，比Gaussian base低约3.43个百分点。六个固定比较只有4门通过。因此本配置不进入完整单seed，更不进入多seed。不改时间、生成源、seed、子集、预算、主指标或控制救援；短筛选不判整个家族不可能。

[比较边界] real12_flow使用实数key/query，但matrix exponential本身可产生复幅，故不是完全去相干。native dephased是原静态population模型，也不是唯一差别只有相位的动态控制。因此这次没有证成量子专属作用或独立机制归因。

[理论边界] 密度矩阵指数、谱函数、Gram交织、对易子和守恒量均为已知工具。原文1307.0401v2第2–3页已读，不能把换到NLP当新T。96组NumPy仅代数核验，utility变化有正有负；模型实际可达性与任务效果是不同问题。

## 技术事实与成本
