# 逐例可修复不等于共享query可修复：固定模型TRAIN诊断

既有Rayleigh诊断允许每条输入自由换query并同时降低各竞争关系；本轮固定全部native竞争logit，只检查gold这一行。相同完整native量子/real12终态、词态、value、decoder、bias均不改。若同类错误与正确保护样本各自可以越过对手，但同一query不能同时做到，就得到一个冻结共享约束冲突。

数学：C_i=A_iy−(max_native_rival−bias_y)B_i；B含原EPS。任意单位query越过固定对手等价q†C_iq>0。正Frobenius缩放后，任何lambda∈[0,1]都给出min(Tr E C_i,Tr E C_j)≤lambda_max(lambda C_i+(1−lambda)C_j)。二者单独正但右侧数值显著负，排除该对在同一纯query或更宽混合效应下同时过门。标准支持函数工具，不是新T。

完整重评估TRAIN58465条/all40；两个模型错误的并集5103条，其中共同错误1578。每类从两模型均正确者取hash排序前4保护锚点，所有并集错例与同类锚点配对，合计20412对。两模型完全同配对；原生混淆矩阵分别精确核对。全部逐类/strata保留在summary。

- quantum: 四类配对计数[1724, 90, 18598, 0]，依次为单条障碍、单条皆正但共享冲突、单条皆正但无冲突证据、单条未决。检查1814个负dual的TorchCPU/NumPy最大误差3.98e-16，native query违反上界最大0。

本冻结配置确实出现共享必要约束冲突。它支持进一步研究同一测量跨输入的耦合限制，不能直接推出条件化会学习成功。

数值结论限于计算出的FP64矩阵、固定rivals和本配对，不是理想线路的舍入包络证明。正dual/未找到负点不说明纯query、原生线路或三个以上约束可满足；负点也不能排除同时重训练key/value/bias/其他关系。两个模型维度不同，不据计数差认定量子根因。配对由已知模型正确/错误选取，保护锚点重复且只取固定4个；没有总体流行率、独立CI或部署收益。

诊断用时70.672秒，零训练更新、新VALID/TEST/COS。源矩阵首3行NumPy核对，全部负dual独立CPU谱计算、全部配对/去重/逐类计数从远端私有数组核对。Windows无模型、词特征或逐例数组下载。既有host wrapper与训练/恢复核心未改，不做续训/COS能力矩阵。
