# SEARCH-41：测量前过滤严格优于事后改判，但未建立任务预测

裁决：**`NONE_FRIO_TASK_ADMISSION`**。固定允许出错及不确定结果的测量确实可以突破一种事后规则的上界；它不同于零错误判别，也不同于调整最终 no‑relation 阈值。这次得到的是一个可检验的测量边界。它仍缺原任务上同输入强经典无法归纳掉的差异预测，未准入实现或小筛。

## 核读的原作及选定假设

核读 [Bagan、Muñoz-Tapia、Olivares-Rentería、Bergou，arXiv:1206.4145v1](https://arxiv.org/pdf/1206.4145v1) PDF 第 1、2、4 页：身份、固定不确定率的风险定义、式 (6)–(8) 的先过滤再对变换后的系综最小错误测量，以及末尾多类扩展的边界。原作展示三态例子，不把两态迹范数公式推广为 40 态闭式，也不把已知过滤变换算成本项目的新理论。[来源凭据](/docs/evidence/rmea/20261128-bounded-discrimination/source-reading.json)

原单样本任务保留 `h_t, role_t`、8 维态 `ψ_t`、掩码、完整有符号 64 维词值和 40 个语义类别。考虑一个共享可接受算符 `0≤A≤I` 和一组 `F_r≥0`、`ΣF_r=I`，定义 `M_r=√A F_r √A`，以及额外物理结果 `M_?=I−A`。词池仍按每类对 `Tr(M_rρ_t)+ε` 掩码归一并汇总全部词值，`?` 不作为第 41 个语义输出、不写成 no‑relation 或提前跳过分类。以下只核先过滤的有限 40 类受控实例。它不是在真实词上以句级金标作词态真值、也没有用评估集选择覆盖率。

## 一个可解的 40 态构造

令 π_j=1/40，`ψ_j[k]=√p_k exp(2πijk/40)`，k=0,…,7，p=(.3,.1,…,.1)。因为目标和约束对 40 次循环作用不变，可以对所有测量平均而不改变风险或覆盖；因此选协变测量，`A` 对角。设 `x_k=p_k A_kk`，覆盖率 η=Σx；代表性结论效果 `M_0` 的对角为 `A_kk/40`。半正定性给 `|(M_0)_kl|≤√(A_kk A_ll)/40`；秩一 Fourier frame 同时达到这些界。故给定覆盖 η 后，最好的已接受条件正确率为

```
  max  (Σ_k √x_k)^2/(40η),    0≤x_k≤p_k, Σ_k x_k=η.
```

在本例的正覆盖约束内，√x 的凹性和交换任意两未饱和坐标给出 `x_k=min(p_k,τ)`；将极小质量移给零质量坐标可提高目标，故无遗漏的零角点最优。这一有限例无须逐样本调用半定规划。Cauchy 给条件正确率上界 `8/40=.20`，当且仅当滤后有效质量恰可相等时达到。即使承担额外不确定率，仍远非零错误判别。

**事后处理的严格对照。** 无过滤最小误差 Fourier 测量的固定记录 j 上，后验最大值各自相同，且为 `c₀=(Σ√p)^2/40≈.1906217783`。把任何记录随机保留、拒答、重映射到其他类，或混合这些操作，只要输入仅是这一次固定测量的结果，给定接受的正确率就是所接受记录后验的加权平均，上界仍为 c₀。这里不限制事后阈值形状。若经典模型可直接读取与 Q 相同的原输入／特征，其可用信息就比「只看固定测量结果」更多；上述上界不适用于它。能读取全部振幅的 Fourier 实数谐波实现可精确回放，但也不是独立训练的同输入基线。

[核验脚本](/docs/evidence/rmea/20261128-bounded-discrimination/check_frio.py)比较稠密效应、独立 Fourier 振幅、去相干和完整带掩码 64 维词值池；最大差 6.67e−16。[实际输出](/docs/evidence/rmea/20261128-bounded-discrimination/math-result.json) 等比例滤波 `A=βI` 只把原概率整体缩放；读出若保留固定 ε，它只改变原无 floor 分布和均匀分布的混合权，程序实际复算误差 2.78e−17。不把 ε 影响报告为量子取舍。人工实例中 40 个类别的接受率都相同，不支持“选择性丢掉语义无关系的词”。

## 对原任务的决定

- 旧零错构造要求 40 个 8 维纯态每个均有正的零错成功率；此次允许错误，人工证据不与旧裁定冲突。旧 PGM 类帧没有这个物理接受位；固定 PGM 后处理的失败不是否定全部 PGM 或同输入模型。类别成本重加权、普通 classifier 阈值也未被重新包装为测量。
- 原任务的可判别预测必须分开 **真实正例→no‑relation** 与 **真实正例→错误正类**，并同时报告 **真实 no‑relation→正类**，在不破坏正类判别的条件下比较相同任务输入的独立经典风险模型、强 Gcov 及冻结的去相干。人工覆盖数对三项都没有自然任务估计，亦无词态与正类错误类型的已验证桥接。以此开新实验会把限制输入的事后规则当成强经典；不准入。
- 人工共享对角滤波可一次缩放每词振幅，8 维、40 类模拟开销量级与固定投影相同；通用输入依赖的 A 要另外核每句矩阵函数、求导、存储、态制备／测量试验次数。实际 GPU 时间、完整控制和自然态可达性未测；已用的 343.895 GPU 秒不重置，同一累计上限内仅余 3256.105 秒未扣新开销。本轮 0 新任务前向、训练、VALID/TEST 或 GPU。

**下一步先查任务缺口，而不是再换过滤器。** 仅使用同一留存开发队列的、已保存且可验证身份的 gen98 Q/D/G/Gcov 完整分数（若保留）：将全40正例错误分成「正类第一名本来正确、仅输给 null」「金标正类第2–3」「正类第4及以后」，并同时保留 false positive、先验与跨控制同一例配对；不做阈值选择或以金标指导部署。复用既有记录并与旧“移除 null 的一阶分解”排重，唯一预期增量是输在多深的次序、且 Q 是否具有对强经典不同的可补空间。缺分数则只报告分层在现存 CM 下不可识别，不复算模型。只在证据支持后改变所选新机制的任务预测，不复活 gen98。原目标持续 Active，旧限定 L4 保留。
