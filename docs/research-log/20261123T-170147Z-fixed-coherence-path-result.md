# 固定训练路径：有局部收益，尚无独立方法优势

本轮只检验一个问题：保持原 Q-RMEA 的最终模型、参数、初始化和训练预算不变，从去相干逐步走到完整相干，能否改善训练，并超过必要对照？答案分两部分：相对直接训练的 Q 有收益，但仍未超过去相干和实数对照，因此不进入正式验证，也不接受新 L3/L4/L5。

所有新模型使用已暴露的 TRAIN 中 4,192 条拟合、4,000 条按句子分组隔离的评估数据；seed13，1,024 次更新，batch32，最终更新为唯一选择。两个新模型都从头训练，使用同一线性进度 eta=(step-1)/1023；评估固定 eta=1。此前四路参照保持原样直接复用，初始状态和批次次序哈希逐项一致。

| 模型 | 正类39类 Macro-F1 | CE |
|---|---:|---:|
| 原 Q，直接训练 | 17.7446% | 0.913702 |
| Q，去相干到相干训练路径 | 21.5778% | 0.856612 |
| 实数，同一路径 | 23.1989% | 0.845278 |
| 实数平方参照 | 24.2217% | 0.845494 |
| 去相干参照 | 27.0908% | 0.838127 |
| softmax 参照 | 18.0461% | 0.858867 |

相对原 Q，新路径提高 3.8332 个百分点；相对同路径实数仍低 1.6211 个百分点，相对去相干低 5.5131 个百分点。五项预定比较只通过两项，固定候选关闭。不能从这个结果声称相干机制、量子方法或整个课程学习家族无效，也不能改变本候选的曲线、种子、切分、更新数或对照来补救评级。

这个局部收益伴随明确的取舍：正类被误判成 null 的数量减少137，但 null 假阳性增加72；旧正确样本损伤215个、旧错误修复267个，净正确增加52。39类中15类 F1 上升、5类下降、19类相同。16个拟合样本不足10条的类别贡献约0.4396个百分点，其余23类贡献约3.3936个百分点。因此收益并非只由少数稀有类别产生，但也不是所有类别一致改善。

本轮还发现筛选协议的局限：完整 TRAIN 有39个正类，此小切分的拟合集覆盖38类、评估集覆盖37类，16类拟合量不足10条。该支持度检查在本轮结果揭晓前完成；它不改变本轮判定，也不能解释全部负向比较。它提醒我们，后续共同筛选协议需要先确认类别支持和训练规模是否足以反映实际任务，不能把每个小规模负结果当成全量方法不可能有效的结论。下一步先做这项协议资格检查，保留所有既有候选及其失败边界，不重开本候选。

实现仅在稳定训练器增加两行逻辑批次进度钩子，模型变化封装为插件；端点、密度矩阵公式及梯度、padding、首步有限性等针对性检查通过。固定评估时与原始纯相干端点完全一致。所有模型均为81,028个注册可训练标量；已知对称不变方向保留并披露，不宣称有效容量相同。标准同伦、去相干通道和已有量子课程学习本身不构成新的高级理论。

本轮两臂实际训练与评估约432.30秒，执行记录 exit0；保存预测独立重算 Macro-F1 误差为0。调度分配已释放。未读取官方 VALID/TEST，未进行 COS 写入，未下载原始数据、预测数组或模型到本机，未重复恢复能力测试。
