# 从多实体相关性，定位到相对排序与绝对拒识的落差

实际流程是Re-TACRED文本与指定主宾实体经带标记RoBERTa形成现有缓存，完整Q-RMEA或经典对照头对词向量取值、加权并输出40类分数。最高分决定关系或无关系。原正式实验以39正类Macro-F1衡量类别平均效果。本轮只复用完整TRAIN58,465条的四头输出，不重新编码、训练、改预测或读取VALID/TEST；以下均为诊断，不是新方法效果。当前重建缓存与历史正式缓存字节不同，不改写已验收L4结果，L5尚未接受。

与上一轮相比，本轮不再用少量结果分层样例推测总体原因，而是先做完整TRAIN的预声明分层相关性检查，再做模型输出盲抽样语义检查，最后描述同文不同实体对的实际预测。最后一项为看到前两项结果后的探索性补充，未伪装为预声明验证。

## [已测事实] 多候选对象与漏拒相关

将“同一句、同一主语、同一对象类型下，存在另一个已标注且不重叠的对象跨度”作为输入结构代理。它不是完整NER清单，更不等于已经验证的语义绑定困难。

TRAIN中15,157条满足代理条件，其中正例4,839条；另一组正例14,865条。按金关系类别与预先固定句长区间匹配可比格，每格两组至少10条，覆盖26类、56格。先在每类内以两组支持较小值加权，再对可比类别等权。预先固定门槛为至少10类、每侧至少500正例、四头漏判率增量均至少1个百分点。

| 完整头 | 分层后正例漏判率增量 | 类型/句长分层后无关系误报率增量 |
| --- | ---: | ---: |
| softmax | +1.2872个百分点 | −1.0309个百分点 |
| real-overlap | +4.1307个百分点 | +0.0608个百分点 |
| Q-RMEA | +1.4475个百分点 | −0.9271个百分点 |
| dephased | +1.9534个百分点 | −0.8960个百分点 |

门槛均通过，故值得继续语义核对；这不证明因果，也不是量子特有现象。完整统计计算2.521秒，0模型前向、0更新。见summary.json与design.json。

首次执行在原始文本与缓存逐行标签不一致时断言停止，没有产生统计结果。依据原提取器定义，以SHA256(str(metadata.id))与缓存id_hash做一一映射，58,465条全部重新排序，所有标签和词数逐条一致，再原样运行原假设、分层和门槛。原失败、修复说明和两次分配记录保留；没有重建特征或重跑模型。独立计数表重算差异最大1.388e-17。gen38/39均已释放。

## [已测事实] 语义检查未支持把代理当作根因

在看到任何模型输出前，以标签和输入结构分层封印32个不同句子：8对正例按类别/句长匹配，8对无关系按主宾类型/句长匹配。正例覆盖8类。标签只用于抽样，读者看不到金标签、模型输出、代理分组、配对或另一份回答；两次Sol6.1/medium使用既有判断提示及解析器。

两份回答均32/32有效。16个正例中，共同明确支持原金标签者10个，低于预设12；两组各16例，均有7例被共同明确判断存在竞争实体，差异0，低于预设25个百分点。故该代理不通过语义资格门槛，不将它当作已建立的实体绑定机制，不换样本或调整门槛补救。

这些是同模型隔离判断，既非独立人类，也不支持重标注或估计数据集噪声上限。详情见[语义汇总](https://github.com/tivilou/Q-Attention/blob/codex/research-loop-runtime-20261122/docs/evidence/rmea/20261123-train-binding-semantics/summary.json)。原句、盲判与逐例对齐均留在私有计算节点，公开文档不包含原文或逐例预测。

## [已测事实] 更直接的落差：已能排序，但仍把两者拒识

随后在完整TRAIN原有同文、同主语、同对象类型的不同对象对上，直接检查原标签与原预测。这是标签知情的描述性普查，与已关闭40对随机语义见证的重新抽样或评级无关。对相同输入只在所有标签一致时按ID哈希保留一个代表；本次没有冲突跨度。全部14,515个不重叠对象对中，2,664对是正关系／无关系标签对，覆盖1,264句、1,975个不同正例和36类正关系。配对数不等于独立样本数。

| 完整头 | 两侧均正确 | 两侧均判无关系 | 双拒识中正例关系margin仍高于负例 |
| --- | ---: | ---: | ---: |
| softmax | 1,808 | 396 | 318 |
| real-overlap | 1,759 | 511 | 402 |
| Q-RMEA | 1,547 | 574 | 459 |
| dephased | 1,572 | 594 | 469 |

这里关系margin是正例原金关系分数减无关系分数，对配对两侧用同一关系行计算。Q的574个双拒识对中，459对已经把真正正例排得更高，但两侧的绝对决策仍均为无关系。四头共同双拒识219对，对应112个不同正例、105句、20个关系标签；不是219个独立可修复错误或预期收益。见paired-collapse.json。统计与私有配对索引的独立核对通过。

## [机制解释] 优先检查绝对证据参照，而非直接增加实体交互

同文配对显示，大量失败仍保留关系的相对排序信息。与简单结构代理未获语义支持相结合，它更值得提出的问题是：为什么已有相对证据没有形成可靠的绝对关系／无关系判断？可能包括上下文相关的拒识参照、证据强度学习不足或标注/语义歧义；当前没有把其中一项确认为主因。

这不是说给每句加金标签偏移就能部署。推理时仅有任务允许的输入，不能使用标签、额外完整实体标注，不能假设一句话至少含一个正关系。已有全局/类型校准、无关系逆滤波、有限梯度步和共享差分方案维持各自关闭状态，本轮不挽救它们。

## [尚未证明] 一个下一方向

唯一推荐：从这些自然正／负配对，推导一个能在原推理输入上计算的上下文相关拒识参照假设，并给出同输入经典对照，再决定是否实现。最低下一动作是明确该参照的可观测输入、公式及区别旧方案的预测；CPU纸面/已有输出分析预算10分钟、0训练，不申请新资源。若只能得到旧全局/类型偏移、旧差分函数的改名，或必须知道至少一个正例，则停止，不开GPU。若有实质区别且可用，再冻结一次最小干预及保护原正确正例/无关系精度的门槛，完成相应实现审查后测试。现有持续研究授权覆盖这个准备阶段。

本轮没有新训练轨迹或新编码反事实，相关sample-trace.v2训练/重编码阶段不适用；私有census、自然配对、固定32句选择和两份判断均有真实哈希。不存在从汇总反推未记录中间激活的行为。没有新效果、量子必要性或L5结论。
