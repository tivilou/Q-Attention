# 点态不可判对解释未出现：下一问题是共享学习，不是无限制表达能力

本项目用固定编码器的词特征和实体角色识别40类关系。原 Q-RMEA 将词映射到三量子比特状态，通过40个独立关系测量产生逐词 Born 分数，分数加 EPS 后归一化，汇聚另一路带符号分类值并加 bias。本次保留同一个已经训练好的原模型；既不训练也不改参数，仅对相同输入比较原版与既定“全部非实体上下文去相位、实体受保护”通道。没有 VALID、TEST、新 checkpoint 或 COS。

与上一轮直接比较固定测量的总体分数不同，这次把每个样本的40个测量方向分别放宽为任意纯态，求它理论上最好的 gold 分类余量。对每个关系，logit 是两个8维厄米矩阵的广义 Rayleigh 商；最小／最大广义特征值给出精确数学端点。gold 最高端点减所有竞争类最低端点中的最大值，若仍为负，才排除这个极宽松模型对该样本的严格正确判别。正余量不代表同一套共享测量、浅线路或真实训练能达到。

## 数据与预设问题

固定使用已有首8192条 TRAIN，7950条满足原输入跨度资格；其余242条在两条件下均恒等。每条都保留，没有按类别或结果挑选。该前缀实际有39种 gold 标签，缺类别23；每次端点计算仍包括全部40个输出类别和竞争者。旧版将“40输出”误写为“必须出现40种gold”，启动在导入Torch／数学fixture／模型调用之前停止；原失败执行、review及第24代资源返回记录保留。修正只允许现有标签子集并报告缺失标签，输入行、通道、阈值和成功／停止规则均未改，窄范围独立复审通过后用新attempt执行。

冻结双向假设：损害翻转中至少一条在去相位侧无论怎样选择测量也判不对；修复翻转中至少一条在原版侧有同样障碍。检查所有正确性翻转，不只检查某个关系。数值余量必须小于 -1e-7 并扣除保守误差才计证据；这里不是外向舍入的严格区间证书。

[已测事实] 事后仅复用已封印343条翻转的矩阵算术：所有点态最优余量都为正，原版侧最小2.023054、去相位侧最小0.402222；最大端点数值 allowance 为1.88e-7。于是这343条实际翻转没有支持点态不可判对解释。它们能被逐输入自由选择的40个测量判对，仍不构成一个共享可训练头或部署方法。

[已测事实] 修复157条中139条为无关系、18条为正关系；损害186条中9条无关系、177条正关系。与前一轮已封印完整开发 VALID 的算术一致：全部上下文去相位把无关系误报1169降为888，却把正关系漏报2293增为2954。这里描述固定干预的错误流向，不把它当独立确认、因果词汇解释或全局 bias 修复方案；旧全局offset与共同下降的负结果继续保留。

## 核对、留存与解释边界

[已测事实] 原实现输出／argmax、直接密度与矩阵商、全部不适用行恒等、源权重不变均通过。首次独立复算因科学环境没有SciPy而停下；改用服务器已经安装NumPy/SciPy的基础环境，原科学文件和输出不变，没有安装依赖或重跑推理。独立SciPy广义特征值逐个复算343×2×40个端点，最大误差2.31e-14；重新构造调整后余量、两组证据掩码、全部40类计数和停止判定，通过。新增gold覆盖字段另与旧资格计数及封印标签算术核对一致。实际退出0、stderr为空，成功attempt第25代资源已返回，宿主和进程组均为空。

原始预测、标签和矩阵仅保存在GPU服务器私有NPZ，Windows只收紧凑结果。无个案文本／sample-trace.v2归因，不能从汇总数反推词义或隐藏态案例。稳定模型、运行器、恢复与调度核心未改。初版静态BLOCK、修订PASS、首次覆盖检查失败和复算环境失败均保留，不重写历史。

[机制解释] 这排除的是当前样本上一个具体、过强的解释：“去相位使固定状态与分类值在任意逐输入测量下都无法判对。”不能排除共享效应的约束、浅线路可达性、优化或泛化，也没有识别它们各自的贡献。理论上的逐样本自由度很大，证据不能支持继续以它替代真实可学习机制。

[尚未证明] 标准广义特征值理论本身没有新颖性；CNM与后续复数量子语言模型近邻比较仍有边界。没有新方法优势、量子必要性、独立实证或L5验收。原版限定L4保留。唯一后继推荐见 primary-next-decision.md。
