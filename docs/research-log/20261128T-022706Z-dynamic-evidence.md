# 动态纠错的任务资格与受限读取的量子边界

## 原任务缺少本轮所需的自然信号—干扰对

固定 FIT4096、原标注和缓存行身份。两个规则在读取结果前确定，且匹配有序实体跨度以及两端的原标注类型。一条规则只允许整段更换一端实体表面文字，其他 token 和跨度坐标严格相同。另一条规则固定两个实体，只允许一个非实体 token 不同，不使用实体或句子级近似匹配。

| 固定规则 | 同标签自然对 | 其中同为正类 | 异标签自然对 |
| --- | ---: | ---: | ---: |
| 仅一端实体表面字串不同 | 0 | 0 | 0 |
| 固定两端实体，仅一个非实体词不同 | 2 | 1 | 0 |

没有行同时连接「改一端实体但保持正关系」与「改一个非实体词而关系标签变化」。这是眼前固定样本和谓词的覆盖结果。两对已标注的同标签例子不足以确认潜在的标签保持规则，尤其不能把类型相同当作可互换实体。[FIT 原位汇总](/docs/evidence/rmea/20261128-dynamic-evidence/variant-result.json)

旧 Round11 的固定 32 条盲筛仅许可两组三元对；既有封口报告认定原句和假名对照各 2/2，变更关系的对照 0/2。它们是提前许可的假设性文本与有限标注，对早先模型构成有范围的诊断。历史结果继续保留，本轮未复跑编码器，也没有把这些例子写进未来小筛或用作普遍标签证书。[Round11 结果](/docs/evidence/rmea/20261116-l5-round11/compact-report.json)

## 动态纠错确实能区分特定合成时序

取 3 比特中的偶奇编码，逻辑状态跨越 |000〉与 |110〉，第一根线的 Z 相位旋转承载正负信号，X 位翻转是手工指定的干扰。由于 X 与 Z 反对易，「先正相位、后翻转」和「先翻转、后负相位」产生相同的未恢复末态。任何只接收这个末态的固定测量对二者给出同一分布。

如果在中点及末端都做奇偶测量和已知翻转恢复，就能保留正负信号，也能在符号相同时抵消早翻与晚翻的差别。对逻辑基底做去相干，两世界的对角分布相同。9 个人工词、40 个独立二元测量及全 64 维词值的复算给出：动态路径最大 logit 差 **6.8635**，只用最终恢复时两世界 logit 差为 **0**。这个量级来自人工词值，不能当作任务效用。

公平的时序对照也应知道事件时序。由同一事件序列计算有符号逻辑相位，再用 (1+cos(θ−φ))/2 生成同等读出，经典对照复现全 40 类和全部值池，最大 logit 差 **5.33×10⁻¹⁵**。这一区分说明中间状态及反馈确有作用，只比较末态时会遗漏信息。它没有分离得到同一信息的经典机制。语料还没有给出把真实关系列入 Z 信号、把某个可验证干扰列入 X 事件的依据。**SEARCH‑50 不选择动态纠错小筛。**[可复算实验](/docs/evidence/rmea/20261128-dynamic-evidence/dynamic-result.json)

## 新的计算角色：有限通道上的事后读取

Ambainis 等原作 v3 明确设定发送者先编码，接收者后来选择要恢复的一个输入位。复核 PDF 第 1–8、13–16 页的任务、经典策略和 2→1 QRAC。使用相同的均匀 2 位合成问题，枚举 16 个经典 1 位编码器及 16 个确定性解码器，平均恢复准确率最高 **0.75**。共享随机性只混合这些确定性策略，均匀平均不能超过该上界。原量子码只读取事后指定的一位时达到 **0.853553**，原编码后固定 Z 去相干时为 **0.676777**。[原作](https://arxiv.org/pdf/0810.2937v3)

若强制用这份编码的一次共同测量同时给出两位，令每个输出 t 的收益算符为 W_t=Σ_b ρ_b·(正确位比例)/4，最大特征值为 3/8，因所有测量效应和为 I，任意该类解码的平均准确率至多 **2×3/8=0.75**。复算的四结果 POVM 达到此值。这条界限只覆盖固定四码字。允许无噪连续实数时，一个标量可凭四个离散取值重放四种输入。用参数数相等代替实际输出信息预算会产生无效的量子归因。[读取边界核验](/docs/evidence/rmea/20261128-dynamic-evidence/qrac-result.json)

原生 Q-RMEA 的固定源中，所有 40 个查询效果和全部词向量一起收缩，并保留完整 64 值路径。它没有同样的单次晚查询前提；多次制备或同时保留全部实数分量都改变了资源模型。只在原任务内部检查是否存在对决定有作用、无需标签、可核算且对经典公平的条件读出机会，才考虑保留这条计算角色。若不能同时保持决策、信息访问和成本约束，就不把有限通信实例移植到 Q-RMEA。原小筛的预算、完整标签及公平对照继续适用。

本轮没有模型前向、更新、GPU 分配、变体生成或新资格标签索引。gen98 停止裁决、原限定 L4 及全部历史保留，新 L3、L4-T 未接受。
