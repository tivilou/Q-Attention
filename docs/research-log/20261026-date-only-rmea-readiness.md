## 项目工作流与这次变化

项目以一句话和有序实体对预测关系。原词及主宾语标记进入冻结 RoBERTa-large，得到词级特征；标签只用于交叉熵训练和评估。可训练部分是词权重、共同值投影与分类器。每种候选关系都计算一组词权重、池化表示和分类分数，40 类共同竞争；验证 Macro-F1 选择 checkpoint。主指标 Macro-F1 固定平均 40 类，非空关系 micro-F1 衡量抽取表现，交叉熵衡量预测分布与标签的差异。测试集不参与这次模型计算。

## 经验、证据上限与推荐

正向经验：[已测事实] 同一份冻结特征可支持三种对照的共同输入；本次 GPU 计算、首步梯度、有限数值和封存导出路径已实测。

负向教训：[已测事实] 两轮不足以建立成熟任务表现，不能把损失下降或 B2 短测领先当作新 idea 成立，也不能把输出哈希当作原始输入哈希。后者曾导致首次审计拒绝，修正后重跑审计通过，未改数据。

机制判断：[机制解释] 类别相关权重可能改变证据分配，但该解释在本次没有机制 trace 支持。[尚未证明] Q-RMEA 效用、与经典对照的关系、重复性、L2/L3、量子归因和新颖性均未建立。当前仅技术可运行，整体资格 `insufficient`，方法 `exploratory_only`；历史 Q-SRM 停止决定不变。

推荐恰好一个方向：先完成共同特征基线资格研究，再决定新方法实现。

- 假设：共同输入和成熟预算能形成可审计的任务学习与基线差距，而非两轮多数类退化。
- 最小实验：先冻结完整预算单 seed 的 B0/B1/B2、同一私有缓存、验证选点、固定 trace 和仅报告回传协议；经审查和 canary 后交给合作者执行。
- 成功门槛：预先声明的全部条件、计数、哈希、无泄漏与公平性门槛通过，形成成熟学习/比较证据；不要求某个新方法胜过经典方法才能资格通过。
- 停止门槛：输入/目标泄漏、非法跨度、条件不齐或不可恢复产物时停止并修复；普通短测零结果不是机制家族否决。
- 资源：一次全体词级 FP16 缓存下限约 6.33 GiB，加索引、元数据和 checkpoint；正式 GPU 时长尚未估准，不能把 88.64 秒直接当成全程预算。
- 不确定性：新输入/骨干与历史十五配置预算不同，历史表现不能直接充当新共同基线。
- 授权：用户“开始”已授权代码准备；完整正式运行只由合作者执行，本检查点未分配运行、未启动新 seed。
