## 实际流程与局部变化

输入为冻结 RoBERTa 的1024维词特征及4维实体角色。原 Q-RMEA 用共享三量子位线路准备词状态，以40个关系状态分别计算保真度，加入 EPS 后在有效词上归一化，再对64维 value 的关系标量读出加权，得到40类 logits。TRAIN 标签通过交叉熵训练小头；本次固定最终第4轮用于评估，VALID 不用于选择不同终点，TEST 在训练后报告。主指标是39个正关系的平均 F1（Macro F1），CE 是平均分类交叉熵。
