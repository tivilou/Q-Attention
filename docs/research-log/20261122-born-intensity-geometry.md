# 实体概率保护：一个仍待实数据验证的方向

本轮受保护/DFT/无保护的三卡全量任务继续运行，未更改其方法、种子或对照。达到50%时备份进程因一次SSH退出255中断；只重启同一备份进程，确认050COS后原训练继续，没有重提训练。

从实际代码发现：当前保护的是完整复振幅；实体状态满跨度时修正为零。Born读出实际只使用概率，较弱的概率约束可能保留额外运动。八维显式例子可以精确保留所有实体概率，同时把一个上下文响应从1/8压至0。常秩几何及相位恢复原文支持这种区别，但这些数学本身是已知事实，不申报L5新定理。

进一步得到一个正则分支上的精确局部回缩构造。固定非正交满跨度合成例中，一阶切向步骤约束误差1.4882e-5，回缩后2.22e-16，能量-0.00112824、相对logit+0.00106078。这里只证明一个合成状态接口的能力；尚不说明实数据、分类收益或浅电路可实现性。

已冻结零拟合32例TRAIN诊断：先按输入角色筛8..13个实体token，再按ID排序取前32例；保留不适用和失败例，固定原生checkpoint、类别0与阈值，不用标签挑方向。原生精度由真实原run配置和执行源码确认float64/complex128。Astra6.2/high数学复核通过；机制审核在修复精度证据缺项后通过。当前全量任务完成并静止后，才用既有CPU调度执行。新诊断源码为experiments/q_rmea_intensity_fiber_probe.py；没有开始新的全量训练。

相位恢复和带二次约束的波束形成是明确近邻，创新性仍需进一步比较。旧方法的限定L4不变，新构造不继承它，L5未达标。详细数学、阅读范围、固定设计、合成结果和准入意见见同日born-intensity-geometry证据目录。
