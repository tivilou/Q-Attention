## 唯一候选的明确公式

取单query内有效词、subject词、object词三种H均值拼成z_q∈R3072。它保留原部署输入边界，但池化有信息损失，未证明充分性。

令d=8，r∈{0,…,39}：

```
v_qr = Circuit_3q,depth2(pi*tanh(W*z_q + theta_r)) |000>
A_qr = exp(beta_r) (v_qr v_qr* + I/d)/2
S_q = sum_r A_qr
E_qr = S_q^(-1/2) A_qr S_q^(-1/2)
p_q(r) = Tr(E_qr)/d
J_qt(r,s) = Tr(E_qr E_ts)/d
```

全秩混合系数固定1/2，不是失败后添加的EPS。每个query的40个正效应和为I。以rho0=I/d为探针态，依次使用K_qr=sqrt(E_qr)的Lüders测量，J就是两次读出的合法概率；其两个边缘分别为p_q、p_t，且此特定探针下两次顺序可交换。它是**pair-composite score**，不是所有关系标签的全局联合分布。W12×3072、theta40×12、beta40共37384个标量，仅公式数组计数，不是有效容量或生产参数证书。没有学到共享实体状态：实体只确定FIT中哪些query组成对，rho0对所有实体相同。

拟议损失是单query平均负对数概率，加每个无序FIT coedge实际两金标的平均负log J，系数固定1。其他实体／标签只作FIT监督，推断仍独立p_q。无硬逆标签、无缺失边=null、无评估邻居标签。

## 为什么数学通过后仍退出

[机制解释／精确恒等式] 记F_qr=E_qr/Tr(E_qr)，则

```
J_qt(r,s) = d*p_q(r)*p_t(s)*Tr(F_qr F_ts)
-log J_qt(y_q,y_t)
  = -log p_q(y_q) -log p_t(y_t)
    -log[d*Tr(F_q,y_q F_t,y_t)]
L = sum_q [1/N + degree(q)/M] * CE_q
    -(1/M)*sum_(q,t) log[d*Tr(F_q,y_q F_t,y_t)]
```

N是FIT query数、M是无序coedge数；最后一式限M>0，不含缺失边。额外反馈确实存在，但可精确辨认为**按图度数加权的分类损失＋相邻样本金标密度表示对齐**。它不是“样本仅放进同一个batch”，也不等于任意无约束经典网络的整个函数类；然而，它没有提供此轮冻结要求的共享实体状态／反馈机制或任务特定区分预测。梯度变化还会混入degree重加权，不能全归因量子联合学习。
