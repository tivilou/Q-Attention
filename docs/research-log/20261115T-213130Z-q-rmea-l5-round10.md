# L5第十轮：名称偏差与任务信息的边界

研究记录时间：2026-11-15T21:31:30.751135+00:00。这是原文/代码审查和下一步诊断设计，未运行新实验。

项目实际流程：冻结RoBERTa先编码带有序实体标记的完整句子；量子头为各词生成各关系的权重，另一路value给出词对类别的数值贡献，两者汇总后选择分数最大的关系。我们负责想法、代码、有界测试与报告审查，师弟执行新正式完整数据实验。Macro-F1反映各类F1等权平均，CE衡量真实类别概率损失；旧限定L4对应已审计的原运行，不能自动迁移给改动后的模型。

[已测事实] 三份精确版本原文已按页读取并核验身份；官方Re-TACRED补丁只给保留样本改关系标签，不逐条重写其余字段。实际缓存生产提交的marker/input两份代码匹配原部署SHA，实体名称先进入上下文编码器。没有读项目test数组、加载模型、生成Case Study或读取合作者服务器；sample-trace在本轮不适用。

[机制解释] 若名称变化通过上下文value改变最终分数，仅看attention稳定会漏掉实际影响；把所有实体信息去掉又可能破坏PERSON:IDENTITY所需共指。CoRE与VIB已有直接相关去偏机制，泛化口号不是新创新。简单乘积变化核算是已知恒等式，不是新定理或因果中介。

[尚未证明] 当前Q-RMEA究竟有何可修复的名称敏感性、量子头贡献多少、是否优于匹配经典控制均未知。独立咨询仅支持一个探索性诊断问题，零个支持充分的新方法；L5未接受，旧限定L4不变。

唯一推荐下一步：先从固定前32个训练ID哈希顺序样本中，建立至多16个原句的模型输出盲态语义证书；对每个可许可样本分别构造保持关系改名和改变关系/共指的对照。不得依据预测更换样本。未来至多48个输入、0训练；先检查语义和来源，再独立审查实际worker并通过统一调度。当前只形成设计，尚未选样或做前向。成功门槛是两种语义对照与完整decision/state/weight/value路径可解释；注意力稳定但分类错误不算成功。若固定池无法产生可信对照，停止该诊断设计。所有小样本结果只能用于发现/否定具体机制，不能接受L5或证明总体收益。
