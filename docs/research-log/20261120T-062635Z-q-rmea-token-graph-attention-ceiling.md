# Token 图传播：固定 key 的注意力上界分离

本项目用冻结文本编码器产生每个 token 的1024维特征，再用原生三量子比特、两层参数电路得到 token 状态和40个类别各自的 query 状态。每个类别分别计算 token 匹配概率并归一化；这40个类别不是一个共同 POVM。最后用注意力对原来的 token 效用值加权，形成40个分类分数。旧 Q-RMEA 的限定 L4 只支持原方法的普通任务效用与局部权重—值对齐。

当前候选在匹配概率之前增加 token 图上的振幅传播，保持原来的值和最终读出不变。图由 token 状态的内积及其模平方构造，传播时间固定1/4，不读取标签。对照包括原生注意力，以及先去掉初始 token 振幅间相干、再经过同一传播的概率对照。本轮研究的是这个候选的数学边界，没有训练新模型或读取文本数据；新候选尚无可报告的 CE（交叉熵）或 Macro 指标。

**[机制解释／解析结果]** 三个固定 token 状态构成的例子中，原生注意力的中间 token 权重至多为 `(1+epsilon)/(2+3epsilon)`；在声明的时间区间内，初始去相干对照也受同一上限约束。相干传播的显式 query 可以严格超过此上限。因此，即使让两个对照各自重新选择任意物理 query，也追不上这个坐标。用固定线性读出能把该间隔变成分类决策间隔；把合成标签反过来则会变成损害，不能由此推断文本收益。

**[机制解释／设计边界]** 线性 Gram 图可等效为对 query 做物理酉变换，固定 key 的完整可达注意力集合不变。当前逐元素三次 Gram 图在一族不对称状态中可打破这个限制；对称例子的该间隔消失。这给出了可区分的控制，不证明三次图是唯一选择，也不证明“非线性”本身足够。

**[已核验事实]** A6API `gpt-6.2-astra`、medium 对两版公式和源码文字映射完成审查，核心公式均通过。三处文档澄清已落实：双精度／有效mask、变换后key的范数、analysis/synthesis术语。审查不是新数值实验，也不是新颖性证明。原文核对包括量子游走神经网络、MagNet、Q-Interference：振幅传播、复数图滤波和相位匹配已有先例；这里可讨论的窄贡献是具体概率分离及其对照边界。

**[尚未证明]** 新三 token 例子尚未在源码中执行；没有梯度、CUDA、训练、真实文本收益或独立实证证据。数学用到已知 frame、广义 Rayleigh 商和 POVM 上界工具；具体结果的重要性和文献优先权仍待判断。原方法 L4 不能自动授予这个改变后的候选。L5保持未接受。

合成案例状态：已给出固定输入、全部参数的构造及解析中间量；新执行 trace 尚未产生。它不是 `sample-trace.v2` 实物，不能将公式当成已测案例。真实文本案例、训练案例和新总体指标本轮均未运行。

唯一推荐的下一步是通过共享调度在2080Ti节点做一次有界源码对应检查，核对有限电路、两个注意力上限、相干决策间隔、线性图对照和超出定理区间的反例。数值误差须小于1e-9且小于决策间隔的千分之一；任何关键不一致即停止对应性接受并保留报告。GPU环境、准确代码和生命周期准入尚须验证；该设计不授权全量训练。随后才冻结面向真实效用的匹配有界实验；新正式全量实验仍交给师弟。
