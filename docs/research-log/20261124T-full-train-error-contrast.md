# 五路完整训练后：量子头能拟合，但优势未能迁移

今天用同一批完整实验的五个最终选中模型，把全部 58,465 条训练样本重新做了一次前向。没有重训或增加验证／测试集访问，运行172秒。

Q 的训练集 Macro 为0.8756，去相干版为0.7937，两个经典对照为0.8789和0.8968。Q 明显能学会训练数据；但它在原测试集上仍落后于去相干与经典对照，因此下一项值得查的是学到的相干贡献是否可靠地泛化。选择epoch不同，这还不是相干过拟合的因果证明。

有867条训练样本只有Q出错、三个非均匀对照都正确，其中754条涉及“有关系／无关系”边界，而且两个方向都有错误。Q也独有地答对295条。这说明要保留有效相干贡献，同时解决样本依赖的边界错误；统一调低“无关系”分数没有得到支持。

接下来先对同一Q权重做内部全去相干的TRAIN配对诊断，把相干本身的决策作用与训练轨迹差别拆开；没有选择新方法、调整强度或重新打开已失败配置。新的L3和L4-T仍未成立，历史限定L4保留。
