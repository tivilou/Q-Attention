# 词元测量强度与分类值的顺序交互：未过证据门槛

项目从句子和实体位置得到冻结的词元特征，量子头计算各关系的词元测量概率，再归一化为注意力并汇总分类值。本轮保持已有预测器不变，检查它对固定词元记录的求和是否遗漏了有用的顺序交互。没有训练新模型；VALID、TEST、完整实验 Macro 和任务收益均不在本轮范围。

候选量把每个词元写成“相对平均测量强度、加权中心化分类值”的二维记录，再计算中心化有向面积。它与上一篇共用量子测量的成本问题不同：这里不抽样、不改测量预算，而是考察模型的读出信息。面积、二阶序列签名和排列投影均有已有数学工具，不能单独当作新理论。

[已测事实] 固定前 8,192 条 TRAIN，按完全相同的词元字符串分组后分为校准 4,192 条、评估 4,000 条，共 7,013 个句子组。没有文档来源 ID，不能把它称为文档级分离；这些 TRAIN 还可能参与过原 checkpoint 的训练，因此只是探索性诊断。

仅用校准集拟合置信度及位置控制，消除这些因素后，每条样本的完整配对和打乱值配对具有相同的类别扰动均方根幅度。两者各自在校准集锁定自己的方向，全部样本保留。评估指标是原模型交叉熵对该方向的导数，负值表示局部方向有利，不等于实际训练收益。

| 评估量 | 平均方向导数 | 句子组 bootstrap 百分位区间 |
| --- | ---: | --- |
| 完整配对／调整后 | -0.013179 | [-0.029730, 0.003784] |
| 打乱配对／调整后 | -0.002230 | 未单独设为主区间 |
| 完整减打乱／配对比较 | -0.010948 | [-0.034715, 0.011101] |
| 原始面积／完整方向 | -0.009818 | 仅检查方向一致性 |

2,000 次 bootstrap 使用事前固定种子，重采样整个相同句子组；这是条件于校准拟合的近似探索性区间，没有保证覆盖率或确认性显著性。[已测事实] 两项主区间均跨过零，虽然平均方向有利，仍未通过冻结门槛。**关闭这个具体方案，不增加样本、改控制、换方向或换种子挽救，不训练对应插件。**它不是全部顺序读出的无效证明。

实际计算 16.054 秒，其中词元记录收集 12.375 秒。前缀、成对、三元组公式、位置分解、条件排列均值、退化和反向序列的数学夹具均通过；原模型重放最大误差约 1.07e-14。首次静态审查指出控制方向恰好为零时应一并使门槛失败，已在任何实验执行前修复，并保留 BLOCK 及后续 PASS 记录。没有把修复当成科学结果重跑。

退出 0、stderr 为空，结果封印、私有数组哈希、方向导数、类别贡献、幅度匹配和区间已独立核对，调度分配已释放。稳定训练核心和运行器没有改动；未运行中断续训／COS 恢复矩阵，未写 checkpoint 或 COS，未下载模型或数据集到 Windows。

本轮没有训练案例。未保存完整逐词元 sample-trace.v2，不能从汇总导数重建文本案例或宣称 Case Study 完成；数学夹具是实际计算检查，不是自然文本案例。量子概率、值和词元记录的语义因果归因未建立。

[机制解释] 结果只说明当前统计量缺少超出预设控制的可靠方向证据，不能用有利的点估计升级。[尚未证明] 新颖性、独立任务收益、量子必要性及 L5 均未成立。原有狭义 L4 保持不变。

唯一推荐的下一步是检查归一化时没有直接进入读出的测量接受率，并以同一测量的去相位接受率为参照。它与词元顺序和分类值无关；先做冻结模型的 TRAIN 诊断，避免重复本轮顺序方案。选择边界见 primary-next-decision.md。
