# 同词出现位置对照：覆盖不足，未运行模型

本项目在 Re-TACRED 中对句子进行 40 类关系分类。词表示、实体角色和原模型均已固定。本轮原计划保持每个关系对某个重复词的总权重，以及两处词在所有关系上的总权重，只移除同词两次出现之间的句子相关分配；再比较正确决策与交叉熵。它不改变原模型，不增加分类参数，也不重训。

与上一轮直接相位读出不同，这一轮不新增预测特征，而是试图对现有注意力作保留边际总量的反事实替换。两个测试的具体方案和停止规则独立。

[已测事实] 已从 owner 现有原始数据恢复前 8,192 条 TRAIN 和全部 19,584 条 VALID 的原词、实体跨度与样本哈希。两个源文件 SHA 与原实验一致；所有 27,776 条样本的 ID、词数、偏移对应和重建角色坐标均与原缓存精确匹配。只通过内存中转，Windows 未落地数据文件；没有新增 COS 写入。

原定 key 是“完全相同的原始词字符串＋完整四个角色坐标”，同一句中恰好出现两次；只使用在 TRAIN 至少出现 32 次的 key。角色前两维是裁剪的连续实体相对距离，后两维是实体成员标记。因此不同位置具有完全相同角色坐标，通常只在距离裁剪饱和区出现。

[已测事实] 覆盖门槛未过，按事前规则关闭这个具体设计。没有执行注意力替换、原模型推理、优化器更新或 TEST 评估。因此没有可报告的 CE／准确率变化，也没有注意力作用大小的估计。

[机制解释] 本轮暴露的是支持重叠不足：对连续位置坐标作完全匹配会把同词出现位置分得过细，无法形成所声明规模的对照。不能把它说成原模型注意力机制无效，也不通过删除角色维度、降低 32 次门槛或改词规则来救回冻结设计。
