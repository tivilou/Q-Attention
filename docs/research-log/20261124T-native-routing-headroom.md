# 这次检查排除了什么，又没有排除什么

我们对已经训练好的原版Q与最强经典real12，完整检查58,465条训练样本。这次没有训练新模型，也没有重新看验证集或测试集，双卡计算用时41秒。

Q答错3,611条，其中3,579条（99.1%）如果允许每条样本独立选取查询方向，在现有词状态、分类值和decoder完全不变的条件下，数值上仍然可以分对；经典模型对应3,068/3,070。

所以，继续用“原来的词权重或分类值表达不了答案”解释大部分失败，证据不支持。难点更可能在如何让同一套参数学到可迁移的规则，但这里还没有区分参数共享、电路参数化、优化和泛化中的哪一个。

99.1%也不是模型能达到的准确率：计算时每条输入、每个关系都可独立选择方向，还用到了正确标签，实际模型没有这些自由度。新L3/L4-T仍未通过，之前三个失败的全量配置保持关闭。

下一步先核对已有量子自然梯度理论，再决定是否存在与归一化注意力直接相关的新训练机制。已知优化器或漂亮矩阵恒等式本身不会被算作新的理论贡献。两张GPU已经释放，本机没有下载checkpoint、特征或逐例预测。
