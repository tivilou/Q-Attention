# 将“正关系被拒识”进一步分解

本轮实际流程：Re-TACRED文本和指定主宾实体经带标记RoBERTa得到已缓存词向量；四个原完整头分别以自己的注意力对线性取值加权，输出40类分数，其中1类为无关系。比较正关系候选与无关系的分数、词级加法贡献及已有盲语义判断，再在完整TRAIN上检查固定路由的读出恒等式与导数。没有训练、改预测或读取TEST；本轮未重新运行RoBERTa。正类Macro-F1衡量39种关系的类别平均效果，CE为交叉熵训练损失，本次新结果只属于诊断。重建缓存与历史正式实验字节不同，不替换已验收历史指标。

本轮保留完整模型和全部标签，先查哪些解释受到数据支持。L4不变，L5尚未接受。

当前最有依据的问题是：**模型已有正确的正关系候选，却未能把针对指定实体对的完整语义证据转化为足够的“有关系”判断。** 四个完整模型共有1,155条正例漏检，其中672条在四个模型中都已经把正确类别排在全部正类的首位。它们最终仍输给无关系。这是带金标签的错误定位，既不构成推理时检测规则，也不等于672条均可被某个方法修复。

如果能在保住原正确正例与无关系精度的同时修复这类拒识，模型表现就有实际改善空间。研究问题必须包括这两个保护条件，不能把普遍压低无关系分数当作解答。

## 1. [已测事实] 共同漏检通常伴随强无关系判断

对四个完整模型已有19,584条VALID输出，仅进行已知概率粗粒化计算：

`E = logsumexp(所有被允许正类logit) − no_relation_logit`。

E为正表示全部正类的softmax概率之和超过无关系概率，并不表示最大正类正确，也不说明应改变现有决策。在1,070条正确标签被类型规则允许的共同漏检中，E为正的数量分别为：softmax15、real11、Q-RMEA36、dephased17。Q-RMEA余下1,034条仍偏向无关系，中位E为−1.854，约对应无关系概率0.865。因此，“正确候选概率被其他正类分散”只覆盖这批漏检中的小部分。

这是固定模型的描述性结果；没有改变预测、拟合阈值或挽救已关闭校准方案。另有48条Q-RMEA原正确无关系样例也满足E>0，因此这一条件自身并非正确修复规则。计算仅0.255秒，0模型前向/更新/TEST/COS，独立归一化概率恒等式误差3.553e-15，gen36已释放。完整记录见[粗粒化诊断](https://github.com/tivilou/Q-Attention/blob/codex/research-loop-runtime-20261122/docs/evidence/rmea/20261123-coarse-evidence-diagnostic/summary.json)。

## 2. [已测事实] 证据读出至少存在两种形态

复用上一轮128个固定实际读出，不重跑模型。在4条两次语义判断共同支持的Q-RMEA漏检中，证据位置对“正确关系−无关系”的贡献依次为：3.800、−0.049、−0.320、3.752；其余词贡献为−6.824、−3.728、−3.462、−5.420。两条已有正向证据却被更大的其余贡献抵消，另两条证据位置本身几乎没有形成正向分数。

正确正例对照也存在负的其余贡献，甚至有一条证据位置贡献略负。因此这些数值只是加法分解，既不是删除词的因果效果，也不足以构造错误检测器。语义证据交集未必包含全部有效信息。

## 3. [机制解释] 先建立完整命题，再处理拒识

一次独立Astra6.2/high咨询读取同一固定32例及完整读出，提出的任务假设是：应区分“某种关系在句中出现”和“该关系确实适用于指定、有方向的实体对”。可能涉及名称等价、指代/简称解析、枚举成员的事件角色，以及关系语义范围。比如参加同一事件本身不等价于居住关系。这些是对样例的解释，尚未证明某一种现象是总体主因，更未确定量子原因。

直接复用已冻结的两次Sol6.1/medium盲审，按原有confident_consensus标准得到：

| 原Q分层 | 共同明确正关系 | 共同明确无关系 | 未解决 |
| --- | ---: | ---: | ---: |
| 共同正例漏检8条 | 4 | 2 | 2 |
| Q正确正例8条 | 7 | 0 | 1 |
| Q无关系误报8条 | 1 | 7 | 0 |
| Q正确无关系8条 | 0 | 8 | 0 |

判断输入没有金标签、模型输出或样例分层，故可充当已有的、共享于四个头的语义对照。它确认这4条漏检和8条拒识在当前读者能力下可区分；同模型隔离调用不等于独立人类，且这是结果分层抽取的32例，不能估计部署收益、重新标注或接受L5。那个被两次判断支持为正关系的标注无关系样例继续保留原标签。

咨询提出了独立冻结NLI检查作为后续工具。已核对原作者NLI模型卡与标签顺序，但没有下载权重、安装依赖或运行新NLI模型：同批样例的初步无标签语义对照已可复用，下一步优先检查原模型。原始句子、提示和回答均留在私有计算节点，Windows只保存代码、哈希及聚合收据。

## 4. [已测事实] 完整TRAIN排除“读出维度不足”的直接解释

源码还给出一个实用的分解：取值层64维、关系40类；取值投影与decoder都是线性的。固定注意力后，两层可合并为每类一个1024维线性取值，函数空间未受64维低秩限制。因而现有证据不足以把错误归因于“64维放不下40类关系”。

这项只读诊断已在完整TRAIN58,465条上完成，Q-RMEA与经典softmax头两卡并行，38.258秒、0更新。合并读出最大误差分别8.094e-6与6.757e-6，对上一轮同缓存原始输出误差均为0。两个decoder的数值秩均40，条件数分别9.014与7.802。因此当前checkpoint没有明显的decoder秩塌缩；这不证明语义表示充分。

Q的原始有效读出梯度范数1.259，经典头0.986。不过，梯度范数受特征坐标原点影响：对同一已保存梯度做解析分解，公共特征平移最多可分别移除其99.9851%和99.9649%的平方范数，剩余范数0.01534与0.01846。这里的最优平移是看标签梯度后的描述量，不是部署规则或实际数据均值。**原始大梯度不足以支持“还有巨大读出学习余量”的判断，也不支持另开一轮校准。** 未测优化差距、有限更新收益或泛化收益。

NumPy独立核对奇异值、链式梯度、类别支持和先前CE，最大恒等式误差7.994e-14；gen37已释放。详见[条件读出推导](../evidence/rmea/20261123-case-evidence-bottleneck/conditional-readout.md)及[完整TRAIN诊断](https://github.com/tivilou/Q-Attention/blob/codex/research-loop-runtime-20261122/docs/evidence/rmea/20261123-conditional-readout-geometry/summary.json)。没有重拟合、调阈值或新量子插件。

## 5. 下一步只验证问题机制

首要候选机制是“针对指定实体对的组合语义证据未被可靠利用”，而非先规定需要某种量子模块。下一项诊断应从TRAIN依据文本结构分层、模型盲抽样，检查多实体、指代、简称与枚举中的关系绑定；同时保留明确正例、明确无关系及错误实体对对照。使用共享、无金标签的语义判断，再检查四个固定头的错误是否集中在某一结构上。先冻结抽样和判断标准，未运行前不把这个设计当作结果。

可区分预测是：若实体绑定确实构成可修复瓶颈，消除绑定歧义应使真实关系样例改善，而把同一线索绑定给错误实体对时不应出现同样改善。该检验需遵守原始编码路径：h已含@subject@/#object#标记，真实实体对反事实需要一致地重新编码，不能只改roles并沿用旧h。已有32例只能提供候选机制，不能代替这项新诊断。

若该结构不解释错误或干预同时增加无关系误报，就放弃该机制。通过后才选择最小插件，并与同输入经典对照比较；最终仍需适当独立实证。当前没有证据表明问题必须由量子方法解决。

建议的最小下一步是TRAIN文本模型盲抽样与匹配消歧诊断，先限制为至多64句、单节点CPU至多10分钟、0训练；需要新实体标记编码时先确认已有权重和资源，再冻结对照及数值门槛。目标是明确正例的关系对无关系margin随真实消歧改善，而错误实体对不出现同样改善；若不成立则停止该机制，不转为调阈值。后续研究在现有授权内，无须购买资源。该诊断尚未抽样或执行。

记录限制：本轮没有新增训练或生成阶段，故相应轨迹不适用。复用的32例推理词级贡献与语义材料沿用既有私有case ID和哈希，见contribution-summary.json与consultation-summary.json；未声称生成新的sample-trace.v2。原始句子、逐词数组和外部提示/回答均不进入公开日志。

这些是问题定位与研究路线的进展，尚未形成新的有效方法或L5理论—实证贡献。
