# 原版仍有路由空间：先区分可表示与可学习

全部不变，只做前向及线性代数计算，没有优化器、续训、VALID、TEST 或 COS
写入。使用此前已经暴露的前 8192 条 TRAIN，沿用整句子组4192／4000划分。
checkpoint 本来可能训练过这些样本，因此以下不是独立泛化或新任务收益。

诊断耗时 **39.072 秒**。4000条评估侧原版有478个错误；每条样本都允许
知道正确标签后，独立选择各关系的任意八维单位测量方向，得到以下结果。

## 计算对应原版，而非另一个未归一化模型

原版有效词元态记作 rho_t=psi_t psi_t†，分类值为u_rt，EPS=1e-6。
S=mean(rho_t)+EPS I；B_r=mean(u_rt rho_t)+EPS mean(u_rt) I。
原版logit等于 bias_r+(phi_r†B_r phi_r)/(phi_r†S phi_r)。两个矩阵中的
EPS项都保留。谱区间来自 S^-1/2 B_r S^-1/2，再把端点方向转换回单位
phi，并用原版 Born+EPS 词元权重直接回放。

全部8192条均检查了原生公式、原模型输出落在谱区间内、端点回放、谱区间
位于凸注意力区间内，以及与已有预测的数值和 argmax 一致性。最大公式误差
4.264e-14，端点回放误差5.608e-12，两个区间包含性违例均为0。
浮点容差事先固定为1e-7*max(1,max|u|+max|bias|)，不宣称严格外包界。

独立代码重新计算全部分区计数，并用首8条预先固定样本的逐词元外积和
Cholesky变换核对谱端点，最大差1.457e-13；原生logit差5.329e-15。
首8条的原生方向和实际端点方向仅存于GPU节点的私有数值fixture。
第一次独立核对因对字符串句子分组调用isfinite而退出1，只修核对器后对
同一不可变结果通过；没有重新做前向或改变科学代码。

审查原记录BLOCK保留；执行前补齐原生区间包含、精确旧argmax一致性及端点
方向留存，gpt-6.2-astra/high重新审查PASS。上述矩阵工具属于已知理论，
本轮不接受新颖性、独立收益、量子必要性或L5。原版限定L4保留。
