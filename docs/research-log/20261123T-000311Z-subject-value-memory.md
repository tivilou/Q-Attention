# 主体寻址值记忆：相干读出有效，但整套结构未胜过原模型

这次在新接入的双 RTX 2080 Ti 节点完成三路匹配训练：完整值算符读出、只读取算符对角线、原 Q-RMEA。同一初始参数、同一批次顺序、每路 512 次更新，全部训练结束后才评估最终状态。总计 1,536 次更新，科学脚本耗时 473.427 秒。没有重跑历史全量 baseline，也没有读取 VALID、TEST。

候选保留原模型的词元量子态、关系测量、分类值与全部 81,028 个参数。主体词构成查询密度 Q；非主体词按其带符号分类值写入 W；分类输出为 b+8Tr(QW)。W 是带符号的厄米算符，并非密度矩阵。对照只把最终读出替换为对角元素内积，保留相干的主体选择。候选不对最终写入词权重再次归一化，也没有经典残差分类器。

[已测事实] 使用已有前 8,192 条 TRAIN 的整句子组划分：4,192 条拟合、4,000 条评估，跨两侧完全相同的句子数为零。这是反复使用过的探索数据，不是独立确认集。三路均使用固定的新初始化和最终第 512 次更新，参数数目相同不表示各路有效容量相同。

| 方法 | 评估 CE，越低越好 | 正类 39 类 Macro-F1，越高越好 |
| --- | ---: | ---: |
| 完整值算符读出 | 1.121292 | 0.068171 |
| 对角值算符读出 | 1.150414 | 0.048242 |
| 原 Q-RMEA，同预算训练 | **0.927892** | **0.106736** |

对角对照减完整读出的逐样本 CE 差为 +0.029123，整句子组 bootstrap 下 2.5% 百分位为 +0.012370；原模型减完整读出为 -0.193400，下百分位为 -0.217928。这些区间条件于当前探索划分、初始化和训练预算，不是独立确认的显著性结论。完整读出相对对角对照的三项门槛均通过，相对原模型的三项均失败。**六项联合门槛不通过，关闭这个具体训练筛选方案；不换种子、划分、增益、掩码、对照或预算挽救。**短训练筛选不证明整个值记忆方法族不可能有效。

[理论结果] 推导并经 gpt-6.2-astra/high 独立静态审核的条件性检索命题，将原建议的对角误差下界 3/7 收紧为精确可达的 1/2：两个八维互无偏基各写入独立平衡正负载荷，查询编码不依赖载荷时，完整读出可精确检索；任意重新学习的归一化对角查询只有七个可用于十四维对比空间的方向，平均平方误差至少 1/2。穷举全部 4,900 个平衡载荷组合验证了构造、协方差及等号情形。

这不是文本任务收益定理。上下文化查询可能已包含答案，原有限参数电路实现理想编码的条件也未证明。投影、互无偏基与协方差工具均为已知数学；经典外积特征可以精确实现完整读出。本轮实际阅读的线性注意力、fast-weight 原论文明确构成近邻。没有新颖性、经典分离、量子必要性或 L5 验收。

[核对结果] 直接算符收缩与高效实现的前向、梯度、padding 不变性，以及三路真实首次更新均通过。独立 NumPy 代码在 GPU 节点本地重新计算 CE、完整混淆矩阵、Macro、全部 2,000 次组重采样和六项判定，结果一致；所有训练先于任何评估。三个最终 checkpoint、代码、设计和输出封印哈希通过。旧版审查 BLOCK 的两项问题在执行前修复并重新审查为 PASS，旧记录保留。

稳定训练核心、共享运行器和宿主包装器没有修改；没有重做单卡／多卡／COS 恢复矩阵。只有紧凑代码、理论及结果报告进入 GitHub；私有数组、训练历史和 checkpoint 留在 GPU 节点，不写入 COS，也没有下载到 Windows。负向筛选没有需要跨机器继续训练的消费者。

执行已退出，宿主与所属进程组均为空，输出封印不变；第 17 代调度分配已通过既有分配接口核对并释放。节点与本机约 0.6 秒的时钟差曾使即时完成观察落在本机未来，资源归还的严格时间检查未通过；等待真实观察时间到达后，同一身份、同一代次的原接口检查通过并完成释放，没有改运行时、放宽检查或重跑训练。

[解释边界] 观察支持“此结构的非对角读出有局部相对作用”，却不支持“它是比原模型更好的结构”。未物化逐词元轨迹，不能断言失败由地址混叠、主体特征泄漏、序列长度稀释或优化困难中的某一个因素造成。下一步应换独立机制问题，而不是把一个对照胜利包装成任务胜利。原先狭义 L4 不变，L5 仍为 NOT_ACCEPTED。
