# 共享池化决策区间：数值通过，没有获得不可替代决策证书

本项目在 Re-TACRED 上进行 40 类关系分类。固定词表示经过原量子状态准备后，由不同关系的测量方向产生各自的词权重；词的解码值、分类偏置与所有参数均来自同一个已经完成训练的 seed13 原模型。本轮只做推理，不训练新模型。

检验的问题是：固定已学好的词值和解码器，允许一个对照对每句话任选一套词权重、让所有类别共用，并允许任意调整全局类别偏置。原模型是否做出了这种对照无论如何都保不住的正确决策？这比上一条重复词出现位置对照覆盖更广，不依赖词重复或相同位置特征；也没有修改上一条测试的 key 或门槛。

对某个关系与 no_relation 的分数差，共享池化能得到的值位于各词解码差的最小值、最大值之间。如果一个原模型正确识别的关系句，其最大值仍至少比一个原模型正确识别的无关系句的最小值低 0.05，这两个正确决策就不能被共享池化同时保住；统一调整偏置也消不掉这个顺序冲突。每一对全局不重叠的句子至少对应一次必然丢失的原正确决策。这个区间推导是已知凸组合数学，不冒充新理论。

## 固定测试与结果

预先固定全部 19,584 条 VALID，按原顺序匹配正类正确句子与满足条件、尚未使用的无关系正确句子；不同关系之间也不重复使用无关系句子。要求至少 196 对，且至少 8 个正关系各有 5 对。另用前 256 条 TRAIN 做新增区间公式与原推理回放检查，不执行优化器更新。

[已测事实] 对已有封印极值的描述性分析表明，存在原模型正确正例的 36 个关系，其二元区间放松全部允许一个统一阈值。最接近排序冲突的最大间隔仍是 -4.4791，故本轮不是恰好卡在 0.05 门槛附近。没有为此重新运行模型或更改原匹配规则。

[机制解释] 允许每句在所有词上任意取权重时，词解码值形成的区间相当宽，当前二元排序证书无法区分类别相关池化。它没有证明所有类别共享同一词权重时能同时复现正确分类；二元区间放松不等于联合多类可行性。也没有识别量子测量是否必要，更不能据此否定原模型全部用途。

[尚未证明] 原五个 fresh seed 的 L4 效果是否由类别相关池化造成、量子独占性、净 Macro 改善以及 L5 均未建立。本轮的任意偏置／固定解码器比较范围与历史 L4 相互独立。
