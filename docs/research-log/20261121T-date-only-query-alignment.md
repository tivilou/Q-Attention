[已测事实] aligned 相对 deranged 增加0.062050个百分点，配对95%区间[-0.264829,0.370787]；相对 training_mean 增加0.084740个百分点，区间[-0.168233,0.346756]。两组区间均跨零，预先要求的“同时优于两对照且区间下界为正”未通过；CE的方向有利也不改变主门槛。

[机制解释] 本轮证据不足以支持“线性路径的收益主要由推理时句子特异的旋转匹配带来”。固定平均和置换没有造成强烈退化，提示训练中形成的表示或固定查询表达能力值得区别检验。

[尚未证明] 区间跨零不证明等价，更不证明完全没有输入依赖作用。原先独立训练 linear 的单seed正向结果仍在；本轮不提高证据等级、不宣称新的L2/L3/L4/L5。重复使用validation进行机制探索也不构成独立确认。历史限定L4不变。

## 下一步：训练梯度而非继续置换输入

唯一推荐方向：检验上下文旋转的反向传播是否通过改变词态学习贡献收益，即使推理时可换成固定旋转。A6API gpt-6.2-astra high 提出了这一待检验假设；Fréchet 导数本身是标准工具，不是L5贡献。

先核对导数并复用原080-progress冻结点：linear模式的第0轮、next_start46816，已包含active参数与AdamW状态，约5.9MB且现存3060，无需新下载。最小实验是同一checkpoint、同一小批次序列的分叉回放：完整梯度、固定8维查询旋转的梯度、固定词图幺正的梯度。先检查同权重前向相同、完整两种表达的总梯度一致、effect/value梯度不变，再测词态prepare梯度差。回放后用预先冻结的同一个training-mean旋转做完整validation评估，排除只靠不同前向提升。

这里有一个必须保留的数学边界：U_token(X)X = X R_feature(X) 前向等价，但 detach(U_token) 与 detach(R_feature) 不是同一干预；分别得到 U_token dX 与 dX R_feature。必须明确计算图与分母处理，不能把“停止某个中间变量梯度”写成与表示无关的因果结论。

成功门槛待代码冻结前明确：额外梯度可观测且相同静态评估下CE改善、Macro方向一致；局部梯度近零则停止局部解释，短回放没有正向转移则不推进全量。预计仍是单次三卡的分钟级开发回放，owner已授权；当前尚未启动此分叉，不重跑历史baseline，不为失败门槛补seed。理论新颖性另需证据，不能因诊断正向就评级L5。
