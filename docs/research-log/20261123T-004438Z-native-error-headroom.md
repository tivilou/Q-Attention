# 先找原模型的实际错误：多数问题在有关系／无关系边界

本轮复用已有原模型预测，没有重新推理或训练。对象是固定 checkpoint
2da52b1c… 的前 8,192 条 TRAIN 输出，沿用整句子组 4,192／4,000 划分。
以下主表来自 4,000 条评估侧。这些训练样本及 checkpoint 已被研究反复使用，
不是独立泛化证据，不能拿本表替代原先的全量、多种子 L4 结果。

| 错误类型 | 数量 |
| --- | ---: |
| 实际有关系，预测无关系 | 216 |
| 实际无关系，预测某个关系 | 202 |
| 实际有关系，预测另一种正关系 | 60 |
| 合计 | 478 |

准确率为 88.05%，正类 39 类 Macro-F1 为 0.678963，CE 为 0.331887。
有关系／无关系误判占错误的 87.45%。这支持先研究输入依赖的证据判断，
却不能断言错误来自背景词、注意力、标签、表示或某种特定量子机制。
本轮没有物化 Case Study 轨迹，也没有读取 VALID、TEST。

先检验简单校准解释：只对无关系类别加一个所有样本共用的偏置，
在校准侧最小化四十类 CE，得到偏置 +0.319865。保持该值应用于评估侧，
CE 降至 0.327423，但准确率降至 88.00%，Macro 降至 0.676136；
漏报由 216 增至 265，误报由 202 降至 160。不能以 CE 改善宣称任务整体改善。

进一步，用评估答案挑选该单偏置族的最佳准确率，枚举全部 4,001 个判定区间，
上限也只有 88.35%，最多净减少 12 个错误。它是带标签的受限族经验 oracle，
不是可部署模型，也不证明某些指定样本对所有偏置都不可纠正。

另一个受限 oracle：若只能从原输出的前两类选一个，且知道正确答案，
最多可达 97.55% 准确率，覆盖当前 478 个错误中的 380 个。它只说明固定
候选池内存在排序空间，不表示一个训练得到的判断器能恢复 380 条，更不是
Macro-F1 的可达上界。无约束模型的 Macro 最优值仍未知；不能用名义最大值
减去当前分数冒充可实现的提升空间。两种 oracle 的约束、单位和分母均已登记。

由此选择一个有限的新假设：保留原来的分类值与归一化汇聚，让每条输入的
原生“无关系”注意力形成状态二阶矩，用其正则化逆调整正关系测量方向。
这与已关闭的主体值记忆不同，没有替换分类值路径，也不是给冻结分类输出
加特征或调阈值。它可能把真正信号当成背景压制；不能把参考状态称为已经
识别的噪声。具体机制、反例和筛选条件在 null-relative-filter-20261123 中。

独立顾问 gpt-6.2-astra/high 建议只做一次有界筛选，并明确一般 Rayleigh
最优性不蕴含分类收益。原始论文的局部阅读还发现 [Elliptical Attention](https://arxiv.org/abs/2406.13770v2) 的
Mahalanobis 变换，以及 [DAMCHA](https://arxiv.org/abs/2610.13261v1) 的输入依赖跨头度量，都是必须面对的近邻。
因此“自适应度量”或“逆二阶矩”本身没有建立新颖性，L5 仍未验收。

本轮只在 GPU 服务器上只读处理既有私有预测，返回聚合计数和受限上界，
没有向 Windows 下载数据、预测数组或 checkpoint，没有 CUDA 推理、训练
或 COS 写入。两份完整原论文保留在本机私有阅读目录，不发布原文。


证据：[错误分布](../evidence/rmea/20261123-native-error-headroom/summary.json)、[受限上界](../evidence/rmea/20261123-native-error-headroom/headroom-assessment.json)。
