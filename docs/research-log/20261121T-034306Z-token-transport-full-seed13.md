## 从训练适应与固定模型交换中学到什么

固定 cubic 最终参数、仅替换路由时，完整 test Macro-F1 分别为：原 cubic43.7325%、native43.9309%、去相干43.9452%、linear43.5672%。此时 linear 比原 cubic 低0.1654个百分点，而独立训练的 linear 最好。两种比较回答不同问题，不能用独立训练的优势证明在任意固定头上替换路由都有益。

[已测事实] 三阶路由对这次任务和预算没有达到预期。相干版本相对独立训练去相干版本的优势存在，但在固定 cubic 权重上去相干略好；相干性的任务必要性未建立。

[已测事实] 32条几何诊断中，三阶相干与三阶去相干均出现32/32的相位规范阻碍，最大行范数偏差0.0183093；linear没有该阻碍，偏差约5.33e-15。几何上更难折叠的结构，并未带来更好的任务表现。不能把不可折叠性本身当作优化目标。
