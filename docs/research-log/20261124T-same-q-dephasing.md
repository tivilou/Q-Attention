# 同一权重关闭相干：保留有效贡献，定位无关系误触发

在刚完成的完整Q模型上，只关闭内部相干，其他权重完全不动，重放全部58,465条TRAIN。45.6秒，没有训练或新VALID／TEST。

Macro从0.8756降到0.7399。原相干模型修复5,467条预测，也损害974条；损害中838条是把无关系判成正关系。两种作用必须一起报告，不能只挑974条或据此统一压制相干。

这个结果支持研究“相干给竞争margin带来的增量是否可靠”的训练问题。相同参数的去相干干预与单独训练的去相干模型是两种证据，不能混用；TRAIN上的有效作用不证明泛化、更不证明新的L3或L4-T。

下一步先检查相干margin约束会不会靠弄坏参考分支作弊，并寻找同规则的经典对照。它仍是未实现假设，已知监督margin工具本身不算理论创新。历史负结果和原限定L4全部保留。
