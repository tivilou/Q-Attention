## 冻结理论与门槛

令 X 为共轭词态组成的矩阵，K=XX†。线性输运满足 U X = X exp[-iτ(X†X−I)/c]，因此等价于8维关系查询的共同输入依赖旋转，保留行范数。一般三阶输运令 Y=UX，z_t=||Y_t||²，则传播分数为 z_t 乘以单位方向的测量分数。三阶图的 z′(0) 精确为零，二阶可非零。这些是已知矩阵恒等式与微分关系，不作为原创定理。

主检验预先固定为 cubic 头：direction_only 相对 full 和 native 的 Macro 差，1000次相同配对 bootstrap 的95%区间下界都大于零，并且 CE 不劣于 native。其他头仅描述，不挽救主检验。
