# 局部共同下降没有变成验证集 F1 改善

项目输入是固定编码器的词元特征、实体角色和有效词元掩码。原版量子电路
生成词元态，并为每个关系提供独立测量；Born 分数加 EPS 后归一化为注意力，
汇聚同一个分类值路径并加 bias，输出 40 类 logits。本轮没有训练、优化器、
新 checkpoint 或 TEST 访问；只对既有原版模型的测量参数做一次固定改变，
在全部 **19,584 条开发 VALID** 上推理。正类 Macro-F1 是 39 个有关系类别
F1 的等权平均；另报 CE、准确率、两组 CE 与错误修复／损害数。

Macro 未超过原版，也未超过等权对照。**只通过无关系 CE 下降、Macro 超过

不更换步长、方向、种子、分区、checkpoint 或门槛挽救。

**[机制解释]** 共同方向净增加 15 个正确预测，Macro 却下降 0.000539；等权
方向净减少 8 个正确预测，Macro 反而提高 0.001267。整体 CE、正确数、两组
平均损失和正类 Macro 是不同目标，不能把一个目标的好转当成另一个的证据。
附带全 39 类混淆矩阵的事后算术分解，不选择有利类别，也不作词元级因果解释。
