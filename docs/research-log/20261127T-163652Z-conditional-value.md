# SEARCH-38：测量后的条件旋转能改变分数，但压缩为两个值池

## 裁决：NONE_EXACT_TWO_POOL_CONDITIONAL_READOUT

沿用原单条输入、40 类、完整 64 维有符号词值，不要求同句反向标签，不增加推断输入。本轮只核一个构造：对原生 3 比特词态做固定强度的弱 Z 测量，按中间结果对值作正/负方向的相同角度旋转，角度随当前输入变化；仍用原类别二元效果读出。固定 gen98 五臂十三门仍 STOP（10/13；Q .500925，Gcov .512054）。gen129 是技术通过后成本暂缓，不是任务跑输。

## 两种假设及实际判别

设 Z 取首比特的 ±1 子空间，`K_b=sqrt((I+bηZ)/2)`，`b=±1`，`0≤η≤1`。`K_+†K_++K_-†K_-=I`。终端对每个 r 单独使用 `E_r=|φ_r><φ_r|`（40 个独立二元测量，不是一个 40 类 POVM）。将输入角度写成有界单标量 z 的半角参数，`c=(1−z²)/(1+z²)`、`k=2z/(1+z²)`。令 J 对 32 个坐标对都施加 90 度旋转，则 `R_b=cI+b kJ`。输入 z 只能来自当前已有输入（例如原有标记角色的池化），不看后续观测标签；这里只定义，不训练角提取器。

对当前词，写 `u=<φ_+|ψ_+>`、`v=<φ_-|ψ_->`，分别为两个 Z 子空间的重叠。类别接受与弱测量结果的联合质量为 `p_b=Tr(E_r K_b ρ K_b†)`；端点的联合概率规则是已知工具。参考 [Gammelmark、Julsgaard、Mølmer 原文](https://arxiv.org/pdf/1305.0681v1) PDF 第 10 页式 (A8) 的分子与结果求和，不搬用其正文一般情形有边界的分母，也不把未来真标签引入任务。[来源定位](/docs/evidence/rmea/20261127-conditional-value/source-reading.json)

解析展开给出：

```
s = p_+ + p_- = |u|² + |v|² + 2 sqrt(1−η²) Re(u v*)
d = p_+ − p_- = η (|u|² − |v|²)
Z_r = Σ_valid (s_rt + ε)
F_r = c · Σ_valid(s_rt + ε) v_t/Z_r + k J · Σ_valid d_rt v_t/Z_r .
```

每个分支加 ε/2，沿用 native ε=1e−6，词掩码在求和前应用。每个 v_t 是完整带符号向量；无绝对值、截断或坐标丢弃。`F_r` 与逐分支旋转再池化完全一致，既没有隐藏分支历史，也无须按词构造稠密64×64矩阵。这里的少量新算子代数不算 L4-T 新理论。

**不是固定解码器回吸。** 在两个人工输入中，原生概率、终端接受总质量都为 1/4，裸弱测量结果概率均为 1/2，计算基种群全相同。令唯一有效词的完整值同为 e₀、角度相同；两次仅改词态内部相位。`d=+3/20` 与 `−3/20`，解码 e₁ 得 ±0.4799980800（含原 ε），分数差 0.9599961600；原生池化特征完全相同，任何固定类解码器均给同分。人工不限原生角度的态不是证明网络从自然文本可达到的态。

**也不是跨 Z 块相干传进了负/正值。** 粗块去相干 `D_Z` 保留 d 的分子，只有 s 和归一化可能变化；在上述人工配对中 s 也不变。完整计算基去相干 `D_diag` 才消掉这对样例的块内相位差，使裸 d 都为 0。把它们当成同一个关键消融会错归因：粗块去相干下 logits 改变，不证明跨块相干造成了 signed-value transport；本轮同时核裸分子和统一分母。

## 对照、公平性、成本与祖先

- **精确同函数核验**：一个正的总质量池和一个有符号差质量池加共享的输入门控就够了。这不是“有经典模拟器所以研究无意义”的论证，而是本提案的新增值路径没有更高阶反馈，只改变这两个池的混合。分支结果并没有改变后续量子计算，已被保留的相干都来自原有 Born 块内重叠。
- **独立经典对照规格（未训练）**：与 Q 同 h、角色、掩码、值、同真标签，分别训练同接口的两个非负分支打分（实数双线性或同容量的共享 trunk + 两个正打分），相同求和/求差、掩码、角度输入和类解码器；绕不开原 Gcov，且保留同一固定 Q 的 `D_Z`/`D_diag` 诊断及必要的独立人口训练控制。不是把 Q 的门概率喂给经典，也不是用只有一个池的弱对照。当前仅证明接口同构，不证明一个训好的经典模型已匹配 Q；尚无预测新增路径能在这种对照下给出特异的自然任务效用。继续投资不成立。
- **真实祖先**：gen79 是两个不同约化视图的独立归一化并固定拆分偶/奇值，四臂小筛 Q .121397、实数 .188483、0/8；本案同一个仪器、公共分母、全维值同时参与两个池，并不声称等价于 gen79。gen102 固定教师词值拟合，无任务共同学习，原 STOP 保留。Q-BAM 真正交换两次量子测量的顺序（旧 toy gate 已关）；本案是一次中间仪器后读并用结果混合经典载荷，不是顺序交换。SEARCH‑36 的固定每类变换可回吸，本案人工见证不回吸，但不足以构成新任务证据。
- **成本分析而非计时**：按固定 d=8 用两个 4 维重叠完成每词、每类质量计算，合计仍为 O(n·40·8)，两次全值汇总为 O(2n·40·64)，角度对每条记录共享，J 仅换位和改变符号。没有原生计时、后端梯度复核或硬件接受率/shot 保证。gen128 与 gen129 已分别保留 62.322 与 281.573 GPU 秒；3600 的累计上限扣除后最多 3256.105 GPU 秒，开销未扣。四臂 2560 次科学更新即使独占剩额，平均也不得超过约 1.272 GPU 秒/更新；这是预算必要条件，不是运行耗时上界。新构造因机制区分未过前门，未开展成本预检，更不是推断全面成本必超。

[核验脚本](/docs/evidence/rmea/20261127-conditional-value/check_conditional_value.py) 的人工 3q、7 词、40 效果在 0、0.6、1 的弱测量边界及三个角度比较了逐分支独立计算与压缩式：64 位值最大差 1.55e−15、40 类分数最大差 5.33e−15；掩码及分支重命名各为精确零，块去相干的裸差误差 1.11e−16。立项前只保留这一个有限命题及反例；没有新任务行、模型前向、参数更新、VALID/TEST 或 GPU。[实际输出](/docs/evidence/rmea/20261127-conditional-value/math-result.json)

## 下一层探索

不再从固定旋转、两视图、条件值或同句监督的邻域继续找角度/门。把父问题从**如何输出现成词态**提升为**如何形成一个能整合证据的共同量子态**：下一轮只核一个有原作支撑的、输入驱动且非幺正的稳定态计算假设（开放系统全句证据形成，不改原任务和输入），并用冻结的 gen119 末态分类、gen120 选择密度似然、gen127/128 非选择性随机幺正历史、旧 R93–R99 类查询 Gibbs 更新及强经典速率/平衡方程排重。必须同时给出保持全词值/40 类的读出、不会退成正则/经典平衡式的可区分预测及预算必要条件；否则暂缓该父方向，记录 NONE，不启动任何运行。原限定 L4 和全部正负历史保留，新 L3/L4-T 未接受；原量子目标继续。
