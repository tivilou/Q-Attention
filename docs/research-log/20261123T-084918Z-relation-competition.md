# 联合关系竞争：证据权重上升，仍可能更偏向无关系

[已测事实] 新的无标签联合归一化改变了全部32条固定TRAIN样本的注意力，但没有修复正关系漏检：8条漏检仍全部错误，8条原正确正关系损坏4条；8条无关系误报全部修复，无关系正确8条保持。结果属于同一冻结模型的开发干预，不能按分层样本净正确数宣布任务增益。本轮不推进该固定干预的全量实验。

## 实际工作流与改动

项目从句子和已给定主、客体跨度开始，冻结RoBERTa-large编码逐词特征，量子关系头用三比特态与40个独立关系效应计算Born分数，再对词级关系分类值加权。本轮不重编码或训练；复用上一轮固定32条TRAIN的真实概率、词级分类值和原分数。原标签、给定类型规则、语义读者分歧及全部反例保留。

原版对每个关系r独立归一化词t的正值分数q_rt。新规则先在每个词上竞争关系，再沿词归一化：

`q_rt = |<phi_r,psi_t>|² + EPS`

`G_t = sum_s q_st; c_rt = q_rt / G_t; alpha'_rt = c_rt / sum_j c_rj`

`z'_r = bias_r + sum_t alpha'_rt * utility_rt`

全部40类（含无关系）进入G_t，没有使用标签、证据词或类型构造新权重。原准备线路、关系效应、分类值、偏置、EPS保持不变。它同时改变全部关系行，区别于之前的单目标行重排与单词衰减；没有增加可训练参数。插件保持原state_dict键，原生分支直接调用未改源码；新分支移除不再适用的原单行sensitivity。训练与恢复核心未改。

| 前一问题定位 | 本轮实际变化 | 本轮边界 |
| --- | --- | --- |
| 有支持证据仍被拒识；单目标行有时不足 | 由全部关系分数生成共享词因子1/G_t | 新的共同词权重，不是已知真实因果修复 |
| 只知道标签知情的修复空间 | 使用完全无标签的固定预测规则 | 32条开发干预，不是群体效用或全量验证 |

## 原文近邻与数学边界

[已测事实] 已局部阅读Sinkformers官方原文第1、3页：交替行列归一化用于经典注意力是已有方法。本轮40×T矩阵只做一轮列归一化再行归一化，不能称为收敛双随机矩阵。[Sinkformers原文](https://proceedings.mlr.press/v151/sander22a/sander22a.pdf)。

随后局部阅读Slot Attention官方原文第1、3页。其式(1)先在slots上softmax，式(2)再按输入归一化聚合。令其理想方程中的`M_tr=log(q_rt)`，两步归一化就得到本轮alpha'；这不包含Slot Attention的迭代GRU和其他更新，其实践中的额外epsilon位置也须区分。因此这不是新的竞争归一化原语。[Slot Attention原文](https://proceedings.neurips.cc/paper_files/paper/2020/file/8511df98c02ab60aea1b2356c013bc0f-Paper.pdf)。

[机制解释] 本轮的量子分数可以由已知框架测量和滤波态给出等价解释，但该解释、已知协方差恒等式及softmax梯度不能算L5理论创新。强经典竞争归一化应是未来任何类似效用研究的对照；当前population_competitive仅是保留同参数形式的去干涉变体，尚未训练或用作任务优势证据。

[机制解释] 在这一固定模型上，语义证据质量、权重分配及最终分类值不是同一个量。“更关注证据”不能代替“提高正确关系相对全部竞争类的分数”。此结果强化了对证据到分类读出的联合考察，尚未证明原模型普遍存在分类值缺陷、训练重学无效、或这一方法族不可能有效。
