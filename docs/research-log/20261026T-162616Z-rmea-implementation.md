# 20261026T-162616Z | rmea-implementation | Q-RMEA 实现验收

本项目输入一句 Re-TACRED 文本及有序主语、宾语位置，输出40种关系的分类分数。原文、实体位置和冻结 RoBERTa-large 的词表示进入模型，真实关系只作训练交叉熵目标或事后评估，不参与权重和置换计算。数据身份沿用原始固定 split；其实体/文档重叠保留。

Q-RMEA 为每个词制备三量子比特态，为每个候选关系学习一个独立二元测量。测量概率在词维归一化成该关系的证据权重，再对共同 value/decoder 的词效用加权求和。它作用于冻结编码器的输出分类头，没有经典残差旁路，不修改 Transformer 内部注意力。训练冻结编码器，只更新分类头；用 valid 全40类 Macro-F1（逐类 F1 的平均值）选检查点，test 在选择后评估。固定检查点置换非实体上下文权重，观察交叉熵 CE 的变化；uniform 必须不变。生成式任务和硬件量子运行不适用。

[已测事实] 代码、完整数值案例和失败恢复通过有界验收；没有运行完整数据训练，没有建立 L1/L2/L3。
