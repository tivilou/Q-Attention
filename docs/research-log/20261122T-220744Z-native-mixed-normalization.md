# 双测量分量：短程学习未获得验证集收益

本项目在 Re-TACRED 上做 40 类关系分类。原 Q-RMEA 根据词状态与关系测量方向的重叠产生词权重，再汇总词的分类值。本轮保留已经训练好的词状态准备、词值、解码器和偏置，只测试每个关系拥有两个测量分量是否有用。

候选先把两个 Born 概率等权混合，再加原来的 EPS、归一化；对照先分别加 EPS、归一化，再平均两个注意力。二者各有 960 个可训练原电路角度参数、相同初始化和训练顺序，都包含分量重合时的原模型。因此测试的是混合与归一化的顺序，而不是给候选额外的门控、特征或预算。

## 固定短测与结果

前 8,192 条 TRAIN、全部 19,584 条 VALID，不读 TEST。每组固定训练两轮、每批 32 条，共 512 次 Adam 更新；固定最后状态评估，不按 VALID 选择 checkpoint。原模型直接复用，没有重训 baseline。

| 方法 | VALID CE，越低越好 | 正类 39 类 Macro-F1，越高越好 | 准确率 |
|---|---:|---:|---:|
| 复用原 Q-RMEA | 0.629858 | 0.516474 | 0.790390 |
| 候选：混合后归一化 | 0.633529 | 0.480549 | 0.786356 |
| 对照：归一化后平均 | 0.632976 | 0.482492 | 0.786867 |

候选相对原模型的 CE 改善为 **−0.003672**，Macro 改善为 **−0.035925**；相对对照分别为 **−0.000554、−0.001944**。事前要求相对两者都至少改善 CE 0.005、Macro 0.003，四项全部未过。

[已测事实] 候选和对照的在线 TRAIN CE 从第一轮约 0.333 降到第二轮约 0.325；这不等于验证集有效，也不足以单独证明过拟合成因。这个固定短测不支持把双分量归一化顺序当作有效的新方法。

[范围限制] 这不是完整 TRAIN 的全模型训练，也不是所有混合测量的否定。按事前规则关闭本次初始化、预算和数据范围的方案；不通过增加轮数、更换秩、初始化、正则、子集、门槛或种子来补测同一个方案。新方法不继承历史 fresh5 的狭义 L4，L5 仍未接受。

## 实现与成本

采用已知矩压缩：把冻结词状态及分类值汇总为 C 和 B 矩阵，两个电路分量直接计算二次型的分子与分母，避免每步重新遍历所有词。混合恒等式与 Rayleigh 表达式均为工具，不是本轮理论创新。

[已测事实] 八条真实 TRAIN 样本长度为 21、48、41、35、40、30、36、46；包含 padding。直接词级与矩压缩的 logits 最大差约 5.33e−15，梯度最大差约 5.27e−16；分量重合回放原模型误差约 7.11e−15。两组各完成一次真实 Adam 检查，检查状态随后丢弃，正式短测从预设初值开始。新增机制的精确 gpt-6.2-astra/high 审查通过；没有重复串行、多卡续训或 COS 恢复矩阵。

实际计算 **68.94 秒**，其中矩收集 38.86 秒、两组训练合计 28.87 秒。报告封印、源码、配置、退出码和调度身份一致，独立从混淆矩阵重算 Macro 与准确率、从指标重算四项门槛均通过。进程已退出，allocation generation 12 已自动释放。原项目训练、调度、恢复核心和 GPU checkout 均保持原版本。

启动前曾发现配置／理论文件 CRLF 与审查文本的 LF 字节不一致，已统一为精确审查过的字节后才启动；没有重复调用审查或重复训练。科学执行退出 0、stderr 为空。
