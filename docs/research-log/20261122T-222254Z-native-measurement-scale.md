# 128 条 TRAIN 的测量成本资格检查

本项目把句子及实体位置编码为词元特征，以独立的关系测量产生注意力，再用固定分类值汇总为 40 类分数。本轮复用已有模型，不训练，不读取标签、VALID 或 TEST；只问保持该模型决策需要怎样的测量尺度。准确率、正类 Macro 和预测收益均不在本轮评估范围。

[已测事实] 计算用时 0.390624 秒。按分类值分配词元采样，在 5,120 个“样本×类别”中的 3,970 个降低了精确总体方差；方差比中位数 0.878539，最大 2.622207。因此它改善多数比较，也会恶化部分比较。

与上一轮改变测量头不同，本轮保持原预测器，改变的只是将来可能使用的测量估计方式。使用存储顺序前 128 条 TRAIN、全部 40 类及全部有效原始词元。取精确分数前两名的中点作为规划阈值；这是使用精确答案的规划条件，不是可部署控制器，也没有声称它是最优阈值。

| 规划尺度 | 均匀词元采样 | 按分类值采样 |
| --- | ---: | ---: |
| 每类 512 次时全部 40 类超过规划宽度 | 0/128 | 0/128 |
| 每类 1,024 次时全部 40 类超过规划宽度 | 0/128 | 1/128 |
| 每类 1,024 次时最差相对宽度的样本中位数 | 10.780071 | 7.315977 |

这里的 Bernstein 形宽度代入了**总体方差**，不是实际样本方差；它不是有效置信区间、实际停止时间、覆盖保证或算法下界。没有抽取任何测量样本。“1/128”只描述这个规划指标，不能解释为真实认证成功率。原模型平均 Born 归一化量的中位数为 0.025911，前两类分差中位数为 4.336150；这些只是已记录的尺度，不单独证明困难来源。

[机制解释] 值采样减少最大重要性权重的标准性质，并不保证方差或总测量数下降。本轮结果不足以支持此前讨论的每类 1,024 次 VALID 研究，因此不采纳、不启动该协议，也不增加上限挽救它。这不否定所有有限测量算法。

原代码的分数重放和阈值符号恒等式最大误差约 1.42e-14，四词元 Bernoulli 枚举误差 4.44e-16。精确代码已通过 A6API gpt-6.2-astra/high 机制审查；执行退出 0，无 stderr，私有数组哈希和各档计数独立复算通过。分配已释放，驻留进程已退出。

训练案例不适用；未产生训练或优化轨迹。原始词元和逐行尺度数组留在 GPU **服务器的磁盘/主存**，不是宣称驻留显存。未保存 sample-trace.v2，未提供完整逐词元 Case Study；不能从汇总结果反推该轨迹。四词元数学夹具是实际执行的计算检查，不是文本案例或独立实证。没有 Windows 模型/数据下载或 COS 写入。

原文阅读确认：经验 Bernstein 界、按方差分配测量及 classical shadows 的共用测量均有明确先行研究。相邻方法可能提供工具；单独换成这些工具不构成 L5 理论创新。具体版本、实际阅读定位和未读范围见 literature-reading.json。
