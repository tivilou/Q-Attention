# Born词间信息形成：完整筛选失败，停止确切结构

## 一句话理解

让每个词按量子态重叠读取其他词，再用更新的主客体表示分类。gen126五臂完整开发筛选已审计：Q Macro-F1为0.1944312848671541，低于独立去相干、三种经典控制及两项历史参照，七门仅敏感性门通过。停止这个确切结构，保留技术正证据和量子研究目标。

## 原任务与动机

原任务是 Re-TACRED 的既定 40 类关系分类，包括 no_relation。每条样本含句子中两个有序实体；输出是这对实体的关系，而非逐词标签。输入沿用冻结骨干产生的每词 1024 维缓存、四维角色数值和有效词掩码。缓存已经含骨干语境，这次并非从没有语境的独立词向量起步，也没有重新训练骨干。

早期实现中有在骨干内改写 key 或叠加 attention-score residual 的路径。本候选则放在冻结词缓存之后，独立产生用于本头分类的词间隐藏表示，没有把旧分类器的输出直接相加。这个位置变化是可核对的实现区别，但通用量子上下文化、Born 重叠注意力已有先例，位置变化本身不构成实质新颖性证明。

可证伪假设是：在相同输入、训练协议和实体读出下，该量子词间权重比独立训练的末态去相干版本及三种强经典权重带来更高任务效用，且固定最终量子模型去相干后交叉熵变差。两项都需要真实任务结果；“存在相位”或“发生梯度更新”不回答这个问题。

## 一步步怎么做

令 B 为批内样本数，T 为批内补齐后的词数，n 为某条样本的有效词数。各维度均为数值特征或类别坐标，没有物理时间单位。

| 步骤 | 输入 | 实际计算 | 输出及用途 |
| --- | --- | --- | --- |
| 取缓存 | h[B,T,1024]、roles[B,T,4]、bool mask[B,T] | 缓存 h 从 FP16 提升到训练用 FP32；每条样本先按 mask 取有效行，再做任何投影 | h[n,1024]、roles[n,4]；padding 中即使有 NaN 也先排除 |
| 检查实体 | roles[n,4] | 第三列 >0 为 subject 成员，第四列 >0 为 object 成员；两者都必须非空 | 两个有序成员集合；本说明不把前两列数值猜成依存图或额外结构 |
| 编码两个状态 | 拼接 x=[h;roles]，形状 n×1028 | 分别经两个独立 Linear1028→12，再用 π·tanh 映射成角度，reshape 为 n×2×3×2 | 每词 query/key 各一套两层、三量子位的 RY/RZ 角 |
| 制备和比较 | 两套角 | 调用原电路的 RY/RZ 与有向 CNOT 环；经典状态向量模拟，取两态内积模平方 | 每个词对的非负 Born 得分，n×n |
| 归一化 | 得分矩阵 | 每项加固定 EPS=10⁻⁶，再除以该行总和 | 行和为 1 的权重 α[n,n]，有效词两两可见，无 causal mask |
| 交换表示 | 原 h 与 α | value=Linear1024→64(h)，再计算 α·value；随后 Linear64→64 和 tanh | 每词更新表示 u[n,64]，保留向量信息，尚未产生类别预测 |
| 有序实体读出 | u 和两成员集合 | 分别取 subject、object 行的均值，按此顺序拼接 | 128 维表示；多词实体按成员数取均值，不按 padding 数取均值 |
| 分类与反馈 | 128 维表示 | Linear128→40；训练时与原目标标签计算交叉熵，推理时取最大 logit 的类别 | 40 logits 与关系类别；没有额外类别分数旁路 |

这里只有一个词间混合块，没有额外多头、递归记忆、图解析、测量采样或量子硬件执行。每条样本独立计算；批内样本之间不交换词。

## 原理与公式

直觉是：先为词形成两种“用于提问和被读取”的状态，让每个词按状态的相似程度读取其他词的 value，再分类。相似度只负责选择读取比例，标签信息通过最终分类损失回传，不是把正确类别直接写进量子态。

记有效词 i 的拼接输入为 xᵢ，两个角投影为 Wq、Wk，原电路为 U。状态分别为 qᵢ=U(π tanh(Wq xᵢ+bq))|000⟩、kᵢ=U(π tanh(Wk xᵢ+bk))|000⟩，均为 8 维复数纯态。量子得分 pᵢⱼ=|qᵢ†kⱼ|²。实现使用 αᵢⱼ=(pᵢⱼ+ε)/Σₗ(pᵢₗ+ε)，并非对量子得分再取 softmax。

独立去相干臂保留同样的内部相干制备，只在两个最终状态上去掉非对角密度分量，得分变成 dᵢⱼ=Σₐ|qᵢₐ|²|kⱼₐ|²，随后使用相同 ε 归一化。它不是删掉所有量子门，也不是参数量相同就等于信息量相同。

混合与读出为 vⱼ=Wv hⱼ+bv，uᵢ=tanh(Wc Σⱼ αᵢⱼvⱼ+bc)，z=Wo[mean_subject(u);mean_object(u)]+bo。z 为 40 logits。tanh 位于混合之后；此处只陈述实现，不把它当作量子优越性或新定理。

经典臂用全 1028 维输入分别形成 64 维 query/key，以缩放点积、负半均方距离（RBF 得分）或成对多层感知机（MLP）产生词对得分，再做行 softmax。其 value、非线性层、实体读出和分类结构与量子臂相同。RBF 用的是 softmax 后的正权重，不是未经归一化的有符号核。

## 哪些参数会学习

每臂的 query、key、value、context 和 classifier 的权重/注册偏置都属于 model.parameters()，由 AdamW 更新；pair-MLP 臂另有成对网络参数。没有额外独立的门角 Parameter：逐词门角由可训练输入投影产生。固定的是三量子位、两层拓扑、CNOT 环、π tanh 角映射、ε、mask 和实体成员读出规则。骨干及其缓存保持冻结。

Q 与独立 D 的全部初始状态完全相同；五臂 value/context/classifier 初值一致，其中只将同形 value 权重和偏置沿用原 native 初值。各条件独立固定 seed13，避免前一个模型构造消耗后一个模型的随机数。技术克隆更新不作为科学筛选暖启动。

注册实参数量为 Q/D 各 99,616，dot 206,568，RBF 206,632，pair-MLP 214,952。经典臂刻意更大；这不构成有效容量匹配。dot 的 key 偏置、pair 网络最后一个标量偏置会被行 softmax 消掉，故未注册。D 的末层 RZ、RBF 共同平移、连续仿射层的吸收冗余仍须保留在解释中。技术检查测得每个参数张量有非零梯度分量，不代表每个方向都可辨认。

## 训练与推理

已完成的 gen125 只对五臂各做一次原 TRAIN128 的克隆更新，验证计算、梯度、成本、保存恢复；没有 assessment，更没有 VALID/TEST。它已经终态审计并归还分配。

gen126 是另一项独立冻结的科学筛选：原 8192 FIT、4096 已反复暴露的 TRAIN assessment、seed13，五臂各 1024 次更新，logical batch128/microbatch4。每个 logical batch 累计均值交叉熵梯度，clip1 后 AdamW；lr=.001、betas=(.9,.999)、eps=10⁻⁸、weight_decay=.01。全部参数接收该损失反馈，缓存不接收反馈。

先完成五臂全部训练，再只评估各自 final1024；不依据 best/latest 的损失选择科学 checkpoint。保存 best/latest/final 是本地恢复与审计机制，不能改写 final-only 的评估规则。固定最终 Q 的双末态去相干评估在所有 fit 完成后构建，复制 Q 的最终权重；它与独立训练的 D 是两个不同对照。

推理沿同一前向链路输出 logits，不更新参数。当前没有新的独立确认、VALID/TEST、额外 seed、硬件采样或重训对照。

## 帮助理解的例子

教学示例，非实测：若某词对三个有效词的得分为 (0.1,0.7,0.2)，则读取权重是 (0.1+ε,0.7+ε,0.2+ε)/(1+3ε)。它读取三个 value 的加权向量，再经过非线性和实体读出；0.7 不是“关系正确的概率”，也不能直接当作解释原因。

真实逐例 Case Study 未提供。本次技术及科学观测均没有物化 sample-trace.v2，不能据人工矩阵编造自然句子、真实注意力、预测类别或正确性。原始特征、权重、逐例 logits 留在服务器；本说明只引用已审计聚合信息。

本次确切配置已STOP，没有继续训练、模型分析或唯一轨迹证据消费者，Case Study记为not_required_closed_exploratory；这不是已生成真实轨迹，也不豁免未来正式实验的可观测性准入。

## 实验设置与对照

科学筛选的五臂为 born_context、dephased_context、dot_context、rbf_context、pair_mlp_context。另复用已审计、同 cohort/顺序/初态与 optimizer 语义的 nativeQ 和强 Gaussian-covariance（Gcov）终值，不重训历史尝试。FP32 dense128 与 micro4 的累加顺序不同，不宣称逐比特轨迹一致。

共七个必要门：Q 的全 40 类 Macro-F1 必须分别至少超过独立 D、dot、RBF、pair-MLP、nativeQ、Gcov 各 0.01；固定最终 Q 双末态去相干的均值交叉熵必须比 Q 至少差 0.005。Macro-F1 是各类 F1 的算术平均，包含 no_relation，并非去掉多数类后的指标。交叉熵是每条样本负对数似然的均值。

预算前瞻固定为每臂含评估 21600 秒、campaign43200 秒、既有共享两 GPU、Torch allocated 峰值每卡 4GiB。技术首批成本不是全部词长/并行负载下的耗时上界。科学门失败就停止这个确切架构、上移父方向；技术失败按非准入处理，均不追加 seed、宽度、深度、编码、学习率、精度、microbatch 或预算救援。

## 成功与失败原因

事实：五臂完整训练、保存恢复、实现数值检查和终态资源归还均通过；固定Q去相干使CE变差。技术可执行及敏感性是保留的正证据，六个效用门全部失败。

诊断支持：全40类聚合矩阵显示Q的预测与真阳性类别覆盖少于D和RBF。这是输出行为，不是优化失败、过度平滑或信息损失的已证原因。

待验证假设：冻结骨干后接浅层量子混合的共同信息/反馈边界可能限制有效学习；经典更大容量、归一化、优化或读出差异仍可能参与。没有逐例轨迹或预声明机制干预来区分它们，本轮不据此追加局部救援实验。

因果边界：fixed-Q相干敏感性不等于独立量子效用；独立D和三经典均更优。通用Born注意力已有原作，当前结果没有新T、硬件加速、实质近邻清关或新L3/L4-T。STOP仅此确切profile，不能推成所有量子上下文机制不可能。

下一步按多尺度skill上移共同信息与学习反馈路径，先有界排重、选择一个新前提或NONE；不在这个结构上补seed、改编码/宽度/深度/LR或加预算。

## 一分钟口述

我们把量子块从词级分类加权移到词间表示形成，之后用同样的非线性主客体读出。五臂都完成1024步，并在全部训练结束后只评最终权重。量子版本Macro约0.194，独立去相干约0.237，最强本轮经典RBF约0.471，都未超过历史强Gcov约0.512。固定量子模型去相干会伤害CE，但这没有转化成独立量子任务收益，所以七门只有一门通过，停止该结构。接下来提高探索层次；原限定L4和全部历史保留，新L3/L4-T仍未接受。

## 面试追问

**为什么不是简单给词打分类权重？** 得分先混合 64 维词值，再经过非线性得到新的逐词表示，之后才按两个实体读出并分类；没有旧类别分数相加的旁路。

**量子版本具体在哪里？** 可训练角投影送入固定三量子位电路，用复数状态重叠模平方决定词间读取权重。当前为经典状态向量模拟，不能称在量子硬件执行。

**去相干是否就是无量子版本？** 它只去掉两个最终状态的非对角项，内部仍有相干制备。独立训练 D 与对最终 Q 做固定权重干预分别回答可替代性与已训练模型依赖性。

**参数一样就公平吗？** Q/D 注册数量一样，但有效方向不同；三经典臂注册数量更大。协议、输入、读出和最终选择一致是本轮的公平性基础，并未完成有效容量匹配。

**有什么实验成功？** 技术资格及完整筛选审计通过，但六个效用门全部失败，确切结构已停止。不能把有限梯度、一次更新、训练损失或文档完成当作 L3/L4-T。

**与前作有何实质区别？** 目前只核对了本项目旧路径的插入位置差异；通用量子上下文与 Born 注意力已有前作。实质近邻区别、非平凡正确理论和可区分预测仍缺证据。
