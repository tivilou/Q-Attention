# Q-RMEA L5 R86：相干读出需要什么，不能继承什么

新增的三项解析边界已由用户指定的 GPT 6.1 Sol／medium 一次核查通过（PASS，must-fix=0）。这不是新方法验收或 L5 验收。没有训练、模型前向、数学数值实验、调度器或 COS 操作。

1. **精确列出相位不变读出的例外。** 对指定 W=sum(u*c)/sum(c)，实部在各 token 相位独立改变时保持不变：只有一个有效 overlap 时成立；两个时还允许“不同 utility 但等幅”；三个及以上时必须所有有效 utility 相同。证明通过展开实二次式并比较 Fourier 系数完成。该命题约束原有独立 projector 接口，没有假称原电路任意相位均可达，也没有禁止明示的受控相位模型。
2. **擦除相位后的结果有严格的平均方式。** 独立均匀相位下 E[pW]/E[p] 精确回到无 epsilon 的 Born pooling。这里是成功概率加权的期望之比；不等于未经加权的 E[W]，也不自动等于有限样本平均。原头的 epsilon 分支仍以 R85 独立记录为准。
3. **大异常输出有一个已知几何代价。** p|W-m|² <= (1-p)Var(O)。这给物理后选择的资源边界；若经典代码直接计算 A/D，不能把 p 冒充运行成本，更不能由此断言 NLP 效果差。弱耦合测量器还需要单独的有效性和噪声分析。

附带明确：把所有 overlap 相位对齐为正实数，指定方案就成为 sqrt(Born score) 的普通非负池化。这不提供新的相位信息，但也不证明所有相位编码都等价于这个变换。
