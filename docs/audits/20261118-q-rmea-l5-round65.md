# Q-RMEA R65：原始冻结分类头的 null 竞争诊断

本轮只回放师弟已经训练完成的 15 个分类头，没有训练新模型。使用原始验证/测试全体样本、原始 batch128 顺序，并要求 60 个原始校验样本在固定容差下吻合、30 个单元的样本数与混淆矩阵逐项等于已认证报告。所有运行通过统一调度器，CPU 单次执行，结束后恢复原绑定。

问题是：在真实标签非空、模型预测为空关系的样本中，正确标签是否已经是其余 39 个正关系分数中唯一最高者？分母包含所有此类误判；正关系并列不计成功；空分母为未定义。冻结标准要求每一个单元严格超过一半。这是回顾性的有限样本描述，不能当成总体显著性检验或可实现收益。

冻结的全部单元标准结果：`ALL30_DEFINED_PASS`。合并比例仅方便阅读，不能替代逐单元验收。

主判断：30 个单元均满足预定的描述性多数标准，提示需要区分“正类之间排序”和“与空类竞争”。两个经典对照也出现同类现象，因此它不是量子特有证据。筛选条件用到了真实标签；我们还不知道哪些错误能在不看标签时被识别，也没有衡量压低空类所增加的真实空类假阳性。30 个单元共用样本，不是 30 次独立重复。

CPU float32 回放通过校验并不证明每个分数与当时 GPU 的逐位结果相同；严格胜者统计属于本轮 CPU 回放。正确正类已排第一也不意味着存在一个能同时保持精度和提升召回的统一阈值，更不证明量子机制贡献。没有选择新方法，L5 仍为 NOT_ACCEPTED；已验收的限定 L4 不变。后续只能从实际错误结构提出具有可区分预测的新机制，不能把调低空类阈值包装为理论创新。

恢复共读取 46 个固定版本分片、2,915,876,864 字节（约 2.716 GiB），无自动重试、无 COS 写入。只保留一份共享验证/测试特征、15 个分类头和 60 个校验样本；逐片哈希、tar 头和文件哈希通过后已移除可重建的大分片。未复制完整归档，未访问师弟服务器。

独立实现审核使用 gpt-6.1-sol / medium，初审要求修正签名链接文件的初始权限与精确任务终态核验；修正后 scope=both、PASS_WITH_RISK。风险包括 CPU/GPU 分数差异、硬崩溃需人工核对、执行耗时事前未知，以及审核者未独立读取私有输入。下载/回放的实际验收与静态审核分别记录。

另一次 gpt-6.1-sol / medium 结果解释审核为 ACCEPT_DESCRIPTIVE，无必改项；它只审阅提供的计数和规则，没有独立回放分数或认证私有原件。下一问题是：在完整冻结分数向量之外，原有核心表示是否还有可辨识的关系证据，能区分“正确正类已排第一却被空类压过”的样本与正确拒绝的真实空类？这是待研究的问题，不是已接受的方法；先核实近邻和可区分理论预测，再决定实现。
