# Q-RMEA L5 第五轮：原纯效应家族内的共同适配反例

本轮完成了原 `RMEAHead` 的有界合成检验：两个 head 各自在两例上全部正确，双向互换注意力后全部错误，按事先确定的读出变换又恢复原 logits。**互换受损不足以证明任务信息丢失；L5 尚未达到，原限定 L4 保持不变。**

## 实际构造与检验

直接导入并核验原模型三个模块的哈希，没有重写其电路。两个人工输入的1024维词特征包同为 `[e0,e1,0,0]`，四个位置都有效；第2、3位置的主客体跨度交换，四个角色特征完全按原距离裁剪/32与成员指示的生产配方生成。所有参数在运行前冻结，没有搜索、训练或读取真实样本。

令 k=atanh(1/2)、eps=1e-6、Z=2+4eps。准备映射只保留第一层 wire0 RY 的偏置k、第一层 wire0 RZ 的预激活 k(h1-h0)、第二层 wire1 RZ 的预激活32k(role0-role1)，之后照用原 πtanh 和两次CNOT环。两个上下文词态为 (|000>±|010>)/sqrt(2)，主客体交换时两态互换；锚点相对相位为±i。关系效应也是原深度2电路内的有限纯态：所有40个关系分别用同一个 plus 或 minus 态，不施加联合POVM约束。显式两次RZ补足了独立顾问原先简写中未指定合法仿射角色映射的缺口，原建议原文仍保留。

第一例中A的前两个权重为 (1+eps)/Z、eps/Z，B相反；两个锚点权重均为1/4，第二例再交换。首个value坐标设为 Z(h0-h1)，其余63维为0；A的两个活跃decoder取+1/-1，B取-1/+1，余下38类bias=-100。两模型自己的活跃logits均为第一例(1,-1)、第二例(-1,1)。互换注意力会交换这两个logits；事先确定的decoder符号变换完全恢复原输出。因此在该两点分布及其任意混合概率下，表示的任务信息相同，固定recipient受损仍可发生。CE增量解析值为每例2。

实际结果：own正确数 `[2, 2]`，swap `[0, 0]`，恢复读出后 `[2, 2]`；最大绝对误差 `8.8817841970012523e-16`，低于冻结容差1e-12。[全部合成数值](../evidence/rmea/20261116-l5-round5/numeric-fixture.json)、[完整推导](../evidence/rmea/20261116-l5-round5/proof.md)。这是一个已知共同适配现象的、符合原参数化的反例，不是新理论贡献。

## 解释边界

反例只在人工冻结特征边界成立，没有证明实际RoBERTa能产生这些词特征，没有解释既有自然语言结果，也没有证明全输入函数等价。真实编码器在构造词特征前加入有序主客体标记，即使uniform没有直接角色输入，其上下文特征也可能携带实体信息。不能把本例中uniform无法区分两例外推为真实baseline缺实体信息。

原仿射value/decoder可折叠为 z_ir=w_r^T sum_t(alpha_irt h_it)+beta_r。value宽度64≥40个关系，所以任何40×1024的有效线性读出均可表示；这是已知矩阵分解事实，不等于优化器、惩罚或隐式偏置相同。后续若比较重新拟合的读出，必须只在训练样本拟合、在另外输入上评价，并处理优化差异；用1024维特征在同1024例上拟合再评价会混入插值。

另一个有限推导指出，固定词特征与mask、共同非实体词对、主客体距离均未裁剪时，仿射role-softmax的词对log权重比不依赖实体中心。这只限制该条件下的条件分布：上下文总质量仍可变，裁剪可打破结论，重新编码会改变词特征，dephased与real-overlap也可出现词对排名变化。没有量子专属性或完整分类能力分离。

## 原文核对

[Henry等《Geometry of Lightning Self-Attention》v3](https://arxiv.org/abs/2408.17221v3)只阅读第1、8、17页；PDF带ICLR2025页眉但该预印本修订于2026-06-11。其单层归一化双线性注意力可识别性定理量化所有输入，模型和量词均不同，本反例不反驳该定理；深层归一化部分是猜想。

[Gross等《Quantum state tomography via compressed sensing》v1](https://arxiv.org/abs/0909.3304v1)只阅读第1–2页。定理依赖独立均匀Pauli采样及迹范数恢复，任务与value诱导的算符不自动满足这些条件，未引入其样本复杂度保证。

[Brody等《How Attentive are Graph Attention Networks?》v1](https://arxiv.org/abs/2105.14491v1)只阅读第1、3–5页。静态/动态注意力和非线性位置已有直接先例；定义中的通用动态族要求比单个排名翻转更强。附录证明和完整实验均未在本轮审核。[版本、哈希与阅读范围](../evidence/rmea/20261116-l5-round5/reading-receipts.json)。
