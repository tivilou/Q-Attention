# Q-RMEA：三天探索得到的认知与尚未得到的结果

有可复用的机制认识和负面证据，尚无通过验收的L5新方法。这些结果没有证明顶刊级理论创新；环境恢复、审核记录和代码数量也不是科学贡献数量。

1. **有效性与量子解释必须分开。** 原全量五种子支持Q头对uniform的Macro效用，以及固定模型内上下文权重与词值对齐的CE功能作用。限定ordinary L4保持；uniform容量混杂、精确sign-flip未过0.05等限制保持。不能把这些端点推成量子或关系语义必要性。
2. **增加实体条件并非自然改进方向。** 训练前缀筛选ECQP−native Macro为+0.000285530302，条件区间跨零；经典完整头点估计更高。B数值活动、训练错配差或供体变化均不等于实体语义必要。本轮规则下不晋级，不靠多跑种子救结果。它也不证明实体条件在所有数据/预算上无效。
3. **最有价值的实证线索是路由与读出之间的适配问题。** 18格冻结块交换中，经典完整头的Macro/CE点估计优势没有双指标迁移到固定量子读出：Macro三升一降，CE四组都变差。应研究配合关系；数据尚未识别唯一原因，潜在基底、校准、共同训练等解释没有被分离，更不能称作已证明的新耦合定律。
4. **理论必须作用到代码实际消费的变量。** 当前RMEA消费概率、signed utility、mask、bias，不消费测量后状态；保持这些量时，换instrument不改变logit。量子信息瓶颈目标更好也不自动意味着一次分类更准。直接引入steering、后测态或互信息概念并不能解释既有增益。

下一步最有信息量的问题是：在同一真实输入上，路由权重与支持正确关系的signed utility如何配合，哪些可测的失配能预测错误，能否形成区别于已知注意力/双线性核的新机制。注意力峰值不等于语义证据；“适配是原因”仍是假设。需要真实数值链和独立干预，不从名字出发补理论。

最新R91只通过原文/角色校验和回放恒等式，历史聚合门槛失败，172份案例中间文件未验收。因此本总结仅依赖此前已审计R81/R84/R87与原全量L4，不把新工程进度计为科研证据。近期工程重复占比过高；后续优先获取能区分解释的结果，避免把更多审核/尝试次数当进展。
