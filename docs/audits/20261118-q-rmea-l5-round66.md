# Q-RMEA R66：冻结表示的证据方差诊断

这条固定诊断没有通过：加入 token 效用方差的探针在五个种子上均优于线性分数探针，但均差于只使用分数及其平方项的对照。没有选择新方法，L5 仍未接受，既有的限定 L4 不变。

研究问题是：原来只聚合加权平均效用的读出，是否遗漏了有用的 token 分歧？预先固定统计量为 `T_r=log1p(Σ_t α_rt(u_rt−Σ_j α_rj u_rj)²)`，使用原始 float32 注意力和效用、float64 累加。这是普通加权方差；相同均值可有不同方差的合成例子只说明描述能力不同，不构成新理论或额外标签信息的证明。

仅使用原验证集 19,584 条样本、原来五个冻结 quantum 分类头。在每个头预测为空关系的样本内，通过固定、与标签无关的 ID 哈希划分拟合/评估，拟合二分类 `Y>0` 探针。比较完整 40 维分数 S、80 维 [S,S²]、80 维 [S,T]；统一训练侧标准化、L2=.01、固定 Newton 求解规则和停止条件。没有重新训练分类头，没有搜索阈值。原测试集仅回放预存的校验样本，没有新的整集预测、拟合或调参。

所有原始分类头都曾按整个验证集选 checkpoint，哈希评估仅隔离本轮探针的拟合/评估，不提供方法层面的独立验证。五个种子共享样本。二次与方差特征数相同，不代表函数类或有效容量相同。对有限探针的成功或失败都不是条件互信息检验或总体结论。

文献核对：[ViM](https://arxiv.org/abs/2203.10807v1) 已有特征残差和 logit 联合判别；它研究 OOD，不能直接当作语义空关系方法。[TPN](https://arxiv.org/abs/2410.00412v1) 已研究自适应 NOTA 原型及置信度训练，但属于少样本文档级关系抽取。实际阅读范围、版本和 PDF 哈希见执行记录；没有读完全部实验、补充和代码，不作穷尽性新颖性判断。另发现二阶池化题录，尚未读原文，不能作为已核实的方法事实。

独立构造咨询没有提出可接受的新机制，指出分数充分和中间表示有额外信号两种情况都与此前计数相容；常见 Bayes 风险/互信息恒等式只是工具。实现初审发现恢复输入根目录不一致，在执行前修正；修正版 gpt-6.1-sol / medium、scope=both、PASS_WITH_RISK。三个 CPU 调度任务均单次终态，精确恢复临时绑定。五个验证集混淆矩阵与原报告逐项吻合，20 个预存校验样本通过固定容差。复用已有 COS 恢复缓存，本轮零新增 COS 读写。

结果解释审核：`ACCEPT_DEVELOPMENT_DESCRIPTION`，无必改项。审核基于提供的源代码及汇总计数，未独立运行私有数据。下一研究问题：Does relation-specific signed token-contribution cancellation, rather than aggregate utility dispersion, causally distinguish recoverable positive null predictions from true-null cases under prespecified matched-score comparisons and controlled token-contribution interventions on the frozen same core?
