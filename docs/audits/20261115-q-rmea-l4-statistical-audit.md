# Q-RMEA：现有五种子证据的 L4 统计审查

**结论分两层：原预声明两端点获得有假设条件的 L4 统计支持；标准证据卡目前仍登记为普通 L3。** 本次完成统计审查，没有新增训练或新一轮确认。范围仍是官方 Re-TACRED 上，固定模型中的非实体上下文权重与词值对齐具有任务效用。

原协议在运行前就分别规定了 Macro 效用门槛和 CE 机制门槛：均差为正、至少4/5种子为正、配对 t 的双侧95%区间下界为正。原两项均通过，实际是5/5正向。Macro 的大幅收益仅相对均匀加权输出头，不代表优于强经典加权方法。

本次从五个原始配对差重算均值、标准差、标准误、df4的 t 统计量和双侧 p，解析尾概率另由审查者用 t 密度数值积分核对。根据原配对 t 模型，原两个统计门槛已获支持；不能将它们说成“尚无统计显著性”。

## 必须保留的统计条件

- 推断单位是独立训练种子；五个种子共享同一个固定数据集，不能算五套数据，更不能将13418条测试样本当作13418次独立训练复现。结论是条件于这个 benchmark 的训练随机性推断。
- 原计划明确假定种子差值独立且近似正态。n=5不足以验证这种分布假设；很小的参数检验 p 不构成无分布假设的保证。
- 原精确双侧符号翻转 p 对两项均为0.0625。这是原来就规定的描述性敏感性结果，未通过0.05，完整保留；它不是这里的配对 t p，也不是原接受门槛。
- 当前单一主张要求效用和机制两项同时通过。其合取可按 intersection-union 理解：只要有一个必要零假设成立，同时拒绝两项的概率不超过误拒该零假设的概率。因此该单一合取不要求将alpha拆分。原文未命名多重比较方法；这里是对已有联合门槛的数学审计，不是追记原来未声明的校正。两个边际95%区间也不是联合95%区间。
- 对两项 t p 乘2的保守敏感性仍分别约8.23e-6和3.68e-5；这只是事后稳健性检查，不替代原计划，不增加独立证据。

## 为何标准卡尚未登记 L4

当前 v3 卡将主比较及每个控制比较绑定到同一个 Macro 指标，并要求逐控制记录相应确认性统计。原实验的正式机制端点却是 CE。现有卡中的置换 Macro 虽然方向一致，但只是辅助分析，不能事后把它当成预声明机制确认门槛。

此外，原卡把描述性的符号翻转 p 保存在通用 p 字段；直接修改等级会把它误当作接受门槛。仅改等级会被标准校验拒绝。本轮不修改共享规则、原卡、历史协议或描述性结果，也不将 CE 伪装成 Macro。

因此，**科学审查支持原两端点在明确假设下的统计确认；标准 L4 登记仍待逐端点证据表示的兼容审查。** 这属于记录表达的缺口。仅为修复它而补种子、重训或重跑全部 baseline 没有科学必要。

已另存[逐端点登记需求](../evidence/rmea/20261115-l4-statistical-audit/registration-proposal.json)，准确列出每个端点的指标、方向、原始配对值、原门槛、对照和敏感性结果。它是待审提案，不是已接受的新格式证据卡，也不授权修改共享 Skill。

## 主张边界与后续

这仍不证明量子相位优势、关系条件化的必要性、全部性能收益的中介解释、新颖性、SOTA、域外泛化或硬件加速。L4统计支持不会自动提高这些主张的证据等级。

当前最省资源的下一步是独立处理逐端点登记兼容性；无需新 GPU 实验。如果研究目标变为弱分布假设下的确认、新数据集泛化或量子独特收益，应另立固定预算和预声明设计；不能逐个补种子直到显著。
