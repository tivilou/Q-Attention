# Q-RMEA：共模不变性与分类风险的边界

本轮得到一项经过独立数学核查的源码对应反例：在当前八维、40类、epsilon=1e-6、
eta=1的测量更新接口上，零均值且与标签独立的共同效用，也可能降低固定模型的
期望交叉熵。移除共同效用会损失这项局部收益。因此，共模不变性本身不足以
为类别中心化提供风险改善保证。

固定路由下，条件零均值共同效用的交叉熵代价可由已知Jensen不等式分析；
实际full路由随效用改变，损失二阶导数还含带符号的路由加速度项。
构造中该项超过softmax的非负曲率，产生严格负曲率。相同方向上，固定native
和construction_only的曲率为正，两个中心化读出为零，形成清楚的区分预测。

指定A6API gpt-6.1-sol、medium，单次数学核查PASS_WITH_RISK，零must-fix，
十项检查通过。核查未包含legacy源码；主模型随后用AST/源码检查确认原EPS和
native权重公式，未运行模型或数值实验。审查范围和残余风险完整保留。

反例位于合法归一化状态的函数接口，尚未证明原输入电路的联合可达性；
有限扰动只给出充分小幅度的存在性，尚无数值验证。它不比较重训练最优值，
不证明数据集上的收益或新颖性，也不构成新候选家族或L5。已验收限定L4保持。

当前研究决策：保留已冻结的六条件训练，实测中心化是否改善任务指标，并通过
centered_native区分普通解码容量限制与测量更新。数学结果只收紧解释，
不改变种子、系数、预算、门槛或独立确认要求。
