## 原始查询重叠不是充分诊断量

在源程序的精确单位态表达下，对有效词元定义 `A_t=ρ_t+εI`、`B=ΣA_t`。令 `M_t=B^(-1/2)A_tB^(-1/2)`，以及 `χφ=B^(1/2)φ/sqrt(φ†Bφ)`，则 `ΣM_t=I` 且源注意力恰为 `χφ†M_tχφ`。

这是对词元索引的等价测量表示，**不是新增40标签联合POVM或修改模型**。由测量收缩迹距离可得

`TV(αφ,αψ) ≤ sqrt(1 − |φ†Bψ|² / [(φ†Bφ)(ψ†Bψ)])`。

所以相关的查询可区分性依赖当前词元集合。固定同一对原始保真度约0.99840096的查询，只更换词元上下文，两个精确有理数例子的注意力TV分别为0和约0.99875081。查询态很近并不足以证明注意力坍缩。两维支撑嵌入C8；未证明此例可由原生两层电路实现，也未把它当作真实文本现象。

对任意固定带符号效用行，查询重新分配引起的logit差不超过该行效用范围乘注意力TV。由此写出完整40类margin不变性证书和CE上界，保留自由偏置与读出。精确Fraction检查通过，log-exp值仅为浮点示例。这些是已知测量、迹距离和TV工具的直接应用，尚不是L5理论；有限精度原生实现仍需要残差检查。
