# Q-RMEA L5 R87：信息增加，究竟由谁读出来

本轮核读两份量子信息瓶颈原作，并把“保留信息”落到明确的读出接口。没有训练、模型前向、数学数值实验、调度器或 COS 操作；未选定新方法，L5 NOT_ACCEPTED。

## 两项具体结果

**同一个原作例子，信息目标更好，不等于一次分类更好。** 对 [Hayashi/Yang 2208.10342v2](https://arxiv.org/abs/2208.10342v2) 第10页 Lemma6–7 的三类均匀无噪声源、qubit/经典 bit、alpha=1、beta>1，量子最优目标为1-beta，经典为(1-beta)h2(1/3)，前者严格更低。但限定“收取一个状态，做一次 POVM，输出类别”，两者的最优正确率都恰为2/3。证明使用已知维数界及 trine POVM，不声称新测量理论。

这没有反驳原文第11–12页的核分类器：它使用状态特征／Hilbert-Schmidt 核，访问方式不同。原文的合成数据结果没有复现，也没有转作本项目性能证据。另一原作 [Datta/Hirche/Winter 1810.03644v3](https://arxiv.org/abs/1810.03644v3) 的操作意义涉及渐近 iid 编码、共享纠缠、辅助信息和重构保真度；未移植为分类风险或当前有限电路的保证。

**当前源码看不到测量后的状态。** 原 RMEA 只消费概率p、经典 signed utility、mask 和 bias；保持这些量，换一个 instrument 不改变40个 logit。Rank-one effect 的成功后局部态固定，但旁边的相关寄存器仍可保留信息。重要的是，原头的 epsilon 平滑可等价表示为 full-rank effect，故 rank-one 结论也不能直接套到这个平滑表示上。valid-token 的 cq 构造精确恢复原 alpha；utility 的期望恢复 logit，不是一次测量直接给确定 logit。
