# Q-RMEA L5 R82：先分离路由与读出，尚未选出新方法

R81 的真实筛选已经完成，ECQP 按原规则不晋级。本轮发现一个解释边界：各条件同时训练了注意力和读出，因此经典头更高的分数还不能被归因于“经典路由更好”。下面给出原源码内可实现的反例，并冻结一个只使用现有权重的交叉回放设计。没有新增训练、模型前向、COS 流量或 L5 接受。

## 已有证据与独立意见

ECQP−native 的 Macro 差为 +0.0002855303018927391，条件区间跨零；六个评估正类缺失。经典 entity/square 对照的本次点估计更高，但每个条件有自己的 value、decoder 和 bias。原始 L4 仍只支持已验收的 ordinary utility 与局部 weight–value alignment。

单次 A6API gpt-6.1-sol、medium 独立构思正常完成，返回 NONE，没有选出新方法。它指出额外实体摘要是对称均值，但完整 prepare 仍读入有序 roles，所以不能据此宣称整个头对实体交换不变。它没有访问文献或执行代码。响应身份和冻结输入哈希见 premise-audit.json。

## 一个原生可实现的对角结果歧义

这是一段解析证明，不是对 R81 实际模型的测量。取两个有效词，隐藏特征分别为 e0、e1，维度1024；实体 flags 分别为(1,0)、(0,1)。角色前两列为0。仅令 prepare 的第一层 wire0 RY 预激活在两个词上为 ±atanh(1/2)，其他坐标及 B 为0。因此物理角为 ±π/2。两轮共享 CNOT 对所有态实施同一个酉变换，内积不变。

量子查询仅令同一 RY 角为 π/6，其余为0；这是有限原参数 atanh(1/6)。两个 Born 响应为3/4、1/4。含原 EPS=1/1000000 的第一词注意力为

`a = (3/4 + EPS)/(1 + 2 EPS) = 750001/1000002`。

softmax12 头保持相同 prepare 与 B=0，只有该查询的第一坐标为 `-sqrt(12)*log(3)/π`。其绝对值小于π，可由有限 effect 预激活实现。两词 score 差为−log3，第一词注意力为 `c=1/4`。所有其他类效应任取合法值，令其 decoder 行为0，输出偏置全0。

value 映射仅保留隐藏特征 e0、e1 为前两个64维坐标，其他值为0。目标类固定为索引1；其 decoder 前两坐标可以独立给出任意有限效用(u0,u1)。这种构造同时满足两个实体非空和原始带符号读出合同。定义 d=a−c>0。

- 世界V：量子头效用为(0,0)，经典头效用为(1,1)。自己的目标 logit 分别为0和1；不论使用哪一个选择器，固定读出下都没有路由贡献。
- 世界R：两个头共享效用 `((a−1)/d, a/d)`。量子注意力给出0，经典注意力给出1；交换读出块没有变化，全部目标 logit 差来自选择器。

两个世界的**全部40类对角 logits**完全相同：量子头40个0，经典头只有目标类为1。故目标CE分别为 log40 与 log(1+39/e)；argmax 的量子并列由索引0获胜，经典选择目标1，二者的预测、CE和混淆也相同。这证明仅凭对角结果无法区分上述解释。

它不证明实际训练读出造成了 R81 差距，也不模拟真实初始化、训练轨迹或自然文本。这是已知可识别性逻辑的源码内见证，不能包装为新理论贡献。

## 下一项诊断及归因上限

对 entity、token-square 各取已完成的 quantum、softmax12、real-overlap12 三个头，分别形成3×3矩阵，共18个单元。仅使用原972条 evaluation，所有六份 final-epoch4 权重及已有输入均固定，不增加数据、种子、轮数或训练适配器。

`L[s,v,r] = sum_t alpha[s,r,t] * utility[v,r,t] + bias[v,r]`。

每次将 value.weight、value.bias、decoder、输出bias作为**完整读出块**保留；不拆开 value/decoder 以免引入64维内部基变换歧义。源代码中注意力与这个块没有前向依赖，样本、词、类别和 H 的接口相同，因此这种组合定义明确。它仍可能打破训练时的配合关系，这正是要观察的兼容性，并非自然语义干预。

先要求所有六个对角单元复现原指标/计数，再看每一经典头在 quantum 与自己的两个固定读出下替换选择器的效果，同时保存完整矩阵。总差、固定读出效应和交互项可作精确四格分解；不把分解恒等式或正负号称为新的定理、训练总收益的中介比例或显著性。
