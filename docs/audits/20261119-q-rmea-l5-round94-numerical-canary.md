R93 v002 的独立模块已实现，并经共享调度器执行一次 CPU 数值验证。

## 实际通过的检查

- 独立 NumPy 谱函数参考：注意力最大误差 7.904787935331115e-14。
- 零更新恢复原 epsilon-Born 注意力：最大误差 3.3306690738754696e-16。
- 正性、归一化、padding/NaN 隔离、效用平移和状态酉变换/相位协变。
- 五个预定正缩放系数与光滑响应；没有声称已放弃的缩放不变性。
- 单 token、相同状态、零/常数/近零效用，包括状态角、查询角、效用的有限梯度。
- 通用光滑点梯度与有限差分：最大误差 3.338349041648314e-11。
- 原生三比特电路产生的非对角见证、Gibbs 界，以及分类损失变差的反例。
- 单纯形效用倾斜、共享归一化的 pinching、仅构造路径置换与独立哈希映射检查。
- 同一原生 state_dict 与 81028 个参数，零更新 head 一致性及端到端有限梯度。

在40类反例中，原 CE=0.6940094074010119，更新后 CE=0.7357383913323555。
这证实“每类自身得分不降”不等于分类收益；它是理论边界，不是真实数据效果。
