# L5 第五十七轮：更新优化近邻，提出待核验的标签态注意力

本轮没有接受 L5，也没有选定新方法。两篇原作缩小了“优化器几何即创新”的空间；随后主代理提出固定量子标签态注意力，当前只进入近邻审查。

## 已读原作与迁移边界

[Xie与Li，2404.04454v1](https://arxiv.org/pdf/2404.04454v1) 的31页已解析，读到第1/2/3/8页。Theorem1.1 的盒约束 KKT 结论有全批量、学习率序列、收敛等前提。第8页确实讨论正ε下的平均更新量界及有限/随机迭代范数，不能笼统说它忽略了ε；这与把精确 KKT 结论直接套给当前有限、随机、裁剪且带正ε的程序是不同问题。

[Zangrando等，Stiefel-AdamW，2609.21039v1](https://arxiv.org/pdf/2609.21039v1) 的26页已解析，读第1至5页。它已专门处理无中间非线性的 W=BA 因子分解，以一个行正交因子、环境空间矩估计及投影/回缩更新处理几何。原生 value/decoder 的线性乘积属于相关对象；直接应用该优化器还不足以成为新量子注意力机制。本轮没有独立复核其全部定理、正交不变性主张、代码或实验。

## 条件性的 ε 反例

核验器以通用一维凸目标 L(x)=−εx，而非原生40类CE，检查带偏差修正的正ε AdamW 公式。令 ε=10⁻⁸、λ=.01、lr=.001、β₁=.9、β₂=.999、x₀=50，矩状态从零开始。每一步修正后的一阶矩为−ε、二阶矩平方根为ε，故自适应方向为−1/2，恰好抵消 λx=1/2 的衰减。所有迭代保持50，位于[−100,100]内部且梯度非零，因而不是把该目标约束于此盒子的 KKT 点。精确分数核验20步，归纳式覆盖后续步。

这只排除不带条件的跨算法套用，不反驳原文的声明算法或第8页的更新量界；也没有测量 Q-RMEA 的错误、实际库行为或持久训练收益。核验退出码0，没有模型/数据前向。
