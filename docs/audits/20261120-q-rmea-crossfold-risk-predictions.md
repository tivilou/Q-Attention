# Cross-fold：可检验的收益区间及其反向情形

同一 cross-fold 候选现在具有一对经过独立数学检查的分类风险预测。它们使用现有 d8、40类、EPS=1e-6、eta=1 接口，理论正文未改动；本次只更新审核状态并保存原文阅读记录。源码仍为 7e82642，八项数值测试和真实数据训练均未因此获得执行结果。

## 新得到什么

- 当正确类证据跨组一致、干扰类误差跨组独立时，在一个明确的小信号参数开区间内，期望逐样本交叉熵满足 cross < full < native < self。这里证明的是实际 CE 的期望，包含现有 full 控制，并非平均 logit 的 CE。
- 当正确类证据本身受独立、零均值的组间扰动时，同一个接口可以满足 self 的期望 CE 严格优于 cross。独立误差本身不足以保证 cross 有益。
- 正向区间阈值仍是存在性结论；尚未证明任何具体信号幅度在浮点实现中可分辨。两个构造均未证明由原始特征和共享神经参数同时实现。

推导、精确公式、渐近余项和反例见同目录 classification-risk-v001.md；七项 PASS 与范围见 risk-review-record.json。这是一条机制的进一步证据，不计为新增机制，也不构成真实任务优势、独立确认或 L5。

## 下一次实验应回答的问题

1. 先运行已审核并冻结的八项源码数值测试，检查当前实现是否符合已有数学与梯度契约；本次推导不擅自改动该契约。
2. 将正向风险区间、反向情形及有限幅度的可分辨性纳入之后单独冻结和审核的验证扩展；禁止搜索幅度后只报告有利点。
3. 真正的任务问题是跨组构造是否提高共同训练预算下的任务指标。需要 self-fold、full、native 等控制；一次冻结模型或独立噪声注入只能检验局部预测，不能识别真实干净效用或天然误差独立性。

已有六条件中心化训练仍是第一个获准空闲窗口的执行优先项。当前跨组研究不接管原训练、不增加种子、训练轮数或系数搜索。L5仍未接受，既有限定L4及历史负结果保持原范围。
