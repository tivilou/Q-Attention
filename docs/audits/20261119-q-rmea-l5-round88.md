# Q-RMEA L5 R88：补齐训练来源的逐样本观测

本轮完成四条件数值轨迹的代码草稿与固定设计，尚未审核、接入调度或运行。没有训练、模型前向、数组科学计算、COS 传输、新检查点或 L5 晋级。

## 已核实的缺口

历史 R3/R19 的七个数值案例属于 validation，并有结果导向的选择背景；它们不是新的训练来源证据。R11 的两组三联文本虽来自训练来源，已经执行并在 R12 关闭，许可文件最初的 outputs_seen=false 不能解释为实验仍未执行。R84 的交叉回放保留了聚合结果与当前前向的一致性检查，没有可冒充历史逐样本输出的 dump。因此不重跑这些案例，也不从聚合差异反推语义机制。

当前节点的只读检查确认，4096 条缓存元数据保留 tokens、subject、object 和输入映射，原检查点目录也存在。恢复所需的文本线索没有随旧主机丢失；本次检查仅读取元数据键和文件身份，没有运行模型。

## 新诊断的固定边界

复用原训练前缀中972条 group-separated eval，以及 native quantum、ECQP quantum、softmax12 entity、real-overlap12 entity 四个 final4 模型。保持原32条批次及 padding，核对四套原始聚合指标完全一致。在每个有样本的类别中取 id_hash 最小的一条，共34条、136个条件案例；选择清单在载入模型前冻结。标签只用于分层与事后评价，绝不作为模型输入。

完整捕获缓存特征、准备态/角度、测量概率/权重、signed utility 与 logits，私有保存 NPZ、阶段输入输出、哈希和可任意坐标读取的 sample-trace.v2。它用于观察真实轨迹，不把注意力大小解释为语义相关，也不提供分类器重新训练、oracle收益或量子必要性的结论。新案例仍是探索性案例，并非独立验证总体。

公共输出仅为两个计数/身份报告文件；文本、预测、数组、权重都不进入 Git。预计 CPU1、RAM4GiB、GPU0、一次600秒预算、私有轨迹硬上限128MiB，无新权重或云传输。

节点已恢复，观察到一张 P4；当前共享节点存在另一项目的活动任务，因此未修改绑定、未启动计算。代码 AST 与设计身份检查仅验证草稿结构。下一步是冻结新运行契约、失败测试和观察器，完成 exact BOTH 审核后按统一调度运行；R83 的旧审核不适用于这份新代码。
