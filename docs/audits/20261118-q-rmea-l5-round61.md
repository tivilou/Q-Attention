# R61：匹配头的共同错误边界

本轮完整核对既有五种子报告中的40类、Q/softmax/real-overlap三头及所选验证集/测试集，没有运行模型、读取原始数据、访问合作者服务器或使用COS。原始七文件和R51输入哈希链全部通过，80个逐类行及30个head/seed/split单元重算一致。既有L4保持不变，L5未达到。

## 观察

测试集每个种子都有5648个正例。Q的正例错误平均1616.8例，其中1255.6例错判无关系、361.2例错判其他正类；先逐种子计算再取均值，错判无关系占正例错误约77.50%。softmax和real-overlap相同比例约78.61%与79.12%。所选验证集三头也呈现76.21%–78.01%的相近模式。这是共同错误分布，不能称为量子特有问题，也不能从最终混淆矩阵认定阈值偏置、校准不足、表示或注意力原因。

测试集Q相对softmax有3类五种子F1同向为正、4类同向为负；相对real-overlap为1类正、3类负。没有一类在两种比较和两个split上都保持五种子同向。所有类别均保留在证据中，不把事后选中的同向子集当新显著性、长尾优势或语义归因。测试集已暴露，验证集又参与过选模；种子重复不等于新总体重复。

## 问题选择

独立gpt-6.1-sol/medium审核接受限定观察，candidate=NONE。下一项待检验问题是：在原30个固定head/seed/split单元的正例无关系误判中，gold是否仍为唯一最高分正类？这能区分已丢失的正类排序信息与仍保留却被null压过的信息，不能单独解释原因。

对于正例，固定tie规则后错误可以分成“最高正类已错”与“最高正类正确但null获胜”两个不交事件。当前聚合矩阵没有未获胜的正类分数，故该分解尚不可识别；没有把计数冒充未观察的中间状态。去掉null且使用gold判断属于oracle诊断，不能当部署决策或预期提升。
