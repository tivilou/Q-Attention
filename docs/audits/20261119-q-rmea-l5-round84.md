# Q-RMEA L5 R84：交叉回放完成，整体优势不能直接归因于路由

本轮经共享调度器完成一次已审核的 CPU-only 冻结检查点回放。18格、六组旧聚合指标精确复现、186次当前批次对角恒等式全部通过；任务退出码0、进程静默、绑定恢复和只读独立验收均已确认。不训练、不拟合适配器、不增加检查点或 COS 操作。

经典头在原训练预算下的整体 Macro/CE 点估计较好，但这不是经典路由单独占优的证据。以下将经典路由接到固定量子读出，所有变化都相对于该量子头自身；Macro 以百分点列出，CE 越低越好。

主要指标 Macro-F1 三组上升、一组下降，必须完整保留；次要 CE 四组全部恶化。因此，这些冻结模型中经典完整头的双指标优势没有作为独立路由优势迁移到量子读出上。结果提示应研究路由与读出的适配关系，尚不识别唯一的适配原因、训练收益中介、量子电路贡献或总体因果效应。

四组 Macro 与负CE 的二维交叉差分均为正，但非线性指标本身可以产生交叉差分；它们不证明新的物理耦合规律。readout 交换包含 value、decoder 与 bias 的完整块，内部潜在基底没有拆开；routing 仍包含一起训练的准备与交互参数。
