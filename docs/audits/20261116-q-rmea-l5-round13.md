## 新核查的具体问题

这次复用同版原文，重核 QHA 页3/4/5/17/18，补读先前收据未覆盖的页6/19。问题仅是：其单层表达下界能否迁移到 Q-RMEA 的冻结上下文编码器之后？

[来源事实] 页17–18将经典类明确限定为原始长度N输入上的单层、H个头、m维嵌入、p位精度的注意力类；页18明确多层下界尚未给出。页6/19也区分了架构类中的 basis-loading 表示见证、实际 RZ re-uploading 训练实例，以及有限规模实测，不能把架构类见证自动当作被训练编码器的定理。

[项目事实] Q-RMEA 先用已经混合全句 token 的冻结 RoBERTa-large 生成 h，再由每个 token 的3qubit制备态、关系纯效应和关系值读出分类。它既不是一个 qubit 对应一个原始 token 的联合电路，也不是上述原始输入单层比较类。首轮已保留对“softmax输出必为二阶”的精确反例；这里不重复该推导，也不宣称推翻 MATCHk 渐近下界。

## 一个明确的迁移反例

令任意二元目标 `f(X)` 取值为±1，允许一个未计入 head 预算的全局编码器令每个有效位置 `h_t=(f(X),0,...,0)`。取均值读出、线性值投影保留第一坐标，再设两个类别 decoder 为±第一坐标方向、其余38类 bias 为−2，则两个类别 logits 是 `f(X)` 和 `−f(X)`，argmax 精确给出目标类别。f 可以是任意阶 parity。

这个见证也落在 Q-RMEA 的一个退化子族：制备线性层、其 bias 和全部关系 angles 都取0，所有 token态及关系态都是|000>；Born概率为1，含ε的归一化便给出每个有效位置1/T。角色特征系数取0；值投影和decoder按上一段设置。对应实际诊断镜像 `RMEAHead.forward` 的 prepare/effect、归一化和值读出，镜像SHA `9f4bfc57a1a966c3383c1a2e82fe406ac3d115b653b062290fcf42d3c4683ee0`。这是参数存在性说明，本轮没有赋值、执行模型或改变正式权重。

它只证明：若允许强大的上下文预处理，却只给后续 head 计预算，就不能沿用原始输入单层下界。计算难度可能已被前面的编码器承担。它不证明真实 RoBERTa 表示含有该f，不给出训练算法/泛化界，也不构成新的量子优势或理论创新。

## 研究决定

该近邻继续作为接口/证明规范参考；“借其高阶分离直接支撑现有 Q-RMEA 的 L5”这条迁移线索关闭。没有改变模型或发起实验，L5未接受，旧限定L4保持。

下一步仅发现和检查真正匹配“共享上下文表示＋按类加权读出”的 label-wise attention 原始工作及其容量/正则化假设，先查已有阅读库去重，再限定两次来源检索。预期产物是同一函数类的近邻差异或明确碰撞；不选方法、不启动训练，不再重复 QHA/CoRE/按类能力审计。

本轮无新模型前向、训练、GPU作业、checkpoint/数组/COS读取。数学见证是已知的表示与预算边界工具，不计入L5的新理论贡献。
