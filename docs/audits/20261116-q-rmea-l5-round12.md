## CoRE 的实际计算空间

复用已验身份的原文 `2205.03784v1`，重读 PDF 第4–5页；另只读作者仓库公开 LUKE 演示的 README 和 core.py，未导入或执行。源码按 tree `c98d69472110d2514458e3b58a6a82f9793974aa` 及 Git blob 哈希固定。HEAD 提交与该 tree 未对齐，版本关系保留为 unresolved，未宣称它就是论文当年的执行提交。

- `core.py:130–146` 直接把主体字符串、一个空格、客体字符串拼起来，重新计算字符跨度，再交给 tokenizer。这个实体分支丢弃了原上下文及原位置；固定有序实体表面形式时，原上下文的 wordpiece 长度不会改变这条分支的字符串/跨度。相同 tokenizer、运行设置和确定性求值仍是相同 nuisance 预测的前提。
- `core.py:158–160,182–184` 在最终组合前对 factual 和实体分支 logits 做 softmax。演示用概率向量与预计算项组合；原文 Eq.2 允许 probability 或 logit 输出，具体实现的空间必须分清。没有采用或拟合演示的系数。
- `core.py:39,173–178` 从预计算资产取得第二 nuisance 项和标签约束；所读两份源码没有提供其生产步骤。本轮没有加载或反序列化该资产，因此完整校正向量跨编辑是否相同尚未证实。

若将这个演示的组合式用于两个合法输入，记 `S_i=P_i-1.6 Q_i+0.1 R_i+C_i`，其中 P、Q 是 softmax 后的向量。下列差分限于有限坐标或共同的有限可行标签集合；屏蔽若包含无穷值，应先限制集合，不能直接相减。固定有序实体、相同且确定的 nuisance 求值给出 `Q_2=Q_1`，于是

`S_2-S_1=(P_2-P_1)+0.1(R_2-R_1)+(C_2-C_1)`。

只有另外证明 R、C 也相同，才可简化为 `S_2-S_1=P_2-P_1`。这说明共同偏移可移动决策边界，却保留这个空间中的向量差；它既不保证原始 logit 差相同，也不保证 argmax 不变或修复任何例子。这是已知常数向量抵消，未当作理论创新。
