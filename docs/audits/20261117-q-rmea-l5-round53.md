# L5 第五十三轮：表达能力不等于损失收益，零相位前提不符源码

本轮验证了R52留下的log-attention rank问题。在一个10个有效词、完整40类的有限参数特征头输入上，Born重叠注意力的逐元素对数经词维中心化后rank为9，而现有8维dot-softmax最多为8。普通未取对数的注意力rank仅为3，两种rank不可混用。实值real-overlap对照能精确复制该见证；所选dephased见证最多为4，但不是整个dephased模型族的上界。

更关键的是：保持同一高log-rank注意力，只改变源码允许的有符号utility，就能使完整40类目标CE分别改善或恶化。因此表达能力分离不是任务收益保证，也不解释旧实验总增益。一次隔离独立核验检查了完整固定源码和推导，要求把损失见证目标明确设为第0类，并区分精确数学参数与未执行的原生浮点forward；已在独立修正版中落实，冻结的原输入保留。见[推导](../evidence/rmea/20261117-l5-round53/mechanism-note.md)、[审计](../evidence/rmea/20261117-l5-round53/log-rank-audit.json)、[独立核验](../evidence/rmea/20261117-l5-round53/primary-review.json)。

原始[softmax bottleneck预印本v1](https://arxiv.org/pdf/1711.03953v1)pp1–4，以及[ICML2020 attention bottleneck论文](https://proceedings.mlr.press/v119/bhojanapalli20a/bhojanapalli20a.pdf)pp1–3已限定阅读，均查看p1／p3图像。前者是2017年under-review版本；没有读取完整附录、实验或代码。一般rank瓶颈属于已有理论，不能把这条特殊见证包装成L5创新。见[版本与范围](../evidence/rmea/20261117-l5-round53/original-readings.json)。

另一次隔离构思建议检查“全零相位初始化导致一阶更新锁定、负曲率可降低任务损失”。这只是条件性建议，未独立证明所有命题。主核验发现现有prepare为普通nn.Linear，effect为随机正态参数乘0.2；源码没有全零RZ初始化约定。因此该前提不适合作为已完成训练的解释；也没有从源码推断实际轨迹是否接近实流形。不得人为改成零初始化来制造问题。见[原建议](../evidence/rmea/20261117-l5-round53/independent-ideation.json)及[前提审计](../evidence/rmea/20261117-l5-round53/phase-premise-audit.json)。

作者指定后续必要语义盲审可使用A6API的gpt 6.1 sol。本轮只做目录连接核验，本机和已绑定owner路径均失败，尚未发送材料或启动模型读者。未来标注必须隐藏方法、结果和标签，明确是模型语义判断，不把同一模型两次输出当作独立人工金标或独立测试证据；人工盲审仍不是研究前提。

本轮未选择新方法、未接受L5，已验收限定L4不变。没有新模型forward、数据读取、训练、正式实验或COS操作。下一步寻找独立成立的任务／损失前提；不继续包装rank理论，不强制零相位初始化，不重启已停止实验族。
