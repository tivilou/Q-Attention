# Q-RMEA R70：保留实体条件化制备的探索候选

本轮保留ECQP（entity-conditioned quantum preparation）供下一份前提与实现契约设计。它只是探索候选：零合格候选、实现尚未就绪、任务效用尚未运行、L5未接受。原限定L4与全部关闭路线保持原范围。

候选先由未接收主模型具体方案的gpt-6.1-sol/medium咨询提出，再由主模型核对旧源码和原文。它以实体摘要与词向量的固定投影Hadamard交互修正原12个制备角度，保留8维词态、原量子效果、归一化和有符号40类读出。新增192个参数，共81220。原上下文化H已经含实体标记信息，不能声称补上了原先不存在的实体信息。

这改变的是词态编码入口。旧ordered从实体侧改变有效查询；旧joint收缩独立寄存器，且词寄存器为4维。此处计算图位置有别，但尚未证明完整函数类分离。对原有正类判空现象的错误统计仍只是动机，未识别因果机制。

已核对1901.08163v1实体感知关系分类、1610.04325v4低秩双线性视觉问答注意力、2609.22005v2注意力弃权的选定原文方法及关键公式图。实体条件化、投影乘性交互和额外分母弃权均有直接先例；本候选近邻碰撞风险高，实质创新与任务理论均未建立。来源效用不迁移。

对冻结六文件和原/旧实现的独立mechanism审核接受探索设计，无必改项；审核未运行代码或独立认证原文。实际执行的Fraction检查通过双线性恒等式、对称性玩具实例、线性分支可折叠性、二次特征有限差分、确定符号指纹和参数计数。它未执行投影buffer、电路、模型、梯度或数据。两份JSON结构校验通过也仅意味着记录契约通过。

下一步需冻结池化与空实体处理、精确P buffer、dtype/device/有限值、零B初始化对齐和梯度检查、实体分组与fit/eval界限、全队列同split错配映射，以及有灵敏度和不确定区间的训练集内诊断。零B时正确/错配摘要输出相同，必须区分初始化一致性与更新后的摘要作用。经典控制需明确交互特征插入位置；token-square及预算匹配控制不能省略。关联诊断通过也不构成训练架构效用，弱阴性不否定整个条件化家族。

本轮两次A6API均为gpt-6.1-sol/medium、各一次无自动重试。零模型前向、零电路运行、零训练、零科学调度任务、零GPU/COS和新增容量。新的完整正式实验仍交由师弟，当前没有发布全量运行指令。
