# Q-RMEA L5 Round36：证据可观测性与共同末层抵消

正式源码声明保存首步前参数、原始梯度、后参数和 batch 索引，compact 七文件报告不含这些数值；两个 checkpoint 只保存 head，不能重建后续 Adam 历史。本轮没有恢复任何私有产物。
