## 同一分数下的决策边界

ATLOP的原始任务为文档级多标签RE，其TH类由输入生成，训练使用专门的双项损失，局部池化利用主客实体的预训练注意力。这里读取的是[原始v3正文](https://arxiv.org/html/2010.11304v3)，不是只看摘要。方法差异和其DocRED消融均不能直接证明Q-RMEA的收益。

对于当前单标签任务，固定相同的40个有限实数分数，记null为索引0；null与正类同分时选null，正类间同分沿用原索引顺序。则“最高正类分数严格大于TH=z0时输出该正类，否则输出null”，与原40类argmax完全一致。这个结论不涉及独立阈值参数化、重训后分数、校准或一般多标签决策。原实现为null提供输入依赖形式的得分，不等于已证明它在实测样本上变化充分或已校准。

损失不能混同。对于唯一正类y，令a=exp(z0−zy)，b为其他正类exp(zr−z0)之和：

`CE = log(1+a+ab)`；`ATL = log((1+a)(1+b))`；二者之差为`log(1+b/(1+a+ab))`。null样本省略ATL正类项时，其负类项等于target-0 CE。损失改动可形成另一项实验，但该目标已有文献来源；这段已知代数不是L5理论贡献。

独立gpt-6.1-sol/medium审核接受上述限定推导，must_fix为空。仅将null改称可学习阈值，不足以形成新的单标签决策机制；这不排除所有null-aware方法。R61的30单元排序问题仍未执行、仍未回答，但无需为这个固定分数恒等式下载分数。后续仅在另有明确诊断或干预价值时重审恢复预算。
