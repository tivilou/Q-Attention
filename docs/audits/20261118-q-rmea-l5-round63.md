# Q-RMEA L5 R63：归一化强度假说的资格审查

本轮没有选出新方法，L5 仍为 `NOT_ACCEPTED`。原先“归一化完全丢掉接受强度”的说法不够准确；代码中的 `EPS=1e-6` 会把强度带入均匀平滑的混合系数。这一修正既不证明强度可恢复，也不证明它对分类有用。已验收的限定 L4 保持不变。

## 1. 执行代码对应的恒等式

原始头的源文件 SHA256 为 `9f4bfc57a1a966c3383c1a2e82fe406ac3d115b653b062290fcf42d3c4683ee0`。对一个标签行的 T 个有效 token，令 p_i 为 Born 响应，μ=mean(p)，ε=1e-6。原代码使用：

`alpha_i = (p_i + ε) / [T(μ + ε)]`。

当 μ>0 时严格有：

`alpha = [μ/(μ+ε)] · [p/sum(p)] + [ε/(μ+ε)] · Uniform(T)`。

μ=0 时 alpha 均匀。因此，一般缩放 p 会改变平滑权重；“完全尺度不变”不成立。反过来，仅给任意 p 数组的 alpha 也未必能恢复 μ：所有 p_i 相等时，任何常数水平都产生均匀 alpha。这个抽象反例尚未证明实际固定词状态框架和原生纯态查询电路存在同样的歧义。若额外已知 μ，则 `p_i=T(μ+ε)alpha_i−ε`。这些是已知归一化代数，不构成 L5 创新。

40 个标签效应是各自独立的二元测量，不是一个 40 结果 POVM。对其响应求和，没有自动获得联合测量概率的解释。完整分类头还使用输入相关的 signed utilities，alpha 的信息问题也不等于整个头丢失预测信息。

## 4. 下一道有边界的数学问题

对一个已固定原始 trace 的一个标签行，固定词状态框架 A_i，令 S=sum(A_i)。给定精确 alpha，原生可达纯态 ρ 必须满足：

`tr[ρ(A_i−alpha_i S)] = ε(T alpha_i−1)`。

在该约束纤维上，`tr(ρS)/T` 是否恒定？恒定则这个固定框架中的 μ 可识别；若存在两个满足同一约束且 μ 不同的原生可达纯态，则不可识别。这是该纤维上必要且充分的判别。`S in span_R{I, A_i−alpha_i S}` 是充分证书，对受限原生纯态族一般不是必要条件。混态松弛中的歧义不能冒充原生纯态反例，float32 保存误差也不能当作精确等式。

此问题尚未执行，不是新架构或 gate 提案。即使解决，也仍缺预测相关性、实质新规则和独立效果证据，不足以单独达到 L5。无需为本问题恢复全量 score 或重跑历史 baseline。
