# Q-RMEA L5 R85：相干读出的两个必要边界

本轮从 R84 的路由／读出组合结果继续研究，未训练、未前向、未重新回放、未调用调度器或 COS。新增结果是一个经过独立核查的原电路解析反例，以及三个原作的限定范围核读。L5 NOT_ACCEPTED，未选定新的实验方法。

## 新结果

尝试从弱测量借鉴“把 token utility 作为可观测量，再后选择读出”。先推导后决定是否值得实现：

1. **保留经典 token 标记时，指定方案精确退回原头。** 用带 epsilon 平滑的标记混合态、token 对角 utility 算符和均匀 token 后选择展开迹，结果正好是原 Born 加权 logit。因此仅替换物理术语不产生新机制。
2. **相干 token 擦除新增相位与资源合同。** 明示相干态给出 W=sum(u_t c_t)/sum(c_t)、成功概率 |sum(c_t)|²/n²。原三比特两层电路存在有限参数构造：改变 token2 两个 RZ 角，仅使其整体态变号，原40个 logit 全部不变，弱值却从 2sqrt(3)-3 变成 -3-2sqrt(3)。两个成功概率分别为 (7+4sqrt(3))/16 与 (7-4sqrt(3))/16，均非零。

这说明相干方案需要把受控制备、分支相对相位、后选择和估计成本写进新模型合同。相干操作本身可以合法定义，但不能假设它仍只依赖原来的各 token projector，也不能继承原模型的 L4。反例是解析实数算术，未宣称浮点逐位等价、无成本放大或任务效用。
