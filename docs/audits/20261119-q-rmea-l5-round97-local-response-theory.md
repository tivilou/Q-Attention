## 得到的数学工具

1. 单类聚合分数在eta0的导数分成query平行块、正交补块和非对角块三个非负项。
2. 采用相同完整范数的pinching控制，恰好移除非对角项的局部响应。
3. 固定表示且原始Born质量F>0时，pinched响应为O(epsilon)，
   有非零非对角耦合时其响应为Theta(1/log(1/epsilon))；两者都趋零。
   因此pinching会大幅改变局部更新幅度，不能当作唯一机制归因证据。
4. 多类交叉熵导数由真实类响应减去概率加权竞争响应决定。单类得分均上升不保证
   分类更好；非对角项对这一差值的贡献也可能为正或负。
