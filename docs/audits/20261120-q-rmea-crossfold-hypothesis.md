# Q-RMEA：交叉分组的选择—读出分离候选

本轮新增一个探索性机制家族：A组token效用构造测量来路由B组，B组反向操作；
全部token仍参与读出。固定原生测量质量作为组间权重，使eta=0精确还原原生注意力。
不增加可训练参数，但每类需要两个矩阵指数，计算量高于原full。

灵感来自Double Q-learning对选择与评估的分离。这里两组是不同token，
并非同一动作的独立估计，所以原RL收益、收敛保证和独立性都不直接转移。
R96联合训练的正向点及R98“本类分数都上升、分类收益仍混合”的结果提供动机，
并未证明真实token效用带有独立噪声。

推导得到：交叉分组的局部响应由两组残差算子的双线性内积决定，正负均可能；
同组构造/读出的匹配对照则是非负二次型。在明确的条件误差假设下，
交叉方式去掉自身噪声读出期望，目标只是噪声路由下的干净值聚合，不是任务风险。
至多三个有效token时该结构完全退化为native，这是必须验证的边界。
