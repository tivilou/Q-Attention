# L5 第五十六轮：相同读出函数不保证相同优化轨迹

本轮从完整40类读出检查新的优化机制。结果是一个准确的算法边界，尚未选出新方法，L5 未接受；原限定 L4 保留。全部核验为源码阅读与精确有理数计算，没有模型前向、数据扫描或新训练。

## 原始注意力理论的适用范围

核验并读取 [Transformers as Support Vector Machines，2308.16898v3](https://arxiv.org/pdf/2308.16898v3) 的第1/3/4/5/6/20/29页，58页均解析，未声称全文深读。第4页用固定线性预测头定义带标签的 token 得分；第6页的 Lemma2/Theorem2 分别要求递减损失、可分 token，以及唯一最优索引等条件。第29页 B.2 用固定最佳 token 的分数界定混合输出，再令可分 softmax 分数尺度趋于无穷以达到该输出。核范数结论的对象是文中规定的正则化路径。

Q-RMEA 的40类 value/decoder 共同训练，Born 分数在[0,1]内且保留 ε=10⁻⁶；实际训练使用 AdamW(lr=.001,decay=.01)、全局梯度裁剪1、20epochs与验证Macro选模。上述差异不能被略去，原文的极限或核范数结论尚无直接源码对应。2024版讨论的扩展问题也不构成“2026仍未解决”的证据。

## 精确的完整40类优化反例

R14 已确认任意40×1024读出矩阵 B 都可由64维因子 D V 表示。这里检验这个函数类等价性是否还能推出优化轨迹等价。

两组合法原生参数均令 prepare/effects 为零，因此注意力均匀；所有 value/decoder 坐标为零，只保留 D₀₀=a、V₀₀=b。value偏置为零，输出第0类偏置为−1/400，其余输出偏置为零。取 (a,b)=(1/20,1/20) 或 (1/10,1/40)，两组 B₀₀ 均为1/400，初始在**全部合法 H/R/mask 输入**上表示同一函数，不只是某一个输入输出相同。

有界构造输入是两个有效实体token，均只有 h[0]=1，其余隐藏维为零，目标y=0；初始40个logit均为零。其完整CE梯度 g₀=−39/40，其他39类各为1/40。所有活跃梯度为 decoder[:,0]=g_vector·b、value.W[0,0]=g₀a、value.bias[0]=g₀a、output.bias[:]=g_vector；选择器梯度为零。

全局梯度范数平方为 2g₀²a²+(1+b²)·39/40，两组均小于1，故配置中的裁剪在这一步不触发。采用显式假设的 AdamW 默认优化器 epsilon=10⁻⁸，第一步偏差修正消去 beta 因子，任一参数更新为

```
x_new = (1 - lr*decay)*x - lr*g/(abs(g)+optimizer_epsilon)
```

精确分数核验表明两组更新后的 B₀₀、目标与其他类的logit间隔均不同；后者差约0.000049999484。各组其余39类logit相等，因此概率与完整40类CE也不同。value偏置和所有类别的梯度已计入，不能用二元简化替代。数值仅作说明，非零性由分数运算检查。

这个结果说明参数化影响一步优化，既不证明长程训练优势，也不否定可能存在的最终隐式偏置定理。它使用人为设置的合法参数，不声称实际随机初始化或真实编码器会产生这个构造。没有执行原始PyTorch浮点步骤；官方版本化默认实现抓取超时，安装版本默认值未独立核验，因此 epsilon=10⁻⁸ 保持显式条件。

## 正ε与硬选择的边界

对 T 个有效token，q∈[0,1]给出 max α≤(1+ε)/(1+Tε)，min α≥ε/(T−1+Tε)，故到任一one-hot的L1距离至少2(T−1)ε/(1+Tε)。正ε使严格的硬选择极限不成立，但该差距很小，不代表现实任务劣势；这些边界也适用于相同分数范围的实值/去相位对照，不是量子专有效应。不声称所有边界可由同一电路同时达到。
