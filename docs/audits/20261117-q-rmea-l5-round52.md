# L5 第五十二轮：均匀概率混合仍可能离开原生模型族

R50只解决了按ID固定置换的情形，本轮解决此前保留的“对全部置换均匀平均概率后，是否必然回到原生模型族”问题。答案是否定的，但范围只限可接收的特征头API，不扩展到真实RoBERTa输出或语义不变文本。

原生模型的每一类都是正权重归一化后的有符号utility均值。所有完整H／R／mask行连同实体行等倍复制，分子和分母同倍增长，因此全部40类预测不变。这一性质也适用于匹配经典头。构造两个context和两个entity行、有限电路参数及rank-one value／decoder，可令Born分数为(1,1/2,1,1)、目标utility为(1,0,0,0)、其他39类logit为零。

在一次和两次复制时，均匀alpha置换的目标logit分布分别为端点各1/2，以及端点各1/6／中点2/3。完整40类目标概率f(z)=exp(z)/(exp(z)+39)在所选区间严格凸，因此两个概率混合不同，而任意原生候选在这两个输入上都相同。由此得到一个存在性不闭包反例。精确有理数枚举746个索引置换、有限参数映射检查通过；没有Torch／真实数据forward。

一次隔离独立核验没有发现致命数学错误，给出有条件的头API结论。主核验补上源码允许的value／decoder参数构造，明确趋零Jensen偏差是相对f(m)，相对原预测f(a)的偏差并不消失，且保留完整复制／可变基数／存在性量词。原独立结果及其未检查源码的限制保持原样。详见[推导](../evidence/rmea/20261117-l5-round52/mechanism-note.md)、[精确审计](../evidence/rmea/20261117-l5-round52/uniform-mixture-audit.json)、[独立核验与修正](../evidence/rmea/20261117-l5-round52/primary-review.json)。

近邻原文[IJCAI2020论文](https://www.ijcai.org/proceedings/2020/0194.pdf)pp1–3已读、p1／p3已渲染核对，说明归一化注意力的复制碰撞属于已有性质；未阅读其完整证明附录或实验，也未做穷尽新颖性检索。见[限定阅读](../evidence/rmea/20261117-l5-round52/original-readings.json)。

这条结果限定了把模型外ensemble的风险性质移植为同一原生族内优化保证的做法。它没有推翻ensemble自身的风险不等式，没有否定另行定义ensemble的任务价值，也不解释实际一次hash置换的CE差。原限定L4不变；未选择新方法、未接受L5。下一步回到实际class-by-token注意力矩阵，检查相对rank8 softmax的log-attention表示约束，并同时检查real-overlap是否共享该能力，再与原始softmax-bottleneck文献核对。此问题尚未验证，不授权实现或新正式实验。
