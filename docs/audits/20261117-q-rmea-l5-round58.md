# L5 第五十八轮：固定标签态的原作与分组论证边界

本轮没有选定新方法，也没有接受 L5。精确构造可行，但当前的标签几何论证尚未提供任务上的可区分预测。

## 最近原作

[Data re-uploading](https://arxiv.org/abs/1907.02085v3) 的第4—5页已使用固定、尽量分离的标签态，通过保真度和加权保真度分类。它处理输入的最终分类，当前草案则以标签态查询词元后做带符号值聚合；两者尚不能直接判作同一完整机制，但“固定量子标签态”本身已有先例。

[MUB 原作](https://arxiv.org/abs/quant-ph/0103162v3) 第14—15页给出对称矩阵和可逆差构造。按其条件实例化 GF(8)，构造了5组各8个秩一投影，使用高斯整数和有理数核验全部1600个重叠。每行恰有1个自身、7个正交、32个重叠为1/8。该构造是已知数学的核验，原生两层电路的可达性仍未证明。

[ECOC 原作](https://arxiv.org/abs/cs/9501101v1) 的PDF第4、7页讨论码间距离及错误相关性。旧字体导致文字提取损坏，本轮以渲染页面阅读。码距的纠错结论并不自动适用于词元归一化与自由分类读出。

## 新得到的边界

假设一个信号词元对齐其所分配的标签投影，8个背景投影之和为单位阵，所有类别对信号的效用相同、对背景为零，且类别偏置为零。令平滑项为 ε，则信号权重为 `(q+ε)/(q+1+9ε)`。40类交叉熵恰为

`log(1 + 7 exp[a(α0−α1)] + 32 exp[a(α1/8−α1)])`。

每个标签有相同的重叠多重集，因此所有标签分配在这些假设下交叉熵相同。加入统一信号误差、背景各向异性及效用误差后，得到的保守上界也不区分分组。**这并不是固定物理编码器、仅置换查询时的损失不变性，也不是实际含噪损失相等。** 需要额外、可检验的标签对相关条件，才能论证某个分组更好。

相同投影几何下，信号效用取正、零、负时，示例交叉熵分别约3.29345、3.68888、4.09020；均匀注意力为3.68888。这只说明完整带符号读出不能被几何优势替代，不是 Re-TACRED 实测或新方法的收益结论。完整条件、证明、哈希及代码在[证据目录](../evidence/rmea/20261117-l5-round58/primary-review.json)。
