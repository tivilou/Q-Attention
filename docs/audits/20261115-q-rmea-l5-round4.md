# Q-RMEA L5 第四轮：可实现性证书与任务损害的分离

本轮已完成有界 CPU 审计，**L5 尚未达到，原限定 L4 保持不变**。三个学习型 donor 各有一个关系的注意力，在固定保存 Q 词态上的迹为1半正定混合效应类中不可实现；uniform 则有显式可行构造。这些结果收窄下一轮问题，没有产生新任务收益或新颖性结论。

## 实际检验对象

仅复用上一轮事后选择的7个验证案例、260个有效 token、5个历史 seed29 selected head 的保存数值，不加载原文或测试集、不调用模型前向、不训练。上一轮缓存来自 CPU 重建，不能认证原 GPU 编码器逐位等价。本轮未读取 COS、下载输入二进制或新建付费资源；私有 witness 数组与输入谱系留在原 CPU worker。

对每个关系独立使用同一个 E≥0、tr(E)=1。不同关系不施加联合 POVM 求和约束；这是原 rank-one 效应的凸松弛，也不等同于一般任意迹二元效应。固定 Q 保存的归一化词态 rho_it，定义 a_it(E)=[tr(E rho_it)+eps]/[tr(E sum_t rho_it)+T_i eps]，eps=1e-6。

## 已冻结的数值判据

对任意有限实数 witness w，记 W=sum_it w_it(rho_it-a_it R_i)、c=eps sum_it w_it(T_i a_it-1)、m=tr(W)/8。若所有坐标误差≤tau=1e-5，则必须满足

    |c-m| <= sqrt(7/8) ||W-mI||_F + B,
    B = tau(1+eps) sum_i T_i sum_t |w_it|.

先检查 |c-m|-B>0，再以定向区间验证平方差 (|c-m|-B)^2-(7/8)||W-mI||_F^2 的严格正下界。原理是已知凸对偶/层析工具；SVD只用于寻找 w，最终证书不依赖数值零空间或数值秩的精确性。[完整推导](../evidence/rmea/20261115-l5-round4/proof.md)。

全部200个 head/关系筛查结果保留；每个 head 仅对筛查最大的一个关系做区间认证，共5次，其中3次确认不可实现。三个学习型 donor 虽各有40个数值正筛查，本轮**没有认证120个关系都不可实现**。反之，未获得证书也不证明 PSD 或纯效应可行。

## 这一轮排除了什么解释

上一轮1,024条验证特征中，uniform 注意力换入 Q 固定效用/解码器后，Macro-F1从50.5462%降到6.7497%，纠错80例、损害303例。本轮的 uniform 构造对任意归一化词态都成立，因此“落在这个迹为1混合测量集合之外”不足以单独解释所有替换损害。

这里必须保留两层边界：I/8 的混合效应未必属于原训练 rank-one 电路参数族；三个 donor 各自的训练词态通常也不同。因此不能断言原纯效应族中的不可实现性已被全面排除，不能把三个证书当作损害原因，更不能从两轮描述性回放推出共同适配的因果确认。它们只说明下一步需要研究任务效用、准备映射和效用/解码器的共同关系。

## 原文核对与下一问题

本轮以既有12篇原文范围阅读记录为基础，另做独立问题检索和跨领域检索，两篇新原文只按明确范围阅读，不把元数据命中当读完论文。[范围记录](../evidence/rmea/20261115-l5-round4/reading-receipts.json)。

[Geiger等《Causal Abstractions of Neural Networks》v1](https://arxiv.org/abs/2106.02997v1)第1–4页要求先提出高层因果变量及与网络内部变量的对应，再检验相应互换干预。任意跨 head 的注意力替换本身尚不建立这种因果抽象。附录H和完整实验协议未在本轮读完。

[Buscemi《Comparison of Quantum Statistical Models》v4](https://arxiv.org/abs/1004.3794v4)第1、16–18页区分统计态射与CPTP充分性；后者的等价条件包含辅助统计模型。单个任务的Macro排序不满足这些比较条件，40个独立二元效应也不能直接替换文中的完整决策测试。读取的是2011年v4预印本，未核读2012年期刊文本，尚未完整审核其前置定义和证明。

下一问题是：共同训练的准备、关系效应与效用/解码器，是否存在一个超出单纯可实现性、能预测决策变化的任务约束？先定义可解释的证据变量和匹配干预，区分可实现性、准备不匹配、共同适配与标签信息，再冻结独立数据上的可区分预测。目前这是研究问题，**没有选出新方法，也没有新颖性放行**；不能把支持函数、互换干预或BSS换名作为L5理论贡献。
