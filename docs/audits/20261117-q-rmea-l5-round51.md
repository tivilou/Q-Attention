# L5 第五十一轮：复用完成实验，校正比较范围

本轮只审计既有报告和原始benchmark来源，未运行模型、训练或正式实验，也未读取原始数据。十五组历史参考与二十五个fresh5匹配头实验已经完成；R15已撤销的“baseline还没做完”阻塞不应重新出现。Oct26只完成小pilot的旧资格记录保留原样，但其中缺少实现、完整匹配队列和规模化可学习性证据的条件已被后续结果覆盖。

本轮资格结论为`qualified`，范围严格限于既有私有固定队列、冻结特征40类研究的回顾解释和复用。官方论文p5的91,467条／40类与上游README的v1.1对应；本地58,465／19,584／13,418划分有固定哈希。未独立重建许可源数据到JSONL的转换链，也未认证原始许可权利，不作数据再分发或独立文档／实体／OOD泛化声明。新候选的因果／机制检验仍需按其具体主张冻结协议。

七文件哈希链通过；25个单元均完成20轮、9,140次更新，按验证集Macro-F1最大值的最早轮选择，测试不参与选择。本轮重算550个验证／选中／测试混淆矩阵记录，指标全部一致。该数字包含25个重复的selected_valid记录，不是550个独立实验。CE仅引用原报告，本轮不从混淆矩阵重建CE。

这是共同输入／训练预算／公共value-decoder初始化的局部比较，参数数并不完全匹配。历史十五组参考是背景；它们的微调方式、选模指标及输入特权不同，不能把较高参考分直接当冻结特征头的可达最优。Q相对softmax均值仅+0.2474个百分点；现有配对CI跨零，不能推出优势，也不能推出等效。原始独立确认针对Q−uniform和固定模型局部alignment的限定L4保持不变。

完整测试集只有39类有支持，但主指标仍固定除以40，所以代数上限为39/40=0.975。按暴露测试均值事后选出的最强经典头softmax，乐观可改进区间只可写为[0,0.4567209638]；没有严格正的可寻址增益下界，也不是优化后的预期效果。R9的2,361／1,024子集界限继续只属于原子集。官方常用非空micro与本研究的full40 macro需分开报告，避免将同名F1当同一指标。
