# L5 第十四轮：按标签注意力的原始先例与实际差异

本轮首次核对 CAML 和 LAAT 的正式原文，确认“共享表示、按类注意力、分别读出”已有明确先例。Q-RMEA 的具体权重函数仍有差别；本轮没有证明这种差别带来新理论或任务优势。限定 L4 保持，L5 仍未接受。

## 与执行代码的精确对应

项目先把带实体标记的整句输入冻结编码器，得到1024维上下文词表示。词表示与4维角色特征经12角度、两层三量子比特电路产生 ψ；每个关系有独立纯效应 φ。有效词上的权重为：

`q_rt=|φ_r†ψ_t|²; α_rt=(q_rt+ε)/Σ_j(q_rj+ε), ε=10⁻⁶`。

随后使用64维线性值投影、每关系解码器及自由偏置产生40类 logits，最终 argmax。诊断镜像 SHA 为 `9f4bfc57a1a966c3383c1a2e82fe406ac3d115b653b062290fcf42d3c4683ee0`；它不是原正式运行源文件的字节副本，原正式来源及限定 L4 身份继续见旧证据卡。

当前 `relation_softmax` 对照使用8维线性 key 与自由关系 query；LAAT 则有非线性共享投影。原文结构相近不等于当前对照完整复现 LAAT，也不证明两个完整模型的函数类相等。

### 权重函数的差别应保留

在有效坐标上，已知标量恒等式给出 `α=softmax(log(q+ε))`，无效坐标设为负无穷。它没有把 `q` 的生成函数变成 CAML 的线性查询或 LAAT 的 tanh 查询。

将同一个 q 直接放进 softmax 则不同：抽象概率夹具 q=(0.8,0.2) 得到 Born 归一化约(0.7999994,0.2000006)，而 softmax(q)约(0.6456563,0.3543437)，最大差0.15434309377540467。正确 log 映射的误差为1.1102230246251565e−16。这是有限实数代数核验，不声称该夹具就是训练模型输出，也不声称浮点执行逐位相同。

### 值投影本身没有增加线性读出的函数类

固定同一 α 时，线性值矩阵 V 与关系解码器 D 的作用可合并为 B=DV，值偏置可并入关系自由偏置。对于任意40×1024的 B，直接取 `V=[B;0_(24×1024)]`、`D=[I_40,0_(40×24)]` 即可恢复它。因此64维宽度足以表达任意40类线性读出；这部分与自由的逐类线性读出在函数类上相同。

该存在性构造不等于训练过程相同。分解参数的初始化、优化、正则化、参数数量仍可改变结果；本轮没有据此解释既有性能。固定小矩阵构造及来源哈希检查见[代数审计](../evidence/rmea/20261116-l5-round14/attention-mapping-audit.json)。这也是普通线性代数，不作为新理论。

## 本轮结论与研究边界

可保留的具体差异收窄到：角色条件化的受限状态制备、纯效应产生的 Born 分数，以及其归一化及训练行为。先前已确认的核映射、密度特征、Rayleigh 商等工具不因这次映射而重新成为新贡献。

要以这部分推进 L5，仍须提出超出已有工具的命题，并给出能区别受限参数化、一般非线性映射及训练因素的预测。现有 Q 对 uniform 的限定 L4 不自动完成这些比较；本轮结构审计也不撤销该 L4。

没有新模型前向、训练、数据或 checkpoint 读取、GPU作业、COS 写入或协作者服务器访问。本轮讨论保持 exploratory_only，没有核发新方法的实验资格。

## 独立意见后的来源检查

两条已按证据排序的外部原生 max 咨询均发生 URLError，随后按咨询技能的可用性回退，由独立子代理读取同一无候选问题包。意见为 justified_stop，支持的新路线数为0：结构描述没有补上连接电路限制与任务收益的独立前提。[意见](../evidence/rmea/20261116-l5-round14/next-theory-advice.json)是研究建议，不是新实验结果或 L5 验收。

继续执行它建议的一次有界来源检查：搜索工具的路由本身返回404，随后使用普通无头浏览器完成两次 arXiv 公共搜索。四条结果中，前三篇是多标签应用/经验研究线索，仅读元数据；选定另一个原始理论来源：[Sarkar等，2610.34945v1](https://arxiv.org/abs/2610.34945v1)。先去重，再核对唯一v1历史及PDF身份，实际阅读页1–5、渲染页3。它是预印本；本轮没有独立验证整篇证明或实验。

这篇工作提供了明确但不适用当前实现的前提：

- 页2明确说明，逐实体换坐标系是一项选择的归纳偏置，并非新实体名称必然带来的对称性。页3式1要求边算子随两端坐标同步变换。
- 页4的宽度定理针对正交递推、有限目标群、所有有限输入串上的精确解码和凸决策区域。Q-RMEA 没有这条递推，没有已核实的目标群及其运算表；40个关系标签本身不提供群结构。
- 当前权重依赖每个关系的共享φ，代码没有逐边传输算子。最后虽有线性值读出，整个ψ到各类logit的映射仍含关系相关的归一化加权，不能仅凭“线性decoder”就认定满足其凸区域假设。

因此该来源不能直接解释原L4，不能把三量子比特逐词状态与它的递推记忆宽度相等同，也没有授权恢复已停止的 ordered/joint 家族。具体迁移卡见[来源前提检查](../evidence/rmea/20261116-l5-round14/transport-premise-gate.json)。这是一次实际完成的否定迁移检查，保留为后续研究的明确边界。
