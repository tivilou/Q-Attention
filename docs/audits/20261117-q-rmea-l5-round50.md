# L5 第五十轮：集合池化近邻与诊断闭包反例

本轮读Attention-based Deep Multiple Instance Learning的p1身份／引言、pp2–4方法／相关工作，以及Deep Sets的pp1–3。它们明确了可训练池化、条件集合表示的近邻，以及原生模型不能直接继承的输入语义和表达性条件。没有把80维分子／分母集合改写当作新理论。arXiv检索失败、官方出版页及PDF成功，检索覆盖限制已记录。

一次隔离的独立理论建议返回NO_QUALIFIED_CANDIDATE，提出概率混合函数类的闭包问题。重核源码发现实际诊断是按ID和位置确定性排序，不能直接当均匀随机置换。针对该实际确定性版本，本轮构造了头API两点输入反例：原生头对共同重排行不变，alpha-only hash后处理却给出不同的完整40类概率，因此后处理不属于固定values／decoder／bias的原生函数类。

原始producer函数的窄单元桩和有理数审计通过；不是Torch forward。独立核验对新冻结包给出PASS_WITH_LIMITS，明确实数数学语义、有限原生角度、头输入域、未认证RoBERTa像集／真实队列／浮点执行及均匀混合情形。没有用它解释现有CE差，更没有接受新候选或L5。
