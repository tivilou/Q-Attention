# Q-RMEA L5 R64：可识别性边界与原始分数诊断准备

本轮得到局部数学结论，并把下一项任务诊断的恢复成本核实到五个原始种子。没有选出新方法，L5 仍为 `NOT_ACCEPTED`，已验收限定 L4 不变。

## 1. 固定样例的全局问题没有被局部结论替代

事前固定原始 seed29、选定 quantum checkpoint 的第一个验证 trace、第 0 行，40 个有效词状态、维度 8。只读取保存的复数状态与相关数值；没有运行电路、模型、训练，也没有读取标签、预测或 utilities。

令 `A_i=psi_i psi_i*/||psi_i||²`、`C_i=A_i+eps I`，`eps=1/1000000`。保存的 complex64 数可精确解释为有理复数，所得单位投影为有理矩阵。这是“保存快照的单位化数学模型”，与从原生电路角度计算的精确超越数状态有区别。

一个充分证书是：存在实系数 d，使 `H=sum_i d_i C_i` **精确 Hermitian、精确半正定、核精确为 span(q)**。相同归一化响应意味着原始响应仅差一个正常数，因而任何同纤维的 trace-one PSD 状态满足 `tr(rho H)=0`，必须等于 `q q*/||q||²`。仅有小残差或数值正特征值不构成该精确证书。

本轮两种构造均未得到此证书。第一种 Frobenius 投影的 `H+rho` 最小特征值为 -0.03341684；随后预先固定的凸交替投影在 250 步上限后为 -0.00326822。两者都是 **INCONCLUSIVE**，不证明证书不可行、不证明存在碰撞，也不证明原生头丢失有用信息。停止扩展这两种求解尝试。

## 2. 精确成立的是局部可识别性

在 q 最大幅值坐标非零的复射影图中固定该坐标为 1，剩余 7 个复坐标给出 14 个实变量。设 `n_i=w* C_i w`、`D=sum_i n_i`，则 `alpha_i=n_i/D`。实部和虚部坐标的导数分别为 `2 Re(C_i w)_j`、`2 Im(C_i w)_j`，再用商法则得到注意力 Jacobian。

这个固定快照的 40×14 Jacobian 存在一个**精确有理数非零的 14×14 子式**；浮点最小奇异值约 0.00779034。逆函数定理因此给出某个邻域内纯态射线的唯一性，平均 Born 响应也在这个邻域内由注意力及固定词框架确定。公共代码可从原始固定 trace 复算；私有精确行列式仅保留哈希。

结论没有覆盖远处碰撞、混态全局唯一性、明确邻域半径、稳定反演或精确原生电路。一次行列式证据保存触发 Python 整数字符串长度限制；失败记录和旧源码保留，限定工作进程的序列化修正后完成复算，没有更换样例或改变数学判据。

## 3. 原生架构确实容许一个退化反例

这是解析推导，不是当前训练头的测量：把 prepare 权重和偏置设为零，所有词状态均为 `|000>`。查询仅保留第一层 wire0 的一个 `RY(theta)`，其余旋转为零。原代码的两次 CNOT 环均是固定 `|000>` 的基排列，所以 `p_i=cos²(theta/2)`，对所有词相同。

取 `theta=pi/2` 与 `pi/3`，平均响应分别为 1/2 和 3/4，但含 eps 的注意力均为 `1/T`。两者均能由有限的 `effect=atanh(theta/pi)` 实现；固定 utilities、偏置和输入时，池化行分数也相同。这证明原生参数族在这个退化词框架中存在不可识别性，**不证明原始训练头存在此碰撞或丢失有用信号**。它与上述固定快照的局部结论可以同时成立。

这些是资格和边界结果，没有建立 L5 新颖性，也不支持增加强度门或重启已停止分支。原始训练框架的全局问题仍开放；在缺乏预测用途时，不继续无界投入全局逆问题。

## 4. 下一项诊断直接针对任务错误

冻结原始 3 个头 × 5 个种子 × valid/test，共 30 个单元。对每个单元，分母为所有 gold-positive、预测 null 的样本；分子为其中正确关系的原生 float32 分数**严格高于**所有其他非空关系的样本。所有 40 类按原索引 argmax，null 索引为 0，精确最大并列时最小索引获胜。正确关系与其他非空关系并列不计入分子。

每个有定义单元须 `2*numerator > denominator` 才符合“严格超过一半”。任一非空单元不满足，即不符合预先写明的 all-cell 判据；空单元为 `UNDEFINED_EMPTY`，不视为通过；非有限分数、错数据/模型、遗漏重复样本或回放校验失败为 `INVALID`。须报告全部单元、计数、精确并列数与比例。

这是看过既有汇总结果后提出的有限样本描述性诊断。失败不是总体统计假说的显著性拒绝；通过也不证明一个共享阈值可恢复这些样本、不保证 precision、收益、因果性或泛化。没有阈值、门、系数或种子搜索。已有完整 score dump 缺失，尚未执行此诊断。

核心定义已冻结；实际回放的 batch/精度/TF32、原始 confusion/count 桥接、固定 trace 容差与调度合同仍须单独冻结并审核。没有借本文件许可任何模型作业或新正式实验。

## 5. 五个原始种子的恢复可用性

复用 seed29 既有已验证库存，另对 seed53/71/97/113 各读取一个固定 VersionId 的 64 MiB 首分片。每个分片完整哈希、首成员 `RUN_COMPLETE` 哈希、原始报告和归档验收链全部匹配。每种子 159 个内部对象。四次 GET 合计 268435456 字节，SDK/HTTP 自动重试 0、云写入 0；全部临时大分片已删除，仅保留紧凑库存/回执。

九个所需缓存文件在五种子中的声明内容哈希全部相同，三个选定头各有五个不同哈希。共享缓存加 15 个选定模型的逻辑大小为 2402441115 字节（2.23744764 GiB），五份分别恢复则为 11993234535 字节。不能把逻辑哈希相同说成现有 COS 对象已物理去重；实际使用前仍须恢复并逐文件校验。

按原始生产者固定 tar 顺序和头部规则推导，数据与模型需读约 2.5625 GiB 完整分片；加入 60 份原始校验 trace 后约 2.71562195 GiB。五档案推导总长度均匹配可信回执。**单个偏移尚未通过实际字节检验，部分恢复器未获验收**；这些是成本计划，不是已完成恢复、当前金额报价或模型回放许可。

下一步是实现并审核有界部分恢复与原始头回放合同，核验实际 tar 头/内层文件哈希，并通过共享调度为合适 CPU 节点准入。保留原始输入、选定模型和全部 30 单元，正式全量实验仍仅交协作者执行。
