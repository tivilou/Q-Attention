# Q-RMEA R68：角色保护滤波的固定头诊断

预定标准没有通过，关闭本次固定头干预，既有的限定 L4 保持原范围，L5 尚未接受。角色保护滤波在五个量子头和五个实值头上均降低正类 Macro-F1；不能把受保护子空间的 Born 质量增加解释为任务收益。

方法为：从两个实体角色的平均密度矩阵取完整主特征子空间，构造其并集投影 P；非实体上下文协方差为 C，Q=I−P，F=(I+8QCQ)⁻¹，关系效果态改为 Fφ/‖Fφ‖。原 EPS、mask、值向量、decoder 和偏置保留。它是新的输入依赖干预；原电路可达性、制备成本及硬件优势未建立，也不继承旧方法的实证等级。

数值规则在观察结果前冻结：complex128 单位化、谱分解和求解，注意力转回 float32。主特征簇容差 1e−8，边界带 [0.5e−8,1.5e−8] 回退；合并子空间奇异值处于 [1e−7,1e−5] 回退。缺角色、无上下文、异常范数均回退原注意力，并对两种滤波共享相同资格规则。全部样本计入，无结果筛选。

比较原头、匹配数值恒等变换、有保护滤波、无保护滤波，以及固定的二次分数探针。实值头应用同一套干预，但使用各自已训练参数，因此只能观察通用滤波效果，不能隔离量子归因。

只使用原验证集 19,584 条，按与 R66 相同的固定 ID 哈希划分拟合和评估。二次分数探针仅在拟合区的原预测空类中学习 Y>0；固定 λ=.01、Newton/线搜索预算及 q>.5 触发。所有策略均以全部哈希评估样本为共同分母，计算 39 个正类的 Macro-F1。原分类头曾按整个验证集选择，故这些结果是开发诊断；五种子共用样本，不是独立确认。原测试集只回放已存的两个校验样本/头，没有新整集预测。

上述为共享样本上的种子—样本对，不能当独立样本数推显著性。计数类别部分重叠，不应相加视作净收益。每个头在 19,583 条样本上应用秩 2 保护，另 1 条无上下文回退；退化不是大规模数值回退造成的。归一化后受保护子空间的 Born 质量平均增加，但这一几何事实不保证实体 token 注意力或分类效用。当前结果否定本次干预收益，尚未单独定位损害由哪个中间环节造成。

执行前的 gpt-6.1-sol / medium 审核 scope=both、PASS_WITH_RISK，无必改项。单元、预检、诊断三个 CPU 调度任务各一次，终态且静止，精确恢复 owner/worker 临时绑定。40 个原始校验样本通过固定容差，十个完整验证集混淆矩阵与原报告完全一致；十个数值恒等对照的预测完全一致。复用原恢复输入，本轮无新增 COS 流量、GPU、容量采购或分类头重训。

关闭的是系数 8、当前投影和回退规则下的固定头干预，不以改系数、阈值、种子或训练预算重开，也不将该负结果推广为所有可训练滤波机制无效。

二次分数对照在五个量子头上的准确率均下降；Macro-F1 改善伴随假阳性增加，不是所有指标一起改善。它只改原预测空类，因而没有破坏原本正确的正类预测，这是策略限制的直接结果。几何统计覆盖完整验证集，效用表和转换计数覆盖 6,501 条哈希评估样本；两种汇总没有建立逐样本因果关联。
