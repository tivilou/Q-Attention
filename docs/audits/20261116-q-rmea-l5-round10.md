# L5第十轮：先界定关系抽取中的有效信息

本轮完成任务原文与实际输入代码核验，尚未选定新方法。原先限定范围的条件性L4保持；L5尚未达到。没有训练、模型前向、调度任务或新云资源。

## 新核验的事实

1. **实体信息不能整体当作噪声。** [Re-TACRED原文](https://arxiv.org/pdf/2104.08398v1)实际读取pp1–5，另核对p10附录C/Table7：PERSON:IDENTITY要求两实体指同一人，并覆盖代词共指。因此，“只保持实体类型就任意独立替换实体”不是全任务的标签不变性。原文报告的类型错误来自其原始TACRED样本审计，不能推为当前数据的剩余错误率。
2. **标签修订不等于类型字段已逐条修复。** 官方仓库固定提交`3e8a1269c0fc59caf64499b3c886b3e1e688aaf9`的[补丁函数](https://raw.githubusercontent.com/gstoica27/Re-TACRED/3e8a1269c0fc59caf64499b3c886b3e1e688aaf9/Re-TACRED/apply_patch.py)复制保留样本、改`relation`、丢弃补丁之外的ID；其余字段未由该函数重写。这不是当前类型存在错误或错误比例的实证结论。若引入类型筛选，还会改变当前模型允许输入，需要单独的公平比较。
3. **当前头部遮蔽不是输入层干预。** 实际缓存生产提交`0e25cf2309cfb1cc406e6b96521c2a29671a1048`的两份审计代码已逐字匹配原部署哈希。`marked_words`使用原句词和有序`@/#`实体标记，不使用标签、类型、metadata；全部词先进入冻结RoBERTa，再池化。剔除标记位置不抹去其上下文作用，剔除实体位置也没有保证其他词不携带实体信息。缓存的四个role字段是距离/跨度，不是类型或共指标注。
4. **泛化的去偏口号已有直接先例。** [CoRE](https://arxiv.org/pdf/2205.03784v1)pp1–5/p5eq2–3通过原始输入遮蔽、重新编码和输出相减处理实体偏差，系数在验证集选择。[VIB](https://arxiv.org/pdf/2506.11381v1)pp1–4/p3在PLM之前混合采样实体embedding，配合CE和KL训练。这些方法不能用来证明当前头的因果结构，也不能把通用反事实/信息瓶颈重新命名成新贡献。只看条件互信息表达式也不等于证明实体身份被消除；本轮没有否定VIB的实际KL目标或实证。

## 对实际Q-RMEA的含义

原Q-RMEA的40个独立binary effects产生token权重，另一路可训练value/decoder产生各类token效用，最后取logit最大类。它不是一个40结果的类别POVM。旧L4支持的固定模型权重排列干预只检验固定values下的局部对齐，不证明名称不变性、语义因果解释或全部收益来源。

对同一模型、相同对齐词位置的两份输入，令权重为alpha、alpha'，效用为u、u'，固定bias抵消。有已知的有限乘积恒等式：

`delta_z_r = sum_t (alpha'_rt-alpha_rt)*(u'_rt+u_rt)/2 + sum_t (alpha'_rt+alpha_rt)*(u'_rt-u_rt)/2`。

第一项核算权重路径，第二项核算效用路径。它只是描述性核算，不是新定理、因果中介识别或可达的模块交换。若词位置不对应，则该分解不适用，不能补造对应关系。态的global-phase-invariant变化可作额外观测，但不替代完整输出的正确性。

## 下一步唯一推荐：先建立可证伪的输入对照

探索性问题是：**原Q-RMEA能否在独立许可的保持关系改名下维持正确判断，同时响应真正改变关系/共指的上下文变化？变化分别来自state/权重和效用的哪条路径？**

这是一项机制诊断问题，尚不是支持充分的新方法或L5理论候选。下一步先形成固定的小型、仅训练集、模型输出盲态的语义对照清单；既有2361/1024开发结果不提供该清单的语义许可，不使用test或已暴露valid挑选有利病例。对照必须先通过关系定义、共指和角色检查，再允许重新编码。详细预算、字段和停止门槛见probe-design.json。注意力稳定而正确性丢失、两类输入都不响应，均不构成成功。

独立咨询和最终边界见independent-advice.json。该诊断不能接受L5，不能继承旧L4，不能单凭少量例子建立总体鲁棒性。新方法仍需实质近邻区别、非平凡理论以及同一贡献的独立实证。完整数据正式训练仍由合作者执行；停止的旧实验家族不恢复。
