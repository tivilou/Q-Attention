## 完整性与呈现边界

读取器从 `REPORT_COMPLETE.json` 验证报告文件，再绑定 trace 身份；每次切片校验原值文件大小、SHA256、shape、dtype。不提供原文件、归档或任意路径 HTTP 路由，不向公共静态目录复制原值。只监听 `127.0.0.1`，无 CORS；正式数据案例不会因页面读取得到新增训练权限。

界面从原句、token、指定实体及位置出发，逐层展示 embedding、打分、内容汇聚和分类结果。相邻阶段沿实际 trace 引用衔接。原值保持完整，页面显示有限切片和 7 位有效数字，可访问任意合法坐标。关系轴未保存可核实名称映射时只展示原索引，不猜测类别顺序。

实际训练案例的 loss 是单个选中样本的损失，梯度是整逻辑批次贡献；页面明确二者范围，不能由该单例独立推导整批梯度。checkpoint 重放只是诊断反向，不执行更新。样本之外的批次成员轨迹、完整逐步参数更新不在这个单例视图中。

本次验证新增 Q-ECPA 格式的阅读路径，不提升已有15参考配置、Q-EPVG等历史案例的完整性。合成案例不进入正式 Idea/Baseline 结果表，不能支撑正式效果、L1、量子归因或计算优势。

## 审查与运行

外部能力排序复用当日分类证据；最高兼容 Astra/max 路由超时，下一兼容 Opus5/max 返回503。按既定协议使用限定只读 subagent 审查，结论 `PASS_WITH_RISK`，无剩余阻断。发现并修复：整数尾零的错误省略、单案例 loss 与整批梯度易混淆、带认证回读的自动重定向风险。实际回读强制指定 CA、直连并拒绝重定向。后续聚焦测试发现 Python3.10 的空查询严格解析问题并修复；窄屏帮助浮层尺寸也补充了实测。
