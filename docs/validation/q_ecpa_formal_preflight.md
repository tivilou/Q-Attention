选定案例使用 sample-trace.v2，覆盖 train/valid/test 各前三条固定样本的 initial/best/final，加可学习任务的首个实际训练更新。八任务共 222 条记录、10,554 份完整数值 NPY；schema strict/complete、文件哈希、任意坐标、复数分量、embedding 加和及 attention×V 链路检查通过。量子任务有 28 条记录、1,428 份完整数值。原始记录保留在私有 run，未纳入 Git。
