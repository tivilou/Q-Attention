# 联合角色测量：开发快照

2026-11-02。当前状态：核心实现已完成独立源码审查，九项机制单元测试已编写但尚未运行。本分支用于保存开发工作，**不是正式实验交付**。没有新的任务性能或 L3 证据；旧版 ordered-entity 的负结果不变。

候选将词、主语、宾语分别映射到两比特纯态。每个关系拥有六比特测量态，计算

`p[r,t] = abs(<Phi[r] | psi[t] tensor subject tensor object>)**2`。

权重为 `(p+1e-6)*mask / sum_t((p+1e-6)*mask)`，沿用原有 value projection、关系 decoder 和 bias。主方法没有经典 logits 残差。代码先收缩实体，再收缩词，避免构造 `B*T*R*64` 张量；不对条件测量向量额外归一化。

固定电路：每个局部态从零态开始，依次逐线 RY、RZ，然后 CNOT。两比特输入使用 `0->1`。六比特关系态使用 `0->1,2->3,4->5`，再按顺序使用跨寄存器 `0->2,2->4,4->0`；wire0 是最高有效位。所有原始角度经 `pi*tanh`。

五个显式条件：

- `static`：直接复用原 RMEA quantum 类，保留精确初始化与行为。
- `joint`：三路输入和跨寄存器关系测量。
- `no_content`：用训练集每例实体池化后的等例均值替代实例实体，不接收标签，均值写入 checkpoint buffer。
- `separable`：仅删除跨寄存器 CNOT，验证乘积测量的退化边界。
- `classical_cp`：同一四维角度输入上的实数 rank2 三线性幅度，平方后走同一归一化和分类路径。

可分离条件满足 `p=c*q`。令 `Q=sum(q)`、有效词数为 `L`，则

`alpha = lambda*q/Q + (1-lambda)*uniform`，`lambda=cQ/(cQ+L*eps)`。

因此它的实体分支只能调整平滑项导致的均匀混合，不能任意改变未平滑的词分布。测试必须检查 joint 的实体交换、错配、均值替换能改变 `p/sum(p)`，不能仅凭 CE 变化宣称实体信息有效。

量子条件名义参数量 81,028，经典 CP 为 81,508。它们不是严格有效容量匹配：不重叠实体的反向角色通道使八个权重固定无效，同角色常量通道还与 bias 冗余；可分离条件在零平滑极限下的实体梯度消失。词态从旧版三比特变为两比特，不能把相对 static 的变化全部归因于联合交互。
