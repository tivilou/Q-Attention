It does not authorize a local full-data run. The current code base is `a7ef16280983b918652c291a9ec6d0f7cb6f8dcc` on the explicitly selected development server, in a new `codex/q-cfra-toy` worktree.

## Question and intervention

Can identity-neutralized, role/type/position-preserving views produce a stable useful **complete attention distribution**, through a shared mixed-state channel, fidelity contrasts and a two-qubit readout? This is a hypothesis. No L1/L2, novelty or quantum advantage is established by this screen.

Each subject/object token ID is replaced one-for-one by a role/type token derived only from training metadata. Length, positions, masks and ordered true pooling spans remain fixed. Unseen types use the role-specific unknown-type token. Overlapping entities are rejected. The frozen first encoder layer contextualizes the original, subject-neutralized and object-neutralized inputs. Q-CFRA replaces the second layer's score producer; the first layer and all base encoder parameters are frozen after the common per-seed baseline warm start. The classifier is updated identically in every condition, including Disabled. Neutral-token embeddings are initialized from the training type's entity-token embedding mean after warm start, without held-out fitting.

For view v, a shared affine projection produces a normalized complex two-amplitude state. A random-unitary channel E(rho) = sum_r softmax(w)_r U_r rho U_r^dagger uses U_r=Ry(pi/4) R_r(theta_r), for learned Rx, Ry and Rz angles. The common fixed basis rotation makes all three angles observable also in the diagonal control; an isolated final Rz would be erased by dephasing. This is a CPTP mixed-state channel by construction, not an arbitrary learned matrix. A fixed 1e-4 depolarization floor keeps qubit fidelity derivatives away from rank-deficient singularities. The qubit fidelity is F(rho,sigma)=Tr(rho sigma)+2 sqrt(det(rho) det(sigma)).

Let r, rs, ro be factual and counterfactual Bloch vectors, a=r-rs and b=r-ro. The real symmetrized covariance of observables a.sigma and b.sigma is c=a.b-(r.a)(r.b). The commutator norm 2|a cross b| is also recorded; diagonal control removes X/Y coherences before all geometry. F_s and F_o compare factual to each aligned counterfactual token. Fidelity is symmetrically clamped at 1e-5 before logit, avoiding infinite inputs.

Each query/key pair encodes [base q.k/sqrt(d), logit(F_s)/4, logit(F_o)/4, c] by pi*tanh, using Ry on each qubit followed by Rz on each qubit. The fixed fidelity scale is declared before results to avoid saturating near-one fidelity inputs. Two shared layers of local Rz/Ry/Rx and CZ produce a normalized four-amplitude state. z=<Z0+Z1+Z0Z1>/0.7; masked softmax yields the entire attention distribution. No additive residual is used. All three views use the same factual/counterfactual geometry and their own base query/key scores. Padding cannot receive attention or contribute to consistency loss.

The runtime compiles the shared learned gates into four-by-four operators before applying them to token pairs; Ry/Rz preparation uses its exact tensor-product amplitudes and phases. Capture still emits the initial, encoded, depth1 and depth2 states. A float64 gate-by-gate reference checks every captured state, logits, encoded-input gradients and all readout gradients. This is the same declared circuit with floating-point evaluation-order differences, not an additional method or an observed-result adaptation.

## Controls, losses and budgets

Explicit modes: disabled, quantum, classical_cosine, classical_rbf, diagonal, shuffled, entity_permuted. All non-disabled modes have identical nominal trainable parameter counts and optimizer update counts; all parameter tensors must receive finite nonzero gradients. Classical controls combine four affine outputs as x_j=z_j+z_4 (j=1..3), then apply a six-parameter real scale/shift plus tanh and normalize the three-vector, followed by cosine/RBF contrasts and a twelve-parameter real readout. This affine combination has an exactly redundant direction; nominal count matching does not establish equal effective capacity or a strict quantum-attribution comparison. The disabled adapter must equal the unmodified model exactly.

Shuffled rotates the *counterfactual token correspondence* by one valid position within each sentence. This is a fixed label-free permutation independent of minibatch partition; factual query/key scores and losses remain unchanged. Entity-permuted rotates the neutralization spans within each sentence while classifier pooling retains the true spans. It tests incorrect entity locations rather than a globally learnable subject/object renaming.

All conditions, including Disabled, optimize factual relation CE plus 0.05 prediction JS across the three views and 0.05 attention JS across the three views. This matches view supervision, classifier budget and extra passes. Consistency is a stated hypothesis about preserving entity types while removing identity, not a claim that arbitrary entity removal preserves the label. Gold is unavailable to view/attention construction. Controls and original factual input use identical samples, label map, split, initialization, batches and validation-only checkpoint selection.

Data screen: for each of the three official splits, choose at most 16 records per available relation, using SHA256(seed=20261020, split, original-index) order, eligible length <=64 and disjoint nonempty entity spans. Minimum one record per relation available under that fixed eligibility rule; unsupported classes are explicitly reported, never silently relabeled. Selection is outcome-blind (stratification uses ground-truth class only to declare evaluation population). Freeze the selected IDs before training. Vocabulary and type tokens use only selected training records; held-out unknown words map to UNK. This small population is not formal full-data evidence.

Model: dim32, heads4, two layers, FF64, dropout0. Warm start each independent seed for 8 epochs, Adam lr0.001 batch16. Then copy the same warm start into all seven conditions and train classifier plus optional plugin for 6 epochs, Adam lr0.001 batch16. Every best checkpoint uses validation Macro-F1 only. Evaluation follows the unchanged project metric function; test is inspected only after each training phase, never for selection. Seeds are fixed 13/29/53/71/97. Do not tune on screen results.

Memory revision before the utility screen: the initial real-data numerical canary was killed in a 1GiB-cgroup container after Disabled completed and before the first quantum epoch. Its partial artifacts remain untouched. The revised runtime uses physical microbatch2 for all screen conditions and evaluation, with the same logical batch16 and one Adam step per logical batch. CE and prediction-JS contributions are weighted by microbatch sample count, while attention-JS is weighted by valid-query count. First-update traces retain the first microbatch's detached observed sample with the whole logical batch's accumulated loss and gradient. A direct gradient/loss equivalence test allows floating-point tolerance; epoch-resume equality remains exact within this fixed route. Changed source/config identities require a fresh run root. This is a memory adaptation, not a change to seeds, selected data, objective, epoch count or optimizer update budget.

## Screen decisions

Promotion requires all numerical/trace/provenance gates, quantum-minus-disabled mean test Macro-F1 >=0.005, >=4/5 positive paired deltas, and paired-delta sample SD <=0.004 **or** <= disabled sample SD. This preserves the portfolio/state OR rule; the shorter recovery dossier omitted that alternative. No post-outcome gate change is allowed.

Kill: fatal numeric/trace/leakage defect, collapsed intervention/gradient, >=4/5 nonpositive paired deltas after the declared budget, or a utility-positive candidate whose shuffled mean is >= quantum mean-0.001. Collapse is measured at the actual first minibatch update: any quantum projection/channel/readout gradient-group norm <=1e-12, or maximum valid-query attention L1 movement from that sample's direct base softmax <=1e-8. These numerical floors are fixed before any screen. Other ordinary small nulls are inconclusive. Classical/diagonal parity constrains quantum attribution separately and does not demote ordinary utility.

## Observability and lifecycle

Before execution, freeze `configs/q_cfra_trace.json`. Select the first hash-ordered record of each split before results, at initial/best/final plus first actual training update. Each condition/seed emits sample-trace.v2 with complete detached NPY arrays for all three view IDs/embeddings, layer0 hidden, channel states/parameters/Bloch vectors, fidelity/covariance, circuit angles/states, attention logits/weights/value/context, layer1 output, pooled features, prediction, target used only after prediction, losses, named parameter gradients and actual update deltas. Disabled captures its own direct attention and three-view states but does not fabricate quantum states. Full numeric values and raw samples stay exchange-only/private; public artifacts contain counts, hashes and aggregate results only.

Runner is a sequential CPU toy process with an exclusive run lock. It writes atomic per-phase checkpoints and resumes only at completed epoch boundaries, checking source/config/subset plus explicit phase/seed/mode identities; screen phases also bind the shared warm-start state hash. A partial epoch is replayed deterministically from the preceding checkpoint. RNG and optimizer state are included. The synthetic canary interrupts every one of the seven conditions after epoch1, rejects a wrong-condition partial checkpoint, and compares final model, Adam and RNG state exactly with uninterrupted execution. Completion markers bind phase identity and summary/trace hashes and are created only after validation. No formal exporter or collaborator package is provided by this screen. Independent both-scope review precedes canary/screen execution.
